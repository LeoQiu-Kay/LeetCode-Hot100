# LeetCode Hot 100

LeetCode 热门 100 题学习仓库，分两部分：

- **`leetcode_hot100/`**：题面 + Python 题解（同一份 md，参考答案 + 直觉记忆点）
- **`leetcode_hot100_practice/`**：刷题骨架 `.py`（带题面 docstring、辅助类、自动生成的测试样板，方法体留空）

按算法套路分类整理，每道题解配生活类比帮助理解记忆。

## 目录结构

```
LeetCode-Hot100/
├── leetcode_hot100/              # 题面 + 参考题解（合并版 md）

│   ├── mid/                      # 中等 68 题
│   └── hard/                     # 困难 12 题

│   ├── simple/                   # 简单 20 题
│   ├── mid/                      # 中等 68 题
│   └── hard/                     # 困难 12 题
│

```

## 怎么用

**刷题**：打开 `leetcode_hot100_practice/{难度}/{题号-题名}.py`，把 `raise NotImplementedError` 替换成你的实现，直接 `python xxx.py` 跑测试
**查参考答案**：打开同名 `leetcode_hot100/{难度}/{题号-题名}.md`，题面在上、题解（含直觉类比 + 逐行注释代码）在下
**按算法套路浏览全部 100 题**：[`leetcode_hot100/README.md`](./leetcode_hot100/README.md) ← **推荐主入口**

## 参考题解格式

题面之后追加五个小节：

1. **直觉 / 记忆点** — 一段生活类比（书店配对、操场跑步、拳击擂台 等），用画面把算法套路记住
2. **思路** — 算法步骤的简短说明
3. **代码** — 完整可提交的 `class Solution`，**逐行中文注释**
4. **复杂度** — 时间 / 空间
5. **易错点** — 一两条边界、容易写错的地方

## 分类速查

按算法套路分组的完整 100 题列表见 [`leetcode_hot100/README.md`](./leetcode_hot100/README.md)，包含：

- 17 个算法套路分类（哈希、栈、链表、二叉树、图论、回溯、二分、双指针、滑窗、DP、贪心、堆、位运算 等）
- 横向对比·相似套路速查表（24 行套路 × 题目链）
- 三阶段学习路径建议（simple 母题 → mid 套路扩展 → hard 综合）
