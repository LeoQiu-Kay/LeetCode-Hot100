# LeetCode Hot 100

LeetCode 热门 100 题的**题面 + Python 题解**合并版学习仓库。题面和题解在同一份 md，按算法套路分类，每道题配生活类比帮助理解记忆。

## 目录结构

```
LeetCode-Hot100/
├── leetcode_hot100/              # 题面 + 题解（合并版）
│   ├── README.md                 # 全 100 题分类索引 ← 主入口
│   ├── simple/                   # 简单 20 题
│   ├── mid/                      # 中等 68 题
│   └── hard/                     # 困难 12 题
│
└── README.md                     # 本文件
```

每道题的 md 由两部分组成：

1. **上半**：leetcode.cn 原始题面（描述 / 示例 / 提示）
2. **下半**（`---` 分隔）：Python 题解，五段式

## 怎么用

**打开任意一题**：`leetcode_hot100/{难度}/{题号-题名}.md`，从题面读到题解一站式完成
**按算法套路浏览全部 100 题**：打开 [`leetcode_hot100/README.md`](./leetcode_hot100/README.md) ← **推荐主入口**

## 题解格式

题面之后追加五个小节：

1. **直觉 / 记忆点** — 一段生活类比（书店配对、操场跑步、拳击擂台 等），用画面把算法套路记住
2. **思路** — 算法步骤的简短说明
3. **代码** — 完整可提交的 `class Solution`，**逐行中文注释**
4. **复杂度** — 时间 / 空间
5. **易错点** — 一两条边界、容易写错的地方

## 分类速查

按算法套路分组的完整 100 题列表见 [`leetcode_hot100/README.md`](./leetcode_hot100/README.md)，包含：

- 17 个算法套路分类（哈希、栈、链表、二叉树、图论、回溯、二分、双指针、滑窗、DP、贪心、堆、位运算 等）
- 横向对比·相似套路速查表（24 行套路 × 题目链）
- 三阶段学习路径建议（simple 母题 → mid 套路扩展 → hard 综合）

## 题面来源

题面均通过 LeetCode 中文站 GraphQL 接口（`https://leetcode.cn/graphql/`）的 `translatedContent` 字段抓取，**非二次创作**，仅作个人学习归档使用。
