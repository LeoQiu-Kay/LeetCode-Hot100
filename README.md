# LeetCode Hot 100

LeetCode 热门 100 题的**题面归档** + **Python 题解**学习仓库。题目按算法套路分类整理，每道题解配生活类比帮助理解记忆。

## 目录结构

```
LeetCode-Hot100/
├── leetcode_hot100/              # 原始题面归档（中文版，自 leetcode.cn 抓取）
│   ├── simple/                   # 简单题 20
│   ├── mid/                      # 中等题 68
│   └── hard/                     # 困难题 12
│
├── hot100_solutions/             # Python 题解
│   ├── README.md                 # 全 100 题分类索引 ← 主入口
│   ├── simple/                   # 简单 20 / 20
│   ├── mid/                      # 中等 68 / 68
│   └── hard/                     # 困难 12 / 12
│
└── README.md                     # 本文件
```

## 怎么用

**想找一道题的题面**：`leetcode_hot100/{难度}/{题号-题名}.md`
**想找一道题的题解**：`hot100_solutions/{难度}/{题号-题名}.md`
**按算法套路浏览全部 100 题**：打开 [`hot100_solutions/README.md`](./hot100_solutions/README.md) ← **推荐主入口**

## 题解格式

每份 Python 题解包含五个小节：

1. **直觉 / 记忆点** — 一段生活类比（书店配对、操场跑步、拳击擂台 等），用画面把算法套路记住
2. **思路** — 算法步骤的简短说明
3. **代码** — 完整可提交的 `class Solution`，**逐行中文注释**
4. **复杂度** — 时间 / 空间
5. **易错点** — 一两条边界、容易写错的地方

## 分类速查

按算法套路分组的完整 100 题列表见 [`hot100_solutions/README.md`](./hot100_solutions/README.md)，包含：

- 17 个算法套路分类（哈希、栈、链表、二叉树、图论、回溯、二分、双指针、滑窗、DP、贪心、堆、位运算 等）
- 横向对比·相似套路速查表（24 行套路 × 题目链）
- 三阶段学习路径建议（simple 母题 → mid 套路扩展 → hard 综合）

## 题面来源
