# 322. 零钱兑换

- LeetCode 题号：322
- 难度：中等
- 英文标题：Coin Change
- 链接：https://leetcode.cn/problems/coin-change/

---

给你一个整数数组 `coins` ，表示不同面额的硬币；以及一个整数 `amount` ，表示总金额。

计算并返回可以凑成总金额所需的 **最少的硬币个数** 。如果没有任何一种硬币组合能组成总金额，返回 `-1` 。

你可以认为每种硬币的数量是无限的。



**示例 1：**

```
输入：coins = `[1, 2, 5]`, amount = `11`
输出：`3`
解释：11 = 5 + 5 + 1
```

**示例 2：**

```
输入：coins = `[2]`, amount = `3`
输出：-1
```

**示例 3：**

```
输入：coins = [1], amount = 0
输出：0
```



**提示：**

- `1 <= coins.length <= 12`

- `1 <= coins[i] <= 2³¹ - 1`

- `0 <= amount <= 10⁴`

---

## 直觉 / 记忆点

> 完全背包变种：硬币无限用，凑出 amount 的**最少**硬币数。dp[i] = 凑成 i 的最少硬币数；转移：`dp[i] = min(dp[i - coin] + 1) for coin in coins`。凑不出就保持初始的"无穷大"。

## 思路

dp 长度 amount + 1。初始 amount + 1（表示"不可能"），dp[0] = 0。

## 代码

```python
class Solution:
    def coinChange(self, coins: list[int], amount: int) -> int:
        # 初始全部置为"不可能达到"的大值（amount + 1 是稳妥上界，因为任何方案不会超过 amount 个硬币）
        INF = amount + 1
        dp = [INF] * (amount + 1)
        dp[0] = 0   # 凑 0 元用 0 枚
        for i in range(1, amount + 1):
            for coin in coins:
                # 当前金额 i 大于等于硬币面值，才能用这枚硬币
                if i >= coin:
                    # 用一枚 coin 的方案数 = dp[i - coin] + 1
                    dp[i] = min(dp[i], dp[i - coin] + 1)
        # 如果 dp[amount] 还是 INF 说明凑不出来
        return dp[amount] if dp[amount] != INF else -1
```

## 复杂度

- 时间：O(amount × len(coins))
- 空间：O(amount)

## 易错点

- 初始值用 INF（不能用 0），dp[0] = 0 是唯一已知的"凑成 0"的情况。
- 最后要判 `dp[amount] != INF`，无解时返回 -1。
