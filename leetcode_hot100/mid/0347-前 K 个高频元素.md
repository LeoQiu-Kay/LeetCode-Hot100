# 347. 前 K 个高频元素

- LeetCode 题号：347
- 难度：中等
- 英文标题：Top K Frequent Elements
- 链接：https://leetcode.cn/problems/top-k-frequent-elements/

---

给你一个整数数组 `nums` 和一个整数 `k` ，请你返回其中出现频率前 `k` 高的元素。你可以按 **任意顺序** 返回答案。



**示例 1：**

**输入：** nums = [1,1,1,2,2,3], k = 2

**输出：** [1,2]

**示例 2：**

**输入：** nums = [1], k = 1

**输出：** [1]

**示例 3：**

**输入：** nums = [1,2,1,2,1,2,3,1,3,2], k = 2

**输出：** [1,2]



**提示：**

- `1 <= nums.length <= 10⁵`

- `-10⁴ <= nums[i] <= 10⁴`

- `k` 的取值范围是 `[1, 数组中不相同的元素的个数]`

- 题目数据保证答案唯一，换句话说，数组中前 `k` 个高频元素的集合是唯一的



**进阶：** 你所设计算法的时间复杂度 **必须** 优于 `O(n log n)` ，其中 `n`* *是数组大小。

---

## 直觉 / 记忆点

> 哈希计数 + 小顶堆维护"k 个最高频"。堆里存 (频次, 数值)，频次小的在顶；超过 k 就弹掉最小。最后把堆中所有数值收集就是答案。

## 思路

`Counter` 统计频次，遍历 (val, freq)：push (freq, val)，size > k 就 pop。

## 代码

```python
from collections import Counter
import heapq

class Solution:
    def topKFrequent(self, nums: list[int], k: int) -> list[int]:
        # 统计每个数字的出现次数
        cnt = Counter(nums)
        # 小顶堆，元素是 (频次, 数字)；按频次比较，频次小的在堆顶
        heap: list[tuple[int, int]] = []
        for v, f in cnt.items():
            heapq.heappush(heap, (f, v))
            # 堆大小超过 k：弹掉频次最小的
            if len(heap) > k:
                heapq.heappop(heap)
        # 堆里剩下的 k 个就是前 k 高频的数字
        return [v for _, v in heap]
```

## 复杂度

- 时间：O(n log k)
- 空间：O(n)

## 易错点

- 堆元素的 tuple 首位**必须**是 freq（按它比较），val 放第二位只是占位。
- 题目允许任意顺序输出，不需要再按频次排序。
