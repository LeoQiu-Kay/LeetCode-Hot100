# 5. 最长回文子串

- LeetCode 题号：5
- 难度：中等
- 英文标题：Longest Palindromic Substring
- 链接：https://leetcode.cn/problems/longest-palindromic-substring/

---

给你一个字符串 `s`，找到 `s` 中最长的 回文 子串。



**示例 1：**

```
输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案。
```

**示例 2：**

```
输入：s = "cbbd"
输出："bb"
```



**提示：**

- `1 <= s.length <= 1000`

- `s` 仅由数字和英文字母组成

---

## 直觉 / 记忆点

> 回文子串以**某个中心**为轴左右对称。枚举每个可能的中心（n 个奇数中心 + n-1 个偶数中心 = 2n-1 个），从中心向两边扩展找最长。比 DP 表更简单。

## 思路

子函数 `expand(l, r)`：从 (l, r) 向两边扩展，返回最长回文。对每个 i 调用奇数中心 (i, i) 和偶数中心 (i, i+1)。

## 代码

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        def expand(l: int, r: int) -> tuple[int, int]:
            # 从 (l, r) 向两侧扩展，返回最长回文的 (起点, 终点+1)
            while l >= 0 and r < len(s) and s[l] == s[r]:
                l -= 1
                r += 1
            # 退出时 s[l]、s[r] 不匹配或越界，有效范围是 [l+1, r-1]
            return l + 1, r
        best = (0, 1)   # (起点, 终点+1)
        for i in range(len(s)):
            # 奇数长度回文（以 i 为正中央）
            a, b = expand(i, i)
            if b - a > best[1] - best[0]:
                best = (a, b)
            # 偶数长度回文（以 i, i+1 为两中央）
            a, b = expand(i, i + 1)
            if b - a > best[1] - best[0]:
                best = (a, b)
        return s[best[0]:best[1]]
```

## 复杂度

- 时间：O(n²)
- 空间：O(1)

## 易错点

- 必须**两种中心都试**：长度为奇数（中心 1 字符）和偶数（中心 2 字符）。
- 退出 while 时 l 和 r 都已"超出一格"，有效范围是 `[l+1, r-1]`，切片用 `s[l+1:r]`。
