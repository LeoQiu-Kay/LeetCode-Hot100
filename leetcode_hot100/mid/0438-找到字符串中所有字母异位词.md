# 438. 找到字符串中所有字母异位词

- LeetCode 题号：438
- 难度：中等
- 英文标题：Find All Anagrams in a String
- 链接：https://leetcode.cn/problems/find-all-anagrams-in-a-string/

---

给定两个字符串 `s` 和 `p`，找到 `s`** **中所有 `p`** **的 **异位词 **的子串，返回这些子串的起始索引。不考虑答案输出的顺序。



**示例 1:**

```
输入: s = "cbaebabacd", p = "abc"
输出: [0,6]
解释:
起始索引等于 0 的子串是 "cba", 它是 "abc" 的异位词。
起始索引等于 6 的子串是 "bac", 它是 "abc" 的异位词。
```

** 示例 2:**

```
输入: s = "abab", p = "ab"
输出: [0,1,2]
解释:
起始索引等于 0 的子串是 "ab", 它是 "ab" 的异位词。
起始索引等于 1 的子串是 "ba", 它是 "ab" 的异位词。
起始索引等于 2 的子串是 "ab", 它是 "ab" 的异位词。
```



**提示:**

- `1 <= s.length, p.length <= 3 * 10⁴`

- `s` 和 `p` 仅包含小写字母

---

## 直觉 / 记忆点

> **定长**滑动窗口（窗口 = len(p)）。维护窗口内字符计数与 p 的字符计数是否相等。每滑一格：右进一个字符（+1）、左出一个字符（-1）。可以用两个数组直接比较，也可以维护"还差几种字符"的计数加速。

## 思路

26 长度计数数组 cnt_p、cnt_w；先初始化首个窗口；然后滑动比较。

## 代码

```python
class Solution:
    def findAnagrams(self, s: str, p: str) -> list[int]:
        ns, np = len(s), len(p)
        if ns < np:
            return []
        # 26 长度的字符计数数组（小写字母）
        cnt_p = [0] * 26
        cnt_w = [0] * 26
        for c in p:
            cnt_p[ord(c) - ord('a')] += 1
        ans: list[int] = []
        for i, c in enumerate(s):
            # 右端字符进窗口
            cnt_w[ord(c) - ord('a')] += 1
            # 窗口长度超过 p 时把左端字符踢出
            if i >= np:
                cnt_w[ord(s[i - np]) - ord('a')] -= 1
            # 窗口长度恰为 np 且与 p 的计数完全相同：找到一个异位词
            if i >= np - 1 and cnt_w == cnt_p:
                # 起点是 i - np + 1
                ans.append(i - np + 1)
        return ans
```

## 复杂度

- 时间：O(N · Σ)，N = len(s)，Σ = 26（数组比较常数）
- 空间：O(1)

## 易错点

- 窗口起点 = `i - np + 1`，别忘了 +1。
- 长度判断：`i >= np` 时才需要踢左端字符；`i >= np - 1` 时才开始比较（窗口刚装满）。
