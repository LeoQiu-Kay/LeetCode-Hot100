# 240. 搜索二维矩阵 II

- LeetCode 题号：240
- 难度：中等
- 英文标题：Search a 2D Matrix II
- 链接：https://leetcode.cn/problems/search-a-2d-matrix-ii/

编写一个高效的算法来搜索 `*m* x *n*` 矩阵 `matrix` 中的一个目标值 `target` 。该矩阵具有以下特性：

- 每行的元素从左到右升序排列。

- 每列的元素从上到下升序排列。



**示例 1：**

![](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2020/11/25/searchgrid2.jpg)

```
输入：matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]], target = 5
输出：true
```

**示例 2：**

```
输入：matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]], target = 20
输出：false
```



**提示：**

- `m == matrix.length`

- `n == matrix[i].length`

- `1 <= n, m <= 300`

- `-10⁹ <= matrix[i][j] <= 10⁹`

- 每行的所有元素从左到右升序排列

- 每列的所有元素从上到下升序排列

- `-10⁹ <= target <= 10⁹`

---

## 直觉 / 记忆点

> 矩阵性质：每行升序、每列升序（但不像 74 那样整体串成一维）。从**右上角**开始走 Z 字：
> - 当前值 > target → 往左（这一列被排除）
> - 当前值 < target → 往下（这一行被排除）
> - 等于 → 找到

## 思路

i = 0, j = n - 1（右上角）；while 不出界。

## 代码

```python
class Solution:
    def searchMatrix(self, matrix: list[list[int]], target: int) -> bool:
        if not matrix:
            return False
        m, n = len(matrix), len(matrix[0])
        # 从右上角开始
        i, j = 0, n - 1
        while i < m and j >= 0:
            if matrix[i][j] == target:
                return True
            elif matrix[i][j] > target:
                # 当前值偏大 → 排除当前列（整列都比 target 大）
                j -= 1
            else:
                # 当前值偏小 → 排除当前行（整行都比 target 小）
                i += 1
        return False
```

## 复杂度

- 时间：O(m + n)
- 空间：O(1)

## 易错点

- 起点选**右上角**或左下角（不能选左上 / 右下，那样一步排除不了整行 / 整列）。
- 走法本质：每一步要么排除一整行、要么排除一整列。
