# 208. 实现 Trie（前缀树）

- LeetCode 题号：208
- 难度：中等
- 英文标题：Implement Trie (Prefix Tree)
- 链接：https://leetcode.cn/problems/implement-trie-prefix-tree/

---

**[Trie](https://baike.baidu.com/item/字典树/9825209?fr=aladdin)**（发音类似 "try"）或者说 **前缀树** 是一种树形数据结构，用于高效地存储和检索字符串数据集中的键。这一数据结构有相当多的应用情景，例如自动补全和拼写检查。

请你实现 Trie 类：

- `Trie()` 初始化前缀树对象。

- `void insert(String word)` 向前缀树中插入字符串 `word` 。

- `boolean search(String word)` 如果字符串 `word` 在前缀树中，返回 `true`（即，在检索之前已经插入）；否则，返回 `false` 。

- `boolean startsWith(String prefix)` 如果之前已经插入的字符串 `word` 的前缀之一为 `prefix` ，返回 `true` ；否则，返回 `false` 。



**示例：**

```
输入
["Trie", "insert", "search", "search", "startsWith", "insert", "search"]
[[], ["apple"], ["apple"], ["app"], ["app"], ["app"], ["app"]]
输出
[null, null, true, false, true, null, true]

解释
Trie trie = new Trie();
trie.insert("apple");
trie.search("apple");   // 返回 True
trie.search("app");     // 返回 False
trie.startsWith("app"); // 返回 True
trie.insert("app");
trie.search("app");     // 返回 True
```



**提示：**

- `1 <= word.length, prefix.length <= 2000`

- `word` 和 `prefix` 仅由小写英文字母组成

- `insert`、`search` 和 `startsWith` 调用次数 **总计** 不超过 `3 * 10⁴` 次

---

## 直觉 / 记忆点

> 字符串集合的"路径树"：从根开始，**每个字符是一条边**。每个节点存最多 26 个孩子的引用，外加一个 `isEnd` 标记表示"是否有某单词在此结束"。三个操作的本质都是"沿字符走链"。

## 思路

`TrieNode` 用 dict（更通用）或 26 长度数组。三个操作共享"从根沿字符走"的子例程，差别在缺孩子时的处理。

## 代码

```python
class TrieNode:
    def __init__(self):
        # 用 dict 比 26-数组更通用（支持任意字符），代码也更简洁
        self.children: dict[str, "TrieNode"] = {}
        # 是否有单词在当前节点结束
        self.is_end = False

class Trie:
    def __init__(self):
        # 根节点不存字符，只起"起点"作用
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        node = self.root
        for c in word:
            # 没有这条边就开一个新孩子
            if c not in node.children:
                node.children[c] = TrieNode()
            # 沿这条边走下去
            node = node.children[c]
        # 走到末尾打标记
        node.is_end = True

    def _walk(self, word: str) -> "TrieNode | None":
        # 沿 word 各字符走，返回最终落点节点；中途断链则返回 None
        node = self.root
        for c in word:
            if c not in node.children:
                return None
            node = node.children[c]
        return node

    def search(self, word: str) -> bool:
        # 必须走到底 且 该节点标记了 isEnd
        node = self._walk(word)
        return node is not None and node.is_end

    def startsWith(self, prefix: str) -> bool:
        # 只要能走到底就行，不要求 isEnd
        return self._walk(prefix) is not None
```

## 复杂度

- 时间：每个操作 O(L)，L 是单词长度
- 空间：O(总字符数)

## 易错点

- `search` 和 `startsWith` 区别在于**是否要求 isEnd**：search 必须 isEnd，startsWith 只需要走得到。
- 根节点本身**不**存字符，只是入口。
