# 516. 最长回文子序列

- LeetCode 题号：516
- 难度：中等
- 英文标题：Longest Palindromic Subsequence
- 链接：https://leetcode.cn/problems/longest-palindromic-subsequence/

> 📌 **不在 Hot 100 题单**，作为区间 DP 的经典母题补充进来（与 5 最长回文子串姊妹）。

---

给你一个字符串 `s` ，找出其中最长的回文子序列，并返回该序列的长度。

子序列定义为：不改变剩余字符顺序的情况下，删除某些字符或者不删除任何字符形成的一个序列。

**示例 1：**

```
输入：s = "bbbab"
输出：4
解释：一个可能的最长回文子序列为 "bbbb" 。
```

**示例 2：**

```
输入：s = "cbbd"
输出：2
解释：一个可能的最长回文子序列为 "bb" 。
```

**提示：**

- `1 <= s.length <= 1000`
- `s` 仅由小写英文字母组成

---

## 直觉 / 记忆点

> `dp[i][j]` = 子串 `s[i..j]`（闭区间）的最长回文**子序列**长度。
> - **两端相等**：把它俩同时纳入 → `dp[i][j] = dp[i+1][j-1] + 2`
> - **两端不等**：丢掉左端 或 丢掉右端，取最长 → `dp[i][j] = max(dp[i+1][j], dp[i][j-1])`

## 思路

区间 DP。

**状态定义**：`dp[i][j]` = `s[i..j]` 的最长回文子序列长度（闭区间）。

**递推**：

- `s[i] == s[j]` → `dp[i][j] = dp[i+1][j-1] + 2`
- `s[i] != s[j]` → `dp[i][j] = max(dp[i+1][j], dp[i][j-1])`

**边界**：`dp[i][i] = 1`（单字符天然回文）。

**填表顺序**：和 5 题一样——`dp[i][j]` 依赖 `dp[i+1][...]`，外层 i 必须**反向遍历**。

**答案**：`dp[0][n-1]`。

## 代码

```python
class Solution:
    def longestPalindromeSubseq(self, s: str) -> int:
        n = len(s)
        # dp[i][j] = s[i..j] 的最长回文子序列长度
        dp = [[0] * n for _ in range(n)]

        # 单字符是长度 1 的回文
        for i in range(n):
            dp[i][i] = 1

        # 外层 i 反向遍历，保证 dp[i+1][...] 先就绪
        for i in reversed(range(n)):
            for j in range(i + 1, n):
                if s[i] == s[j]:
                    # 两端相等：内层 +2；i+1 > j-1 时（即 j == i+1），dp[i+1][j-1] = dp[i+1][i] = 0，加 2 得 2，正确
                    dp[i][j] = dp[i + 1][j - 1] + 2
                else:
                    # 两端不等：丢左端 或 丢右端
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])

        return dp[0][n - 1]
```

## 复杂度

- 时间：O(n²)
- 空间：O(n²)（可压成 O(n) 滚动）

## 易错点

- **求的是子序列长度**，不是子串长度。区别：子序列**不要求连续**（可以删除中间字符），子串要求连续。
- **填表顺序**：外层 i 反向、内层 j 正向。如果按 i 正向填，会用到还没算的 `dp[i+1]`。
- **长度 2 单独看**：`j == i + 1` 时 `dp[i+1][j-1] = dp[i+1][i]`，由于 i+1 > i，这是个"非法区间" → 默认 0；`dp[i][j] = 0 + 2 = 2`，恰好正确。所以不用单独写 `j - i == 1` 分支。
- **答案是 `dp[0][n-1]`**（整个字符串），不是 `max(dp)`。
