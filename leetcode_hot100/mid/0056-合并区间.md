# 56. 合并区间

- LeetCode 题号：56
- 难度：中等
- 英文标题：Merge Intervals
- 链接：https://leetcode.cn/problems/merge-intervals/

---

以数组 `intervals` 表示若干个区间的集合，其中单个区间为 `intervals[i] = [starti, endi]` 。请你合并所有重叠的区间，并返回 *一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间* 。



**示例 1：**

```
输入：intervals = [[1,3],[2,6],[8,10],[15,18]]
输出：[[1,6],[8,10],[15,18]]
解释：区间 [1,3] 和 [2,6] 重叠, 将它们合并为 [1,6].
```

**示例 2：**

```
输入：intervals = [[1,4],[4,5]]
输出：[[1,5]]
解释：区间 [1,4] 和 [4,5] 可被视为重叠区间。
```

**示例 3：**

```
输入：intervals = [[4,7],[1,4]]
输出：[[1,7]]
解释：区间 [1,4] 和 [4,7] 可被视为重叠区间。
```



**提示：**

- `1 <= intervals.length <= 10⁴`

- `intervals[i].length == 2`

- `0 <= starti <= endi <= 10⁴`

---

## 直觉 / 记忆点

> 按**起点**排序后，相邻区间要合并只看一件事：当前区间的起点是否 ≤ 上一个合并后区间的终点。是 → 把终点扩展到 max；否 → 当前区间独立成段。

## 思路

sort + 一次扫。

## 代码

```python
class Solution:
    def merge(self, intervals: list[list[int]]) -> list[list[int]]:
        # 按起点升序排序，让"重叠"只可能发生在相邻两个之间
        intervals.sort(key=lambda x: x[0])
        res: list[list[int]] = []
        for s, e in intervals:
            # 当前区间和最后合并段相交（注意是 res[-1][1] >= s，包含端点相等）
            if res and res[-1][1] >= s:
                # 合并：把终点扩到两者更大
                res[-1][1] = max(res[-1][1], e)
            else:
                # 不相交，开新段（拷贝一份，避免后续 .max 改原 intervals 元素）
                res.append([s, e])
        return res
```

## 复杂度

- 时间：O(n log n)
- 空间：O(n)（输出）

## 易错点

- 排序必须**按起点**升序。
- 判重叠用 `>=`（端点相等也算重叠，如 [1,3] 和 [3,5] 应合并为 [1,5]）。
