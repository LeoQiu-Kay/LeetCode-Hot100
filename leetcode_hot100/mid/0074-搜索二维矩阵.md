# 74. 搜索二维矩阵

- LeetCode 题号：74
- 难度：中等
- 英文标题：Search a 2D Matrix
- 链接：https://leetcode.cn/problems/search-a-2d-matrix/

---

给你一个满足下述两条属性的 `m x n` 整数矩阵：

- 每行中的整数从左到右按非严格递增顺序排列。

- 每行的第一个整数大于前一行的最后一个整数。

给你一个整数 `target` ，如果 `target` 在矩阵中，返回 `true` ；否则，返回 `false` 。



**示例 1：**

![](https://assets.leetcode.com/uploads/2020/10/05/mat.jpg)

```
输入：matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 3
输出：true
```

**示例 2：**

![](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2020/11/25/mat2.jpg)

```
输入：matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 13
输出：false
```



**提示：**

- `m == matrix.length`

- `n == matrix[i].length`

- `1 <= m, n <= 100`

- `-10⁴ <= matrix[i][j], target <= 10⁴`

---

## 直觉 / 记忆点

> 题目保证"每行升序、下一行首 > 上一行末"——整个矩阵展开就是一个**升序数组**。把 `[i][j]` 映射为下标 `i*n + j`、做标准二分即可。

## 思路

二分整个矩阵当作一维数组：lo = 0, hi = m * n - 1。

## 代码

```python
class Solution:
    def searchMatrix(self, matrix: list[list[int]], target: int) -> bool:
        if not matrix or not matrix[0]:
            return False
        m, n = len(matrix), len(matrix[0])
        lo, hi = 0, m * n - 1
        # 闭区间二分（lo <= hi 时继续）
        while lo <= hi:
            mid = (lo + hi) // 2
            # 把一维下标 mid 映射回二维坐标
            x = matrix[mid // n][mid % n]
            if x == target:
                return True
            elif x < target:
                lo = mid + 1
            else:
                hi = mid - 1
        return False
```

## 复杂度

- 时间：O(log(m × n))
- 空间：O(1)

## 易错点

- 行号是 `mid // n`，列号是 `mid % n`（n 是**列数**，不是行数）。
- 题目对"下一行首 > 上一行末"的保证是关键，若只保证"每行升序"则要用 240 那种 Z 字搜索。
