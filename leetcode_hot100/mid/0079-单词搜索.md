# 79. 单词搜索

- LeetCode 题号：79
- 难度：中等
- 英文标题：Word Search
- 链接：https://leetcode.cn/problems/word-search/

---

给定一个 `m x n` 二维字符网格 `board` 和一个字符串单词 `word` 。如果 `word` 存在于网格中，返回 `true` ；否则，返回 `false` 。

单词必须按照字母顺序，通过相邻的单元格内的字母构成，其中“相邻”单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母不允许被重复使用。



**示例 1：**

![](https://assets.leetcode.com/uploads/2020/11/04/word2.jpg)

```
输入：board = [['A','B','C','E'],['S','F','C','S'],['A','D','E','E']], word = "ABCCED"
输出：true
```

**示例 2：**

![](https://assets.leetcode.com/uploads/2020/11/04/word-1.jpg)

```
输入：board = [['A','B','C','E'],['S','F','C','S'],['A','D','E','E']], word = "SEE"
输出：true
```

**示例 3：**

![](https://assets.leetcode.com/uploads/2020/10/15/word3.jpg)

```
输入：board = [['A','B','C','E'],['S','F','C','S'],['A','D','E','E']], word = "ABCB"
输出：false
```



**提示：**

- `m == board.length`

- `n = board[i].length`

- `1 <= m, n <= 6`

- `1 <= word.length <= 15`

- `board` 和 `word` 仅由大小写英文字母组成



**进阶：** 你可以使用搜索剪枝的技术来优化解决方案，使其在 `board` 更大的情况下可以更快解决问题？

---

## 直觉 / 记忆点

> 网格 DFS + 回溯。从每个格子尝试作为起点，沿四方向走，看能不能拼出单词。**关键技巧**：把走过的格子原地改成 `#`（visited 标记），递归返回后**恢复**为原字符（回溯撤销）。

## 思路

DFS(i, j, k)：当前要匹配 word[k]。匹配则把格子改 #、四方向递归、恢复字符。

## 代码

```python
class Solution:
    def exist(self, board: list[list[str]], word: str) -> bool:
        m, n = len(board), len(board[0])
        def dfs(i: int, j: int, k: int) -> bool:
            # 整个单词匹配完，成功
            if k == len(word):
                return True
            # 越界或字符不匹配
            if not (0 <= i < m and 0 <= j < n) or board[i][j] != word[k]:
                return False
            # 原地改成 '#'（visited 标记），防止后续递归走回这个格子
            tmp = board[i][j]
            board[i][j] = '#'
            # 四方向递归找下一个字符
            found = (dfs(i + 1, j, k + 1) or dfs(i - 1, j, k + 1)
                     or dfs(i, j + 1, k + 1) or dfs(i, j - 1, k + 1))
            # 回溯：恢复原字符，让别的搜索路径还能用这个格子
            board[i][j] = tmp
            return found
        # 尝试每个格子作为起点
        for i in range(m):
            for j in range(n):
                if dfs(i, j, 0):
                    return True
        return False
```

## 复杂度

- 时间：O(m × n × 4ᴸ)，L 是单词长度
- 空间：O(L)（递归栈）

## 易错点

- 回溯**必须**恢复字符，否则一条失败的搜索路径会污染后续别的搜索。
- 不需要单独的 visited 数组，原地改 `#` 然后恢复更省空间。
