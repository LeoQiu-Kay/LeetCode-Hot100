# 105. 从前序与中序遍历序列构造二叉树

- LeetCode 题号：105
- 难度：中等
- 英文标题：Construct Binary Tree from Preorder and Inorder Traversal
- 链接：https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/

---

给定两个整数数组 `preorder` 和 `inorder` ，其中 `preorder` 是二叉树的**先序遍历**， `inorder` 是同一棵树的**中序遍历**，请构造二叉树并返回其根节点。



**示例 1:**

![](https://assets.leetcode.com/uploads/2021/02/19/tree.jpg)

```
输入: preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
输出: [3,9,20,null,null,15,7]
```

**示例 2:**

```
输入: preorder = [-1], inorder = [-1]
输出: [-1]
```



**提示:**

- `1 <= preorder.length <= 3000`

- `inorder.length == preorder.length`

- `-3000 <= preorder[i], inorder[i] <= 3000`

- `preorder` 和 `inorder` 均 **无重复** 元素

- `inorder` 均出现在 `preorder`

- `preorder` **保证** 为二叉树的前序遍历序列

- `inorder` **保证** 为二叉树的中序遍历序列

---

## 直觉 / 记忆点

> 前序的**第一个元素**永远是当前子树的根；中序里**根的左边**是左子树、**根的右边**是右子树。所以每次：preorder 头部取根 → 用根的值在中序里切分 → 左右两半递归构造。

## 思路

预处理一个 `中序值 → 下标` 的哈希表，免去每次 O(n) 查找。前序用一个全局指针推进，中序用 [l, r] 区间界定子树范围。

## 代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def buildTree(self, preorder: list[int], inorder: list[int]) -> TreeNode | None:
        # 中序值 → 下标，方便 O(1) 找到根在中序里的位置
        idx_map = {v: i for i, v in enumerate(inorder)}
        # 用 list 包一下 pre_i，方便闭包内修改（也可以用 nonlocal 配合普通变量）
        pre_i = [0]
        def build(l: int, r: int) -> TreeNode | None:
            # 中序区间为空，对应空子树
            if l > r:
                return None
            # 当前子树的根：前序的下一个元素
            val = preorder[pre_i[0]]
            pre_i[0] += 1
            root = TreeNode(val)
            # 找到根在中序里的位置，划分左右
            mid = idx_map[val]
            # 注意：必须**先递归左子树**，再递归右子树
            # 因为 preorder 是"根→左→右"，左子树的所有节点会先在前序里出现
            root.left = build(l, mid - 1)
            root.right = build(mid + 1, r)
            return root
        return build(0, len(inorder) - 1)
```

## 复杂度

- 时间：O(n)
- 空间：O(n)（哈希表 + 递归栈）

## 易错点

- **必须先递归左、后递归右**。因为 `pre_i` 是按前序顺序消耗，前序里的左子树节点全在右子树之前。
- 中序的下标范围用闭区间 [l, r]，出口判 `l > r`。
- 题目保证元素无重复，所以中序值 → 下标的映射是唯一的。
