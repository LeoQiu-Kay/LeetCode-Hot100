# 207. 课程表

- LeetCode 题号：207
- 难度：中等
- 英文标题：Course Schedule
- 链接：https://leetcode.cn/problems/course-schedule/

---

你这个学期必须选修 `numCourses` 门课程，记为 `0` 到 `numCourses - 1` 。

在选修某些课程之前需要一些先修课程。 先修课程按数组 `prerequisites` 给出，其中 `prerequisites[i] = [ai, bi]` ，表示如果要学习课程 `ai` 则 **必须** 先学习课程  `bi` 。

- 例如，先修课程对 `[0, 1]` 表示：想要学习课程 `0` ，你需要先完成课程 `1` 。

请你判断是否可能完成所有课程的学习？如果可以，返回 `true` ；否则，返回 `false` 。



**示例 1：**

```
输入：numCourses = 2, prerequisites = [[1,0]]
输出：true
解释：总共有 2 门课程。学习课程 1 之前，你需要完成课程 0 。这是可能的。
```

**示例 2：**

```
输入：numCourses = 2, prerequisites = [[1,0],[0,1]]
输出：false
解释：总共有 2 门课程。学习课程 1 之前，你需要先完成课程 0 ；并且学习课程 0 之前，你还应先完成课程 1 。这是不可能的。
```



**提示：**

- `1 <= numCourses <= 2000`

- `0 <= prerequisites.length <= 5000`

- `prerequisites[i].length == 2`

- `0 <= ai, bi < numCourses`

- `prerequisites[i]` 中的所有课程对 **互不相同**

---

## 直觉 / 记忆点

> 课程依赖 = 有向图。"能否修完所有课"等价于"图里有没有环"——有环就锁死无解，无环就一定有合法顺序。**Kahn 拓扑排序**：把"入度为 0"的节点入队，每出队一个就把它的所有后继入度 -1，新变成 0 的入队。最后看出队节点数是否等于 n。

## 思路

建邻接表 + 入度数组；BFS 拓扑；统计出队总数。

## 代码

```python
from collections import deque

class Solution:
    def canFinish(self, numCourses: int, prerequisites: list[list[int]]) -> bool:
        # 邻接表：g[a] 列出所有"以 a 为先修课"的下游课程
        # 入度数组：indeg[b] 是课程 b 还有几个未完成的先修课
        g: list[list[int]] = [[] for _ in range(numCourses)]
        indeg = [0] * numCourses
        for b, a in prerequisites:
            # 题目格式 [b, a] 表示要修 b 必须先修 a，即 a → b
            g[a].append(b)
            indeg[b] += 1
        # 所有入度为 0 的课（无先修课）先入队
        q = deque(i for i in range(numCourses) if indeg[i] == 0)
        done = 0   # 已完成的课程数
        while q:
            x = q.popleft()
            done += 1
            # 把 x 的所有后继课程的入度减 1
            for y in g[x]:
                indeg[y] -= 1
                # 入度归零意味着所有先修课已修完，可以学了
                if indeg[y] == 0:
                    q.append(y)
        # 全部完成 ⟺ 无环
        return done == numCourses
```

## 复杂度

- 时间：O(V + E)
- 空间：O(V + E)

## 易错点

- prerequisites 的格式：`[b, a]` 表示"修 b 之前必须先修 a"，对应有向边 a → b（不是 b → a），别画反。
- BFS 拓扑必须用 deque + 入度数组；如果换成 DFS 判环也行，但实现更繁琐（要区分"白/灰/黑"三态）。
