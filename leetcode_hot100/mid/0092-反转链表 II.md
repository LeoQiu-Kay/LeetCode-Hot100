# 92. 反转链表 II

- LeetCode 题号：92
- 难度：中等
- 英文标题：Reverse Linked List II
- 链接：https://leetcode.cn/problems/reverse-linked-list-ii/

> 📌 **不在 Hot 100 题单**，作为链表反转（206）的进阶补充。

---

给你单链表的头指针 `head` 和两个整数 `left` 和 `right` ，其中 `left <= right` 。请你反转从位置 `left` 到位置 `right` 的链表节点，返回 **反转后的链表** 。

**示例 1：**

```
输入：head = [1,2,3,4,5], left = 2, right = 4
输出：[1,4,3,2,5]
```

**示例 2：**

```
输入：head = [5], left = 1, right = 1
输出：[5]
```

**提示：**

- 链表中节点数目为 `n`
- `1 <= n <= 500`
- `-500 <= Node.val <= 500`
- `1 <= left <= right <= n`

**进阶：** 你可以使用一趟扫描完成反转吗？

---

## 直觉 / 记忆点

> 用 **dummy 头** + **头插法**一趟反转 `[left, right]` 段。先让 `prev` 停在 left 的**前一个**节点，然后把 `cur`（left 位置）后面的节点一个个"摘下来、插到 prev 后面"，共 `right - left` 次。

## 思路

1. dummy 头消除"反转段包含头节点"的边界。
2. `prev` 走 `left - 1` 步，停在 left 的前驱。
3. `cur = prev.next`（反转段第一个节点，反转后会沉到段尾，但它始终是 cur）。
4. 头插法做 `right - left` 次：把 `cur.next` 摘下，插到 `prev.next` 位置。

## 代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def reverseBetween(self, head: ListNode | None, left: int, right: int) -> ListNode | None:
        dummy = ListNode(0, head)
        # prev 走到 left 的前一个节点
        prev = dummy
        for _ in range(left - 1):
            prev = prev.next
        # cur 是反转段的第一个节点；它会逐步沉到段尾，但引用始终不变
        cur = prev.next
        # 头插法：把 cur 后面的节点一个个摘下来，插到 prev 之后
        for _ in range(right - left):
            nxt = cur.next          # 要摘下来的节点
            cur.next = nxt.next     # cur 跳过 nxt
            nxt.next = prev.next    # nxt 插到段首
            prev.next = nxt         # prev 接上新段首
        return dummy.next
```

## 复杂度

- 时间：O(n)，一趟
- 空间：O(1)

## 易错点

- **dummy 必备**：`left == 1` 时反转段包含头节点，没 dummy 要特判。
- **头插次数是 `right - left`**（不是 right - left + 1）：每次把一个节点提到段首，n 个节点只需 n-1 次提升。
- **cur 始终指向反转段原来的第一个节点**：它在反转后会变成段尾，但代码里不更新 cur。
- 三行重连顺序：`cur.next = nxt.next` → `nxt.next = prev.next` → `prev.next = nxt`，别乱。
