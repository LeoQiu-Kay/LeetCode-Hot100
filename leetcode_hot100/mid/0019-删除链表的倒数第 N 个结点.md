# 19. 删除链表的倒数第 N 个结点

- LeetCode 题号：19
- 难度：中等
- 英文标题：Remove Nth Node From End of List
- 链接：https://leetcode.cn/problems/remove-nth-node-from-end-of-list/

---

给你一个链表，删除链表的倒数第 `n`* *个结点，并且返回链表的头结点。



**示例 1：**

![](https://assets.leetcode.com/uploads/2020/10/03/remove_ex1.jpg)

```
输入：head = [1,2,3,4,5], n = 2
输出：[1,2,3,5]
```

**示例 2：**

```
输入：head = [1], n = 1
输出：[]
```

**示例 3：**

```
输入：head = [1,2], n = 1
输出：[1]
```



**提示：**

- 链表中结点的数目为 `sz`

- `1 <= sz <= 30`

- `0 <= Node.val <= 100`

- `1 <= n <= sz`



**进阶：**你能尝试使用一趟扫描实现吗？

---

## 直觉 / 记忆点

> 想知道"倒数第 N 个"，让一个**快指针先走 N 步**，再让快慢指针**同步**往后走。快指针走到末尾时，慢指针正好停在"倒数第 N 个**的前一个**"，删除就一步搞定。用 dummy 头避免删第一个节点的边界。

## 思路

dummy → fast 先走 n+1 步 → fast/slow 同步走到 fast 为 None → `slow.next = slow.next.next`。

## 代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def removeNthFromEnd(self, head: ListNode | None, n: int) -> ListNode | None:
        # 加 dummy 是为了把"删第一个节点"也能用统一逻辑处理
        dummy = ListNode(0, head)
        fast = slow = dummy
        # fast 先走 n+1 步：让 fast 与 slow 之间隔出"被删节点 + 倒数 N 个空位"
        # 这样后面同步走时，slow 最终会停在"被删节点的前一个"
        for _ in range(n + 1):
            fast = fast.next
        # fast/slow 同步往后走，直到 fast 走到 None
        while fast:
            fast = fast.next
            slow = slow.next
        # 此时 slow.next 就是要删除的节点，跳过它即可
        slow.next = slow.next.next
        # 返回真实首节点（可能等于原 head，也可能 head 已被删）
        return dummy.next
```

## 复杂度

- 时间：O(L)（一趟）
- 空间：O(1)

## 易错点

- fast 多走的是 `n + 1` 步（不是 n），slow 才能停在被删节点的**前面**。
- 没 dummy 时删第一个节点要特判，加 dummy 后统一处理。
