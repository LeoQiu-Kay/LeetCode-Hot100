# 279. 完全平方数

- LeetCode 题号：279
- 难度：中等
- 英文标题：Perfect Squares
- 链接：https://leetcode.cn/problems/perfect-squares/

---

给你一个整数 `n` ，返回 *和为 `n` 的完全平方数的最少数量* 。

**完全平方数** 是一个整数，其值等于另一个整数的平方；换句话说，其值等于一个整数自乘的积。例如，`1`、`4`、`9` 和 `16` 都是完全平方数，而 `3` 和 `11` 不是。



**示例 1：**

```
输入：n = `12`
输出：3
解释：`12 = 4 + 4 + 4`
```

**示例 2：**

```
输入：n = `13`
输出：2
解释：`13 = 4 + 9`
```



**提示：**

- `1 <= n <= 10⁴`

---

## 直觉 / 记忆点

> 完全背包：物品是 1²、2²、3²…，每个能用无限次，凑出 n 用的最少件数。`dp[i]` = 凑成 i 所需的最少完全平方数。转移：`dp[i] = min(dp[i - j²]) + 1`，遍历所有 j² ≤ i。

## 思路

dp 数组长度 n+1。dp[0] = 0；外层 i 从 1 到 n，内层 j 从 1 到 √i。

## 代码

```python
class Solution:
    def numSquares(self, n: int) -> int:
        # dp[i] = 凑成 i 至少需要几个完全平方数
        # 初始置为"足够大"（n 本身就是上界，因为 1+1+...+1 = n 永远可行）
        dp = [0] + [n] * n
        for i in range(1, n + 1):
            # 枚举所有可能作为"最后一个数"的 j²
            j = 1
            while j * j <= i:
                # 用 j² 当最后一个：dp[i] 至少是 dp[i - j²] + 1
                dp[i] = min(dp[i], dp[i - j * j] + 1)
                j += 1
        return dp[n]
```

## 复杂度

- 时间：O(n × √n)
- 空间：O(n)

## 易错点

- dp 初始值要足够大（用 n 是稳妥的上界）。dp[0] = 0 是基本情况："凑成 0 用 0 个数"。
- 数学定理（拉格朗日四平方和）说答案最大是 4，但 leetcode 不要求用，DP 解清晰更通用。
