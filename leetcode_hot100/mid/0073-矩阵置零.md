# 73. 矩阵置零

- LeetCode 题号：73
- 难度：中等
- 英文标题：Set Matrix Zeroes
- 链接：https://leetcode.cn/problems/set-matrix-zeroes/

---

给定一个 `*m* x *n*` 的矩阵，如果一个元素为 **0 **，则将其所在行和列的所有元素都设为 **0** 。请使用 **[原地](http://baike.baidu.com/item/%E5%8E%9F%E5%9C%B0%E7%AE%97%E6%B3%95)** 算法**。**



**示例 1：**

![](https://assets.leetcode.com/uploads/2020/08/17/mat1.jpg)

```
输入：matrix = [[1,1,1],[1,0,1],[1,1,1]]
输出：[[1,0,1],[0,0,0],[1,0,1]]
```

**示例 2：**

![](https://assets.leetcode.com/uploads/2020/08/17/mat2.jpg)

```
输入：matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
输出：[[0,0,0,0],[0,4,5,0],[0,3,1,0]]
```



**提示：**

- `m == matrix.length`

- `n == matrix[0].length`

- `1 <= m, n <= 200`

- `-2³¹ <= matrix[i][j] <= 2³¹ - 1`



**进阶：**

- 一个直观的解决方案是使用  `O(*m**n*)` 的额外空间，但这并不是一个好的解决方案。

- 一个简单的改进方案是使用 `O(*m* + *n*)` 的额外空间，但这仍然不是最好的解决方案。

- 你能想出一个仅使用常量空间的解决方案吗？

---

## 直觉 / 记忆点

> 用**首行 / 首列**当"标记本"。第一遍扫：如果 `matrix[i][j] == 0`，就把 `matrix[i][0]` 和 `matrix[0][j]` 也标 0；同时单独记一下首行 / 首列原本是否有 0。第二遍扫：根据首行 / 首列的标记把对应位置置 0。最后再处理首行 / 首列本身。

## 思路

两个 bool: row0_zero、col0_zero 记原始首行首列；其余位置原地标记。

## 代码

```python
class Solution:
    def setZeroes(self, matrix: list[list[int]]) -> None:
        m, n = len(matrix), len(matrix[0])
        # 先记下首行首列原本是否有 0，因为后面要用它俩当"标记本"
        row0_zero = any(matrix[0][j] == 0 for j in range(n))
        col0_zero = any(matrix[i][0] == 0 for i in range(m))
        # 第一遍：扫除首行首列外的格子，发现 0 就把对应首行首列标 0
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][j] == 0:
                    matrix[i][0] = 0
                    matrix[0][j] = 0
        # 第二遍：根据首行首列的标记把内部置 0
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][0] == 0 or matrix[0][j] == 0:
                    matrix[i][j] = 0
        # 最后处理首行首列本身（用一开始记下的标志）
        if row0_zero:
            for j in range(n):
                matrix[0][j] = 0
        if col0_zero:
            for i in range(m):
                matrix[i][0] = 0
```

## 复杂度

- 时间：O(m × n)
- 空间：O(1)

## 易错点

- **必须先**记下原始首行 / 首列的状态，否则第一遍标记会污染首行 / 首列的原始信息。
- 第二遍只处理 `i >= 1, j >= 1` 的内部格子，最后再单独把首行 / 首列按记录置 0。
