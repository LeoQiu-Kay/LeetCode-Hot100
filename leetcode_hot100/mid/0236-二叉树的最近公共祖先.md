# 236. 二叉树的最近公共祖先

- LeetCode 题号：236
- 难度：中等
- 英文标题：Lowest Common Ancestor of a Binary Tree
- 链接：https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/

---

给定一个二叉树, 找到该树中两个指定节点的最近公共祖先。

[百度百科](https://baike.baidu.com/item/%E6%9C%80%E8%BF%91%E5%85%AC%E5%85%B1%E7%A5%96%E5%85%88/8918834?fr=aladdin)中最近公共祖先的定义为：“对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（**一个节点也可以是它自己的祖先**）。”



**示例 1：**

![](https://assets.leetcode.com/uploads/2018/12/14/binarytree.png)

```
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
输出：3
解释：节点 `5 `和节点 `1 `的最近公共祖先是节点 `3 。`
```

**示例 2：**

![](https://assets.leetcode.com/uploads/2018/12/14/binarytree.png)

```
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4
输出：5
解释：节点 `5 `和节点 `4 `的最近公共祖先是节点 `5 。`因为根据定义最近公共祖先节点可以为节点本身。
```

**示例 3：**

```
输入：root = [1,2], p = 1, q = 2
输出：1
```



**提示：**

- 树中节点数目在范围 `[2, 10⁵]` 内。

- `-10⁹ <= Node.val <= 10⁹`

- 所有 `Node.val` `互不相同` 。

- `p != q`

- `p` 和 `q` 均存在于给定的二叉树中。

---

## 直觉 / 记忆点

> 后序递归：每个节点问左右子树"你们各自包含 p 或 q 吗？"
> - 左右都返回非空 → 当前节点就是 LCA（p、q 分散在两边，**只有这里能同时覆盖**）
> - 只有一边返回非空 → 把那一边的结果**原样上传**（LCA 在那一边，或就是 p/q 本身）
> - 两边都空 → 返回 None
>
> 把 p 或 q 本身也算"找到的祖先"，递归就能优雅处理"一个是另一个的祖先"的情况。

## 思路

DFS 返回值含义："在以 node 为根的子树里，找到的 p 或 q 或它们的 LCA"。

## 代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def lowestCommonAncestor(self, root: TreeNode, p: TreeNode, q: TreeNode) -> TreeNode:
        # 出口：空子树返回 None；遇到 p 或 q 直接返回它自己（视为"找到了 ≥ 1 个目标"）
        if not root or root is p or root is q:
            return root
        # 递归看左右子树各自的结果
        left = self.lowestCommonAncestor(root.left, p, q)
        right = self.lowestCommonAncestor(root.right, p, q)
        # 两边都找到了 → 当前节点就是分叉点，即 LCA
        if left and right:
            return root
        # 只有一边非空 → LCA 在那一边，或本身就是 p/q（向上传递）
        return left or right
```

## 复杂度

- 时间：O(n)
- 空间：O(h)

## 易错点

- 节点比较用 `is`（同一对象）而不是 `==`（值相等），题目保证节点唯一，但严谨起见还是用 is。
- "返回 p 或 q 本身"是关键技巧，能让"p 是 q 的祖先"这类情况自动满足（递归到 q 的祖先 p 时，p 自身被返回；另一侧 None；上一层只有一侧非空就返回它）。
