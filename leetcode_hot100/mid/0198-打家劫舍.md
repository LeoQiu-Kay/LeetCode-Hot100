# 198. 打家劫舍

- LeetCode 题号：198
- 难度：中等
- 英文标题：House Robber
- 链接：https://leetcode.cn/problems/house-robber/

---

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，**如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。

给定一个代表每个房屋存放金额的非负整数数组，计算你** 不触动警报装置的情况下 **，一夜之内能够偷窃到的最高金额。



**示例 1：**

```
输入：[1,2,3,1]
输出：4
解释：偷窃 1 号房屋 (金额 = 1) ，然后偷窃 3 号房屋 (金额 = 3)。
     偷窃到的最高金额 = 1 + 3 = 4 。
```

**示例 2：**

```
输入：[2,7,9,3,1]
输出：12
解释：偷窃 1 号房屋 (金额 = 2), 偷窃 3 号房屋 (金额 = 9)，接着偷窃 5 号房屋 (金额 = 1)。
     偷窃到的最高金额 = 2 + 9 + 1 = 12 。
```



**提示：**

- `1 <= nums.length <= 100`

- `0 <= nums[i] <= 400`

---

## 直觉 / 记忆点

> 站在第 i 间房子前的选择："偷或不偷"：
> - 偷：上一间必须不偷 → `dp[i-2] + nums[i]`
> - 不偷：沿用 `dp[i-1]`
>
> 答案是 `max(两者)`。和爬楼梯结构一样，可以滚动到 O(1) 空间。

## 思路

`prev2` 表示 dp[i-2]，`prev1` 表示 dp[i-1]。每步 cur = max(prev1, prev2 + x)。

## 代码

```python
class Solution:
    def rob(self, nums: list[int]) -> int:
        # prev2 表示"不包括当前位置往前推 2 间"的最大值（dp[i-2]）
        # prev1 表示"到上一间为止"的最大值（dp[i-1]）
        prev2 = prev1 = 0
        for x in nums:
            # cur = max(不偷当前=prev1, 偷当前=prev2+x)
            cur = max(prev1, prev2 + x)
            # 滚动：旧的 prev1 变成新的 prev2
            prev2, prev1 = prev1, cur
        # 循环结束 prev1 就是答案
        return prev1
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- prev2 和 prev1 初始都是 0（表示"空房"的最大金额是 0）。
- 滚动一行 `prev2, prev1 = prev1, cur`：Python 元组赋值原子，没问题。
