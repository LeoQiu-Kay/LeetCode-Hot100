# 53. 最大子数组和

- LeetCode 题号：53
- 难度：中等
- 英文标题：Maximum Subarray
- 链接：https://leetcode.cn/problems/maximum-subarray/

---

给你一个整数数组 `nums` ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

**子数组 **是数组中的一个连续部分。



**示例 1：**

```
输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
解释：连续子数组 [4,-1,2,1] 的和最大，为 6 。
```

**示例 2：**

```
输入：nums = [1]
输出：1
```

**示例 3：**

```
输入：nums = [5,4,-1,7,8]
输出：23
```



**提示：**

- `1 <= nums.length <= 10⁵`

- `-10⁴ <= nums[i] <= 10⁴`



**进阶：**如果你已经实现复杂度为 `O(n)` 的解法，尝试使用更为精妙的 **分治法** 求解。

---

## 直觉 / 记忆点

> **Kadane 算法**：维护"以 i 结尾的最大子数组和 `cur`"。决策很简单：
> - 把当前数加到现有子数组里：`cur + x`
> - 或者放弃前面、从当前数重新开始：`x`
>
> 选大的那个。全局答案取所有 cur 的最大值。

## 思路

cur 滚动，ans 维护全局最大。

## 代码

```python
class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        # cur 表示以当前下标结尾的最大子数组和
        cur = ans = nums[0]
        for x in nums[1:]:
            # 关键决策：cur + x 还不如 x 大，说明前面那段是累赘，放弃，从 x 重新开始
            cur = max(x, cur + x)
            ans = max(ans, cur)
        return ans
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- ans 初始用 `nums[0]`，不能用 0：全负数时答案是 nums 里最大那个负数。
- cur 的更新只关心"加进去还是另起一段"，不关心子数组实际范围。
