# 189. 轮转数组

- LeetCode 题号：189
- 难度：中等
- 英文标题：Rotate Array
- 链接：https://leetcode.cn/problems/rotate-array/

---

给定一个整数数组 `nums`，将数组中的元素向右轮转 `k`* *个位置，其中 `k`* *是非负数。



**示例 1:**

```
输入: nums = [1,2,3,4,5,6,7], k = 3
输出: `[5,6,7,1,2,3,4]`
解释:
向右轮转 1 步: `[7,1,2,3,4,5,6]`
向右轮转 2 步: `[6,7,1,2,3,4,5]
`向右轮转 3 步: `[5,6,7,1,2,3,4]`
```

**示例 2:**

```
输入：nums = [-1,-100,3,99], k = 2
输出：[3,99,-1,-100]
解释:
向右轮转 1 步: [99,-1,-100,3]
向右轮转 2 步: [3,99,-1,-100]
```



**提示：**

- `1 <= nums.length <= 10⁵`

- `-2³¹ <= nums[i] <= 2³¹ - 1`

- `0 <= k <= 10⁵`



**进阶：**

- 尽可能想出更多的解决方案，至少有 **三种** 不同的方法可以解决这个问题。

- 你可以使用空间复杂度为 `O(1)` 的 **原地 **算法解决这个问题吗？

## 直觉 / 记忆点

> **三次反转**法：
> 1. 反转整个数组
> 2. 反转前 k 个
> 3. 反转剩下 n-k 个
>
> 神奇的事实：上面三步合起来等于"右移 k 位"。O(1) 额外空间，且不用拷贝。

## 思路

注意先 `k %= n` 处理 k > n 的情况。

## 代码

```python
class Solution:
    def rotate(self, nums: list[int], k: int) -> None:
        n = len(nums)
        k %= n   # k > n 时取模（轮转 n 次回到原状）
        def reverse(l: int, r: int) -> None:
            # 反转 nums[l..r]（闭区间）
            while l < r:
                nums[l], nums[r] = nums[r], nums[l]
                l += 1
                r -= 1
        # 1. 全反
        reverse(0, n - 1)
        # 2. 反转前 k 个
        reverse(0, k - 1)
        # 3. 反转后 n-k 个
        reverse(k, n - 1)
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- **必须** `k %= n`，否则 k > n 时反转区间错乱。
- 反转区间用闭区间 [l, r]，对应 `reverse(0, k-1)` 而不是 `reverse(0, k)`。
