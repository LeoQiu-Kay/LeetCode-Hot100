# 394. 字符串解码

- LeetCode 题号：394
- 难度：中等
- 英文标题：Decode String
- 链接：https://leetcode.cn/problems/decode-string/

---

给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为: `k[encoded_string]`，表示其中方括号内部的 `encoded_string` 正好重复 `k` 次。注意 `k` 保证为正整数。

你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。

此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数 `k` ，例如不会出现像 `3a` 或 `2[4]` 的输入。

测试用例保证输出的长度不会超过 `10⁵`。



**示例 1：**

```
输入：s = "3[a]2[bc]"
输出："aaabcbc"
```

**示例 2：**

```
输入：s = "3[a2[c]]"
输出："accaccacc"
```

**示例 3：**

```
输入：s = "2[abc]3[cd]ef"
输出："abcabccdcdcdef"
```

**示例 4：**

```
输入：s = "abc3[cd]xyz"
输出："abccdcdcdxyz"
```



**提示：**

- `1 <= s.length <= 30`

- `s` 由小写英文字母、数字和方括号 `'[]'` 组成

- `s` 保证是一个 **有效** 的输入。

- `s` 中所有整数的取值范围为 `[1, 300]`

---

## 直觉 / 记忆点

> `3[a2[c]]` 这种嵌套结构典型用两个栈处理：一个**数字栈**（重复次数）、一个**字符串栈**（外层已积累的字符串）。遇到 `[` 把当前数字和字符串压栈，重新开始；遇到 `]` 弹栈把内层重复 num 次拼到外层。

## 思路

扫描字符。数字累积成 num；字母累积到 cur；`[` 入栈保存上下文；`]` 弹栈把 cur 重复并拼回。

## 代码

```python
class Solution:
    def decodeString(self, s: str) -> str:
        num_stack: list[int] = []   # 嵌套层的重复次数栈
        str_stack: list[str] = []   # 嵌套层的"外层已积累字符串"栈
        cur = ""    # 当前层正在累积的字符串
        num = 0     # 当前层正在累积的数字
        for c in s:
            if c.isdigit():
                # 数字可能多位，累加
                num = num * 10 + int(c)
            elif c == '[':
                # 进入新一层：把外层的数字和字符串压栈，当前层从头开始
                num_stack.append(num)
                str_stack.append(cur)
                num = 0
                cur = ""
            elif c == ']':
                # 结束当前层：弹出"外层字符串"和"重复次数"
                # 新 cur = 外层字符串 + 当前层字符串 * 次数
                k = num_stack.pop()
                prev = str_stack.pop()
                cur = prev + cur * k
            else:
                # 字母直接累积
                cur += c
        return cur
```

## 复杂度

- 时间：O(N)（N 是解码后的总长度）
- 空间：O(d)（嵌套深度 d）

## 易错点

- 数字要支持**多位**（`12[a]` 重复 12 次而不是 2 次），所以用 `num = num*10 + int(c)`。
- `[` 进栈时**当前的 num 和 cur 都要存**，并各自清零，下一层从头算。
- 弹栈时拼接顺序：外层在前、内层重复结果在后。
