# 49. 字母异位词分组

- LeetCode 题号：49
- 难度：中等
- 英文标题：Group Anagrams
- 链接：https://leetcode.cn/problems/group-anagrams/

---

给你一个字符串数组，请你将 字母异位词 组合在一起。可以按任意顺序返回结果列表。



**示例 1:**

**输入:** strs = ["eat", "tea", "tan", "ate", "nat", "bat"]

**输出: **[["bat"],["nat","tan"],["ate","eat","tea"]]

**解释：**

- 在 strs 中没有字符串可以通过重新排列来形成 `"bat"`。

- 字符串 `"nat"` 和 `"tan"` 是字母异位词，因为它们可以重新排列以形成彼此。

- 字符串 `"ate"` ，`"eat"` 和 `"tea"` 是字母异位词，因为它们可以重新排列以形成彼此。

**示例 2:**

**输入:** strs = [""]

**输出: **[[""]]

**示例 3:**

**输入:** strs = ["a"]

**输出: **[["a"]]



**提示：**

- `1 <= strs.length <= 10⁴`

- `0 <= strs[i].length <= 100`

- `strs[i]` 仅包含小写字母

---

## 直觉 / 记忆点

> "字母异位词"的特征是**字母组成完全相同**。给每组挑一个**指纹**：把单词字母排序后得到的字符串就行，或者用 26 维字母计数元组。指纹一致的塞进同一桶，最后输出所有桶。

## 思路

字典 `指纹 → 单词列表`。指纹用 `tuple(sorted(s))` 或 `''.join(sorted(s))` 都行。

## 代码

```python
from collections import defaultdict

class Solution:
    def groupAnagrams(self, strs: list[str]) -> list[list[str]]:
        # 字典：指纹（排序后字符串）→ 该指纹对应的单词列表
        groups: dict[str, list[str]] = defaultdict(list)
        for s in strs:
            # 排序后字符串作为指纹：字母相同的单词指纹也相同
            key = ''.join(sorted(s))
            groups[key].append(s)
        # 返回所有桶（题目允许任意顺序）
        return list(groups.values())
```

## 复杂度

- 时间：O(N · K log K)，N 是字符串数、K 是字符串平均长度
- 空间：O(N · K)

## 易错点

- 用 `tuple(sorted(s))` 也行，元组可哈希；但 `sorted(s)` 是 list 不能直接当 key。
- 用字母计数（长度 26 元组）可以做到 O(N · K) 不依赖排序，但代码更长。
