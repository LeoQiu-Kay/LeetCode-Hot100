# 300. 最长递增子序列

- LeetCode 题号：300
- 难度：中等
- 英文标题：Longest Increasing Subsequence
- 链接：https://leetcode.cn/problems/longest-increasing-subsequence/

---

给你一个整数数组 `nums` ，找到其中最长严格递增子序列的长度。

**子序列 **是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，`[3,6,2,7]` 是数组 `[0,3,1,6,2,2,7]` 的子序列。



**示例 1：**

```
输入：nums = [10,9,2,5,3,7,101,18]
输出：4
解释：最长递增子序列是 [2,3,7,101]，因此长度为 4 。
```

**示例 2：**

```
输入：nums = [0,1,0,3,2,3]
输出：4
```

**示例 3：**

```
输入：nums = [7,7,7,7,7,7,7]
输出：1
```



**提示：**

- `1 <= nums.length <= 2500`

- `-10⁴ <= nums[i] <= 10⁴`



**进阶：**

- 你能将算法的时间复杂度降低到 `O(n log(n))` 吗?

---

## 直觉 / 记忆点

> O(n²) DP：`dp[i]` = 以 `nums[i]` 结尾的 LIS 长度，转移 `dp[i] = max(dp[j] + 1)` 对所有 `j < i 且 nums[j] < nums[i]`。
> O(n log n) 巧解：维护 `tails`，`tails[k]` 是"长度为 k+1 的递增子序列里、最后一个元素的最小值"。每个 x 在 tails 里二分找第一个 `>= x` 的位置替换；找不到就 append。tails 长度即答案。

## 思路

直接给 O(n log n) 解，更优雅。

## 代码

```python
from bisect import bisect_left

class Solution:
    def lengthOfLIS(self, nums: list[int]) -> int:
        # tails[k] = "长度为 k+1 的递增子序列的最小末尾值"
        # tails 本身始终保持递增
        tails: list[int] = []
        for x in nums:
            # 找第一个 >= x 的位置
            i = bisect_left(tails, x)
            if i == len(tails):
                # x 比所有已知末尾都大，扩展 tails（LIS 长度 +1）
                tails.append(x)
            else:
                # 替换：让长度为 i+1 的子序列末尾变得更小，给后续留更多空间
                tails[i] = x
        return len(tails)
```

## 复杂度

- 时间：O(n log n)
- 空间：O(n)

## 易错点

- tails 不是真正的最长子序列，只是一个"长度 → 最小末尾"映射；要还原序列得用其它方法。
- 用 `bisect_left`（严格递增）；如果题目改"非严格递增"就用 `bisect_right`。
