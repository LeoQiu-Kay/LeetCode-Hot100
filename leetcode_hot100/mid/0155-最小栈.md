# 155. 最小栈

- LeetCode 题号：155
- 难度：中等
- 英文标题：Min Stack
- 链接：https://leetcode.cn/problems/min-stack/

---

设计一个支持 `push` ，`pop` ，`top` 操作，并能在常数时间内检索到最小元素的栈。

实现 `MinStack` 类:

- `MinStack()` 初始化堆栈对象。

- `void push(int val)` 将元素val推入堆栈。

- `void pop()` 删除堆栈顶部的元素。

- `int top()` 获取堆栈顶部的元素。

- `int getMin()` 获取堆栈中的最小元素。



**示例 1:**

```
输入：
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]

输出：
[null,null,null,null,-3,null,0,-2]

解释：
MinStack minStack = new MinStack();
minStack.push(-2);
minStack.push(0);
minStack.push(-3);
minStack.getMin();   --> 返回 -3.
minStack.pop();
minStack.top();      --> 返回 0.
minStack.getMin();   --> 返回 -2.
```



**提示：**

- `-2³¹ <= val <= 2³¹ - 1`

- `pop`、`top` 和 `getMin` 操作总是在 **非空栈** 上调用

- `push`, `pop`, `top`, and `getMin`最多被调用 `3 * 10⁴` 次

---

## 直觉 / 记忆点

> 要 push/pop/top/getMin 都 O(1)。**辅助栈**同步维护"到目前为止的最小值"：主栈每入栈一个 x，辅助栈就 push `min(辅助栈顶, x)`。pop 时两个栈一起 pop。这样辅助栈的栈顶**永远**是当前主栈所有元素的最小值。

## 思路

两个栈同步增删，min_stack 栈顶就是答案。

## 代码

```python
class MinStack:
    def __init__(self):
        # 主栈：实际存所有元素
        self.stack: list[int] = []
        # 辅助栈：每个位置对应主栈到该位置为止的最小值
        # 两个栈长度永远相同，pop/push 同步进行
        self.min_stack: list[int] = []

    def push(self, val: int) -> None:
        self.stack.append(val)
        # 辅助栈 push 的是"当前 val"与"之前最小"的较小值
        # 这样不论主栈如何 push，min_stack[-1] 永远是当前主栈的最小
        if self.min_stack:
            self.min_stack.append(min(self.min_stack[-1], val))
        else:
            self.min_stack.append(val)

    def pop(self) -> None:
        # 两个栈一起 pop，保持同步
        self.stack.pop()
        self.min_stack.pop()

    def top(self) -> int:
        return self.stack[-1]

    def getMin(self) -> int:
        return self.min_stack[-1]
```

## 复杂度

- 时间：所有操作 O(1)
- 空间：O(n)

## 易错点

- 辅助栈 push 的不是 val，而是 **min(栈顶, val)**——保证栈顶永远是"到目前为止的最小"。
- pop 时**两个栈都要 pop**，否则会错位。
