# 2. 两数相加

- LeetCode 题号：2
- 难度：中等
- 英文标题：Add Two Numbers
- 链接：https://leetcode.cn/problems/add-two-numbers/

---

给你两个 **非空** 的链表，表示两个非负的整数。它们每位数字都是按照 **逆序** 的方式存储的，并且每个节点只能存储 **一位** 数字。

请你将两个数相加，并以相同形式返回一个表示和的链表。

你可以假设除了数字 0 之外，这两个数都不会以 0 开头。



**示例 1：**

![](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2021/01/02/addtwonumber1.jpg)

```
输入：l1 = [2,4,3], l2 = [5,6,4]
输出：[7,0,8]
解释：342 + 465 = 807.
```

**示例 2：**

```
输入：l1 = [0], l2 = [0]
输出：[0]
```

**示例 3：**

```
输入：l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
输出：[8,9,9,9,0,0,0,1]
```



**提示：**

- 每个链表中的节点数在范围 `[1, 100]` 内

- `0 <= Node.val <= 9`

- 题目数据保证列表表示的数字不含前导零

---

## 直觉 / 记忆点

> 两条链表是两个**反着写的数字**（个位在最前）。像小学竖式加法那样，从低位一路往高位加，**用一个 `carry` 变量**记进位即可。哪条链短就当成 0 补足，最后别忘了若 carry==1 还要再补一个节点。

## 思路

dummy 头 + 双指针扫两条链表 + carry。每一步：`s = a + b + carry`，新节点值 `s % 10`，carry 更新为 `s // 10`。

## 代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def addTwoNumbers(self, l1: ListNode | None, l2: ListNode | None) -> ListNode | None:
        # dummy 哑节点，最后返回 dummy.next 即结果首节点
        dummy = ListNode()
        cur = dummy          # cur 是新链表的"尾巴"
        carry = 0            # 进位
        # 只要还有数位要处理、或还有进位没消化，就继续
        while l1 or l2 or carry:
            # 取当前位的值；走到 None 就当作 0（短链表补 0）
            a = l1.val if l1 else 0
            b = l2.val if l2 else 0
            # 当前位求和：两个数位 + 上一位进上来的进位
            s = a + b + carry
            # 新节点存个位（s 模 10）
            cur.next = ListNode(s % 10)
            cur = cur.next
            # 把整十位提取出来，作为下一位的进位（0 或 1）
            carry = s // 10
            # 两条链表各自前进一步（前提是还没到 None）
            if l1: l1 = l1.next
            if l2: l2 = l2.next
        return dummy.next
```

## 复杂度

- 时间：O(max(m, n))
- 空间：O(max(m, n))（新链表）

## 易错点

- 循环条件含 `carry`，否则 `[5] + [5]` 末位进位 1 会漏。
- 数字是**反序**存的（个位在表头），算完直接返回，不需要再反转。
