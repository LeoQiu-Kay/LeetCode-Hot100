# 3. 无重复字符的最长子串

- LeetCode 题号：3
- 难度：中等
- 英文标题：Longest Substring Without Repeating Characters
- 链接：https://leetcode.cn/problems/longest-substring-without-repeating-characters/

---

给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长 子串**** **的长度。



**示例 1:**

```
输入: s = "abcabcbb"
输出: 3
解释: 因为无重复字符的最长子串是 `"abc"`，所以其长度为 3。注意 "bca" 和 "cab" 也是正确答案。
```

**示例 2:**

```
输入: s = "bbbbb"
输出: 1
解释: 因为无重复字符的最长子串是 `"b"`，所以其长度为 1。
```

**示例 3:**

```
输入: s = "pwwkew"
输出: 3
解释: 因为无重复字符的最长子串是 `"wke"`，所以其长度为 3。
     请注意，你的答案必须是 子串 的长度，`"pwke"` 是一个*子序列，*不是子串。
```



**提示：**

- `0 <= s.length <= 5 * 10⁴`

- `s` 由英文字母、数字、符号和空格组成

---

## 直觉 / 记忆点

> 滑动窗口。右指针 r 一路扩张，遇到重复字符时**左指针 l 直接跳到那个重复字符上次出现位置 +1**（哈希记录每个字符上次的位置）。每一步更新答案 `r - l + 1`。

## 思路

dict `字符 → 上次出现下标`。l 是当前窗口左端。

## 代码

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        last: dict[str, int] = {}   # 字符 → 上次出现的下标
        l = 0   # 当前窗口左端
        ans = 0
        for r, c in enumerate(s):
            # 如果 c 上次出现在当前窗口内，把 l 跳到上次位置 +1
            # 用 max 是为了防止"旧记录"把 l 拉回去（窗口左端只增不减）
            if c in last and last[c] >= l:
                l = last[c] + 1
            # 更新 c 的最新位置
            last[c] = r
            # 当前窗口长度 r - l + 1
            ans = max(ans, r - l + 1)
        return ans
```

## 复杂度

- 时间：O(n)
- 空间：O(字符集大小)

## 易错点

- 用 `max(l, last[c] + 1)` 等价写法也行；关键是 l **只能向右**，旧记录的字符如果已经滑出窗口就不能用它来回拉 l。
- 必须先判 `c in last`，否则 `last[c]` 会 KeyError。
