# 75. 颜色分类

- LeetCode 题号：75
- 难度：中等
- 英文标题：Sort Colors
- 链接：https://leetcode.cn/problems/sort-colors/

---

给定一个包含红色、白色和蓝色、共 `n`* *个元素的数组 `nums` ，**[原地](https://baike.baidu.com/item/%E5%8E%9F%E5%9C%B0%E7%AE%97%E6%B3%95) **对它们进行排序，使得相同颜色的元素相邻，并按照红色、白色、蓝色顺序排列。

我们使用整数 `0`、 `1` 和 `2` 分别表示红色、白色和蓝色。

必须在不使用库内置的 sort 函数的情况下解决这个问题。



**示例 1：**

```
输入：nums = [2,0,2,1,1,0]
输出：[0,0,1,1,2,2]
```

**示例 2：**

```
输入：nums = [2,0,1]
输出：[0,1,2]
```



**提示：**

- `n == nums.length`

- `1 <= n <= 300`

- `nums[i]` 为 `0`、`1` 或 `2`



**进阶：**

- 你能想出一个仅使用常数空间的一趟扫描算法吗？

---

## 直觉 / 记忆点

> **荷兰国旗三指针**：lo 是 0 区右边界、hi 是 2 区左边界、mid 是扫描指针。
> - `nums[mid] == 0`：和 lo 交换，lo 和 mid 都右移
> - `nums[mid] == 2`：和 hi 交换，hi 左移，mid **不动**（换过来的还得检查）
> - `nums[mid] == 1`：mid 直接右移

## 思路

一趟扫描，原地分三段。

## 代码

```python
class Solution:
    def sortColors(self, nums: list[int]) -> None:
        # 三个指针：
        # [0, lo) 是已确认的 0 区
        # [lo, mid) 是已确认的 1 区
        # [mid, hi] 是未处理区
        # (hi, n) 是已确认的 2 区
        lo, mid, hi = 0, 0, len(nums) - 1
        while mid <= hi:
            if nums[mid] == 0:
                # 当前是 0：换到 0 区末尾，lo 和 mid 都前进
                nums[lo], nums[mid] = nums[mid], nums[lo]
                lo += 1
                mid += 1
            elif nums[mid] == 2:
                # 当前是 2：换到 2 区开头，hi 左移
                # 注意 mid 不动：从 hi 换过来的元素还没处理过，下一轮重新看
                nums[mid], nums[hi] = nums[hi], nums[mid]
                hi -= 1
            else:
                # 当前是 1：1 直接进 1 区
                mid += 1
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- 遇到 2 交换后 `mid` **不前进**，因为换过来的元素是新的、还没分类。
- 遇到 0 交换后 mid **必须前进**（换过来的来自 [lo, mid) 是 1 区，已经分类好的 1）。
