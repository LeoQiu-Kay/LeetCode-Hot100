# 72. 编辑距离

- LeetCode 题号：72
- 难度：中等
- 英文标题：Edit Distance
- 链接：https://leetcode.cn/problems/edit-distance/

---

给你两个单词 `word1` 和 `word2`， *请返回将 `word1` 转换成 `word2` 所使用的最少操作数*  。

你可以对一个单词进行如下三种操作：

- 插入一个字符

- 删除一个字符

- 替换一个字符



**示例 1：**

```
输入：word1 = "horse", word2 = "ros"
输出：3
解释：
horse -> rorse (将 'h' 替换为 'r')
rorse -> rose (删除 'r')
rose -> ros (删除 'e')
```

**示例 2：**

```
输入：word1 = "intention", word2 = "execution"
输出：5
解释：
intention -> inention (删除 't')
inention -> enention (将 'i' 替换为 'e')
enention -> exention (将 'n' 替换为 'x')
exention -> exection (将 'n' 替换为 'c')
exection -> execution (插入 'u')
```



**提示：**

- `0 <= word1.length, word2.length <= 500`

- `word1` 和 `word2` 由小写英文字母组成

---

## 直觉 / 记忆点

> `dp[i][j]` = 把 `word1[:i]` 变成 `word2[:j]` 的最少操作数。
> - 末位字符相同：`dp[i][j] = dp[i-1][j-1]`（不用操作）
> - 不同：三种操作选最小再 +1
>   - 删 word1 末位 → `dp[i-1][j]`
>   - 插一个 word2 末位 → `dp[i][j-1]`
>   - 改 word1 末位 → `dp[i-1][j-1]`

## 思路

二维 dp，边界 `dp[i][0] = i`、`dp[0][j] = j`。

## 代码

```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m, n = len(word1), len(word2)
        # dp[i][j]：把 word1[:i] 变成 word2[:j] 的最少操作数
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        # 边界：把长度 i 的串变成空串要 i 次删除；空串变成长度 j 要 j 次插入
        for i in range(m + 1):
            dp[i][0] = i
        for j in range(n + 1):
            dp[0][j] = j
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if word1[i - 1] == word2[j - 1]:
                    # 末位相同：不需要操作，直接继承
                    dp[i][j] = dp[i - 1][j - 1]
                else:
                    # 末位不同：三种操作选最小再 +1
                    # 删（dp[i-1][j]）/ 插（dp[i][j-1]）/ 改（dp[i-1][j-1]）
                    dp[i][j] = 1 + min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1])
        return dp[m][n]
```

## 复杂度

- 时间：O(m × n)
- 空间：O(m × n)（可压成 O(n)）

## 易错点

- 三种操作对应三个状态来源，**别漏改 = dp[i-1][j-1]+1**（最容易忘）。
- 边界要单独初始化：dp[i][0] = i、dp[0][j] = j。
