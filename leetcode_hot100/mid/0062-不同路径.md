# 62. 不同路径

- LeetCode 题号：62
- 难度：中等
- 英文标题：Unique Paths
- 链接：https://leetcode.cn/problems/unique-paths/

---

一个机器人位于一个 `m x n`* *网格的左上角 （起始点在下图中标记为 “Start” ）。

机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 “Finish” ）。

问总共有多少条不同的路径？



**示例 1：**

![](https://pic.leetcode.cn/1697422740-adxmsI-image.png)

```
输入：m = 3, n = 7
输出：28
```

**示例 2：**

```
输入：m = 3, n = 2
输出：3
解释：
从左上角开始，总共有 3 条路径可以到达右下角。
1. 向右 -> 向下 -> 向下
2. 向下 -> 向下 -> 向右
3. 向下 -> 向右 -> 向下
```

**示例 3：**

```
输入：m = 7, n = 3
输出：28
```

**示例 4：**

```
输入：m = 3, n = 3
输出：6
```



**提示：**

- `1 <= m, n <= 100`

- 题目数据保证答案小于等于 `2 * 10⁹`

---

## 直觉 / 记忆点

> 每个格子只能从上或左来，所以 `dp[i][j] = dp[i-1][j] + dp[i][j-1]`。第一行第一列只有一种走法（全 1）。空间可压成一维滚动。

## 思路

一维 dp 长度 n（列数）。每行从左到右用 `dp[j] += dp[j-1]` 滚动。

## 代码

```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        # 一维 dp：dp[j] 表示"到达当前行第 j 列"的路径数
        # 初始相当于第一行（全 1，只有一种走法）
        dp = [1] * n
        # 从第二行开始更新
        for _ in range(1, m):
            for j in range(1, n):
                # dp[j] 当前还是"上一行第 j 列"，dp[j-1] 是"本行第 j-1 列"
                # 相加即"上面来的 + 左边来的"
                dp[j] += dp[j - 1]
        return dp[-1]
```

## 复杂度

- 时间：O(m × n)
- 空间：O(n)

## 易错点

- 一维滚动的关键：`dp[j] += dp[j-1]` 中，左边的 `dp[j]` 还是"上一行第 j 列"的值（即将被覆盖前用一下）；`dp[j-1]` 是已更新过的本行第 j-1 列。
- 第一列 `j=0` 永远是 1，循环从 1 开始正好跳过。
