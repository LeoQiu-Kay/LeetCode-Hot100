# 39. 组合总和

- LeetCode 题号：39
- 难度：中等
- 英文标题：Combination Sum
- 链接：https://leetcode.cn/problems/combination-sum/

---

给你一个 **无重复元素** 的整数数组 `candidates` 和一个目标整数 `target` ，找出 `candidates` 中可以使数字和为目标数 `target` 的 所有* ***不同组合** ，并以列表形式返回。你可以按 **任意顺序** 返回这些组合。

`candidates` 中的 **同一个** 数字可以 **无限制重复被选取** 。如果至少一个数字的被选数量不同，则两种组合是不同的。

对于给定的输入，保证和为 `target` 的不同组合数少于 `150` 个。



**示例 1：**

```
输入：candidates = [2,3,6,7], target = 7
输出：[[2,2,3],[7]]
解释：
2 和 3 可以形成一组候选，2 + 2 + 3 = 7 。注意 2 可以使用多次。
7 也是一个候选， 7 = 7 。
仅有这两种组合。
```

**示例 2：**

```
输入: candidates = [2,3,5], target = 8
输出: [[2,2,2,2],[2,3,3],[3,5]]
```

**示例 3：**

```
输入: candidates = [2], target = 1
输出: []
```



**提示：**

- `1 <= candidates.length <= 30`

- `2 <= candidates[i] <= 40`

- `candidates` 的所有元素 **互不相同**

- `1 <= target <= 40`

---

## 直觉 / 记忆点

> 每个数字**可以重复用**多次，但同一组合不分顺序（`[2,2,3]` 和 `[3,2,2]` 算同一个）。回溯时用 `start` 控制只能往后选（避免重复组合），但递归时下次仍从 i 开始（**不是 i+1**），允许重复选当前元素。

## 思路

DFS(start, remain)。remain == 0 收集答案；remain < 0 剪枝；否则循环 i from start。

## 代码

```python
class Solution:
    def combinationSum(self, candidates: list[int], target: int) -> list[list[int]]:
        ans: list[list[int]] = []
        path: list[int] = []
        def dfs(start: int, remain: int) -> None:
            # 凑够了：收集一个组合
            if remain == 0:
                ans.append(path.copy())
                return
            # 已经超了：剪枝
            if remain < 0:
                return
            # 从 start 开始往后选（保证组合按下标递增，不会出现 [2,3] 和 [3,2] 重复）
            for i in range(start, len(candidates)):
                path.append(candidates[i])
                # 注意：下次从 i 开始（不是 i+1），允许重复使用 candidates[i]
                dfs(i, remain - candidates[i])
                path.pop()
        dfs(0, target)
        return ans
```

## 复杂度

- 时间：和具体数据有关，最坏指数级
- 空间：O(target / min(candidates))（递归深度）

## 易错点

- 关键区别于 78 子集：**下次递归从 i 开始**（不是 i+1），允许重复选。
- 用 `start` 保证组合不重复（按下标递增挑），不需要去重哈希。
- 剪枝 `remain < 0` 可省（题目说数字都 ≥ 1，先排序后还可以 `if candidates[i] > remain: break`），不剪也能过。
