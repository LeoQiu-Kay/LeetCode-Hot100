# 437. 路径总和 III

- LeetCode 题号：437
- 难度：中等
- 英文标题：Path Sum III
- 链接：https://leetcode.cn/problems/path-sum-iii/

---

给定一个二叉树的根节点 `root` ，和一个整数 `targetSum` ，求该二叉树里节点值之和等于 `targetSum` 的 **路径** 的数目。

**路径** 不需要从根节点开始，也不需要在叶子节点结束，但是路径方向必须是向下的（只能从父节点到子节点）。



**示例 1：**

![](https://assets.leetcode.com/uploads/2021/04/09/pathsum3-1-tree.jpg)

```
输入：root = [10,5,-3,3,2,null,11,3,-2,null,1], targetSum = 8
输出：3
解释：和等于 8 的路径有 3 条，如图所示。
```

**示例 2：**

```
输入：root = [5,4,8,11,null,13,4,7,2,null,null,5,1], targetSum = 22
输出：3
```



**提示:**

- 二叉树的节点个数的范围是 `[0,1000]`

- `-10⁹ <= Node.val <= 10⁹`

- `-1000 <= targetSum <= 1000`

---

## 直觉 / 记忆点

> 路径起点不固定（不必从根）、方向往下。**前缀和 + 哈希**经典套路：DFS 过程中维护"从根到当前节点的前缀和"。如果当前前缀和是 `cur`，那么之前**任何**前缀和为 `cur - targetSum` 的祖先位置到当前节点就是一条合法路径。回溯时把当前前缀和从哈希里减回去（避免影响其它分支）。

## 思路

dict 计 `前缀和 → 出现次数`，初始 `{0: 1}`（表示"空路径"）。DFS：算 cur → 累加答案 `count[cur - target]` → 把 cur 加入字典 → 递归左右 → 回溯时把 cur 减回。

## 代码

```python
from collections import defaultdict

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def pathSum(self, root: TreeNode | None, targetSum: int) -> int:
        # count[s] = "从根到当前路径上"前缀和为 s 的节点数（路径上）
        count = defaultdict(int)
        # 初始放一个 {0: 1}，表示"从根开始的整条路径"也可以算（cur - 0 = cur 时直接命中）
        count[0] = 1
        self.ans = 0
        def dfs(node: TreeNode | None, cur: int) -> None:
            if not node:
                return
            cur += node.val
            # 找 (cur - targetSum) 这个前缀和在祖先链中出现的次数
            # 每一次匹配代表"那个祖先位置到当前节点"是一条和为 target 的路径
            self.ans += count[cur - targetSum]
            # 当前前缀和进入字典，供下层使用
            count[cur] += 1
            # 递归左右
            dfs(node.left, cur)
            dfs(node.right, cur)
            # 回溯：退出本节点时撤销其贡献，避免影响兄弟分支
            count[cur] -= 1
        dfs(root, 0)
        return self.ans
```

## 复杂度

- 时间：O(n)
- 空间：O(n)（哈希表 + 递归栈）

## 易错点

- **回溯时一定要 `count[cur] -= 1`**，否则左子树的前缀和会污染右子树的搜索。
- 初始字典必须有 `count[0] = 1`，否则"从根开始的整条路径恰好等于 target"会漏算。
- 题目允许节点值为负，所以前缀和不一定递增，必须用哈希查找。
