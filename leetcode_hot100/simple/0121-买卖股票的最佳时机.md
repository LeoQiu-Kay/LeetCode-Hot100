# 121. 买卖股票的最佳时机

- LeetCode 题号：121
- 难度：简单
- 英文标题：Best Time to Buy and Sell Stock
- 链接：https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/

---

给定一个数组 `prices` ，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。

你只能选择 **某一天** 买入这只股票，并选择在 **未来的某一个不同的日子** 卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 `0` 。



**示例 1：**

```
输入：[7,1,5,3,6,4]
输出：5
解释：在第 2 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 6）的时候卖出，最大利润 = 6-1 = 5 。
     注意利润不能是 7-1 = 6, 因为卖出价格需要大于买入价格；同时，你不能在买入前卖出股票。
```

**示例 2：**

```
输入：prices = [7,6,4,3,1]
输出：0
解释：在这种情况下, 没有交易完成, 所以最大利润为 0。
```



**提示：**

- `1 <= prices.length <= 10⁵`

- `0 <= prices[i] <= 10⁴`

---

## 直觉 / 记忆点

> 你只能买一次、卖一次。一边逐天往后看，一边在脑子里记着"到今天为止见过的最低价"。每到一天就问自己一句"如果今天卖，赚多少 = 今天价 − 历史最低价"。把所有这种"今天卖"的利润里挑最大的，亏本就不操作（下界 0）。

## 思路

只能买卖一次，等价于"找一个数对 `(i, j)`，`i < j`，使 `prices[j] - prices[i]` 最大"。一次遍历：维护到目前为止见到的最低买入价 `lo`，每个 `p` 更新答案 `p - lo`。

## 代码

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        # lo 维护"到目前为止见到的最低买入价"，初始设为正无穷
        lo = float("inf")
        # ans 是最大利润，下界 0（不操作）
        ans = 0
        # 一次遍历每天的价格
        for p in prices:
            # 先更新历史最低（保证 lo <= p，且 lo 出现在 p 之前或同位）
            lo = min(lo, p)
            # 再计算"今天卖"的利润，更新答案
            ans = max(ans, p - lo)
        return ans
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- 答案下界是 0（一笔都不做），不要返回负数。
- 必须**先更新 lo 再算差价**，保证买入在当前位置之前或同位（差价 0 不亏）。
