# 283. 移动零

- LeetCode 题号：283
- 难度：简单
- 英文标题：Move Zeroes
- 链接：https://leetcode.cn/problems/move-zeroes/

---

给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序。

**请注意** ，必须在不复制数组的情况下原地对数组进行操作。



**示例 1:**

```
输入: nums = `[0,1,0,3,12]`
输出: `[1,3,12,0,0]`
```

**示例 2:**

```
输入: nums = `[0]`
输出: `[0]`
```



**提示**:

- `1 <= nums.length <= 10⁴`

- `-2³¹ <= nums[i] <= 2³¹ - 1`



**进阶：** 你能尽量减少完成的操作次数吗？

---

## 直觉 / 记忆点

> 一队学生里非零的"留下"、零的"去后排"。你扫一遍数组，左手 `i` 始终停在"下一个非零该填的格子"。遇到非零就把它和 `i` 处交换并 `i++`；零留在原地等着以后被换到后排。最后非零按原序在前，零自然全到后面。

## 思路

双指针。`i` 指向下一个非零应该填入的位置，`j` 扫描全数组。遇到非零就和 `i` 交换并 `i += 1`。最终前 `i` 个是按原序的非零，后面自动是 0。

## 代码

```python
class Solution:
    def moveZeroes(self, nums: list[int]) -> None:
        # i 是"下一个非零应该填入的位置"
        i = 0
        # j 扫描整个数组
        for j, x in enumerate(nums):
            if x != 0:
                # 遇到非零：和 i 位置交换
                # 这样既保证 i 之前都是按原序的非零，又把 0 推到后面
                nums[i], nums[j] = nums[j], nums[i]
                # i 前进一格，准备接收下一个非零
                i += 1
        # 注意：函数不返回值（原地修改 nums）
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- 要**原地修改**，函数没有返回值（题目要求 `Do not return anything`）。
- 用 "把非零先压到前面、剩下填 0" 也可以但是写两次循环；交换法一遍搞定且保持非零相对顺序。
