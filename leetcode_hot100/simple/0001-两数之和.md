# 1. 两数之和

- LeetCode 题号：1
- 难度：简单
- 英文标题：Two Sum
- 链接：https://leetcode.cn/problems/two-sum/

---

给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出 **和为目标值 ***`target`*  的那 **两个** 整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。

你可以按任意顺序返回答案。



**示例 1：**

```
输入：nums = [2,7,11,15], target = 9
输出：[0,1]
解释：因为 nums[0] + nums[1] == 9 ，返回 [0, 1] 。
```

**示例 2：**

```
输入：nums = [3,2,4], target = 6
输出：[1,2]
```

**示例 3：**

```
输入：nums = [3,3], target = 6
输出：[0,1]
```



**提示：**

- `2 <= nums.length <= 10⁴`

- `-10⁹ <= nums[i] <= 10⁹`

- `-10⁹ <= target <= 10⁹`

- **只会存在一个有效答案**



**进阶：**你可以想出一个时间复杂度小于 `O(n²)` 的算法吗？

---

## 直觉 / 记忆点

> 像在书店给朋友凑一对配对的书，你边翻边在小本子上记下"书名 → 它在第几排"。下一本书来时，先翻小本子看有没有它的"另一半"——有就立刻配对成功，没有就把它也登记进去等下一本来配。这个小本子就是哈希表，**先查再登记**，否则同一本书可能被自己配对。

## 思路

哈希表存"值 → 下标"。遍历 `nums`，对每个 `x` 看 `target - x` 是否已经在表里。第一次进入循环时表是空的，所以**先查后存**就不会让一个元素被用两次。

## 代码

```python
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        # 哈希表：键是"出现过的数值"，值是它的下标
        seen: dict[int, int] = {}
        # 遍历数组，i 是当前下标，x 是当前数值
        for i, x in enumerate(nums):
            # 计算"凑成 target 还差多少"
            need = target - x
            # 如果差值之前出现过，说明配对成功
            if need in seen:
                # 返回那个数的下标和当前下标
                return [seen[need], i]
            # 没配上就把当前数登记进哈希表，留给后面的数来配
            seen[x] = i
        # 题目保证有解，理论上走不到这里
        return []
```

## 复杂度

- 时间：O(n)
- 空间：O(n)

## 易错点

- 必须**先查再存**，否则 `nums = [3,3], target = 6` 会返回 `[0,0]`。
- 题目保证恰好一个解，不需要处理多解。
