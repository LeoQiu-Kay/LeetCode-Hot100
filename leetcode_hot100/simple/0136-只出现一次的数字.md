# 136. 只出现一次的数字

- LeetCode 题号：136
- 难度：简单
- 英文标题：Single Number
- 链接：https://leetcode.cn/problems/single-number/

---

给你一个 **非空** 整数数组 `nums` ，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。



**示例 1 ：**

**输入：** nums = [2,2,1]

**输出：** 1

**示例 2 ：**

**输入：** nums = [4,1,2,1,2]

**输出：** 4

**示例 3 ：**

**输入：** nums = [1]

**输出：** 1



**提示：**

- `1 <= nums.length <= 3 * 10⁴`

- `-3 * 10⁴ <= nums[i] <= 3 * 10⁴`

- 除了某个元素只出现一次以外，其余每个元素均出现两次。

---

## 直觉 / 记忆点

> 想象一个"配对消除"机器：每对相同的数字一进去就互相抵消变成 0，单身的那个会一路活到最后。异或就是这台机器：`a ^ a = 0`（同类相消）、`a ^ 0 = a`（不和空气抵消）、顺序怎么换都不影响结果。

## 思路

利用异或的两条性质：`a ^ a = 0`、`a ^ 0 = a`、满足交换/结合律。把所有数全部异或，成对的互相抵消为 0，只剩那个出现一次的数。

## 代码

```python
from functools import reduce
from operator import xor

class Solution:
    def singleNumber(self, nums: list[int]) -> int:
        # reduce(xor, nums) 等价于 nums[0] ^ nums[1] ^ ... ^ nums[-1]
        # 利用 a ^ a = 0、a ^ 0 = a，所有"成对"的数字会自相抵消
        # 最终剩下的就是那个只出现一次的数
        return reduce(xor, nums)
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- 题目限定"其它每个元素恰好出现两次"才能用 XOR；出现三次的版本是另一道题。
- 不需要排序或哈希表（题目要求 O(1) 额外空间）。
