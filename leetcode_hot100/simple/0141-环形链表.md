# 141. 环形链表

- LeetCode 题号：141
- 难度：简单
- 英文标题：Linked List Cycle
- 链接：https://leetcode.cn/problems/linked-list-cycle/

---

给你一个链表的头节点 `head` ，判断链表中是否有环。

如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。 为了表示给定链表中的环，评测系统内部使用整数 `pos` 来表示链表尾连接到链表中的位置（索引从 0 开始）。**注意：`pos` 不作为参数进行传递 **。仅仅是为了标识链表的实际情况。

*如果链表中存在环* ，则返回 `true` 。 否则，返回 `false` 。



**示例 1：**

![](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2018/12/07/circularlinkedlist.png)

```
输入：head = [3,2,0,-4], pos = 1
输出：true
解释：链表中有一个环，其尾部连接到第二个节点。
```

**示例 2：**

![](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2018/12/07/circularlinkedlist_test2.png)

```
输入：head = [1,2], pos = 0
输出：true
解释：链表中有一个环，其尾部连接到第一个节点。
```

**示例 3：**

![](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2018/12/07/circularlinkedlist_test3.png)

```
输入：head = [1], pos = -1
输出：false
解释：链表中没有环。
```



**提示：**

- 链表中节点的数目范围是 `[0, 10⁴]`

- `-10⁵ <= Node.val <= 10⁵`

- `pos` 为 `-1` 或者链表中的一个 **有效索引** 。



**进阶：**你能用 `O(1)`（即，常量）内存解决此问题吗？

---

## 直觉 / 记忆点

> 操场上两个人跑步：慢的每秒走 1 步，快的每秒走 2 步。如果跑道是**直线**，快的会先冲出终点（指针撞到 `None`）；如果跑道是**圆形**，每过一秒快的相对慢的多走一步，相当于在圆环里以"速度 1"追，最多绕一圈就一定追上——两人在同一节点重合，就是环存在的铁证。

## 思路

Floyd 龟兔赛跑：慢指针每次走 1 步，快指针每次走 2 步。若有环，两者**必然**相遇；若无环，快指针先到 `None`。

## 代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def hasCycle(self, head: ListNode | None) -> bool:
        # 两指针都从头出发：slow 每次走 1 步，fast 每次走 2 步
        slow = fast = head
        # 只要 fast 还能往前走两步，就继续；否则说明遇到链尾（无环）
        while fast and fast.next:
            slow = slow.next          # 慢指针走 1 步
            fast = fast.next.next     # 快指针走 2 步
            # 用 is 比较节点对象本身是否相同（同一个引用），不是比较 val
            if slow is fast:
                return True
        # 跳出循环说明 fast 走到 None，无环
        return False
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- 判 `fast` 和 `fast.next` 都不为空再走两步，否则空指针。
- 相遇判定用 `is`（同一节点对象）；不要用 `==`（会按 `val` 比较自定义类型时行为可能不对）。
