# 70. 爬楼梯

- LeetCode 题号：70
- 难度：简单
- 英文标题：Climbing Stairs
- 链接：https://leetcode.cn/problems/climbing-stairs/

---

假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。

每次你可以爬 `1` 或 `2` 个台阶。你有多少种不同的方法可以爬到楼顶呢？



**示例 1：**

```
输入：n = 2
输出：2
解释：有两种方法可以爬到楼顶。
1. 1 阶 + 1 阶
2. 2 阶
```

**示例 2：**

```
输入：n = 3
输出：3
解释：有三种方法可以爬到楼顶。
1. 1 阶 + 1 阶 + 1 阶
2. 1 阶 + 2 阶
3. 2 阶 + 1 阶
```



**提示：**

- `1 <= n <= 45`

---

## 直觉 / 记忆点

> 站在第 `n` 阶，回头看最后一脚怎么上来的：要么从 `n−1` 阶迈了 1 步，要么从 `n−2` 阶跨了 2 步。所以"上到第 n 阶的方法数 = 上到 n−1 的方法数 + 上到 n−2 的方法数"。从 1、2 阶开始一路累加就是斐波那契，**两个变量滚动**即可。

## 思路

到第 `n` 阶的方法数 `f(n) = f(n-1) + f(n-2)`（上一步走 1 或 2），等价于斐波那契。用两个变量滚动，把空间压到 O(1)。

## 代码

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        # a 表示 f(0)、b 表示 f(1)，都视为 1 种方案
        a, b = 1, 1
        # 滚动 n 次，每次让 (a, b) 变成 (b, a+b)
        # 含义：原本的 b 变成新 a，原本的 a+b 变成新 b
        for _ in range(n):
            a, b = b, a + b
        # 滚动 n 次后，a 恰好等于 f(n)
        return a
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- 初始值 `f(0) = f(1) = 1`（爬 0 阶视为一种"不爬"方案）。
- 循环 `n` 次后 `a == f(n)`，写错偏移容易差 1。
