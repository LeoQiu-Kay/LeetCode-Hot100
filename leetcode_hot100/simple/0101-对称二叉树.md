# 101. 对称二叉树

- LeetCode 题号：101
- 难度：简单
- 英文标题：Symmetric Tree
- 链接：https://leetcode.cn/problems/symmetric-tree/

给你一个二叉树的根节点 `root` ， 检查它是否轴对称。



**示例 1：**

![](https://pic.leetcode.cn/1698026966-JDYPDU-image.png)

```
输入：root = [1,2,2,3,4,4,3]
输出：true
```

**示例 2：**

![](https://pic.leetcode.cn/1698027008-nPFLbM-image.png)

```
输入：root = [1,2,2,null,3,null,3]
输出：false
```



**提示：**

- 树中节点数目在范围 `[1, 1000]` 内

- `-100 <= Node.val <= 100`



**进阶：** 你可以运用递归和迭代两种方法解决这个问题吗？

---

## 直觉 / 记忆点

> 把树从中间竖着对折，看左右半边能不能完全重叠。所以要**对偶**地比：左半的左孩子 vs 右半的右孩子（外侧对外侧），左半的右孩子 vs 右半的左孩子（内侧对内侧）。两个都空算重合，只空一个就破对称。

## 思路

对称 = "左子树" 与 "右子树" 互为镜像。递归比较：`same(a, b)` 要求 `a.val == b.val` 且 `a.left ↔ b.right`、`a.right ↔ b.left`。

## 代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def isSymmetric(self, root: TreeNode | None) -> bool:
        # 子函数：判断两棵子树是否互为镜像
        def same(a: TreeNode | None, b: TreeNode | None) -> bool:
            # 两个都空：成功对称
            if not a and not b:
                return True
            # 只有一个空：不对称
            if not a or not b:
                return False
            # 值要相等；并且：
            #   a 的左 ↔ b 的右（外侧对外侧）
            #   a 的右 ↔ b 的左（内侧对内侧）
            return a.val == b.val and same(a.left, b.right) and same(a.right, b.left)
        # 空树视为对称；否则比较左右子树
        return not root or same(root.left, root.right)
```

## 复杂度

- 时间：O(n)
- 空间：O(h)

## 易错点

- 比较的是**两棵子树之间的镜像**，不是同一棵的左右子节点值相等。
- 两个都空返回 `True`，**只有一个空**返回 `False`，顺序别写反。
