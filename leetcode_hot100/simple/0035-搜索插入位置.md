# 35. 搜索插入位置

- LeetCode 题号：35
- 难度：简单
- 英文标题：Search Insert Position
- 链接：https://leetcode.cn/problems/search-insert-position/

---

给定一个排序数组和一个目标值，在数组中找到目标值，并返回其索引。如果目标值不存在于数组中，返回它将会被按顺序插入的位置。

请必须使用时间复杂度为 `O(log n)` 的算法。



**示例 1:**

```
输入: nums = [1,3,5,6], target = 5
输出: 2
```

**示例 2:**

```
输入: nums = [1,3,5,6], target = 2
输出: 1
```

**示例 3:**

```
输入: nums = [1,3,5,6], target = 7
输出: 4
```



**提示:**

- `1 <= nums.length <= 10⁴`

- `-10⁴ <= nums[i] <= 10⁴`

- `nums` 为 **无重复元素 **的 **升序 **排列数组

- `-10⁴ <= target <= 10⁴`

---

## 直觉 / 记忆点

> 你按身高站队，新同学要插队找合适位置：每次和**中间那位**比身高，比他矮就到他左半边继续比，不矮就到他右半边（包括他）继续比。直到剩一个位置——这就是新同学该站的格子，无论队里原来有没有同身高的人。

## 思路

二分查找下界（lower_bound）：找第一个 `>= target` 的位置。用半开区间 `[lo, hi)`，结束时 `lo == hi` 就是答案；若数组中存在 `target` 也会落在该位置。

## 代码

```python
class Solution:
    def searchInsert(self, nums: list[int], target: int) -> int:
        # 半开区间 [lo, hi)：lo 是下界、hi 是"超过末尾"的位置
        # hi 取 len(nums) 是因为答案可能等于数组长度（插在末尾）
        lo, hi = 0, len(nums)
        while lo < hi:
            # 取中点（向下取整，对半开区间不会越界）
            mid = (lo + hi) // 2
            if nums[mid] < target:
                # 中点比 target 小，答案一定在 mid 右边
                lo = mid + 1
            else:
                # 中点 >= target，mid 自己也可能是答案，所以 hi = mid 不是 mid - 1
                hi = mid
        # 循环结束 lo == hi，就是第一个 >= target 的位置（即插入点）
        return lo
```

## 复杂度

- 时间：O(log n)
- 空间：O(1)

## 易错点

- `hi = len(nums)` 而不是 `len(nums) - 1`，因为答案可能 = 数组长度（插到末尾）。
- 半开区间下，循环条件用 `<`，`hi = mid`（不要 `mid - 1`）。
