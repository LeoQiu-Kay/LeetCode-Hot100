# 234. 回文链表

- LeetCode 题号：234
- 难度：简单
- 英文标题：Palindrome Linked List
- 链接：https://leetcode.cn/problems/palindrome-linked-list/

---

给你一个单链表的头节点 `head` ，请你判断该链表是否为回文链表。如果是，返回 `true` ；否则，返回 `false` 。



**示例 1：**

![](https://assets.leetcode.com/uploads/2021/03/03/pal1linked-list.jpg)

```
输入：head = [1,2,2,1]
输出：true
```

**示例 2：**

![](https://assets.leetcode.com/uploads/2021/03/03/pal2linked-list.jpg)

```
输入：head = [1,2]
输出：false
```



**提示：**

- 链表中节点数目在范围`[1, 10⁵]` 内

- `0 <= Node.val <= 9`



**进阶：** 你能否用 `O(n)` 时间复杂度和 `O(1)` 空间复杂度解决此题？

---

## 直觉 / 记忆点

> 判一首诗正反读一样，但只能从头读到尾、不能跳读——三步走：1) **龟兔赛跑找中点**（兔到终点时龟到中央）；2) 把后半段链表**就地反转**；3) 从原头和反转后的后半段同时往后比，逐字对上才是回文。空间 O(1) 的关键就在"反转"那一步。

## 思路

要求 O(1) 空间，三步走：
1. **快慢指针**找到中点（慢指针走到中间）；
2. **反转**后半段链表；
3. 从头和反转后的后半段同时往后比较值，全相等就是回文。

## 代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def isPalindrome(self, head: ListNode | None) -> bool:
        # 1. 用快慢指针找中点（fast 走到尽头时 slow 在中央/中右）
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
        # 2. 从 slow 开始，把后半段链表就地反转（用 206 的三指针法）
        prev = None
        while slow:
            # 这一行是 206 的三步合并：先存下一个、改指向、整体右移
            slow.next, prev, slow = prev, slow, slow.next
        # 3. 用反转后的后半段（prev）和原链表头同步比对
        while prev:
            if prev.val != head.val:
                return False
            prev = prev.next
            head = head.next
        # 后半段全部比完即回文（即使原链表长度奇数，中点不影响判定）
        return True
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- 偶数长度时慢指针落在中右；奇数时落在正中央。两种情况下反转后两段长度差最多 1，**用反转后那段作为循环终止条件**即可避免越界。
- 用列表 `vals = [...]; return vals == vals[::-1]` 也能过，但是 O(n) 空间；面试要写 O(1)。
