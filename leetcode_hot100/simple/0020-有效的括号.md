# 20. 有效的括号

- LeetCode 题号：20
- 难度：简单
- 英文标题：Valid Parentheses
- 链接：https://leetcode.cn/problems/valid-parentheses/

---

给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s` ，判断字符串是否有效。

有效字符串需满足：

- 左括号必须用相同类型的右括号闭合。

- 左括号必须以正确的顺序闭合。

- 每个右括号都有一个对应的相同类型的左括号。



**示例 1：**

**输入：**s = "()"

**输出：**true

**示例 2：**

**输入：**s = "()[]{}"

**输出：**true

**示例 3：**

**输入：**s = "(]"

**输出：**false

**示例 4：**

**输入：**s = "([])"

**输出：**true

**示例 5：**

**输入：**s = "([)]"

**输出：**false



**提示：**

- `1 <= s.length <= 10⁴`

- `s` 仅由括号 `'()[]{}'` 组成

---

## 直觉 / 记忆点

> 进游乐场每种括号是一种印章：进门盖左印章（入栈），出门要核对**右印章**和最后那个盖的左印章是否成对。遇到对不上、或者还没盖过就要出门——立刻判违规。最后所有人都成功出去（**栈空**）才算合法。

## 思路

栈匹配。遇到左括号入栈；遇到右括号检查栈顶是否是对应的左括号，匹配则弹出，否则非法。遍历结束栈必须为空。

## 代码

```python
class Solution:
    def isValid(self, s: str) -> bool:
        # 右括号 → 对应的左括号，用于核对
        pair = {')': '(', ']': '[', '}': '{'}
        # 栈：存放尚未配对的左括号
        stack: list[str] = []
        # 遍历每个字符
        for c in s:
            # 如果是右括号
            if c in pair:
                # 栈空说明没有左括号可以匹配；或者栈顶左括号类型不对
                if not stack or stack.pop() != pair[c]:
                    return False
            else:
                # 左括号直接入栈，等右括号来配对
                stack.append(c)
        # 全部扫完后栈必须空，否则有未闭合的左括号
        return not stack
```

## 复杂度

- 时间：O(n)
- 空间：O(n)

## 易错点

- 结束时**栈必须为空**，否则 `"(("` 也会被判为合法。
- 右括号到来时若栈为空，直接 `False`（不能 pop 空栈）。
