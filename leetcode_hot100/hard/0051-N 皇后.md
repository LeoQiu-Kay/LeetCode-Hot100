# 51. N 皇后

- LeetCode 题号：51
- 难度：困难
- 英文标题：N-Queens
- 链接：https://leetcode.cn/problems/n-queens/

---

按照国际象棋的规则，皇后可以攻击与之处在同一行或同一列或同一斜线上的棋子。

**n 皇后问题** 研究的是如何将 `n` 个皇后放置在 `n×n` 的棋盘上，并且使皇后彼此之间不能相互攻击。

给你一个整数 `n` ，返回所有不同的 **n* *皇后问题** 的解决方案。

每一种解法包含一个不同的 **n 皇后问题** 的棋子放置方案，该方案中 `'Q'` 和 `'.'` 分别代表了皇后和空位。



**示例 1：**

![](https://assets.leetcode.com/uploads/2020/11/13/queens.jpg)

```
输入：n = 4
输出：[[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]
解释：如上图所示，4 皇后问题存在两个不同的解法。
```

**示例 2：**

```
输入：n = 1
输出：[["Q"]]
```



**提示：**

- `1 <= n <= 9`

---

## 直觉 / 记忆点

> 按行 DFS（一行只能放一个皇后）。维护三个 set 标记当前被占用的：**列**、**主对角线**（row - col 常数）、**副对角线**（row + col 常数）。每行枚举列：三个 set 都没占用就放下，递归下一行，回溯撤销。

## 思路

DFS(row, cols, diag1, diag2, path)。row == n 收集结果。

## 代码

```python
class Solution:
    def solveNQueens(self, n: int) -> list[list[str]]:
        ans: list[list[str]] = []
        cols: set[int] = set()      # 已被占用的列
        diag1: set[int] = set()     # 主对角线：row - col 相同的属于同一条
        diag2: set[int] = set()     # 副对角线：row + col 相同的属于同一条
        path: list[int] = []        # path[i] 表示第 i 行皇后所在的列
        def dfs(row: int) -> None:
            if row == n:
                # 把列号方案转成棋盘字符串
                ans.append(['.' * c + 'Q' + '.' * (n - c - 1) for c in path])
                return
            for col in range(n):
                # 当前位置被任一约束占用，跳过
                if col in cols or (row - col) in diag1 or (row + col) in diag2:
                    continue
                # 放下皇后，登记三个约束
                cols.add(col)
                diag1.add(row - col)
                diag2.add(row + col)
                path.append(col)
                dfs(row + 1)
                # 回溯：撤销四个状态
                cols.remove(col)
                diag1.remove(row - col)
                diag2.remove(row + col)
                path.pop()
        dfs(0)
        return ans
```

## 复杂度

- 时间：O(n!)（剪枝后）
- 空间：O(n)

## 易错点

- 三条约束：**列、主对角线、副对角线**，缺一不可。主对角线常数是 `row - col`，副对角线是 `row + col`。
- 回溯时四个状态都要撤销：cols、diag1、diag2、path。
