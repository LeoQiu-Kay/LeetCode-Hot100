# 4. 寻找两个正序数组的中位数

- LeetCode 题号：4
- 难度：困难
- 英文标题：Median of Two Sorted Arrays
- 链接：https://leetcode.cn/problems/median-of-two-sorted-arrays/

---

给定两个大小分别为 `m` 和 `n` 的正序（从小到大）数组 `nums1` 和 `nums2`。请你找出并返回这两个正序数组的 **中位数** 。

算法的时间复杂度应该为 `O(log (m+n))` 。



**示例 1：**

```
输入：nums1 = [1,3], nums2 = [2]
输出：2.00000
解释：合并数组 = [1,2,3] ，中位数 2
```

**示例 2：**

```
输入：nums1 = [1,2], nums2 = [3,4]
输出：2.50000
解释：合并数组 = [1,2,3,4] ，中位数 (2 + 3) / 2 = 2.5
```





**提示：**

- `nums1.length == m`

- `nums2.length == n`

- `0 <= m <= 1000`

- `0 <= n <= 1000`

- `1 <= m + n <= 2000`

- `-10⁶ <= nums1[i], nums2[i] <= 10⁶`

---

## 直觉 / 记忆点

> O(log(m+n)) 必须二分。在**较短数组**上二分一个切分位置 `i`，对应另一数组的切分位置 `j` 满足 `i + j = (m+n+1)//2`（左半元素数 = 总长一半，奇数时左多一个）。合法切分要求：`A 左边 <= B 右边` 且 `B 左边 <= A 右边`。

## 思路

二分较短数组的左半长度 i ∈ [0, m]，对应 j = (m+n+1)//2 - i。检查四个边界值的大小关系决定缩左还是缩右。

## 代码

```python
class Solution:
    def findMedianSortedArrays(self, nums1: list[int], nums2: list[int]) -> float:
        # 保证 nums1 较短（在短的那个上二分，效率更高）
        if len(nums1) > len(nums2):
            nums1, nums2 = nums2, nums1
        m, n = len(nums1), len(nums2)
        # half 是"左半部分"应该包含的元素总数（奇数时左多一个）
        half = (m + n + 1) // 2
        lo, hi = 0, m
        while lo <= hi:
            # i 是 nums1 中"分到左半"的元素个数
            i = (lo + hi) // 2
            # j 是 nums2 中相应的元素个数（保证 i + j == half）
            j = half - i
            # 四个边界值；用 ±inf 处理 i / j 在两端的边界
            A_left = nums1[i - 1] if i > 0 else float("-inf")
            A_right = nums1[i] if i < m else float("inf")
            B_left = nums2[j - 1] if j > 0 else float("-inf")
            B_right = nums2[j] if j < n else float("inf")
            # 合法切分：A 左边 <= B 右边 且 B 左边 <= A 右边
            if A_left <= B_right and B_left <= A_right:
                if (m + n) % 2 == 1:
                    # 总长奇数：中位数 = 两个左边里更大的（左半比右半多 1）
                    return float(max(A_left, B_left))
                # 总长偶数：(左半 max + 右半 min) / 2
                return (max(A_left, B_left) + min(A_right, B_right)) / 2
            elif A_left > B_right:
                # A 左边太大 → i 太大，需要往左缩
                hi = i - 1
            else:
                # B 左边太大 → i 太小，需要往右增
                lo = i + 1
        return 0.0   # 理论上不会到这里
```

## 复杂度

- 时间：O(log(min(m, n)))
- 空间：O(1)

## 易错点

- 一定要在**较短数组**上二分（保证 lo/hi 范围最小、效率最高、并避免 j 越界）。
- ±inf 哨兵处理 i 或 j 在两端的边界情况，比写一堆 if 简洁得多。
- `half = (m + n + 1) // 2` 用 `+1` 是为了奇数时让左半多一个元素，这样奇数时中位数直接是左半最大值。
