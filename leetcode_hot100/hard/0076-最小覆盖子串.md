# 76. 最小覆盖子串

- LeetCode 题号：76
- 难度：困难
- 英文标题：Minimum Window Substring
- 链接：https://leetcode.cn/problems/minimum-window-substring/

---

给定两个字符串 `s` 和 `t`，长度分别是 `m` 和 `n`，返回 s 中的 **最短窗口 子串**，使得该子串包含 `t` 中的每一个字符（**包括重复字符**）。如果没有这样的子串，返回空字符串* *`""`。

测试用例保证答案唯一。



**示例 1：**

```
输入：s = "ADOBECODEBANC", t = "ABC"
输出："BANC"
解释：最小覆盖子串 "BANC" 包含来自字符串 t 的 'A'、'B' 和 'C'。
```

**示例 2：**

```
输入：s = "a", t = "a"
输出："a"
解释：整个字符串 s 是最小覆盖子串。
```

**示例 3:**

```
输入: s = "a", t = "aa"
输出: ""
解释: t 中两个字符 'a' 均应包含在 s 的子串中，
因此没有符合条件的子字符串，返回空字符串。
```



**提示：**

- `m == s.length`

- `n == t.length`

- `1 <= m, n <= 10⁵`

- `s` 和 `t` 由英文字母组成



**进阶：** 你能设计一个在 `O(m + n)` 时间内解决此问题的算法吗？

---

## 直觉 / 记忆点

> **变长**滑动窗口。右指针扩张到"窗口覆盖了 t 所有字符"，然后左指针收缩到"刚好不再覆盖"，过程中记录最小窗口。用"还需要的字符数 `need`"代替整张计数表的比较：每个字符的需求 -1 时，若它原本是需要的（cnt > 0），need -= 1；左缩时反向操作。

## 思路

`need = len(t)`（实际还需要凑齐的字符次数总和）；`cnt[c]` 表示"窗口外还需要的 c 的个数"，可负。

## 代码

```python
from collections import Counter

class Solution:
    def minWindow(self, s: str, t: str) -> str:
        if not t or not s:
            return ""
        # cnt[c] > 0 表示窗口外还差几个 c；< 0 表示窗口里多了几个 c
        cnt = Counter(t)
        need = len(t)        # 还需要凑的字符总数（重复也算）
        l = 0
        best = (float("inf"), 0, 0)   # (长度, 起点, 终点+1)
        for r, c in enumerate(s):
            # 这个字符是 t 需要的（cnt[c] > 0），凑一个就让 need -= 1
            if cnt[c] > 0:
                need -= 1
            cnt[c] -= 1
            # 窗口已覆盖 t 时，尝试左缩
            while need == 0:
                if r - l + 1 < best[0]:
                    best = (r - l + 1, l, r + 1)
                # 左端字符出窗口
                cnt[s[l]] += 1
                # 出窗口后 cnt > 0 说明这个字符是 t 需要的且现在不够了
                if cnt[s[l]] > 0:
                    need += 1
                l += 1
        return s[best[1]:best[2]] if best[0] != float("inf") else ""
```

## 复杂度

- 时间：O(|s| + |t|)
- 空间：O(|s| + |t|)

## 易错点

- 用 `need` 单变量代替整个计数表比较，是窗口题的常见优化。
- 左缩时**先**更新 cnt 再判断"是否打破覆盖"：`cnt[s[l]] += 1` 后若变正说明缺了它，need += 1。
