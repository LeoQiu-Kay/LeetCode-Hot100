# 41. 缺失的第一个正数

- LeetCode 题号：41
- 难度：困难
- 英文标题：First Missing Positive
- 链接：https://leetcode.cn/problems/first-missing-positive/

---

给你一个未排序的整数数组 `nums` ，请你找出其中没有出现的最小的正整数。

请你实现时间复杂度为 `O(n)` 并且只使用常数级别额外空间的解决方案。



**示例 1：**

```
输入：nums = [1,2,0]
输出：3
解释：范围 [1,2] 中的数字都在数组中。
```

**示例 2：**

```
输入：nums = [3,4,-1,1]
输出：2
解释：1 在数组中，但 2 没有。
```

**示例 3：**

```
输入：nums = [7,8,9,11,12]
输出：1
解释：最小的正数 1 没有出现。
```



**提示：**

- `1 <= nums.length <= 10⁵`

- `-2³¹ <= nums[i] <= 2³¹ - 1`

---

## 直觉 / 记忆点

> 答案必在 `[1, n+1]` 中（n = len(nums)）。**原地哈希**：把每个正数 x（1 ≤ x ≤ n）放到下标 `x - 1` 的位置。然后扫一遍：第一个 `nums[i] != i + 1` 的位置 i，答案就是 `i + 1`；都对的话答案是 `n + 1`。

## 思路

while 循环就地交换："如果 nums[i] 在合法范围内且没放在正确位置上，就和目标位置交换"。

## 代码

```python
class Solution:
    def firstMissingPositive(self, nums: list[int]) -> int:
        n = len(nums)
        # 第一步：让每个 1..n 的数尽量放到下标 nums[i] - 1 处
        i = 0
        while i < n:
            x = nums[i]
            # x 在 [1, n] 范围内 且 它该去的位置（x-1）还没有 x（避免相等时死循环）
            if 1 <= x <= n and nums[x - 1] != x:
                # 把 x 换到正确位置；换过来的元素继续在当前位置 i 处理（i 不前进）
                nums[i], nums[x - 1] = nums[x - 1], nums[i]
            else:
                i += 1
        # 第二步：找第一个"位置不对"的下标，答案是 i + 1
        for i in range(n):
            if nums[i] != i + 1:
                return i + 1
        # 所有位置都对，说明 1..n 全在，答案是 n + 1
        return n + 1
```

## 复杂度

- 时间：O(n)（每次交换至少把一个数放对位置，总交换次数 ≤ n）
- 空间：O(1)

## 易错点

- 交换的判定 `nums[x - 1] != x` 是为了**防死循环**：x 已经在正确位置时不再交换。
- 交换后 i **不前进**：换过来的新值还没检查，下一轮还在同一个 i。
- 答案范围是 [1, n+1]，所以最坏返回 n + 1（数组里恰好是 1..n）。
