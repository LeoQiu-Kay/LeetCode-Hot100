# 84. 柱状图中最大的矩形

- LeetCode 题号：84
- 难度：困难
- 英文标题：Largest Rectangle in Histogram
- 链接：https://leetcode.cn/problems/largest-rectangle-in-histogram/

---

给定 *n* 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 1 。

求在该柱状图中，能够勾勒出来的矩形的最大面积。



**示例 1:**

![](https://assets.leetcode.com/uploads/2021/01/04/histogram.jpg)

```
输入：heights = [2,1,5,6,2,3]
输出：10
解释：最大的矩形为图中红色区域，面积为 10
```

**示例 2：**

![](https://assets.leetcode.com/uploads/2021/01/04/histogram-1.jpg)

```
输入： heights = [2,4]
输出： 4
```



**提示：**

- `1 <= heights.length <=10⁵`

- `0 <= heights[i] <= 10⁴`

---

## 直觉 / 记忆点

> 以每根柱子为"矩形高度"，找它能向左右扩展的最大宽度——即左右两侧第一个比它**矮**的位置。**单调递增栈**一次扫描搞定：栈里存"还没结算的柱子下标"，对应高度严格递增。新柱子比栈顶矮时，弹出栈顶并立刻结算它的最大矩形（左边界 = 弹出后新栈顶 + 1，右边界 = 当前下标 - 1）。在数组两侧补哨兵 0 简化边界。

## 思路

`heights + [0]` 末尾加个 0 哨兵，保证最后栈里所有柱子都能被弹出结算。栈底放 -1 当左边界哨兵，省去判空。

## 代码

```python
class Solution:
    def largestRectangleArea(self, heights: list[int]) -> int:
        # 末尾加 0 哨兵：保证扫到最后时栈里所有柱子都能被弹出结算
        heights = heights + [0]
        # 栈底放 -1：当作"左边界前一位"的哨兵，结算时 width = i - (-1) - 1 = i
        stack: list[int] = [-1]
        ans = 0
        for i, h in enumerate(heights):
            # 新柱子 h 比栈顶柱子矮：栈顶柱子的"右边界第一个更矮的位置"就是 i
            # 弹出栈顶并结算它能扩展的最大矩形
            while stack[-1] != -1 and heights[stack[-1]] >= h:
                top = stack.pop()
                # 弹出后栈顶就是"左边界第一个更矮的位置"
                # 矩形宽 = 右边界(i) - 左边界(stack[-1]) - 1
                width = i - stack[-1] - 1
                ans = max(ans, heights[top] * width)
            # 当前柱子入栈，等待将来某个更矮的来结算
            stack.append(i)
        return ans
```

## 复杂度

- 时间：O(n)（每根柱子最多入栈、出栈一次）
- 空间：O(n)

## 易错点

- 末尾**必须**加 0 哨兵，否则栈里残留的递增柱子最后没机会结算。
- 栈底放 -1 是经典技巧：让"宽度 = i - 左边界 - 1"在没有更矮左侧时也成立（此时宽度 = i）。
- 单调用 `>=`（栈顶 ≥ 新柱子就弹）：相等也弹，保证算到的是"右边界第一个**严格**更矮"。
