# 295. 数据流的中位数

- LeetCode 题号：295
- 难度：困难
- 英文标题：Find Median from Data Stream
- 链接：https://leetcode.cn/problems/find-median-from-data-stream/

---

**中位数**是有序整数列表中的中间值。如果列表的大小是偶数，则没有中间值，中位数是两个中间值的平均值。

- 例如 `arr = [2,3,4]` 的中位数是 `3` 。

- 例如 `arr = [2,3]` 的中位数是 `(2 + 3) / 2 = 2.5` 。

实现 MedianFinder 类:

-

`MedianFinder()` 初始化 `MedianFinder` 对象。



-

`void addNum(int num)` 将数据流中的整数 `num` 添加到数据结构中。



-

`double findMedian()` 返回到目前为止所有元素的中位数。与实际答案相差 `10⁻⁵` 以内的答案将被接受。



**示例 1：**

```
输入
["MedianFinder", "addNum", "addNum", "findMedian", "addNum", "findMedian"]
[[], [1], [2], [], [3], []]
输出
[null, null, null, 1.5, null, 2.0]

解释
MedianFinder medianFinder = new MedianFinder();
medianFinder.addNum(1);    // arr = [1]
medianFinder.addNum(2);    // arr = [1, 2]
medianFinder.findMedian(); // 返回 1.5 ((1 + 2) / 2)
medianFinder.addNum(3);    // arr[1, 2, 3]
medianFinder.findMedian(); // return 2.0
```

**提示:**

- `-10⁵ <= num <= 10⁵`

- 在调用 `findMedian` 之前，数据结构中至少有一个元素

- 最多 `5 * 10⁴` 次调用 `addNum` 和 `findMedian`

---

## 直觉 / 记忆点

> 用**两个堆**把数据流分两半：
> - **大顶堆 `lo`** 存较小的一半（堆顶 = 这半边的最大）
> - **小顶堆 `hi`** 存较大的一半（堆顶 = 这半边的最小）
>
> 保持两个堆的大小相差 ≤ 1。中位数 = `lo` 多一个时取 lo 顶；相等时取两堆顶平均。

## 思路

heapq 没有大顶堆，把数取负放进去模拟。每次 addNum：先按规则塞一边，再调整两堆大小差。

## 代码

```python
import heapq

class MedianFinder:
    def __init__(self):
        # lo 是大顶堆（存较小一半）；存入时取负，弹出时再取负还原
        self.lo: list[int] = []
        # hi 是小顶堆（存较大一半）
        self.hi: list[int] = []

    def addNum(self, num: int) -> None:
        # 策略：先把 num 放进 lo（大顶堆）
        # 然后从 lo 弹出最大值塞到 hi，相当于做一次"过滤"
        # 这样保证 lo 的所有元素都 <= hi 的所有元素
        heapq.heappush(self.lo, -num)
        heapq.heappush(self.hi, -heapq.heappop(self.lo))
        # 平衡两堆大小：让 lo 比 hi 多 1 个（奇数时）或相等（偶数时）
        if len(self.hi) > len(self.lo):
            heapq.heappush(self.lo, -heapq.heappop(self.hi))

    def findMedian(self) -> float:
        # 总数奇数：lo 多一个，中位数是 lo 顶（注意取负还原）
        if len(self.lo) > len(self.hi):
            return -self.lo[0]
        # 总数偶数：两堆顶平均
        return (-self.lo[0] + self.hi[0]) / 2
```

## 复杂度

- 时间：addNum O(log n)，findMedian O(1)
- 空间：O(n)

## 易错点

- Python heapq 只有小顶堆，用**取负**模拟大顶堆，注意 push 时取负、pop 后再取负还原。
- "先 lo 再 hi 再平衡"的三步法保证任何时候 lo 的所有元素都 ≤ hi 的所有元素。
