# 32. 最长有效括号

- LeetCode 题号：32
- 难度：困难
- 英文标题：Longest Valid Parentheses
- 链接：https://leetcode.cn/problems/longest-valid-parentheses/

---

给你一个只包含 `'('` 和 `')'` 的字符串，找出最长有效（格式正确且连续）括号 子串 的长度。

左右括号匹配，即每个左括号都有对应的右括号将其闭合的字符串是格式正确的，比如 `"(()())"`。



**示例 1：**

```
输入：s = "(()"
输出：2
解释：最长有效括号子串是 "()"
```

**示例 2：**

```
输入：s = ")()())"
输出：4
解释：最长有效括号子串是 "()()"
```

**示例 3：**

```
输入：s = ""
输出：0
```



**提示：**

- `0 <= s.length <= 3 * 10⁴`

- `s[i]` 为 `'('` 或 `')'`

---

## 直觉 / 记忆点

> 两种解法都好：
> - **栈解法**：栈底维护"上一个未匹配 ')' 的位置"作为"基准下标"。遇到 '(' 入栈、'(' 与 ')' 配对时弹出，弹出后栈顶即为当前有效串的起点前一位，长度 = i - 栈顶。
> - DP 解法：`dp[i]` = 以 i 结尾的最长有效串长度，分 `s[i] == ')'` 时两种子情况推。
>
> 栈解法代码短、好记。

## 思路

栈初始放 -1（基准前位）。遇 '(' 入栈下标；遇 ')' 先 pop，pop 后若栈空则 push 当前下标当新基准，否则 i - 栈顶就是当前 ans。

## 代码

```python
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        # 栈底放 -1 作为"基准前位"：第一对配上时 i - (-1) 正好得到长度 2
        stack: list[int] = [-1]
        ans = 0
        for i, c in enumerate(s):
            if c == '(':
                # 左括号下标入栈，等右括号来配
                stack.append(i)
            else:
                # 右括号：先 pop 一个出来配对
                stack.pop()
                if not stack:
                    # 栈空说明没有左括号能配 → 当前 ')' 是新的"无效基准"
                    stack.append(i)
                else:
                    # 配对成功，当前有效串长度 = i - 栈顶（基准前位）
                    ans = max(ans, i - stack[-1])
        return ans
```

## 复杂度

- 时间：O(n)
- 空间：O(n)

## 易错点

- 栈底**必须**先放 -1，否则空字符串/首字符就配对的情况算不出长度。
- 弹栈后若栈空说明匹配失败，这个 ')' 自己变成新"基准"。
