# 239. 滑动窗口最大值

- LeetCode 题号：239
- 难度：困难
- 英文标题：Sliding Window Maximum
- 链接：https://leetcode.cn/problems/sliding-window-maximum/

---

给你一个整数数组 `nums`，有一个大小为 `k`* *的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。

返回 *滑动窗口中的最大值 *。



**示例 1：**

```
输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]
解释：
滑动窗口的位置                最大值
---------------               -----
[1  3  -1] -3  5  3  6  7       3
 1 [3  -1  -3] 5  3  6  7       3
 1  3 [-1  -3  5] 3  6  7       5
 1  3  -1 [-3  5  3] 6  7       5
 1  3  -1  -3 [5  3  6] 7       6
 1  3  -1  -3  5 [3  6  7]      7
```

**示例 2：**

```
输入：nums = [1], k = 1
输出：[1]
```



**提示：**

- `1 <= nums.length <= 10⁵`

- `-10⁴ <= nums[i] <= 10⁴`

- `1 <= k <= nums.length`

---

## 直觉 / 记忆点

> **单调递减双端队列**：队列存下标，对应的值从队头到队尾递减。新元素入队前，把队尾所有 ≤ 它的下标都弹出（它们活不到当前窗口结束）；队头若已滑出窗口左边界就弹掉。这样队头永远是当前窗口最大值。

## 思路

deque 存下标。遍历 i：清队头（i - k 已滑出）→ 清队尾（< nums[i]）→ append i → i ≥ k-1 时记录答案 nums[队头]。

## 代码

```python
from collections import deque

class Solution:
    def maxSlidingWindow(self, nums: list[int], k: int) -> list[int]:
        # 双端队列存下标；对应的 nums 值从队头到队尾**严格递减**
        dq: deque[int] = deque()
        ans: list[int] = []
        for i, x in enumerate(nums):
            # 队头下标已滑出窗口左边界（最早只能是 i - k + 1），弹掉
            if dq and dq[0] < i - k + 1:
                dq.popleft()
            # 维护单调递减：从队尾弹出所有 <= x 的下标
            # 它们再也不可能是后续窗口最大值（被 x 替代了）
            while dq and nums[dq[-1]] <= x:
                dq.pop()
            dq.append(i)
            # 窗口装满（i >= k - 1）时记录当前窗口最大值
            if i >= k - 1:
                ans.append(nums[dq[0]])
        return ans
```

## 复杂度

- 时间：O(n)（每个下标最多入队、出队一次）
- 空间：O(k)

## 易错点

- 队列里存**下标**而不是值，否则没法判断"队头是否已滑出"。
- 维护单调用 `<=` 而不是 `<`：相等也弹，保留下标更靠右的（活得更久）。
- 队头滑出的判定 `dq[0] < i - k + 1`（窗口起点是 `i - k + 1`）。
