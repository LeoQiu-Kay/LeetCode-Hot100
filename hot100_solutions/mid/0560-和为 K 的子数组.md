# 560. 和为 K 的子数组

- 难度：中等
- 链接：https://leetcode.cn/problems/subarray-sum-equals-k/

## 直觉 / 记忆点

> 子数组和 = 前缀和差："和为 k 的子数组 [i..j]" ⟺ "`prefix[j+1] - prefix[i] == k`"。所以一边扫一边维护"前缀和 → 出现次数"哈希表：在位置 j，答案累加 `count[当前前缀和 - k]`（之前有多少个前缀和能匹配上）。

## 思路

`count[0] = 1`（空前缀的"前缀和"是 0），cur 累加 `num`，答案 += count[cur - k]，再 count[cur] += 1。

## 代码

```python
from collections import defaultdict

class Solution:
    def subarraySum(self, nums: list[int], k: int) -> int:
        # 前缀和出现次数；count[0] = 1 表示"空前缀"的前缀和是 0，
        # 这样从下标 0 开始且和为 k 的子数组也能被正确计入
        count = defaultdict(int)
        count[0] = 1
        cur = 0      # 到当前位置的前缀和
        ans = 0
        for x in nums:
            cur += x
            # 之前有多少个前缀和等于 cur - k，就有多少条以当前位置结尾、和为 k 的子数组
            ans += count[cur - k]
            # 当前前缀和加入字典，供后面位置使用
            count[cur] += 1
        return ans
```

## 复杂度

- 时间：O(n)
- 空间：O(n)

## 易错点

- 顺序必须是"先累加答案、再把当前前缀和加入字典"，否则当 k=0 时会把"自己"算成一个有效子数组。
- 不能用滑动窗口（数组可能含负数，窗口大小不单调）。
