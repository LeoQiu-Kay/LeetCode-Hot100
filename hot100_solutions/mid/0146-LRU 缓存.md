# 146. LRU 缓存

- 难度：中等
- 链接：https://leetcode.cn/problems/lru-cache/

## 直觉 / 记忆点

> 要求 get/put 都 O(1)，**单一数据结构**做不到。组合两个：
> - **哈希表** 提供 O(1) 查找（key → 节点）
> - **双向链表** 提供 O(1) 移动到表头 + O(1) 从中间删（淘汰表尾）
>
> 每次访问就把节点拉到表头（最新），容量满时砍掉表尾（最久未用）。两个 dummy 头尾节点能消除所有边界判断。

## 思路

`Node` 存 key、val、prev、next。维护 dummy head/tail。`_add`：插到 head 后；`_remove`：删任意节点；`_move_to_head` = remove + add。put 满了就先删除 tail.prev。

## 代码

```python
class Node:
    def __init__(self, key=0, val=0):
        self.key = key
        self.val = val
        self.prev = None
        self.next = None

class LRUCache:
    def __init__(self, capacity: int):
        self.cap = capacity
        self.map: dict[int, Node] = {}    # key → 链表节点
        # dummy 头尾节点，让链表非空，所有插入/删除都不用判 None
        self.head = Node()
        self.tail = Node()
        self.head.next = self.tail
        self.tail.prev = self.head

    def _remove(self, node: Node) -> None:
        # 把 node 从链表中摘出（不释放）
        node.prev.next = node.next
        node.next.prev = node.prev

    def _add_to_head(self, node: Node) -> None:
        # 把 node 插入到 head 之后（即"最新"位置）
        node.prev = self.head
        node.next = self.head.next
        self.head.next.prev = node
        self.head.next = node

    def get(self, key: int) -> int:
        if key not in self.map:
            return -1
        node = self.map[key]
        # 命中后把节点移到表头（标记为最近访问）
        self._remove(node)
        self._add_to_head(node)
        return node.val

    def put(self, key: int, value: int) -> None:
        if key in self.map:
            # 已存在：更新值并移到表头
            node = self.map[key]
            node.val = value
            self._remove(node)
            self._add_to_head(node)
        else:
            # 新建节点，插入哈希表和链表头
            node = Node(key, value)
            self.map[key] = node
            self._add_to_head(node)
            # 超容量：淘汰表尾（最久未用）
            if len(self.map) > self.cap:
                lru = self.tail.prev
                self._remove(lru)
                del self.map[lru.key]    # 别忘了从哈希表里也删
```

## 复杂度

- 时间：get/put 均摊 O(1)
- 空间：O(capacity)

## 易错点

- Node 必须存 `key`（不只是 val），否则淘汰时不知道要在哈希表里删哪个键。
- dummy 头尾节点是关键：让链表"非空"，省掉一大堆 if node is None 判断。
- 4 个指针的更新顺序：插入时**先**改 node 的两个指针，**再**改链表里两个邻居的指针，否则会丢链。
