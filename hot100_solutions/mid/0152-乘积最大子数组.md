# 152. 乘积最大子数组

- 难度：中等
- 链接：https://leetcode.cn/problems/maximum-product-subarray/

## 直觉 / 记忆点

> 和最大子数组的区别：负数 × 负数 = 正数，"当前最大"可能来源于"上一步最小 × 当前负数"。所以必须**同时维护**两个 DP：以 i 结尾的"最大乘积"和"最小乘积"。每步用 `(x, max_prev*x, min_prev*x)` 三个候选取最大 / 最小。

## 思路

cur_max、cur_min 各自滚动。每步：候选三个值 → 更新 cur_max / cur_min → 更新答案。

## 代码

```python
class Solution:
    def maxProduct(self, nums: list[int]) -> int:
        # 维护以 i 结尾的最大乘积和最小乘积
        cur_max = cur_min = ans = nums[0]
        for x in nums[1:]:
            # 三个候选：自己单独成段 / 之前的最大 × x / 之前的最小 × x
            # 必须用上一步的 cur_max 和 cur_min，所以先存起来
            mx, mn = cur_max, cur_min
            cur_max = max(x, mx * x, mn * x)
            cur_min = min(x, mx * x, mn * x)
            ans = max(ans, cur_max)
        return ans
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- 必须**先保存上一步的 cur_max 和 cur_min**，否则更新完 cur_max 后再算 cur_min 就用错值了。
- 答案初始用 `nums[0]`（不能用 0，全负数时会错）。
- 同时维护 max 和 min 是因为负数翻转大小关系。
