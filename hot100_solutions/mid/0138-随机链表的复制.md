# 138. 随机链表的复制

- 难度：中等
- 链接：https://leetcode.cn/problems/copy-list-with-random-pointer/

## 直觉 / 记忆点

> 难点是 `random` 可能指到链表里**任何**位置，单趟扫描时"目标节点的复制版"可能还没创建。解决：用一张哈希表登记"旧节点 → 新节点"，**先扫一遍只造节点**，再扫一遍把 `next` 和 `random` 全部按映射接上。

## 思路

第一趟：用字典 `m[old] = Node(old.val)` 复制所有节点。
第二趟：对每个 old，设置 `m[old].next = m.get(old.next)`、`m[old].random = m.get(old.random)`。`m.get(None)` 自动返回 None。

## 代码

```python
class Node:
    def __init__(self, x: int, next=None, random=None):
        self.val = x
        self.next = next
        self.random = random

class Solution:
    def copyRandomList(self, head: 'Node | None') -> 'Node | None':
        if not head:
            return None
        # 第一趟：为每个旧节点创建对应的新节点，登记映射
        m: dict[Node, Node] = {}
        cur = head
        while cur:
            m[cur] = Node(cur.val)
            cur = cur.next
        # 第二趟：按映射拼接新链表的 next 和 random
        cur = head
        while cur:
            # m.get(None) 返回 None，所以末尾的 next、为空的 random 都能自然处理
            m[cur].next = m.get(cur.next)
            m[cur].random = m.get(cur.random)
            cur = cur.next
        # 返回新链表的头
        return m[head]
```

## 复杂度

- 时间：O(n)
- 空间：O(n)

## 易错点

- **必须**两趟扫：第一趟先把所有节点造好，否则第二趟设 random 时目标可能还不存在。
- `m.get(cur.next)` 比 `m[cur.next]` 安全：链表末尾时 `cur.next` 是 None，get 会返回 None 而不是 KeyError。
