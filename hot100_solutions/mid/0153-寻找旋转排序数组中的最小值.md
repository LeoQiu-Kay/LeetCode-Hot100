# 153. 寻找旋转排序数组中的最小值

- 难度：中等
- 链接：https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array/

## 直觉 / 记忆点

> 最小值是"两段升序的拼接处"。每次和**右端点** `nums[hi]` 比较：
> - `nums[mid] > nums[hi]` → 最小值在 mid 右边
> - `nums[mid] < nums[hi]` → 最小值在 mid 或 mid 左边
>
> 收缩到 lo == hi 时就是答案。注意比的是 `nums[hi]` 不是 `nums[lo]`，否则未旋转的情况会出错。

## 思路

闭区间二分，循环条件 `lo < hi`，永远比 `nums[hi]`。

## 代码

```python
class Solution:
    def findMin(self, nums: list[int]) -> int:
        lo, hi = 0, len(nums) - 1
        while lo < hi:
            mid = (lo + hi) // 2
            # 关键：和右端点比，不是和左端点
            if nums[mid] > nums[hi]:
                # mid 在左段（较大的段），最小值在 mid 右边
                lo = mid + 1
            else:
                # nums[mid] <= nums[hi]：mid 在右段，最小值在 mid 或 mid 左边
                hi = mid
        # 收缩到 lo == hi 时就是最小值位置
        return nums[lo]
```

## 复杂度

- 时间：O(log n)
- 空间：O(1)

## 易错点

- 必须和 `nums[hi]` 比，不能和 `nums[lo]` 比。原因：未旋转的数组（如 `[1,2,3,4,5]`）和左端点比时 `nums[mid] > nums[lo]` 恒成立，会走错分支。
- 循环条件用 `<` 不是 `<=`，收缩到 `lo == hi` 自然停止。
