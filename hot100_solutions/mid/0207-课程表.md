# 207. 课程表

- 难度：中等
- 链接：https://leetcode.cn/problems/course-schedule/

## 直觉 / 记忆点

> 课程依赖 = 有向图。"能否修完所有课"等价于"图里有没有环"——有环就锁死无解，无环就一定有合法顺序。**Kahn 拓扑排序**：把"入度为 0"的节点入队，每出队一个就把它的所有后继入度 -1，新变成 0 的入队。最后看出队节点数是否等于 n。

## 思路

建邻接表 + 入度数组；BFS 拓扑；统计出队总数。

## 代码

```python
from collections import deque

class Solution:
    def canFinish(self, numCourses: int, prerequisites: list[list[int]]) -> bool:
        # 邻接表：g[a] 列出所有"以 a 为先修课"的下游课程
        # 入度数组：indeg[b] 是课程 b 还有几个未完成的先修课
        g: list[list[int]] = [[] for _ in range(numCourses)]
        indeg = [0] * numCourses
        for b, a in prerequisites:
            # 题目格式 [b, a] 表示要修 b 必须先修 a，即 a → b
            g[a].append(b)
            indeg[b] += 1
        # 所有入度为 0 的课（无先修课）先入队
        q = deque(i for i in range(numCourses) if indeg[i] == 0)
        done = 0   # 已完成的课程数
        while q:
            x = q.popleft()
            done += 1
            # 把 x 的所有后继课程的入度减 1
            for y in g[x]:
                indeg[y] -= 1
                # 入度归零意味着所有先修课已修完，可以学了
                if indeg[y] == 0:
                    q.append(y)
        # 全部完成 ⟺ 无环
        return done == numCourses
```

## 复杂度

- 时间：O(V + E)
- 空间：O(V + E)

## 易错点

- prerequisites 的格式：`[b, a]` 表示"修 b 之前必须先修 a"，对应有向边 a → b（不是 b → a），别画反。
- BFS 拓扑必须用 deque + 入度数组；如果换成 DFS 判环也行，但实现更繁琐（要区分"白/灰/黑"三态）。
