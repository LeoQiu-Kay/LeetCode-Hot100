# 131. 分割回文串

- 难度：中等
- 链接：https://leetcode.cn/problems/palindrome-partitioning/

## 直觉 / 记忆点

> 枚举所有"切点"组合，每一段都必须是回文。回溯：从 start 开始枚举右端点 i，若 `s[start..i]` 是回文就把它加入 path，递归 `i + 1`；否则跳过。

## 思路

DFS(start)。start == len(s) 收集结果；否则循环 i 从 start 到末尾，判断 s[start..i] 是否回文。

## 代码

```python
class Solution:
    def partition(self, s: str) -> list[list[str]]:
        ans: list[list[str]] = []
        path: list[str] = []
        n = len(s)
        def is_pal(l: int, r: int) -> bool:
            # 判断 s[l..r] 是否回文（双指针对撞）
            while l < r:
                if s[l] != s[r]:
                    return False
                l += 1
                r -= 1
            return True
        def dfs(start: int) -> None:
            # 整个字符串切完，收集一种切法
            if start == n:
                ans.append(path.copy())
                return
            # 枚举本段的右端点 i（闭区间 [start, i]）
            for i in range(start, n):
                if is_pal(start, i):
                    # 本段是回文，加入路径继续切剩余部分
                    path.append(s[start:i + 1])
                    dfs(i + 1)
                    path.pop()
        dfs(0)
        return ans
```

## 复杂度

- 时间：最坏 O(n · 2ⁿ)（每个位置都可切）
- 空间：O(n)

## 易错点

- `s[start:i+1]` 切片是右开区间，要 `+1`。
- 可以预处理 `dp[l][r]` 缓存"是否回文"，但本题数据规模下直接 is_pal 也够。
