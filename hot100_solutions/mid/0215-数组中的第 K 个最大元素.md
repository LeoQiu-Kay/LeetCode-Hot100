# 215. 数组中的第 K 个最大元素

- 难度：中等
- 链接：https://leetcode.cn/problems/kth-largest-element-in-an-array/

## 直觉 / 记忆点

> 用**小顶堆**维护"目前见到的 k 个最大值"——堆大小固定为 k。新元素若大于堆顶就替换，最后堆顶就是第 k 大。也可以快速选择 O(n) 平均，但堆解法 O(n log k) 代码短易写对。

## 思路

heapq 默认小顶堆。维护大小为 k 的堆，遍历每个数：push → 若 size > k 就 pop 最小。

## 代码

```python
import heapq

class Solution:
    def findKthLargest(self, nums: list[int], k: int) -> int:
        # heapq 是小顶堆，堆顶是最小值
        # 我们保留 k 个最大值在堆里，堆顶就是这 k 个里最小的，即第 k 大
        heap: list[int] = []
        for x in nums:
            heapq.heappush(heap, x)
            # 超过 k 个就把最小的弹出，保持堆大小为 k
            if len(heap) > k:
                heapq.heappop(heap)
        return heap[0]
```

## 复杂度

- 时间：O(n log k)
- 空间：O(k)

## 易错点

- heapq 默认是小顶堆，要找"第 k 大"用小顶堆维护"最大的 k 个"；找"第 k 小"则用大顶堆（push 时取负）。
- 题目允许 O(n log n) 排序后取 `sorted(nums)[-k]`，但堆解法更通用、更快。
