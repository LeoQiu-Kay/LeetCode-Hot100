# 74. 搜索二维矩阵

- 难度：中等
- 链接：https://leetcode.cn/problems/search-a-2d-matrix/

## 直觉 / 记忆点

> 题目保证"每行升序、下一行首 > 上一行末"——整个矩阵展开就是一个**升序数组**。把 `[i][j]` 映射为下标 `i*n + j`、做标准二分即可。

## 思路

二分整个矩阵当作一维数组：lo = 0, hi = m * n - 1。

## 代码

```python
class Solution:
    def searchMatrix(self, matrix: list[list[int]], target: int) -> bool:
        if not matrix or not matrix[0]:
            return False
        m, n = len(matrix), len(matrix[0])
        lo, hi = 0, m * n - 1
        # 闭区间二分（lo <= hi 时继续）
        while lo <= hi:
            mid = (lo + hi) // 2
            # 把一维下标 mid 映射回二维坐标
            x = matrix[mid // n][mid % n]
            if x == target:
                return True
            elif x < target:
                lo = mid + 1
            else:
                hi = mid - 1
        return False
```

## 复杂度

- 时间：O(log(m × n))
- 空间：O(1)

## 易错点

- 行号是 `mid // n`，列号是 `mid % n`（n 是**列数**，不是行数）。
- 题目对"下一行首 > 上一行末"的保证是关键，若只保证"每行升序"则要用 240 那种 Z 字搜索。
