# 739. 每日温度

- 难度：中等
- 链接：https://leetcode.cn/problems/daily-temperatures/

## 直觉 / 记忆点

> "找右边第一个比我大"的经典套路——**单调递减栈**。栈里存还没找到答案的下标，温度从高到低（栈底到栈顶递减）。新一天的温度若大于栈顶下标对应的温度，就**把栈顶弹出并结算它的答案**（距离 = 当前下标 - 栈顶下标）。

## 思路

栈存下标。遍历每天 i：当 stack 非空且 `T[i] > T[stack[-1]]` 时弹出并填答案，最后把 i 入栈。

## 代码

```python
class Solution:
    def dailyTemperatures(self, temperatures: list[int]) -> list[int]:
        n = len(temperatures)
        ans = [0] * n
        # 单调栈：存下标，栈底到栈顶对应温度严格递减
        stack: list[int] = []
        for i, t in enumerate(temperatures):
            # 新温度比栈顶下标对应温度高 → 栈顶等待的"答案"就是当前 i
            while stack and temperatures[stack[-1]] < t:
                j = stack.pop()
                ans[j] = i - j
            # 当前下标入栈，等待未来某天来给它结算
            stack.append(i)
        # 最后栈里剩下的下标对应"右边没有更大值"的天，答案保持 0
        return ans
```

## 复杂度

- 时间：O(n)（每个下标最多入栈、出栈一次）
- 空间：O(n)

## 易错点

- 栈里存**下标**而不是温度本身，否则算不了"距离"。
- 用 `<` 而不是 `<=`：题目要求严格大于。
