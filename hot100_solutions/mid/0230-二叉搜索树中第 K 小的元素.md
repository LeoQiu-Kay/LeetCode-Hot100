# 230. 二叉搜索树中第 K 小的元素

- 难度：中等
- 链接：https://leetcode.cn/problems/kth-smallest-element-in-a-bst/

## 直觉 / 记忆点

> BST 的**中序遍历是升序序列**。把 94 的迭代中序模板改一下：每弹出一个节点就 k -= 1，当 k 变成 0 时，那个就是第 k 小。提前 return，不必遍历全树。

## 思路

栈模拟中序遍历。

## 代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def kthSmallest(self, root: TreeNode | None, k: int) -> int:
        stack: list[TreeNode] = []
        cur = root
        while cur or stack:
            # 沿左孩子一路下到底
            while cur:
                stack.append(cur)
                cur = cur.left
            # 弹出最左未访问的节点（按中序刚好是当前最小）
            cur = stack.pop()
            k -= 1
            if k == 0:
                return cur.val
            # 转向右子树继续
            cur = cur.right
        return -1   # 题目保证 k 合法，理论上不会到这里
```

## 复杂度

- 时间：O(h + k)（沿左链下到底 + 弹 k 次）
- 空间：O(h)

## 易错点

- 中序模板里的指针移动顺序：**先 push 左链 → 弹出 → 转右**，循环条件是 `cur or stack`。
- 找到答案要提前 return，否则虽然结果对但浪费时间。
