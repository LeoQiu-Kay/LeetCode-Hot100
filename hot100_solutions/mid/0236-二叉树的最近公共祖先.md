# 236. 二叉树的最近公共祖先

- 难度：中等
- 链接：https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/

## 直觉 / 记忆点

> 后序递归：每个节点问左右子树"你们各自包含 p 或 q 吗？"
> - 左右都返回非空 → 当前节点就是 LCA（p、q 分散在两边，**只有这里能同时覆盖**）
> - 只有一边返回非空 → 把那一边的结果**原样上传**（LCA 在那一边，或就是 p/q 本身）
> - 两边都空 → 返回 None
>
> 把 p 或 q 本身也算"找到的祖先"，递归就能优雅处理"一个是另一个的祖先"的情况。

## 思路

DFS 返回值含义："在以 node 为根的子树里，找到的 p 或 q 或它们的 LCA"。

## 代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def lowestCommonAncestor(self, root: TreeNode, p: TreeNode, q: TreeNode) -> TreeNode:
        # 出口：空子树返回 None；遇到 p 或 q 直接返回它自己（视为"找到了 ≥ 1 个目标"）
        if not root or root is p or root is q:
            return root
        # 递归看左右子树各自的结果
        left = self.lowestCommonAncestor(root.left, p, q)
        right = self.lowestCommonAncestor(root.right, p, q)
        # 两边都找到了 → 当前节点就是分叉点，即 LCA
        if left and right:
            return root
        # 只有一边非空 → LCA 在那一边，或本身就是 p/q（向上传递）
        return left or right
```

## 复杂度

- 时间：O(n)
- 空间：O(h)

## 易错点

- 节点比较用 `is`（同一对象）而不是 `==`（值相等），题目保证节点唯一，但严谨起见还是用 is。
- "返回 p 或 q 本身"是关键技巧，能让"p 是 q 的祖先"这类情况自动满足（递归到 q 的祖先 p 时，p 自身被返回；另一侧 None；上一层只有一侧非空就返回它）。
