# 238. 除自身以外数组的乘积

- 难度：中等
- 链接：https://leetcode.cn/problems/product-of-array-except-self/

## 直觉 / 记忆点

> 不能用除法，但答案 = **左前缀积 × 右后缀积**。第一遍从左到右把"i 左边所有元素的乘积"填进 ans；第二遍从右到左用一个 running 变量乘"i 右边所有元素的乘积"。

## 思路

两遍扫，不开额外数组。

## 代码

```python
class Solution:
    def productExceptSelf(self, nums: list[int]) -> list[int]:
        n = len(nums)
        ans = [1] * n
        # 第一遍：ans[i] 暂时存"i 左边所有元素的乘积"（i=0 时为 1）
        for i in range(1, n):
            ans[i] = ans[i - 1] * nums[i - 1]
        # 第二遍：从右往左，用 right 累乘"i 右边所有元素的乘积"
        right = 1
        for i in range(n - 1, -1, -1):
            # ans[i] = 左前缀积 × 右后缀积
            ans[i] *= right
            # 更新 right 为"包含当前 nums[i]"的右后缀积，供下一个 i-1 使用
            right *= nums[i]
        return ans
```

## 复杂度

- 时间：O(n)
- 空间：O(1)（输出 ans 不算）

## 易错点

- 第一遍 ans[0] 必须是 1（左边没东西，乘积为 1）。
- 第二遍 right 的初始值是 1，每次先"乘进答案"再"更新 right"，顺序不能反。
