# 64. 最小路径和

- 难度：中等
- 链接：https://leetcode.cn/problems/minimum-path-sum/

## 直觉 / 记忆点

> 62 的变种："路径数" → "路径和的最小值"。转移把加法换成 `min(上来, 左来) + grid[i][j]`。第一行只能从左来、第一列只能从上来，单独处理。

## 思路

原地修改 grid 当 dp 用，省空间。

## 代码

```python
class Solution:
    def minPathSum(self, grid: list[list[int]]) -> int:
        m, n = len(grid), len(grid[0])
        # 第一行：只能从左来，累加
        for j in range(1, n):
            grid[0][j] += grid[0][j - 1]
        # 第一列：只能从上来，累加
        for i in range(1, m):
            grid[i][0] += grid[i - 1][0]
        # 其它格子：从上来 vs 从左来，取小的 + 自己
        for i in range(1, m):
            for j in range(1, n):
                grid[i][j] += min(grid[i - 1][j], grid[i][j - 1])
        return grid[-1][-1]
```

## 复杂度

- 时间：O(m × n)
- 空间：O(1)（原地）

## 易错点

- 第一行第一列单独处理，否则 `grid[-1][j]` 或 `grid[i][-1]` 会越过边界引到错位置（Python 负索引"绕一圈"）。
- 不想改原数组就用一维 dp，逻辑相同。
