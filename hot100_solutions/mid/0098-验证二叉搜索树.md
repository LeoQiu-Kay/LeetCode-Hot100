# 98. 验证二叉搜索树

- 难度：中等
- 链接：https://leetcode.cn/problems/validate-binary-search-tree/

## 直觉 / 记忆点

> "左子树的**所有**值 < 根 < 右子树的**所有**值"，不能只比直系儿子。两种思路：
> - **上下界递归**：每次递归带着"允许的开区间"`(lo, hi)`，到子树就把根加进区间里收紧。
> - **中序遍历必须严格递增**：BST 的中序是有序序列，扫一遍验证就行。

## 思路

用上下界递归更直观。空树视为合法；当前 node 必须 `lo < node.val < hi`；递归左子树更新 `hi = node.val`，右子树更新 `lo = node.val`。

## 代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def isValidBST(self, root: TreeNode | None) -> bool:
        # 子函数：验证以 node 为根的子树是否合法
        # lo / hi 是"允许的开区间"，初始是 (-inf, +inf)
        def check(node: TreeNode | None, lo: float, hi: float) -> bool:
            if not node:
                return True
            # 当前节点必须严格落在开区间内
            if not (lo < node.val < hi):
                return False
            # 递归左子树：上界收紧为 node.val（左子树所有值都要 < node.val）
            # 递归右子树：下界收紧为 node.val
            return check(node.left, lo, node.val) and check(node.right, node.val, hi)
        return check(root, float("-inf"), float("inf"))
```

## 复杂度

- 时间：O(n)
- 空间：O(h)（递归栈）

## 易错点

- 必须用**严格**不等号 `<`（题目要求严格 BST，相等也不行）。
- 不能只比节点和直接子节点的值，必须传递上下界让"祖先的约束"也生效。
