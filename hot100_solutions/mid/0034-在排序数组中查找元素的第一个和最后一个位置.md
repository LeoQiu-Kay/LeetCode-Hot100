# 34. 在排序数组中查找元素的第一个和最后一个位置

- 难度：中等
- 链接：https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/

## 直觉 / 记忆点

> 两次"下界二分"：
> - `lower_bound(target)` → 第一次出现位置
> - `lower_bound(target + 1) - 1` → 最后一次出现位置
>
> 若第一次出现位置越界或对应值不等于 target，说明不存在。

## 思路

复用 35 的 lower_bound 模板。

## 代码

```python
class Solution:
    def searchRange(self, nums: list[int], target: int) -> list[int]:
        def lower_bound(t: int) -> int:
            # 找第一个 >= t 的位置（半开区间二分）
            lo, hi = 0, len(nums)
            while lo < hi:
                mid = (lo + hi) // 2
                if nums[mid] < t:
                    lo = mid + 1
                else:
                    hi = mid
            return lo
        left = lower_bound(target)
        # target 不存在的两种情况：左边界越界 或 对应位置不是 target
        if left == len(nums) or nums[left] != target:
            return [-1, -1]
        # 找第一个 > target 的位置（即 lower_bound(target + 1)），再减 1 就是最后位置
        right = lower_bound(target + 1) - 1
        return [left, right]
```

## 复杂度

- 时间：O(log n)
- 空间：O(1)

## 易错点

- 必须先判 `left == len(nums)` 再访问 `nums[left]`，否则越界。
- `lower_bound(target + 1) - 1` 比写一个 upper_bound 更简洁。
