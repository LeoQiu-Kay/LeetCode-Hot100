# 24. 两两交换链表中的节点

- 难度：中等
- 链接：https://leetcode.cn/problems/swap-nodes-in-pairs/

## 直觉 / 记忆点

> 把链表里**每两个相邻节点**像跳交谊舞一样换位。每对的"换位"动作有三步：把前一对的"尾巴"指向后一对的"第二个"，再让"第二个"挂到"第一个"前面，最后"第一个"接到剩余链表。用 dummy 头省去边界。

## 思路

dummy 头 + 指针 `prev`，每轮取 `a = prev.next`、`b = a.next`，做指针重连后让 prev 跳到 `a`（新一对的"前驱"）。

## 代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def swapPairs(self, head: ListNode | None) -> ListNode | None:
        # dummy 头，便于统一处理"第一对"
        dummy = ListNode(0, head)
        prev = dummy   # prev 始终是"将要交换的一对"的前一个节点
        # 至少要有两个节点才能交换
        while prev.next and prev.next.next:
            a = prev.next        # 这一对的第一个
            b = a.next           # 这一对的第二个
            # 三条边重连，画图最清楚：
            #   prev → b → a → (b 原本的下一个)
            a.next = b.next      # a 指向"对子的下下一个"
            b.next = a           # b 指向 a，完成内部交换
            prev.next = b        # 前驱接 b，让 b 成为这一对的新头
            # prev 跳到 a（也就是新一对的前驱），准备下一轮
            prev = a
        return dummy.next
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- 三条边重连的**顺序不能乱**：先保存 a/b，再重写 `a.next`、`b.next`、`prev.next`。
- prev 最后要跳到 a（不是 b），因为交换后 a 才是这对里靠后的节点，下一对要以它为前驱。
