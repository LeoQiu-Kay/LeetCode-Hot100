# 199. 二叉树的右视图

- 难度：中等
- 链接：https://leetcode.cn/problems/binary-tree-right-side-view/

## 直觉 / 记忆点

> 站在树的右边往左看，每一层只能看到**最右边那个**节点。在 102 层序遍历的基础上，每一层只保留最后一个出队的节点即可。

## 思路

BFS。本层循环结束的最后一个节点就是该层最右；或者每次取 `q[size-1]` 也行。

## 代码

```python
from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def rightSideView(self, root: TreeNode | None) -> list[int]:
        if not root:
            return []
        res: list[int] = []
        q = deque([root])
        while q:
            size = len(q)
            for i in range(size):
                node = q.popleft()
                # 本层最后一个出队的就是最右节点
                if i == size - 1:
                    res.append(node.val)
                if node.left:
                    q.append(node.left)
                if node.right:
                    q.append(node.right)
        return res
```

## 复杂度

- 时间：O(n)
- 空间：O(n)

## 易错点

- 不能只取"右子树最右"，因为如果右子树缺失，能看到的可能是左子树的某个节点（如根的右子树为空，左子树最深节点会"露出来"）。
- 用层序遍历的"本层最后一个"才能正确处理这种情形。
