# 75. 颜色分类

- 难度：中等
- 链接：https://leetcode.cn/problems/sort-colors/

## 直觉 / 记忆点

> **荷兰国旗三指针**：lo 是 0 区右边界、hi 是 2 区左边界、mid 是扫描指针。
> - `nums[mid] == 0`：和 lo 交换，lo 和 mid 都右移
> - `nums[mid] == 2`：和 hi 交换，hi 左移，mid **不动**（换过来的还得检查）
> - `nums[mid] == 1`：mid 直接右移

## 思路

一趟扫描，原地分三段。

## 代码

```python
class Solution:
    def sortColors(self, nums: list[int]) -> None:
        # 三个指针：
        # [0, lo) 是已确认的 0 区
        # [lo, mid) 是已确认的 1 区
        # [mid, hi] 是未处理区
        # (hi, n) 是已确认的 2 区
        lo, mid, hi = 0, 0, len(nums) - 1
        while mid <= hi:
            if nums[mid] == 0:
                # 当前是 0：换到 0 区末尾，lo 和 mid 都前进
                nums[lo], nums[mid] = nums[mid], nums[lo]
                lo += 1
                mid += 1
            elif nums[mid] == 2:
                # 当前是 2：换到 2 区开头，hi 左移
                # 注意 mid 不动：从 hi 换过来的元素还没处理过，下一轮重新看
                nums[mid], nums[hi] = nums[hi], nums[mid]
                hi -= 1
            else:
                # 当前是 1：1 直接进 1 区
                mid += 1
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- 遇到 2 交换后 `mid` **不前进**，因为换过来的元素是新的、还没分类。
- 遇到 0 交换后 mid **必须前进**（换过来的来自 [lo, mid) 是 1 区，已经分类好的 1）。
