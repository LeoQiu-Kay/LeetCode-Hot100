# 15. 三数之和

- 难度：中等
- 链接：https://leetcode.cn/problems/3sum/

## 直觉 / 记忆点

> 排序后**固定 i**、剩下用**双指针**找两数之和等于 -nums[i]。排序的好处：1) 两数之和能用相向双指针；2) 跳重复非常方便（相邻相同就跳过）。

## 思路

排序 → 外层枚举 i → 内层 l, r 在 [i+1, n-1] 相向移动。三层都要跳重复。

## 代码

```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        nums.sort()
        n = len(nums)
        ans: list[list[int]] = []
        for i in range(n - 2):
            # 剪枝：最小都 > 0，后面三数和不可能为 0
            if nums[i] > 0:
                break
            # 外层跳重复：i 和前一个相同，结果会和上一轮重复
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            l, r = i + 1, n - 1
            target = -nums[i]
            while l < r:
                s = nums[l] + nums[r]
                if s == target:
                    ans.append([nums[i], nums[l], nums[r]])
                    # 内层跳重复：l 和右移后相同则继续右移
                    l += 1
                    while l < r and nums[l] == nums[l - 1]:
                        l += 1
                    # 同理 r 跳重复
                    r -= 1
                    while l < r and nums[r] == nums[r + 1]:
                        r -= 1
                elif s < target:
                    l += 1
                else:
                    r -= 1
        return ans
```

## 复杂度

- 时间：O(n²)
- 空间：O(1)（不算输出）

## 易错点

- **三个位置都要跳重复**：外层 i、找到答案后内层 l 和 r。
- 排序是必须的，没排序不能用双指针。
