# 48. 旋转图像

- 难度：中等
- 链接：https://leetcode.cn/problems/rotate-image/

## 直觉 / 记忆点

> 顺时针旋转 90° = **先转置（沿主对角线翻）+ 再每行左右翻转**。两步都是 O(1) 额外空间的原地操作。

## 思路

第一步转置：交换 `matrix[i][j]` 和 `matrix[j][i]`（i < j）；第二步每行反转。

## 代码

```python
class Solution:
    def rotate(self, matrix: list[list[int]]) -> None:
        n = len(matrix)
        # 1. 沿主对角线翻转（转置）
        # 只交换 i < j 的部分，否则会自相消
        for i in range(n):
            for j in range(i + 1, n):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
        # 2. 每一行做左右翻转
        for row in matrix:
            row.reverse()
```

## 复杂度

- 时间：O(n²)
- 空间：O(1)

## 易错点

- 转置时内层从 `j = i + 1` 开始，不能从 0 开始（否则每对元素被交换两次，等于没做）。
- 顺时针 90° = 转置 + 行反转；如果要逆时针，就改成"转置 + 列反转"或"先行反转后转置"。
