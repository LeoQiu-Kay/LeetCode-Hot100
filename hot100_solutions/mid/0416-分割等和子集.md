# 416. 分割等和子集

- 难度：中等
- 链接：https://leetcode.cn/problems/partition-equal-subset-sum/

## 直觉 / 记忆点

> 把"能否分两半等和"转化为：**能不能从 nums 中挑一些数恰好凑出 sum/2**——经典 01 背包"能否凑出 target"。
> dp[j] 表示能否凑出和 j；遍历 nums 时**逆序更新**容量（保证每个数只被用一次）。

## 思路

总和奇数直接 False。target = sum // 2。dp 长度 target + 1。

## 代码

```python
class Solution:
    def canPartition(self, nums: list[int]) -> bool:
        s = sum(nums)
        # 总和奇数，不可能平分
        if s % 2 == 1:
            return False
        target = s // 2
        # dp[j] 表示能否从 nums 选出若干个数使其和等于 j
        dp = [False] * (target + 1)
        dp[0] = True   # 不选任何数能凑出 0
        for x in nums:
            # 必须**逆序**更新（01 背包标准技巧）
            # 否则 dp[j - x] 已被本轮更新过，相当于 x 被重复使用
            for j in range(target, x - 1, -1):
                # 选 x：dp[j] = dp[j - x]；不选 x：dp[j] 保持原值
                dp[j] = dp[j] or dp[j - x]
        return dp[target]
```

## 复杂度

- 时间：O(n × target)
- 空间：O(target)

## 易错点

- **01 背包必须逆序**遍历容量，否则同一个数会被多次使用（变成完全背包）。
- 内层 `range(target, x - 1, -1)`：从 target 倒着到 x，包含 x。
