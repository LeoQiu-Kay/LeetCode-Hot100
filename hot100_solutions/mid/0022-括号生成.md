# 22. 括号生成

- 难度：中等
- 链接：https://leetcode.cn/problems/generate-parentheses/

## 直觉 / 记忆点

> n 对括号，回溯生成所有合法序列。两条剪枝规则：
> - **`left < n`** 才能加左括号（还有左括号没用完）
> - **`right < left`** 才能加右括号（已用左 > 已用右，否则会出现 `)(` 这种非法前缀）

## 思路

DFS(left, right, path)。剪枝两条即可，不需要事后判合法。

## 代码

```python
class Solution:
    def generateParenthesis(self, n: int) -> list[str]:
        ans: list[str] = []
        def dfs(left: int, right: int, path: str) -> None:
            # 用了 n 对括号，path 长度 == 2n，得到一种合法序列
            if len(path) == 2 * n:
                ans.append(path)
                return
            # 左括号还没用完，可以加
            if left < n:
                dfs(left + 1, right, path + '(')
            # 已用左括号比右括号多，才能加右括号
            # 否则会出现 ')' 在前面没有 '(' 配对的非法情形
            if right < left:
                dfs(left, right + 1, path + ')')
        dfs(0, 0, "")
        return ans
```

## 复杂度

- 时间：O(C(n))，第 n 个 Catalan 数
- 空间：O(n)

## 易错点

- 第二条剪枝是 `right < left`（不是 `right < n`），核心是"右括号数始终不能超过左括号数"。
- 这里 path 用字符串拼接，每次 `path + '('` 会新建字符串；想优化可以改成 list 然后 pop 回溯。
