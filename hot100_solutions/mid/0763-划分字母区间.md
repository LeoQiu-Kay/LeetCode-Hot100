# 763. 划分字母区间

- 难度：中等
- 链接：https://leetcode.cn/problems/partition-labels/

## 直觉 / 记忆点

> 同一字母必须在同一段里 → 一段的右端 = 段内所有字母**最后出现位置**的最大值。先扫一遍记每字母最后下标，再扫一遍：维护段右端 `end`，扫到 i == end 时切段。

## 思路

预处理 last 字典；遍历 s 时 end = max(end, last[c])；i == end 收集段长度。

## 代码

```python
class Solution:
    def partitionLabels(self, s: str) -> list[int]:
        # 每个字母最后出现的下标
        last = {c: i for i, c in enumerate(s)}
        ans: list[int] = []
        start = 0   # 当前段起点
        end = 0     # 当前段必须延伸到的右端
        for i, c in enumerate(s):
            # 当前字母最后出现位置可能拉长本段
            end = max(end, last[c])
            # 走到段尾：收集段长，开始下一段
            if i == end:
                ans.append(i - start + 1)
                start = i + 1
        return ans
```

## 复杂度

- 时间：O(n)
- 空间：O(Σ) = O(26)

## 易错点

- 切段后 `start = i + 1`，下一段从下个字符开始。
- 一定要先扫一遍记录每字母最后位置，再开始切段；否则 last 不全。
