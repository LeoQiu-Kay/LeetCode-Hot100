# 39. 组合总和

- 难度：中等
- 链接：https://leetcode.cn/problems/combination-sum/

## 直觉 / 记忆点

> 每个数字**可以重复用**多次，但同一组合不分顺序（`[2,2,3]` 和 `[3,2,2]` 算同一个）。回溯时用 `start` 控制只能往后选（避免重复组合），但递归时下次仍从 i 开始（**不是 i+1**），允许重复选当前元素。

## 思路

DFS(start, remain)。remain == 0 收集答案；remain < 0 剪枝；否则循环 i from start。

## 代码

```python
class Solution:
    def combinationSum(self, candidates: list[int], target: int) -> list[list[int]]:
        ans: list[list[int]] = []
        path: list[int] = []
        def dfs(start: int, remain: int) -> None:
            # 凑够了：收集一个组合
            if remain == 0:
                ans.append(path.copy())
                return
            # 已经超了：剪枝
            if remain < 0:
                return
            # 从 start 开始往后选（保证组合按下标递增，不会出现 [2,3] 和 [3,2] 重复）
            for i in range(start, len(candidates)):
                path.append(candidates[i])
                # 注意：下次从 i 开始（不是 i+1），允许重复使用 candidates[i]
                dfs(i, remain - candidates[i])
                path.pop()
        dfs(0, target)
        return ans
```

## 复杂度

- 时间：和具体数据有关，最坏指数级
- 空间：O(target / min(candidates))（递归深度）

## 易错点

- 关键区别于 78 子集：**下次递归从 i 开始**（不是 i+1），允许重复选。
- 用 `start` 保证组合不重复（按下标递增挑），不需要去重哈希。
- 剪枝 `remain < 0` 可省（题目说数字都 ≥ 1，先排序后还可以 `if candidates[i] > remain: break`），不剪也能过。
