# 31. 下一个排列

- 难度：中等
- 链接：https://leetcode.cn/problems/next-permutation/

## 直觉 / 记忆点

> 字典序的下一个排列三步：
> 1. **从右向左**找第一个"下降点" i，使 `nums[i] < nums[i+1]`（i 右边已经是降序的"尽头"）
> 2. 再**从右向左**找第一个 `nums[j] > nums[i]`，交换 i、j
> 3. **反转 i+1 之后**（让那段变升序，即字典序最小）
>
> 找不到第 1 步的下降点说明已是字典序最大，整体反转即可。

## 思路

三步走。

## 代码

```python
class Solution:
    def nextPermutation(self, nums: list[int]) -> None:
        n = len(nums)
        # 1. 从右往左找第一个下降点 i（nums[i] < nums[i+1]）
        i = n - 2
        while i >= 0 and nums[i] >= nums[i + 1]:
            i -= 1
        if i >= 0:
            # 2. 从右往左找第一个比 nums[i] 大的位置 j，交换
            # 因为 i 右边是降序，从右往左找到的第一个 > nums[i] 就是"最小的更大值"
            j = n - 1
            while nums[j] <= nums[i]:
                j -= 1
            nums[i], nums[j] = nums[j], nums[i]
        # 3. 反转 i+1 之后的部分（把降序段变成升序段，得到字典序最小后缀）
        l, r = i + 1, n - 1
        while l < r:
            nums[l], nums[r] = nums[r], nums[l]
            l += 1
            r -= 1
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- 第一步用 `>=` 不是 `>`：相等时也要继续往左找。
- 第二步用 `<=`：相等时也跳过，找严格更大的。
- 找不到下降点（i = -1）时仍要执行第 3 步（反转整个数组，从最大排列回到最小排列）。
