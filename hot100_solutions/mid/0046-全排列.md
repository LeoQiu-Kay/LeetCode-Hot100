# 46. 全排列

- 难度：中等
- 链接：https://leetcode.cn/problems/permutations/

## 直觉 / 记忆点

> 站在排列树的每一层："这一位我能选哪个？"——选过的不能再选。所以用 `used` 数组标记已选元素。DFS 沿一条路走到底（路径长度 = n）就把当前 path 加入结果，然后回溯撤销选择。

## 思路

DFS + path + used。终止条件：path 长度 == n。

## 代码

```python
class Solution:
    def permute(self, nums: list[int]) -> list[list[int]]:
        n = len(nums)
        ans: list[list[int]] = []
        path: list[int] = []         # 当前正在构造的排列
        used = [False] * n           # 标记哪些下标已经在 path 中
        def dfs() -> None:
            # 路径长度等于 n：得到一个完整排列
            if len(path) == n:
                ans.append(path.copy())   # 必须拷贝，否则后续修改会影响已加入的结果
                return
            for i in range(n):
                # 跳过已选过的元素
                if used[i]:
                    continue
                # 做选择
                used[i] = True
                path.append(nums[i])
                dfs()
                # 撤销选择（回溯）
                path.pop()
                used[i] = False
        dfs()
        return ans
```

## 复杂度

- 时间：O(n! · n)
- 空间：O(n)（递归栈 + path）

## 易错点

- 加入 ans 时必须 `path.copy()`（或 `path[:]`），直接 append path 会导致最终所有引用都是同一个空 path。
- 回溯时**两件事都要撤销**：`used[i] = False` 和 `path.pop()`，否则后续状态不对。
