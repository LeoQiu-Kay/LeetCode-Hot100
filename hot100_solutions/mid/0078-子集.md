# 78. 子集

- 难度：中等
- 链接：https://leetcode.cn/problems/subsets/

## 直觉 / 记忆点

> 每个元素都有"**选或不选**"两种状态，n 个元素总共 2ⁿ 个子集。回溯模板：从 `start` 开始遍历，每个元素先把"包含它"的状态加入答案，再 DFS 探索后续元素，回溯时撤销。和 46 的区别是用 `start` 单向推进而不是 `used` 标记。

## 思路

DFS(start)。每进入函数把当前 path 加入结果，然后循环 i from start to n-1：append nums[i] → DFS(i+1) → pop。

## 代码

```python
class Solution:
    def subsets(self, nums: list[int]) -> list[list[int]]:
        ans: list[list[int]] = []
        path: list[int] = []
        def dfs(start: int) -> None:
            # 每个状态（无论 path 长度多少）都是一个子集
            ans.append(path.copy())
            # 从 start 开始往后挑（保证子集元素按原顺序，不重复）
            for i in range(start, len(nums)):
                path.append(nums[i])
                # 注意是 i+1 不是 start+1：下次从"刚选过这个之后"往后继续
                dfs(i + 1)
                path.pop()
        dfs(0)
        return ans
```

## 复杂度

- 时间：O(n · 2ⁿ)
- 空间：O(n)

## 易错点

- DFS 入口处就把 `path.copy()` 加入答案（包括空子集 `[]` 也会被加入，因为初次进入时 path 为空）。
- 内层递归用 `i + 1` 不是 `start + 1`，否则会跳过元素。
