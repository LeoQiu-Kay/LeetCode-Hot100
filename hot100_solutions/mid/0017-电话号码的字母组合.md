# 17. 电话号码的字母组合

- 难度：中等
- 链接：https://leetcode.cn/problems/letter-combinations-of-a-phone-number/

## 直觉 / 记忆点

> 输入 n 个数字，每个数字有 3–4 个字母，所有组合 = 笛卡尔积。回溯每一层对应一个数字位置，循环这个数字的所有字母，选一个加到 path 继续递归下一位。

## 思路

字典存数字 → 字母字符串。DFS(i) 表示正在处理 digits[i]。i == len(digits) 时加入结果。

## 代码

```python
class Solution:
    def letterCombinations(self, digits: str) -> list[str]:
        if not digits:
            return []
        m = {
            '2': 'abc', '3': 'def', '4': 'ghi', '5': 'jkl',
            '6': 'mno', '7': 'pqrs', '8': 'tuv', '9': 'wxyz',
        }
        ans: list[str] = []
        path: list[str] = []
        def dfs(i: int) -> None:
            # 走完所有数字位置，得到一种组合
            if i == len(digits):
                ans.append(''.join(path))
                return
            # 当前数字对应的所有字母，每个都试一遍
            for ch in m[digits[i]]:
                path.append(ch)
                dfs(i + 1)
                path.pop()
        dfs(0)
        return ans
```

## 复杂度

- 时间：O(3ⁿ · n) 或 O(4ⁿ · n)（n 个数字、每个 3-4 个字母，最后还要 ''.join）
- 空间：O(n)

## 易错点

- 空输入要特判返回 `[]`，否则会得到 `[""]`。
- 用 `''.join(path)` 把字符列表拼成字符串，比每次字符串 + 字符快（字符串不可变会重复创建）。
