# 128. 最长连续序列

- 难度：中等
- 链接：https://leetcode.cn/problems/longest-consecutive-sequence/

## 直觉 / 记忆点

> 暴力 O(n²)：每个数 x 检查 x+1、x+2...在不在数组里。优化：用 set 把查找降到 O(1)，但还要避免"重复从中间往后数"——**只从序列的起点开始数**。判断 x 是起点的方法：`x - 1` 不在 set 里。

## 思路

set 去重；遍历每个 x，只在 `x-1 not in set` 时才往后数 streak 长度，更新答案。

## 代码

```python
class Solution:
    def longestConsecutive(self, nums: list[int]) -> int:
        s = set(nums)
        ans = 0
        for x in s:
            # 关键剪枝：只从"序列的最左端点"开始数
            # x 是起点的条件：x - 1 不在集合里
            if x - 1 not in s:
                cur = x
                length = 1
                # 一路往后数，统计这段连续序列的长度
                while cur + 1 in s:
                    cur += 1
                    length += 1
                ans = max(ans, length)
        return ans
```

## 复杂度

- 时间：O(n)（每个数最多被"内层 while"访问一次，外层只在起点触发）
- 空间：O(n)

## 易错点

- **必须**判 `x-1 not in s`，否则每段从中间开始数都重新数一遍，复杂度退化为 O(n²)。
- 遍历用 `for x in s`（去重后的集合）而不是 `for x in nums`，避免重复处理。
