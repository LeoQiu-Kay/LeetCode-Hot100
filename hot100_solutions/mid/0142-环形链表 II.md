# 142. 环形链表 II

- 难度：中等
- 链接：https://leetcode.cn/problems/linked-list-cycle-ii/

## 直觉 / 记忆点

> 141 是判有没有环，这道要**找到环入口**。Floyd 数学结论：当快慢相遇后，再放一个**慢指针从 head 出发**，与原来的慢指针**同速**齐进，两者必然在**环入口**相遇。原因：从 head 到入口的距离 = 从相遇点继续走到入口的距离（环长的整数倍）。

## 思路

第一阶段：快慢指针判环（同 141）。第二阶段：相遇后让一个新慢从 head 出发，原慢继续，两者相遇即入口。

## 代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def detectCycle(self, head: ListNode | None) -> ListNode | None:
        # 第一阶段：标准 Floyd 龟兔判环
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow is fast:
                # 第二阶段：相遇后，新慢从 head 出发
                p = head
                # p 和 slow 同速前进，在环入口相遇（数学性质决定）
                while p is not slow:
                    p = p.next
                    slow = slow.next
                return p
        # fast 走到链尾说明无环
        return None
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- 第二阶段的两个指针必须**同速**（都走 1 步），不要再用快慢。
- 第二阶段相遇判定用 `is`，跟 141 一样比对节点对象。
