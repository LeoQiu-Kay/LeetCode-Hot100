# 114. 二叉树展开为链表

- 难度：中等
- 链接：https://leetcode.cn/problems/flatten-binary-tree-to-linked-list/

## 直觉 / 记忆点

> 要把树展开成"前序顺序的单向链表"——只用右指针、左指针全为 None。最优解法是**逆向后序遍历**（右→左→根）：用一个全局指针 `prev` 记住"已经处理过的链表头"，每次让当前节点的 right 指向 prev、left 置空、再把 prev 更新为当前节点。

## 思路

DFS 顺序：先右子树、再左子树、最后处理当前节点。这样处理当前节点时，prev 正好是"它在前序中的下一个节点"。

## 代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def flatten(self, root: TreeNode | None) -> None:
        # prev 是"已处理段链表的头"，处理新节点时它的 right 直接指到 prev
        self.prev: TreeNode | None = None
        def dfs(node: TreeNode | None) -> None:
            if not node:
                return
            # 先递归处理右子树（逆向后序：右 → 左 → 根）
            dfs(node.right)
            # 再处理左子树
            dfs(node.left)
            # 现在处理当前节点：把它接到已展开链表的最前面
            node.right = self.prev
            node.left = None
            # 把当前节点设为新的链表头
            self.prev = node
        dfs(root)
```

## 复杂度

- 时间：O(n)
- 空间：O(h)（递归栈）

## 易错点

- 顺序必须是**右 → 左 → 根**，反向就错了。因为我们要让 prev 自然累积成"前序的逆序"，处理时把它接到当前节点右边正好恢复前序。
- 别忘了 `node.left = None`，否则展开后还有左指针，不符合"单向链表"。
