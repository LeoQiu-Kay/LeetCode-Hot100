# 11. 盛最多水的容器

- 难度：中等
- 链接：https://leetcode.cn/problems/container-with-most-water/

## 直觉 / 记忆点

> 容量 = `min(高1, 高2) × 宽度`。**相向双指针**从两端往中间走，每次移动**更矮**的那根：因为留着矮的不动、缩窄宽度，新容量必然 ≤ 当前；移动矮的才有可能换来更高的"短板"。

## 思路

l, r 从两端出发。每轮算面积、更新答案，然后移动矮的那侧。

## 代码

```python
class Solution:
    def maxArea(self, height: list[int]) -> int:
        l, r = 0, len(height) - 1
        ans = 0
        while l < r:
            # 短板决定容量
            h = min(height[l], height[r])
            ans = max(ans, h * (r - l))
            # 移动矮的那侧（移动高的没意义：宽度减小、高度仍受短板限制）
            if height[l] < height[r]:
                l += 1
            else:
                r -= 1
        return ans
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- 移动**矮的那侧**而不是高的，是因为答案受短板限制，留着高的没问题、留着矮的不会带来更大答案。
- 相等时移哪边都行（不影响正确性）。
