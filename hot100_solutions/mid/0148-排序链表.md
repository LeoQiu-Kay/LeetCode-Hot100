# 148. 排序链表

- 难度：中等
- 链接：https://leetcode.cn/problems/sort-list/

## 直觉 / 记忆点

> 要 O(n log n) + O(1) 额外空间——**归并排序**最匹配：链表归并不像数组那样需要辅助数组。三步：1) 快慢指针**找中点**把链表切两半；2) 各自**递归排序**；3) 用 21 题的合并模板**合并**两条有序链表。

## 思路

- 出口：链表为空或只有一个节点直接返回。
- 找中点 mid（slow 走 1 步 / fast 走 2 步），并切断 mid 之前的 next。
- 递归排好左右两半，调合并模板拼回。

## 代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def sortList(self, head: ListNode | None) -> ListNode | None:
        # 出口：空或单节点，直接返回（已有序）
        if not head or not head.next:
            return head
        # 1. 快慢指针找中点 + 切断前半段
        # 这里 fast 从 head.next 开始，保证偶数长度时切在前中（slow 落在前半段末）
        slow, fast = head, head.next
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
        mid = slow.next     # 后半段起点
        slow.next = None    # 切断！否则前半段会一直串到尾
        # 2. 递归排好左右两半
        left = self.sortList(head)
        right = self.sortList(mid)
        # 3. 用 21 题合并模板把两条有序链表合起来
        return self._merge(left, right)

    def _merge(self, a: ListNode | None, b: ListNode | None) -> ListNode | None:
        dummy = ListNode()
        cur = dummy
        while a and b:
            if a.val <= b.val:
                cur.next, a = a, a.next
            else:
                cur.next, b = b, b.next
            cur = cur.next
        cur.next = a or b
        return dummy.next
```

## 复杂度

- 时间：O(n log n)
- 空间：O(log n)（递归栈）

## 易错点

- **必须切断** `slow.next = None`，否则前半段链表无尽地往后挂着，递归会死循环。
- fast 从 `head.next` 开始（不是 head），偶数长度时切点更靠左，递归才能保证分得真正小一些。
- 严格 O(1) 空间要求迭代版（自底向上归并），常见 leetcode 测试用例下递归版也能过。
