# 994. 腐烂的橘子

- 难度：中等
- 链接：https://leetcode.cn/problems/rotting-oranges/

## 直觉 / 记忆点

> **多源 BFS**：所有腐烂的橘子（值为 2）**同时**开始扩散。把它们一起加入初始队列，按层 BFS，每一层就是一分钟。最后若还有新鲜橘子（值为 1）没被波及就返回 -1，否则返回 BFS 总层数。

## 思路

队列初始放所有腐烂橘子的坐标 + 统计新鲜橘子数。BFS 每层用 size 控制；每弹出一个腐烂橘子，把周围的新鲜橘子腐烂掉并入队、新鲜计数 -1。

## 代码

```python
from collections import deque

class Solution:
    def orangesRotting(self, grid: list[list[int]]) -> int:
        m, n = len(grid), len(grid[0])
        q = deque()
        fresh = 0
        # 初始扫描：所有腐烂的入队、统计新鲜
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 2:
                    q.append((i, j))
                elif grid[i][j] == 1:
                    fresh += 1
        # 没有新鲜橘子，0 分钟就完成
        if fresh == 0:
            return 0
        minutes = 0
        dirs = [(1, 0), (-1, 0), (0, 1), (0, -1)]
        # 标准"按层 BFS"：每轮处理当前队列里所有节点，再 +1 分钟
        while q and fresh > 0:
            for _ in range(len(q)):
                i, j = q.popleft()
                for di, dj in dirs:
                    ni, nj = i + di, j + dj
                    # 邻居是新鲜橘子 → 腐烂、入队、计数 -1
                    if 0 <= ni < m and 0 <= nj < n and grid[ni][nj] == 1:
                        grid[ni][nj] = 2
                        fresh -= 1
                        q.append((ni, nj))
            minutes += 1
        # 还有新鲜橘子没被腐烂 → 不可能全部腐烂
        return minutes if fresh == 0 else -1
```

## 复杂度

- 时间：O(m × n)
- 空间：O(m × n)

## 易错点

- 必须是**多源 BFS**：初始把**所有**腐烂橘子一起入队，不能从一个开始（否则结果不正确）。
- 起步要特判 fresh == 0：直接返回 0 分钟（没有新鲜橘子要腐烂）。
- BFS 结束后 fresh 仍 > 0 表示有孤立的新鲜橘子（被墙隔开），返回 -1。
