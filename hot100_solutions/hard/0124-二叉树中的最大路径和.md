# 124. 二叉树中的最大路径和

- 难度：困难
- 链接:https://leetcode.cn/problems/binary-tree-maximum-path-sum/

## 直觉 / 记忆点

> 543"求直径"的**权值版**。还是后序 DFS"问左右、汇总自己"：
> - 每个节点返回"以我为根、**只能往单边**走的最大路径和"（值或值+max(0, max(左,右))）。负贡献的子树用 0 截断（不要这一段）。
> - 顺手用 `val + 左单边 + 右单边` 更新全局最大值（这才是"穿过当前节点的双侧路径和"）。

## 思路

DFS 返回单边贡献。

## 代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def maxPathSum(self, root: TreeNode | None) -> int:
        # 答案的下界是 -inf（题目允许全负数）
        self.ans = float("-inf")
        def gain(node: TreeNode | None) -> int:
            if not node:
                return 0
            # 左/右子树各自的"单边最大贡献"，负数就直接砍成 0（即"不要这一段"）
            l = max(0, gain(node.left))
            r = max(0, gain(node.right))
            # 穿过当前节点的"双侧路径和" = 自己 + 左单边 + 右单边
            # 用它更新全局答案（这条路径不能再向上延伸，因为它在当前节点拐弯了）
            self.ans = max(self.ans, node.val + l + r)
            # 返回给父节点的是"单边贡献"：只能选左或右继续向上
            return node.val + max(l, r)
        gain(root)
        return self.ans
```

## 复杂度

- 时间：O(n)
- 空间：O(h)

## 易错点

- 全局答案初始要用 **-inf**（不要 0），否则全是负数的情况下会错。
- 返回给父节点的是**单边**贡献（父节点用它继续构造一条直线路径），而双侧只能在拐点处贡献给全局答案。
- 负贡献用 `max(0, ...)` 砍掉，相当于不要那一段子树。
