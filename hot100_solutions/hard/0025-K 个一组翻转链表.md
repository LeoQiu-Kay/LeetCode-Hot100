# 25. K 个一组翻转链表

- 难度：困难
- 链接：https://leetcode.cn/problems/reverse-nodes-in-k-group/

## 直觉 / 记忆点

> 把 206 反转链表当作"局部子程序"，外面用 dummy + 指针拼接。每轮：1) **数 K 个节点**，不够 K 就剩余原样保留；2) **局部反转**这 K 个；3) 把反转后的小段**重新接回**前面的 prev 和后面的剩余。

## 思路

`prev` 指向"已处理段尾部"，每轮：

1. 让 `tail = prev`，往后走 k 步，看够不够。
2. 取出 [prev.next, tail] 这段，反转。
3. 把反转后的小段接回 prev，并把"原本的下一个 group 起点"接到反转后的小段尾。

## 代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def reverseKGroup(self, head: ListNode | None, k: int) -> ListNode | None:
        dummy = ListNode(0, head)
        prev_group = dummy   # "已处理段的尾巴"，下一组从 prev_group.next 开始
        while True:
            # 1. 数 k 个节点，看够不够
            kth = prev_group
            for _ in range(k):
                kth = kth.next
                if not kth:
                    return dummy.next   # 不够 k 个，剩余原样保留
            # 2. 切出本组：start = 本组第一个；nxt_group = 下一组第一个
            start = prev_group.next
            nxt_group = kth.next
            # 3. 反转本组（从 start 到 kth），用 206 的三指针法
            # 把 prev 初始化为 nxt_group，反转完成后 start.next 直接指到下一组首
            prev, cur = nxt_group, start
            while cur is not nxt_group:
                tmp = cur.next
                cur.next = prev
                prev = cur
                cur = tmp
            # 4. 反转完毕：kth 是新头、start 是新尾
            # 把上一段尾巴接到新头 kth；start（新尾）的 next 已经在反转时指到了 nxt_group
            prev_group.next = kth
            prev_group = start   # start 现在变成"已处理段尾巴"，下一轮从这里继续
```

## 复杂度

- 时间：O(n)（每个节点最多被访问 2 次：数 + 反转）
- 空间：O(1)

## 易错点

- 数 K 个时若中途碰到 None，**整组放弃反转**，直接返回结果。
- 反转那一段时把 `prev` 初始化为 `nxt_group` 是技巧：反转结束时新尾（start）的 next 已自动指向了下一组的首节点，省一行重接代码。
- 反转结束后 `prev_group` 要更新为 `start`（不是 kth），因为反转后 start 变成"本组尾巴"。
