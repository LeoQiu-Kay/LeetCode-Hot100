# 51. N 皇后

- 难度：困难
- 链接：https://leetcode.cn/problems/n-queens/

## 直觉 / 记忆点

> 按行 DFS（一行只能放一个皇后）。维护三个 set 标记当前被占用的：**列**、**主对角线**（row - col 常数）、**副对角线**（row + col 常数）。每行枚举列：三个 set 都没占用就放下，递归下一行，回溯撤销。

## 思路

DFS(row, cols, diag1, diag2, path)。row == n 收集结果。

## 代码

```python
class Solution:
    def solveNQueens(self, n: int) -> list[list[str]]:
        ans: list[list[str]] = []
        cols: set[int] = set()      # 已被占用的列
        diag1: set[int] = set()     # 主对角线：row - col 相同的属于同一条
        diag2: set[int] = set()     # 副对角线：row + col 相同的属于同一条
        path: list[int] = []        # path[i] 表示第 i 行皇后所在的列
        def dfs(row: int) -> None:
            if row == n:
                # 把列号方案转成棋盘字符串
                ans.append(['.' * c + 'Q' + '.' * (n - c - 1) for c in path])
                return
            for col in range(n):
                # 当前位置被任一约束占用，跳过
                if col in cols or (row - col) in diag1 or (row + col) in diag2:
                    continue
                # 放下皇后，登记三个约束
                cols.add(col)
                diag1.add(row - col)
                diag2.add(row + col)
                path.append(col)
                dfs(row + 1)
                # 回溯：撤销四个状态
                cols.remove(col)
                diag1.remove(row - col)
                diag2.remove(row + col)
                path.pop()
        dfs(0)
        return ans
```

## 复杂度

- 时间：O(n!)（剪枝后）
- 空间：O(n)

## 易错点

- 三条约束：**列、主对角线、副对角线**，缺一不可。主对角线常数是 `row - col`，副对角线是 `row + col`。
- 回溯时四个状态都要撤销：cols、diag1、diag2、path。
