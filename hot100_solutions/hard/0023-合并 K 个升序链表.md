# 23. 合并 K 个升序链表

- 难度：困难
- 链接：https://leetcode.cn/problems/merge-k-sorted-lists/

## 直觉 / 记忆点

> 21 题"合并两条"的扩展。两种思路：
> - **小顶堆**：把 K 个链表的当前头节点丢进堆里，每次取最小、把它的 next 再放进去——像 K 路归并的赛跑。
> - **分治两两合并**：把 K 条链表两两配对合并，配对完一轮变 K/2 条，再一轮 K/4 条…log K 轮变 1 条。
>
> 二选一，堆解法代码短，分治更好理解复杂度。

## 思路

用堆：把每条链表头节点 `(val, idx, node)` 入堆（idx 是为了避免堆比较时撞到 ListNode 比较），每次 pop 最小，挂到结果尾巴，再把它的 next 入堆。

## 代码

```python
import heapq

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def mergeKLists(self, lists: list[ListNode | None]) -> ListNode | None:
        # 小顶堆，元素是三元组 (val, 唯一序号, 节点)
        # 中间那个 idx 是关键：堆按字典序比较，当 val 相同时会去比第二个元素
        # ListNode 之间不能直接比较（没定义 __lt__），所以塞一个唯一的整数避免冲突
        heap: list[tuple[int, int, ListNode]] = []
        for i, node in enumerate(lists):
            if node:
                heapq.heappush(heap, (node.val, i, node))
        dummy = ListNode()
        cur = dummy
        # 计数器，给后续 push 的节点提供唯一序号
        idx = len(lists)
        while heap:
            # 弹出当前所有链表头节点里 val 最小的那个
            _, _, node = heapq.heappop(heap)
            cur.next = node
            cur = cur.next
            # 把它的下一个节点也入堆（如果存在）
            if node.next:
                heapq.heappush(heap, (node.next.val, idx, node.next))
                idx += 1
        return dummy.next
```

## 复杂度

- 时间：O(N log K)，N 是总节点数，K 是链表数
- 空间：O(K)（堆里同时最多 K 个节点）

## 易错点

- 三元组里的"唯一序号"不能省：相同 val 时堆会去比 ListNode 对象，Python 没定义比较就报错。
- 堆里只保存"还没接到结果的节点"，每条链表同时只占一个堆位。
