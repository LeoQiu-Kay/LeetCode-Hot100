# 42. 接雨水

- 难度：困难
- 链接：https://leetcode.cn/problems/trapping-rain-water/

## 直觉 / 记忆点

> 某一柱能接的水 = `min(左边最高, 右边最高) - 自身高度`。**相向双指针**：维护 `lmax`（左侧已遇到的最大值）和 `rmax`（右侧），每轮移动**较矮**的那侧。因为较矮一侧的"短板"就是当前确定的，能立即结算这一柱的水量。

## 思路

l, r 从两端走；lmax、rmax 边走边更新；总是移动较矮的那一边。

## 代码

```python
class Solution:
    def trap(self, height: list[int]) -> int:
        l, r = 0, len(height) - 1
        lmax = rmax = 0   # 左侧已扫的最大、右侧已扫的最大
        ans = 0
        while l < r:
            if height[l] < height[r]:
                # 左边较矮 → 左边的短板是 lmax（因为右边一定有比 height[l] 高的柱子）
                if height[l] >= lmax:
                    lmax = height[l]   # 更新左侧最高（这一柱当不了水池底）
                else:
                    ans += lmax - height[l]   # 这一柱能接 lmax - height[l] 的水
                l += 1
            else:
                # 右边较矮（或相等） → 右边的短板是 rmax
                if height[r] >= rmax:
                    rmax = height[r]
                else:
                    ans += rmax - height[r]
                r -= 1
        return ans
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- 移动**较矮**的一边（和 11 题反直觉地相同）：较矮一侧的水量已经被对侧的更高柱子"封住"，可以立即结算。
- 还有"单调栈"和"前后缀最大值数组"两种解法，本质都是要知道每根柱子左右两侧的最大值。
