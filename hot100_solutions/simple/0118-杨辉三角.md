# 118. 杨辉三角

- 难度：简单
- 链接：https://leetcode.cn/problems/pascals-triangle/

## 直觉 / 记忆点

> 每一行都是把上一行**复制两份并错开一格**，然后**对位相加**：左边那份在右肩添个空位、右边那份在左肩添个空位，两端因为错位露出来都填 1，中间相加得到这一行。一行一行往下推。

## 思路

逐行生成。第 `i` 行长度 `i + 1`，两端是 1，中间 `row[j] = prev[j-1] + prev[j]`。

## 代码

```python
class Solution:
    def generate(self, numRows: int) -> list[list[int]]:
        res: list[list[int]] = []   # 存放每一行
        # i 从 0 到 numRows-1，依次生成第 i 行
        for i in range(numRows):
            # 整行先全部填 1，长度为 i+1，两端的 1 就这样自然就位
            row = [1] * (i + 1)
            # 中间的位置（j = 1..i-1）由上一行相邻两个元素相加得到
            # 注意 i = 0、1 时这个循环 range(1, i) 为空，正好两端都是 1 即可
            for j in range(1, i):
                row[j] = res[i - 1][j - 1] + res[i - 1][j]
            res.append(row)
        return res
```

## 复杂度

- 时间：O(n²)
- 空间：O(n²)（仅输出本身）

## 易错点

- 内层 `range(1, i)` 跳过两端 1；`i = 0, 1` 时内层不进入，正好正确。
- 别引用还没写入的 `res[i - 1]`；先 append 后引用次序要对。
