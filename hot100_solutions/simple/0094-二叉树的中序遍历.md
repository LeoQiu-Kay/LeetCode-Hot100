# 94. 二叉树的中序遍历

- 难度：简单
- 链接：https://leetcode.cn/problems/binary-tree-inorder-traversal/

## 直觉 / 记忆点

> 中序就是"先把**左口袋**掏空，再点一下**自己**，最后掏**右口袋**"。沿左孩子一路往下塞栈（先把左口袋的所有东西全部拿出来排队），逐个弹出登记一下；每登记一个就去看它的右子树——同样这套方法再做一遍。

## 思路

中序 = 左 → 根 → 右。迭代写法用栈模拟：沿左链一直入栈，弹出时访问当前节点，再转向右子树继续。

## 代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def inorderTraversal(self, root: TreeNode | None) -> list[int]:
        res: list[int] = []        # 最终的中序结果
        stack: list[TreeNode] = []  # 模拟递归的栈
        cur = root                  # 当前要访问的节点
        # 当前节点非空 或 栈里还有节点（还没回溯完）就继续
        while cur or stack:
            # 沿着左孩子链一路下到底，把经过的节点都压栈
            while cur:
                stack.append(cur)
                cur = cur.left
            # 左边到底了，弹出最近的节点（中序此时正好访问到它）
            cur = stack.pop()
            res.append(cur.val)
            # 然后转向它的右子树，重复上面的"左到底"
            cur = cur.right
        return res
```

## 复杂度

- 时间：O(n)
- 空间：O(h)（栈深度，h 为树高，最坏 O(n)）

## 易错点

- 循环条件是 `cur or stack`，两者同时为空才能停。
- 递归版面试官常追问迭代版，记牢"沿左入栈 → 弹出访问 → 转右"。
