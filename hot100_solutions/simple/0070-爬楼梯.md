# 70. 爬楼梯

- 难度：简单
- 链接：https://leetcode.cn/problems/climbing-stairs/

## 直觉 / 记忆点

> 站在第 `n` 阶，回头看最后一脚怎么上来的：要么从 `n−1` 阶迈了 1 步，要么从 `n−2` 阶跨了 2 步。所以"上到第 n 阶的方法数 = 上到 n−1 的方法数 + 上到 n−2 的方法数"。从 1、2 阶开始一路累加就是斐波那契，**两个变量滚动**即可。

## 思路

到第 `n` 阶的方法数 `f(n) = f(n-1) + f(n-2)`（上一步走 1 或 2），等价于斐波那契。用两个变量滚动，把空间压到 O(1)。

## 代码

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        a, b = 1, 1  # f(0), f(1)
        for _ in range(n):
            a, b = b, a + b
        return a
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- 初始值 `f(0) = f(1) = 1`（爬 0 阶视为一种"不爬"方案）。
- 循环 `n` 次后 `a == f(n)`，写错偏移容易差 1。
