# 283. 移动零

- 难度：简单
- 链接：https://leetcode.cn/problems/move-zeroes/

## 直觉 / 记忆点

> 一队学生里非零的"留下"、零的"去后排"。你扫一遍数组，左手 `i` 始终停在"下一个非零该填的格子"。遇到非零就把它和 `i` 处交换并 `i++`；零留在原地等着以后被换到后排。最后非零按原序在前，零自然全到后面。

## 思路

双指针。`i` 指向下一个非零应该填入的位置，`j` 扫描全数组。遇到非零就和 `i` 交换并 `i += 1`。最终前 `i` 个是按原序的非零，后面自动是 0。

## 代码

```python
class Solution:
    def moveZeroes(self, nums: list[int]) -> None:
        i = 0
        for j, x in enumerate(nums):
            if x != 0:
                nums[i], nums[j] = nums[j], nums[i]
                i += 1
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- 要**原地修改**，函数没有返回值（题目要求 `Do not return anything`）。
- 用 "把非零先压到前面、剩下填 0" 也可以但是写两次循环；交换法一遍搞定且保持非零相对顺序。
