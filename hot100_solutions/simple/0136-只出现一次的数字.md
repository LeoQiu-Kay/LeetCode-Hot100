# 136. 只出现一次的数字

- 难度：简单
- 链接：https://leetcode.cn/problems/single-number/

## 直觉 / 记忆点

> 想象一个"配对消除"机器：每对相同的数字一进去就互相抵消变成 0，单身的那个会一路活到最后。异或就是这台机器：`a ^ a = 0`（同类相消）、`a ^ 0 = a`（不和空气抵消）、顺序怎么换都不影响结果。

## 思路

利用异或的两条性质：`a ^ a = 0`、`a ^ 0 = a`、满足交换/结合律。把所有数全部异或，成对的互相抵消为 0，只剩那个出现一次的数。

## 代码

```python
from functools import reduce
from operator import xor

class Solution:
    def singleNumber(self, nums: list[int]) -> int:
        return reduce(xor, nums)
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- 题目限定"其它每个元素恰好出现两次"才能用 XOR；出现三次的版本是另一道题。
- 不需要排序或哈希表（题目要求 O(1) 额外空间）。
