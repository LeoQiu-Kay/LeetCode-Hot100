# 141. 环形链表

- 难度：简单
- 链接：https://leetcode.cn/problems/linked-list-cycle/

## 直觉 / 记忆点

> 操场上两个人跑步：慢的每秒走 1 步，快的每秒走 2 步。如果跑道是**直线**，快的会先冲出终点（指针撞到 `None`）；如果跑道是**圆形**，每过一秒快的相对慢的多走一步，相当于在圆环里以"速度 1"追，最多绕一圈就一定追上——两人在同一节点重合，就是环存在的铁证。

## 思路

Floyd 龟兔赛跑：慢指针每次走 1 步，快指针每次走 2 步。若有环，两者**必然**相遇；若无环，快指针先到 `None`。

## 代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def hasCycle(self, head: ListNode | None) -> bool:
        # 两指针都从头出发：slow 每次走 1 步，fast 每次走 2 步
        slow = fast = head
        # 只要 fast 还能往前走两步，就继续；否则说明遇到链尾（无环）
        while fast and fast.next:
            slow = slow.next          # 慢指针走 1 步
            fast = fast.next.next     # 快指针走 2 步
            # 用 is 比较节点对象本身是否相同（同一个引用），不是比较 val
            if slow is fast:
                return True
        # 跳出循环说明 fast 走到 None，无环
        return False
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- 判 `fast` 和 `fast.next` 都不为空再走两步，否则空指针。
- 相遇判定用 `is`（同一节点对象）；不要用 `==`（会按 `val` 比较自定义类型时行为可能不对）。
