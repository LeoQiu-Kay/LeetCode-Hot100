# 226. 翻转二叉树

- 难度：简单
- 链接：https://leetcode.cn/problems/invert-binary-tree/

## 直觉 / 记忆点

> 给整棵树照"镜子"：每个节点的左右孩子原地**互换位置**，再让左右孩子各自对自己的子树照一遍镜子。递归一路下到叶子，整棵树就左右翻过来了。

## 思路

每个节点交换左右子树指针，递归处理两边。后序/前序都行，只要左右都被处理。

## 代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def invertTree(self, root: TreeNode | None) -> TreeNode | None:
        if not root:
            return None
        root.left, root.right = self.invertTree(root.right), self.invertTree(root.left)
        return root
```

## 复杂度

- 时间：O(n)
- 空间：O(h)

## 易错点

- Python 一行 `a, b = b, a` 是原子的元组赋值，先求右边再绑左边，没问题；用 C++/Java 时**必须**用临时变量。
- 迭代版用 BFS / DFS 出队/出栈时交换左右子节点也行。
