# 160. 相交链表

- 难度：简单
- 链接：https://leetcode.cn/problems/intersection-of-two-linked-lists/

## 直觉 / 记忆点

> 两个人各走各的路（A、B），走完后**自动切到对方起点继续走**。这样不管 A、B 多长，两人在切换后走过的总路程都是 `m + n`，长度差被互换路径补齐。结果两人**必然**在第一个相交点同时踩到（或者同时走到 `None` 表示无交点）。

## 思路

两个指针分别从 A、B 出发，走到末尾后切换到对方链表头继续走。这样两人走过的总路程都是 `m + n`，必然在相交点（或同时为 `None`）相遇。

直觉：先走完短链表的人会去走长链表，把"长度差"补齐。

## 代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def getIntersectionNode(self, headA: ListNode | None, headB: ListNode | None) -> ListNode | None:
        a, b = headA, headB
        while a is not b:
            a = a.next if a else headB
            b = b.next if b else headA
        return a
```

## 复杂度

- 时间：O(m + n)
- 空间：O(1)

## 易错点

- 切换头时是 `a = headB`（**对方**的头），不是回到自己头，否则死循环。
- 无相交时两个指针会同时变成 `None`，循环也会正确退出（返回 `None`）。
