# 21. 合并两个有序链表

- 难度：简单
- 链接：https://leetcode.cn/problems/merge-two-sorted-lists/

## 直觉 / 记忆点

> 两支队伍按身高排好队过闸机，门口你负责合流：每次只放**矮的那个**先进，那一队往前挪一个人。哪一队走完了，剩下整段塞到队尾就行。门口先摆个"假人"（dummy）当起点，省得纠结第一个谁先到。

## 思路

哑节点（dummy）+ 双指针。每次把较小的节点接到 `cur.next`，对应指针往后挪。一个走完后把另一个剩下的整段挂上。

## 代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def mergeTwoLists(self, list1: ListNode | None, list2: ListNode | None) -> ListNode | None:
        dummy = ListNode()
        cur = dummy
        while list1 and list2:
            if list1.val <= list2.val:
                cur.next, list1 = list1, list1.next
            else:
                cur.next, list2 = list2, list2.next
            cur = cur.next
        cur.next = list1 or list2
        return dummy.next
```

## 复杂度

- 时间：O(m + n)
- 空间：O(1)（只复用原节点，不新建）

## 易错点

- 链表题先想 `dummy` 简化头节点边界。
- 循环结束**必须**把剩余的整段挂上（任意一条可能没走完）。
