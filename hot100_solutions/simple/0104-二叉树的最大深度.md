# 104. 二叉树的最大深度

- 难度：简单
- 链接：https://leetcode.cn/problems/maximum-depth-of-binary-tree/

## 直觉 / 记忆点

> 老板（根节点）要知道公司有多少层，问下面两个总监："你们部门最深几层"。两人各自再问自己的下属，层层汇报。老板拿两个总监答案里**更大那个**加上自己这一层，就是公司深度。空节点（没人）汇报 0。这是典型的"问下属、汇总回报"递归。

## 思路

后序递归：当前深度 = 1 + max(左子树深度, 右子树深度)。空节点深度为 0。

## 代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def maxDepth(self, root: TreeNode | None) -> int:
        # 空节点深度为 0（递归出口）
        if not root:
            return 0
        # 当前深度 = 1（自己这一层）+ 两个子树更深的那一边
        return 1 + max(self.maxDepth(root.left), self.maxDepth(root.right))
```

## 复杂度

- 时间：O(n)
- 空间：O(h)（递归栈，最坏退化为链状 O(n)）

## 易错点

- 二叉树深度 ≠ 路径数；一根节点单棵树深度是 1，不是 0。
- 想避免栈溢出可以改 BFS 层序遍历计数。
