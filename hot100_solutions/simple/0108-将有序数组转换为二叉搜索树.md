# 108. 将有序数组转换为二叉搜索树

- 难度：简单
- 链接：https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/

## 直觉 / 记忆点

> 给一根有序的尺子要折成"天平稳的支架"：取**正中间**那个数当支点（根），左半段递归造左子树、右半段递归造右子树。每次都从中间切一刀，左右长度差最多 1，整棵树自然就是平衡的。

## 思路

数组中点作为根（保证两边长度差 ≤ 1，自然平衡），左半递归构造左子树，右半递归构造右子树。等价于"折半建 BST"。

## 代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def sortedArrayToBST(self, nums: list[int]) -> TreeNode | None:
        # 子函数：用 nums[l..r] 这段（闭区间）构造一棵平衡 BST
        def build(l: int, r: int) -> TreeNode | None:
            # 区间无效，对应空子树
            if l > r:
                return None
            # 取中点作为当前子树的根
            m = (l + r) // 2
            # 左半段递归构造左子树，右半段递归构造右子树
            return TreeNode(nums[m], build(l, m - 1), build(m + 1, r))
        # 用整个数组的闭区间 [0, len-1] 启动
        return build(0, len(nums) - 1)
```

## 复杂度

- 时间：O(n)
- 空间：O(log n)（递归栈，因为树高度被平衡到 log n）

## 易错点

- 区间用闭区间 `[l, r]`，递归边界是 `l > r`。
- "高度平衡 BST" 不要求唯一，取 `(l+r)//2` 或 `(l+r+1)//2` 都行。
