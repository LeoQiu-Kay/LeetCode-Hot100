# 121. 买卖股票的最佳时机

- 难度：简单
- 链接：https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/

## 直觉 / 记忆点

> 你只能买一次、卖一次。一边逐天往后看，一边在脑子里记着"到今天为止见过的最低价"。每到一天就问自己一句"如果今天卖，赚多少 = 今天价 − 历史最低价"。把所有这种"今天卖"的利润里挑最大的，亏本就不操作（下界 0）。

## 思路

只能买卖一次，等价于"找一个数对 `(i, j)`，`i < j`，使 `prices[j] - prices[i]` 最大"。一次遍历：维护到目前为止见到的最低买入价 `lo`，每个 `p` 更新答案 `p - lo`。

## 代码

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        # lo 维护"到目前为止见到的最低买入价"，初始设为正无穷
        lo = float("inf")
        # ans 是最大利润，下界 0（不操作）
        ans = 0
        # 一次遍历每天的价格
        for p in prices:
            # 先更新历史最低（保证 lo <= p，且 lo 出现在 p 之前或同位）
            lo = min(lo, p)
            # 再计算"今天卖"的利润，更新答案
            ans = max(ans, p - lo)
        return ans
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- 答案下界是 0（一笔都不做），不要返回负数。
- 必须**先更新 lo 再算差价**，保证买入在当前位置之前或同位（差价 0 不亏）。
