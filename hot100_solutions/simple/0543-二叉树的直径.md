# 543. 二叉树的直径

- 难度：简单
- 链接：https://leetcode.cn/problems/diameter-of-binary-tree/

## 直觉 / 记忆点

> 直径是树里两点之间最长的边数。**最长那条路径一定在某个节点"拐弯"**——这个拐点的"左子树最深路径 + 右子树最深路径"就是穿过它的最长。于是做一遍后序递归：每个节点干两件事，1) 返回"以我为根的单边最深"给父亲用；2) 顺手用 `左 + 右` 更新**全局答案**。直径不一定经过整棵树的根，所以一定要用全局变量。

## 思路

直径 = 任意两个节点之间最长路径的**边数** = 某个节点处 `左子树深度 + 右子树深度` 的最大值。所以做一次后序遍历：每个节点算"以我为根的左右深度和"更新答案，递归返回值是"以我为根的最大单边深度 + 1"。

注意直径不一定经过整树的根。

## 代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def diameterOfBinaryTree(self, root: TreeNode | None) -> int:
        self.ans = 0
        def depth(node: TreeNode | None) -> int:
            if not node:
                return 0
            l = depth(node.left)
            r = depth(node.right)
            self.ans = max(self.ans, l + r)
            return 1 + max(l, r)
        depth(root)
        return self.ans
```

## 复杂度

- 时间：O(n)
- 空间：O(h)

## 易错点

- 返回的是**边数**不是节点数，所以 `l + r` 不加 1。
- 必须用全局变量（或可变容器/`nonlocal`）记录答案，单纯返回深度拿不到跨子树的最大值。
