# 35. 搜索插入位置

- 难度：简单
- 链接：https://leetcode.cn/problems/search-insert-position/

## 直觉 / 记忆点

> 你按身高站队，新同学要插队找合适位置：每次和**中间那位**比身高，比他矮就到他左半边继续比，不矮就到他右半边（包括他）继续比。直到剩一个位置——这就是新同学该站的格子，无论队里原来有没有同身高的人。

## 思路

二分查找下界（lower_bound）：找第一个 `>= target` 的位置。用半开区间 `[lo, hi)`，结束时 `lo == hi` 就是答案；若数组中存在 `target` 也会落在该位置。

## 代码

```python
class Solution:
    def searchInsert(self, nums: list[int], target: int) -> int:
        lo, hi = 0, len(nums)
        while lo < hi:
            mid = (lo + hi) // 2
            if nums[mid] < target:
                lo = mid + 1
            else:
                hi = mid
        return lo
```

## 复杂度

- 时间：O(log n)
- 空间：O(1)

## 易错点

- `hi = len(nums)` 而不是 `len(nums) - 1`，因为答案可能 = 数组长度（插到末尾）。
- 半开区间下，循环条件用 `<`，`hi = mid`（不要 `mid - 1`）。
