# 1. 两数之和

- 难度：简单
- 链接：https://leetcode.cn/problems/two-sum/

## 直觉 / 记忆点

> 像在书店给朋友凑一对配对的书，你边翻边在小本子上记下"书名 → 它在第几排"。下一本书来时，先翻小本子看有没有它的"另一半"——有就立刻配对成功，没有就把它也登记进去等下一本来配。这个小本子就是哈希表，**先查再登记**，否则同一本书可能被自己配对。

## 思路

哈希表存"值 → 下标"。遍历 `nums`，对每个 `x` 看 `target - x` 是否已经在表里。第一次进入循环时表是空的，所以**先查后存**就不会让一个元素被用两次。

## 代码

```python
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        # 哈希表：键是"出现过的数值"，值是它的下标
        seen: dict[int, int] = {}
        # 遍历数组，i 是当前下标，x 是当前数值
        for i, x in enumerate(nums):
            # 计算"凑成 target 还差多少"
            need = target - x
            # 如果差值之前出现过，说明配对成功
            if need in seen:
                # 返回那个数的下标和当前下标
                return [seen[need], i]
            # 没配上就把当前数登记进哈希表，留给后面的数来配
            seen[x] = i
        # 题目保证有解，理论上走不到这里
        return []
```

## 复杂度

- 时间：O(n)
- 空间：O(n)

## 易错点

- 必须**先查再存**，否则 `nums = [3,3], target = 6` 会返回 `[0,0]`。
- 题目保证恰好一个解，不需要处理多解。
