# 1. 两数之和

- 难度：简单
- 链接：https://leetcode.cn/problems/two-sum/

## 直觉 / 记忆点

> 像在书店给朋友凑一对配对的书，你边翻边在小本子上记下"书名 → 它在第几排"。下一本书来时，先翻小本子看有没有它的"另一半"——有就立刻配对成功，没有就把它也登记进去等下一本来配。这个小本子就是哈希表，**先查再登记**，否则同一本书可能被自己配对。

## 思路

哈希表存"值 → 下标"。遍历 `nums`，对每个 `x` 看 `target - x` 是否已经在表里。第一次进入循环时表是空的，所以**先查后存**就不会让一个元素被用两次。

## 代码

```python
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        seen: dict[int, int] = {}
        for i, x in enumerate(nums):
            need = target - x
            if need in seen:
                return [seen[need], i]
            seen[x] = i
        return []
```

## 复杂度

- 时间：O(n)
- 空间：O(n)

## 易错点

- 必须**先查再存**，否则 `nums = [3,3], target = 6` 会返回 `[0,0]`。
- 题目保证恰好一个解，不需要处理多解。
