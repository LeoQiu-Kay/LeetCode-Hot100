# 169. 多数元素

- 难度：简单
- 链接：https://leetcode.cn/problems/majority-element/

## 直觉 / 记忆点

> 擂台赛：同名选手互相助威（+1），异名选手两两同归于尽（−1）。因为"多数元素"的人数 > 一半，他比所有其他选手加起来都多。所有对手被消灭完之后，他至少还能剩一个站在擂台上。代码就只用维护"当前擂主 + 剩余气血"两个变量。

## 思路

Boyer-Moore 投票法。维护候选人 `cand` 和计数 `cnt`。遍历时：
- 当前数 == cand：`cnt += 1`
- 不等：`cnt -= 1`，若 `cnt == 0` 换下一个为候选人

因为多数元素出现次数 `> n/2`，最后剩下的候选人**一定**是它。

## 代码

```python
class Solution:
    def majorityElement(self, nums: list[int]) -> int:
        cand = 0
        cnt = 0
        for n in nums:
            if cnt == 0:
                cand = n
            cnt += 1 if n == cand else -1
        return cand
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- 题目保证多数元素一定存在，所以不需要二次扫描验证；若题目不保证，需再扫一遍数一次。
- 排序取中位数 `nums[n//2]` 也是 O(n log n) 的合法解，但 Boyer-Moore 是面试官想看到的最优解。
