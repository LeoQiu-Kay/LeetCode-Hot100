# 206. 反转链表

- 难度：简单
- 链接：https://leetcode.cn/problems/reverse-linked-list/

## 直觉 / 记忆点

> 一队人原本前手拉前人的肩膀，现在要让大家**反过来**拉。一次只能改一个人，所以你需要三只手：左手记住"前一个人"`prev`，右手按着"当前这个人"`cur`，另外**先记一下"它原本要拉谁"** `nxt`，否则手一改链就再也找不到下一个。改好之后整体往后挪一位继续。

## 思路

三指针迭代：`prev`、`cur`、`nxt`。每次先记住 `cur.next`，再把 `cur.next` 指向 `prev`，然后整体右移。

## 代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def reverseList(self, head: ListNode | None) -> ListNode | None:
        # prev：当前节点反转后要指向的"前驱"，初始为 None（反转后头变尾）
        # cur：当前正在处理的节点
        prev, cur = None, head
        while cur:
            # 第一步：先把"原本的下一个"存住，否则下一行改完链就丢了
            nxt = cur.next
            # 第二步：把当前节点的 next 指向 prev（这就是反转的核心动作）
            cur.next = prev
            # 第三步：prev、cur 整体右移一位，继续处理下一个节点
            prev = cur
            cur = nxt
        # 循环结束 cur == None，prev 指向原链表的最后一个节点，也就是新链表的头
        return prev
```

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点

- **先存 nxt 再改指向**，否则丢链。
- 返回 `prev` 不是 `cur`（cur 最后是 None）。
- 递归版常被追问：`reverse(head)` 返回新头，`head.next.next = head; head.next = None`。
