# 104. 二叉树的最大深度 · 阅读版

> 难度：简单 · [LeetCode 链接](https://leetcode.cn/problems/maximum-depth-of-binary-tree/)

---

## 一、题目讲了什么

求二叉树的**最大深度**——根到任一叶子节点的最长路径上的节点数。

例：

```
    3
   / \
  9  20         深度 = 3（路径 3 → 20 → 15 或 7）
     / \
    15  7
```

---

## 二、递归思路：问下属

把整棵树想象成一个公司：

> 我（根）的深度 = 1（我自己这层）+ 我两个下属里**更深**的那个的深度

也就是：

```
depth(node) = 1 + max(depth(node.left), depth(node.right))
```

空节点（没下属）深度 0。

这是"**后序递归**"的典型套路：先问左右子树各自的答案，再汇总成自己的答案。

---

## 三、为什么递归在这道题这么自然

二叉树本身就是**递归定义**的：每个节点要么是空，要么是"一个值 + 左子树 + 右子树"。把"求深度"也写成递归，结构完美匹配数据结构本身。

很多树题都符合"**问下属、汇总自己**"这个套路：

- **深度** = 1 + max(左, 右)
- **节点数** = 1 + 左 + 右
- **是否平衡** = 左平衡 ∧ 右平衡 ∧ |左高-右高| ≤ 1
- ……

## 四、写成代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def maxDepth(self, root: TreeNode | None) -> int:
        # 空节点深度为 0（递归出口）
        if not root:
            return 0
        # 当前深度 = 1（自己这一层）+ 两个子树更深的那一边
        return 1 + max(self.maxDepth(root.left), self.maxDepth(root.right))
```

三行，比题目本身还短。

---

## 五、复杂度

- **时间** `O(n)`：每个节点访问一次
- **空间** `O(h)`：递归栈，h 是树高（最坏退化成链 O(n)）

---

## 六、BFS 版（可选）

担心递归爆栈可以改成 BFS：层序遍历，记录走了多少层。

```python
from collections import deque

def maxDepth(root):
    if not root: return 0
    q = deque([root])
    depth = 0
    while q:
        depth += 1
        for _ in range(len(q)):
            node = q.popleft()
            if node.left: q.append(node.left)
            if node.right: q.append(node.right)
    return depth
```

---

## 七、容易踩的坑

1. **空树深度 0**（不是 1）。
2. **单节点深度 1**（不是 0）。
3. **深度是"节点数"还是"边数"**？本题是**节点数**（根算 1）。有的题用"边数"，差 1。

---

## 八、一句话记忆

> **后序递归三件套**：空树返 0；否则 `1 + max(左, 右)`。
