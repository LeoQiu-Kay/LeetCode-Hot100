# 169. 多数元素 · 阅读版

> 难度：简单 · [LeetCode 链接](https://leetcode.cn/problems/majority-element/)

---

## 一、题目讲了什么

数组里有一个数**出现次数 > n / 2**（"多数元素"），找出它。题目保证一定存在。

要求最优：**O(n) 时间、O(1) 空间**。

例：`[3, 2, 3]` → 3；`[2, 2, 1, 1, 1, 2, 2]` → 2。

---

## 二、几种思路对比

| 思路 | 时间 | 空间 | 评价 |
|---|---|---|---|
| 哈希计数 | O(n) | O(n) | 直接，但不满足空间约束 |
| 排序后取中位数 | O(n log n) | O(1) | 多数元素必在中位数位置（占了一半以上） |
| **Boyer-Moore 投票** | **O(n)** | **O(1)** | 神技——同时满足两个约束 |

中位数解法很巧但要 O(n log n)；投票法才是真正的最优解。

---

## 三、Boyer-Moore 投票法的核心想法

> 多数元素的人数 **比所有其它人加起来还多**（因为 > n/2）。

类比：擂台赛。

- 每个数字是一个"选手"
- **同名互相加血**（+1）
- **异名同归于尽**（-1）

战斗结束后，多数元素的"剩余血量"必然 > 0（因为他比所有对手加起来都多），他**至少剩 1 个站在擂台上**——就是最终留下的擂主。

---

## 四、算法细节

维护两个变量：

- `cand`：当前擂主
- `cnt`：擂主当前的"剩余气血"

遍历每个数字 `n`：

- `cnt == 0`：擂主已倒下，**新人 n 接任**
- `n == cand`：同名加血，`cnt += 1`
- `n != cand`：异名互殴，`cnt -= 1`

遍历结束，`cand` 就是多数元素。

---

## 五、过一遍 `[2, 2, 1, 1, 1, 2, 2]`

| 数 | 动作 | cand | cnt |
|---|---|---|---|
| 2 | cnt=0，接任 | 2 | 1 |
| 2 | 同名 | 2 | 2 |
| 1 | 异名 | 2 | 1 |
| 1 | 异名 | 2 | 0 |
| 1 | cnt=0，接任 | 1 | 1 |
| 2 | 异名 | 1 | 0 |
| 2 | cnt=0，接任 | 2 | 1 |

最终 cand = 2。

注意中途 cand 几度变化，但只要"多数元素存在"，他最后一定会笑到最后。

---

## 六、写成代码

```python
class Solution:
    def majorityElement(self, nums: list[int]) -> int:
        # cand 当前候选擂主，cnt 当前剩余气血
        cand = 0
        cnt = 0
        for n in nums:
            # 气血归零时，让当前数字接任擂主
            if cnt == 0:
                cand = n
            # 同名 +1，异名 -1（相当于"同归于尽"）
            cnt += 1 if n == cand else -1
        # 因为多数元素 > n/2，对手全部消耗完后他至少还剩 1，必然是答案
        return cand
```

---

## 七、复杂度

- **时间** `O(n)`：一次扫描
- **空间** `O(1)`：两个变量

---

## 八、容易踩的坑

1. **必须题目保证多数元素存在**才能直接返回 `cand`。否则要再扫一遍验证（数 cand 真的出现 > n/2 次）。
2. **`cnt == 0` 时**："**接任**"和"加血"两个动作在代码上是 if 在前、`cnt += 1` 紧跟，效果一致。
3. **方法名 Boyer-Moore Voting** 面试时能讲出来加分。

---

## 九、一句话记忆

> **同名加血、异名互殴**：多数元素 > 一半，**他比所有人加起来都多**，必能笑到最后。
