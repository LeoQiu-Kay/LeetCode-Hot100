# 101. 对称二叉树 · 阅读版

> 难度：简单 · [LeetCode 链接](https://leetcode.cn/problems/symmetric-tree/)

---

## 一、题目讲了什么

判断一棵二叉树**沿中线对折是否完全重合**——即"左子树是右子树的镜像"。

例：

```
      1                      1
     / \                    / \
    2   2     ←对称         2   2
   / \ / \                   \   \
  3  4 4  3                   3   3   ← 不对称
```

---

## 二、关键转换：把问题"对偶化"

要判断一整棵树自己对称，等价于判：

> **左子树**和**右子树**互为镜像。

"两棵树互为镜像"的判定，要比"一棵树自己对称"清晰得多——它有明确的两个输入。所以我们定义一个**辅助函数**：

```
isMirror(a, b)  ←  a 和 b 这两棵子树互为镜像吗？
```

主函数只要调用一次 `isMirror(root.left, root.right)`。

---

## 三、镜像递归三条件

`a` 和 `b` 互为镜像，当且仅当：

1. **两个都空** → 镜像（递归出口）
2. **只有一个空** → 不镜像
3. 两个都非空时，要满足：
   - 根值相等：`a.val == b.val`
   - **外侧对外侧**：`a.left ↔ b.right`
   - **内侧对内侧**：`a.right ↔ b.left`

第 3 条的"对偶"是关键，画个图就秒懂：

```
       a            b
      / \          / \
   外侧  内侧    内侧  外侧
   (左)  (右)    (左)  (右)
```

中线对折后，**a 的左**要碰上**b 的右**（都是外侧），**a 的右**要碰上**b 的左**（都是内侧）。

很多人写错的地方就在这里：直觉地写 `a.left ↔ b.left`、`a.right ↔ b.right` —— 那是判"两棵树相同"不是"互为镜像"。

---

## 四、写成代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def isSymmetric(self, root):
        def isMirror(a, b):
            if not a and not b:
                return True            # 都空，对称
            if not a or not b:
                return False           # 只有一个空，不对称
            return (a.val == b.val
                    and isMirror(a.left, b.right)    # 外 ↔ 外
                    and isMirror(a.right, b.left))   # 内 ↔ 内
        return not root or isMirror(root.left, root.right)
```

---

## 五、复杂度

- **时间** `O(n)`：每个节点访问一次
- **空间** `O(h)`：递归栈

---

## 六、容易踩的坑

1. **递归参数是"对偶的一对"**：`(a.left, b.right)` 和 `(a.right, b.left)`，写成 `(a.left, b.left)` 就成了"判相同"。
2. **两个都空才 True，只一个空就 False**：顺序别错。
3. **空树是对称的**：`root is None` 返回 True。

---

## 七、一句话记忆

> 自己对称 = **左右子树互为镜像**；镜像递归看"**外对外 + 内对内**"。
