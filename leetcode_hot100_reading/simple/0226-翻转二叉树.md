# 226. 翻转二叉树 · 阅读版

> 难度：简单 · [LeetCode 链接](https://leetcode.cn/problems/invert-binary-tree/)

---

## 一、题目讲了什么

把一棵二叉树**沿中线左右翻转**——每个节点的左右孩子互换位置。

例：

```
       4                       4
      / \                     / \
     2   7      →            7   2
    / \ / \                 / \ / \
   1  3 6  9               9  6 3  1
```

是 101"对称二叉树"的"动手版"——101 是判定，226 是真的去翻。

---

## 二、递归思路

每个节点要做的事："**把自己的左右孩子换位**，然后让两个孩子自己也翻"。

```
invert(node):
    if node is None: return None
    左孩子 = invert(node.right)    # 原右孩子翻转后的结果，挂到左
    右孩子 = invert(node.left)     # 原左孩子翻转后的结果，挂到右
    node.left, node.right = 左孩子, 右孩子
    return node
```

也可以写成"先递归再交换"或"先交换再递归"，顺序不影响结果（因为每个节点最终都会换且都会递归处理）。

---

## 三、用 Python 元组赋值的偷懒写法

Python 的 `a, b = b, a` 是**原子**操作：先把右边的值算完，再绑左边的变量。所以：

```python
root.left, root.right = self.invertTree(root.right), self.invertTree(root.left)
```

一行同时完成"两个子树递归翻转 + 互换挂载"。

> **C++ / Java 用户注意**：你们的赋值不是原子的，必须用临时变量，否则 `root.left = invert(root.right)` 后 `root.left` 已经变，再 `root.right = invert(root.left)` 就用错值了。

---

## 四、写成代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def invertTree(self, root: TreeNode | None) -> TreeNode | None:
        # 递归出口：空节点直接返回 None
        if not root:
            return None
        # Python 元组赋值是"先算右边再绑左边"，所以这一行同时完成：
        #   1. 对左右子树各自递归翻转
        #   2. 把翻转后的右子树挂到 root.left，反之亦然
        root.left, root.right = self.invertTree(root.right), self.invertTree(root.left)
        return root
```

---

## 五、复杂度

- **时间** `O(n)`：每个节点访问一次
- **空间** `O(h)`：递归栈，h 是树高

---

## 六、迭代版（BFS）

```python
from collections import deque

def invertTree(root):
    if not root: return None
    q = deque([root])
    while q:
        node = q.popleft()
        node.left, node.right = node.right, node.left   # 交换
        if node.left:  q.append(node.left)
        if node.right: q.append(node.right)
    return root
```

层序遍历每个节点同时把它的左右孩子交换。

---

## 七、容易踩的坑

1. **C++/Java 不能直接抄一行写法**，要用临时变量。
2. **空节点要先判**：`if not root: return None`，否则 `root.left` 爆 None。
3. **方向无所谓**：先交换再递归 / 先递归再交换 / 一行同时——结果都对。

---

## 八、一句话记忆

> 翻转 = **每个节点左右孩子互换 + 递归到子树**。Python 一行优雅，其它语言要临时变量。
