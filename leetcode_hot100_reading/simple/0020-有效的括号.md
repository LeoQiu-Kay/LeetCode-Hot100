# 20. 有效的括号 · 阅读版

> 难度：简单 · [LeetCode 链接](https://leetcode.cn/problems/valid-parentheses/)

---

## 一、题目讲了什么

给一个只含 `() [] {}` 六种字符的字符串，判断是否"合法配对"。

合法的规则两条：

1. 每个右括号必须能匹配到一个**同类型**的左括号
2. 配对要按**正确顺序**——后开的先关

例子：

- `"()"` ✓
- `"()[]{}"` ✓
- `"([)]"` ✗（顺序不对：`[` 在 `(` 之后开，应该先关）
- `"(("` ✗（有左括号没关）

---

## 二、找规律：最近开的最先关

观察合法序列里的右括号：它要匹配的，永远是**离它最近的、还没配对的那个左括号**。

例：`"([{}])"` 这串里，遇到第一个 `}` 时，应该和最近的 `{` 配对；接着 `]` 和最近的 `[` 配对；最后 `)` 和最近的 `(` 配对。

> "最近的、还没配对的、最先取出来用" —— 这就是**栈**（LIFO，后进先出）的定义。

---

## 三、把规律变成算法

扫一遍字符串：

- 遇到**左括号** `( [ {` → 入栈，等右括号来配
- 遇到**右括号** `) ] }` → 看栈顶：
  - 栈空？没东西可配，**非法**
  - 栈顶不是对应的左括号？类型对不上，**非法**
  - 配上了？把栈顶弹出
- 扫完后栈必须是**空**的（所有左括号都配对了），否则有未关的左括号，**非法**

最后一步特别容易漏：`"(("` 全部入栈，扫完后栈非空，要判断它非法。

---

## 四、画个表演示 `"([])"`

| 当前字符 | 动作 | 栈（栈底到栈顶） |
|---|---|---|
| `(` | 入栈 | `[ '(' ]` |
| `[` | 入栈 | `[ '(', '[' ]` |
| `]` | 栈顶 `[`，匹配，弹出 | `[ '(' ]` |
| `)` | 栈顶 `(`，匹配，弹出 | `[]` |

扫完栈空 → 合法。

如果中途有问题，比如 `"([)]"`：

| 当前字符 | 动作 | 栈 |
|---|---|---|
| `(` | 入栈 | `[ '(' ]` |
| `[` | 入栈 | `[ '(', '[' ]` |
| `)` | 栈顶 `[`，**对不上**（应该是 `(`） → 立刻返回 False | |

---

## 五、写成代码

```python
class Solution:
    def isValid(self, s: str) -> bool:
        # 右括号 → 对应的左括号
        pair = {')': '(', ']': '[', '}': '{'}
        stack: list[str] = []
        for c in s:
            if c in pair:                 # 是右括号
                # 栈空 或 栈顶不是对应左括号 → 非法
                if not stack or stack.pop() != pair[c]:
                    return False
            else:                          # 是左括号
                stack.append(c)
        # 全部扫完后栈必须空
        return not stack
```

---

## 六、复杂度

- **时间** `O(n)`：每个字符最多入栈、出栈一次
- **空间** `O(n)`：最坏全是左括号都入栈

---

## 七、容易踩的坑

1. **结尾必须判栈空**：忘了这条会把 `"(("` 当合法。
2. **右括号来时先判栈空**：栈空不能 `pop`，会异常。
3. **字典只存"右→左"映射**：判 `c in pair` 等价于"c 是右括号"，代码更紧凑。

---

## 八、一句话记忆

> **左入栈、右配对，最后栈空才合法**。
