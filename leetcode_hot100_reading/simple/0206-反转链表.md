# 206. 反转链表 · 阅读版

> 难度：简单 · [LeetCode 链接](https://leetcode.cn/problems/reverse-linked-list/)

---

## 一、题目讲了什么

把单链表反转。

例：`1 → 2 → 3 → 4 → 5` → `5 → 4 → 3 → 2 → 1`

链表题最基础的母题之一，几乎所有难一档的链表题（25 K 个一组反转、234 回文链表、92 反转区间）都依赖这个 5 行代码。

---

## 二、为什么不能"原地交换"

数组反转可以 `swap(arr[l], arr[r])` 双指针对撞。链表不行——单链表只能从前往后走，没法 O(1) 拿到"前一个节点"。

得换思路：**逐个改方向**。

---

## 三、单步动作的画面

每个节点要做的事是把自己的 `next` 指针**调头**——从指向后继，改成指向前驱。但只能一个一个改。

需要三只手：

- `prev`：当前节点改完后，要让它的 `next` 指向谁
- `cur`：当前正在处理的节点
- `nxt`：**先把"原本的下一个"存住**，否则改完 `cur.next` 就再也找不到下一个节点了

```
反转前：  prev → None    cur → 1 → 2 → 3 → ...

第 1 步：先存 nxt = cur.next（= 2）
第 2 步：cur.next = prev      （让 1 指向 None）
第 3 步：prev = cur          （prev 移到 1）
第 4 步：cur = nxt           （cur 移到 2）

反转后：  prev → 1 → None    cur → 2 → 3 → ...
```

继续循环。`cur` 走到 None 时，`prev` 就是新的头。

---

## 四、写成代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def reverseList(self, head: ListNode | None) -> ListNode | None:
        # prev：当前节点反转后要指向的"前驱"，初始为 None（反转后头变尾）
        # cur：当前正在处理的节点
        prev, cur = None, head
        while cur:
            # 第一步：先把"原本的下一个"存住，否则下一行改完链就丢了
            nxt = cur.next
            # 第二步：把当前节点的 next 指向 prev（这就是反转的核心动作）
            cur.next = prev
            # 第三步：prev、cur 整体右移一位，继续处理下一个节点
            prev = cur
            cur = nxt
        # 循环结束 cur == None，prev 指向原链表的最后一个节点，也就是新链表的头
        return prev
```

---

## 五、复杂度

- **时间** `O(n)`：每个节点访问一次
- **空间** `O(1)`：三个指针

---

## 六、四步顺序不能错

最容易出 bug 的是顺序：

❌ 先 `cur.next = prev` 再算 nxt → cur 的 next 已被改，再 `cur.next` 不再是原来的下一个了。

✓ **先存 nxt，再改 next**。这是**所有指针调整题**的通用法则："**先备份要丢失的引用**"。

---

## 七、递归版（可选）

```python
def reverseList(head):
    if not head or not head.next:
        return head
    new_head = reverseList(head.next)
    head.next.next = head    # 让"原本的下一个"反指向我
    head.next = None         # 我自己的 next 切断
    return new_head
```

不直观但很优雅，面试时被追问"再写个递归版"可以背一下。

---

## 八、容易踩的坑

1. **三指针顺序**：`先存 nxt → 改 cur.next → 移 prev → 移 cur`，逆序就丢链。
2. **返回的是 prev 不是 cur**：循环结束 cur = None，prev 才是新头。
3. **空链表 / 单节点**：上面代码不需要特判（while 一次都不进入，直接返回 head 也对）。

---

## 九、一句话记忆

> **三只手 + 四步走**：存 nxt、改 next、移 prev、移 cur。返回 prev。
