# 94. 二叉树的中序遍历 · 阅读版

> 难度：简单 · [LeetCode 链接](https://leetcode.cn/problems/binary-tree-inorder-traversal/)

---

## 一、题目讲了什么

中序遍历一棵二叉树，返回所有节点值的列表。

**中序**的定义：对每个子树，按 **左 → 根 → 右** 的顺序访问。

例：
```
      1
       \
        2
       /
      3
```
中序结果是 `[1, 3, 2]`。

---

## 二、递归是最自然的写法

递归三行就完：

```python
def inorder(node):
    if not node:
        return
    inorder(node.left)    # 左
    res.append(node.val)  # 根
    inorder(node.right)   # 右
```

但面试官常追问"**不用递归怎么写**"——这才是这题的重点。

---

## 三、为什么要学迭代版

两个理由：

1. **递归深度可能爆栈**：极端情况下树退化成链表，递归深 n 层。
2. **迭代写法揭示了"递归到底在做什么"**：递归的本质是**栈**——函数调用栈帮你存中间状态。手动用栈模拟，你就真正理解了。

---

## 四、把递归"展开"成迭代

观察递归版的执行流：

```
进入 inorder(root)
  → 调用 inorder(root.left)
      → 调用 inorder(root.left.left)
          → ...
          → 一路下到最左节点 X，左为空返回
      → 访问 X.val
      → 调用 inorder(X.right)
      ...
```

模式很清晰：

1. **沿着左孩子链一路往下**，路过的节点先压栈
2. 走到左尽头，**弹出栈顶访问**它（这一刻它是"中序的下一个"）
3. **转向它的右子树**，重复上面过程

---

## 五、画一遍 `[1, null, 2, 3]` 的过程

树结构：

```
1
 \
  2
 /
3
```

| 步骤 | cur | stack | 动作 | res |
|---|---|---|---|---|
| 0 | 1 | [] | 入栈 1，cur=1.left=None | [] |
| 1 | None | [1] | 弹出 1，访问，cur=1.right=2 | [1] |
| 2 | 2 | [] | 入栈 2，cur=2.left=3 | [1] |
| 3 | 3 | [2] | 入栈 3，cur=3.left=None | [1] |
| 4 | None | [2,3] | 弹出 3，访问，cur=3.right=None | [1,3] |
| 5 | None | [2] | 弹出 2，访问，cur=2.right=None | [1,3,2] |
| 6 | None | [] | 栈空且 cur 空，结束 | [1,3,2] |

## 六、写成代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def inorderTraversal(self, root: TreeNode | None) -> list[int]:
        res: list[int] = []        # 最终的中序结果
        stack: list[TreeNode] = []  # 模拟递归的栈
        cur = root                  # 当前要访问的节点
        # 当前节点非空 或 栈里还有节点（还没回溯完）就继续
        while cur or stack:
            # 沿着左孩子链一路下到底，把经过的节点都压栈
            while cur:
                stack.append(cur)
                cur = cur.left
            # 左边到底了，弹出最近的节点（中序此时正好访问到它）
            cur = stack.pop()
            res.append(cur.val)
            # 然后转向它的右子树，重复上面的"左到底"
            cur = cur.right
        return res
```

---

## 七、复杂度

- **时间** `O(n)`：每个节点入栈、出栈各一次
- **空间** `O(h)`：栈深度等于树高；最坏退化成链表时是 O(n)

---

## 八、容易踩的坑

1. **循环条件** 是 `cur or stack`，两者**都空**才结束。只判一个会提前退出。
2. **"沿左链下到底"是内层 while**，别和外层 while 混。
3. **弹出后立刻转右**：弹出 cur，访问后立刻 `cur = cur.right`，下一轮外层 while 再走"沿左链"。

---

## 九、一句话记忆

> 中序迭代三件套：**沿左压栈 → 弹出访问 → 转向右子树**，循环直到栈空且 cur 空。
