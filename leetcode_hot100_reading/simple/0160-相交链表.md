# 160. 相交链表 · 阅读版

> 难度：简单 · [LeetCode 链接](https://leetcode.cn/problems/intersection-of-two-linked-lists/)

---

## 一、题目讲了什么

两条链表 `A` 和 `B` 可能在某个节点开始**共用相同的后续节点**（即相交，从那个节点开始两条链合二为一）。找出**第一个公共节点**；不相交返回 `None`。

注意"相交"指**指针相同**（同一个对象），不是值相等。

例：

```
A: a1 → a2
              ↘
                c1 → c2 → c3     ← 公共部分
              ↗
B: b1 → b2 → b3
```

返回 c1。

---

## 二、暴力 O(m × n)：把每个 A 节点和每个 B 节点比对——慢。

**哈希表 O(m + n)**：把 A 全塞进 set，扫 B 时找第一个出现的。简单可行，但 O(n) 空间。能不能 **O(1) 空间**？

---

## 三、巧解：a + b = b + a

设 A 长 m，B 长 n，公共部分长 c：

- A 独有：`m - c` 个节点
- B 独有：`n - c` 个节点

让两个指针：

- **pA** 从 A 头出发，走完 A 后**跳到 B 头**继续
- **pB** 从 B 头出发，走完 B 后**跳到 A 头**继续

两指针走过的**总路程一样**：都是 `m + n` 步。

- 如果有相交：两指针会在第一个公共节点同时到达
- 如果没相交：两指针会同时变成 `None`（也算"到达"，循环终止）

```
路径长度对比：
pA:  m  +  n
pB:  n  +  m
两者最终在同一个位置（要么交点，要么 None）
```

**精彩之处**：靠"互换路径"自动补齐了 A、B 长度差，省去了"先算长度再对齐"的繁琐。

---

## 四、写成代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def getIntersectionNode(self, headA, headB):
        a, b = headA, headB
        while a is not b:
            a = a.next if a else headB   # a 走完了切到 B 的头
            b = b.next if b else headA   # b 走完了切到 A 的头
        return a   # 要么交点，要么 None
```

---

## 五、复杂度

- **时间** `O(m + n)`：每个指针走完 m + n 步
- **空间** `O(1)`：两个指针

---

## 六、容易踩的坑

1. **切换的是"对方的头"，不是自己的头**：写错就死循环。
2. **比较用 `is not`**：本题要的是同一节点对象。
3. **不相交时**两个指针**同时**变 None，循环正确退出返回 None。注意三元式里的 `if a else headB` 保证 a 是 None 时下一步切到 B 头，而不是 `a.next` 爆错。

---

## 七、一句话记忆

> **a + b = b + a**：两个指针互换路径走，长度差被自动补齐，最终在交点（或 None）相遇。
