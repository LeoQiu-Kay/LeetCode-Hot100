# 283. 移动零 · 阅读版

> 难度：简单 · [LeetCode 链接](https://leetcode.cn/problems/move-zeroes/)

---

## 一、题目讲了什么

把数组里所有 0 移到末尾，**保持非零元素的相对顺序**，**原地**操作（不允许新建数组）。

例：`[0, 1, 0, 3, 12]` → `[1, 3, 12, 0, 0]`

---

## 二、双指针思路：写指针 + 扫指针

用两个指针：

- **写指针 `i`**：始终指向"下一个非零应该填入的位置"
- **扫指针 `j`**：遍历整个数组

当 `j` 遇到非零元素 → 交换 `nums[i]` 和 `nums[j]`，然后 `i += 1`。

为什么交换而不是直接赋值？因为我们要**保留**原 i 位置上的 0（它会被换到后面，最终在末尾自然就位）。这样**一遍扫描**就完成"非零按原序往前堆 + 零自然到后面"两件事。

---

## 三、走一遍 `[0, 1, 0, 3, 12]`

初始：`i = 0`，`nums = [0, 1, 0, 3, 12]`

| j | nums[j] | 动作 | i | nums |
|---|---|---|---|---|
| 0 | 0 | 跳过 | 0 | [0, 1, 0, 3, 12] |
| 1 | 1 | swap(0,1)，i++ | 1 | [1, 0, 0, 3, 12] |
| 2 | 0 | 跳过 | 1 | [1, 0, 0, 3, 12] |
| 3 | 3 | swap(1,3)，i++ | 2 | [1, 3, 0, 0, 12] |
| 4 | 12 | swap(2,4)，i++ | 3 | [1, 3, 12, 0, 0] |

完成。

---

## 四、写成代码

```python
class Solution:
    def moveZeroes(self, nums):
        i = 0
        for j, x in enumerate(nums):
            if x != 0:
                nums[i], nums[j] = nums[j], nums[i]
                i += 1
        # 题目要求"不返回值"，原地修改即可
```

---

## 五、复杂度

- **时间** `O(n)`：一趟扫描
- **空间** `O(1)`：两个下标变量

---

## 六、为什么这样能保留非零相对顺序

写指针 `i` 永远走在扫指针 `j` 的左边或同位：

- 当 `j` 遇到非零时，`i` 处要么是 0 要么是 i==j（这意味着前面没零，i 一直跟着 j）
- 交换不会打乱前面已经"压紧"的非零段，只是把当前非零搬到下一个空位

所以非零按它们在原数组的顺序依次落到前段。

---

## 七、容易踩的坑

1. **不能 return**：题目要求**原地**。返回新数组算违规。
2. **不要先压零、再补零**："非零都搬前面、剩下填 0"是另一种写法（两趟扫描），但**单趟交换法**最优雅。
3. **i 和 j 的递增条件不同**：`j` 每轮 +1，`i` 仅在遇到非零时 +1。

---

## 八、一句话记忆

> **同向双指针**：i 写非零位置、j 扫整数组，遇到非零就 swap 并 i++。
