# 35. 搜索插入位置 · 阅读版

> 难度：简单 · [LeetCode 链接](https://leetcode.cn/problems/search-insert-position/)

---

## 一、题目讲了什么

一个**已排序**的不重复数组 `nums`，给一个 `target`：

- target 在数组里 → 返回它的下标
- 不在 → 返回它**应该插入**到哪个位置才能保持有序

例：`nums = [1, 3, 5, 6]`

- `target = 5` → `2`（已在）
- `target = 2` → `1`（插到 3 前面）
- `target = 7` → `4`（追加到末尾）

要求时间复杂度 `O(log n)` —— 这是在明示**二分查找**。

---

## 二、把问题抽象一下

不管 target 在不在，答案都是**第一个 ≥ target 的位置**：

- target 在 `[1,3,5,6]` 找 5：第一个 ≥ 5 的位置就是下标 2
- target 不在 找 2：第一个 ≥ 2 的位置就是下标 1（3 的位置）
- target 比谁都大 找 7：没有任何元素 ≥ 7，应该插在末尾下标 4 = 数组长度

**统一描述**：找第一个 `≥ target` 的下标。这有个标准名字叫 **lower_bound**（下界），C++ STL 里就叫这个。

---

## 三、二分模板：闭区间 vs 半开区间

二分有两种常见写法，**半开区间** `[lo, hi)` 写出来对应"找第一个满足条件"的题最自然，本题用这个。

```
lo = 0
hi = n               ← 注意是 n，不是 n - 1
                       因为答案可能等于 n（插到末尾）

循环：lo < hi 时
    mid = (lo + hi) // 2
    if nums[mid] < target:
        lo = mid + 1     ← mid 太小，从 mid+1 找起
    else:
        hi = mid         ← mid 可能就是答案，所以 hi 不减 1，只缩到 mid

循环结束：lo == hi，这就是答案
```

**关键点**：

1. `hi` 初始是 `n`（数组长度），不是 `n - 1`。理由是答案可能等于 n。
2. `nums[mid] >= target` 时 `hi = mid`（**不是** `mid - 1`），因为 `mid` 本身还在候选集里。

这两条不一致就会死循环或漏答案。

---

## 四、为什么循环结束时 lo == hi 就是答案

每一轮我们都在维护一个**不变量**："答案落在 `[lo, hi)` 区间内"。

- 若 `nums[mid] < target`：`mid` 不可能是答案（它更小），答案在 `mid` 右边 → 把左边界推到 `mid + 1`
- 若 `nums[mid] >= target`：`mid` 可能是答案，答案不会超过 `mid` → 把右边界压到 `mid`

区间不断收缩，直到只剩**零长度**的一个点 `lo == hi`，那就是答案。

---

## 五、写成代码

```python
class Solution:
    def searchInsert(self, nums: list[int], target: int) -> int:
        # 半开区间 [lo, hi)：lo 是下界、hi 是"超过末尾"的位置
        # hi 取 len(nums) 是因为答案可能等于数组长度（插在末尾）
        lo, hi = 0, len(nums)
        while lo < hi:
            # 取中点（向下取整，对半开区间不会越界）
            mid = (lo + hi) // 2
            if nums[mid] < target:
                # 中点比 target 小，答案一定在 mid 右边
                lo = mid + 1
            else:
                # 中点 >= target，mid 自己也可能是答案，所以 hi = mid 不是 mid - 1
                hi = mid
        # 循环结束 lo == hi，就是第一个 >= target 的位置（即插入点）
        return lo
```

短到不能再短。学会这 7 行你拿到一大类"在有序数组里找位置"题的钥匙。

---

## 六、复杂度

- **时间** `O(log n)`：每轮区间长度减半
- **空间** `O(1)`

---

## 七、容易踩的坑

1. **`hi` 初始用 `len(nums)`**，不是 `len(nums) - 1`。否则 target 比所有元素都大时漏一个位置。
2. **循环条件 `lo < hi`**，配 `hi = mid`（不减 1）。如果改成闭区间 `[lo, hi]` 写法，那循环条件、更新规则全都要换，混用会死循环。
3. **想清楚边界一次性**，比如 target 比所有都大、比所有都小、空数组——脑子里走一遍确保都对。

---

## 八、一句话记忆

> 看到"有序数组找位置 / 找第一个满足"→ **lower_bound 半开区间二分**：`hi=n`、`lo<hi`、`hi=mid`。
