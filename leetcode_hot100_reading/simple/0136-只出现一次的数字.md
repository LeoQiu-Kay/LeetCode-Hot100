# 136. 只出现一次的数字 · 阅读版

> 难度：简单 · [LeetCode 链接](https://leetcode.cn/problems/single-number/)

---

## 一、题目讲了什么

数组中**除了一个数外，其它每个数都出现两次**。找出那个只出现一次的数。

要求：**线性时间、常数空间**。

例：`[4, 1, 2, 1, 2]` → 4。

---

## 二、几种常规思路与它们的缺点

- **哈希表计数**：O(n) 时间，但 O(n) 空间，不满足常数空间。
- **排序后看相邻**：O(n log n) 时间，不满足线性时间。
- **集合 add/remove**：O(n) 时间但 O(n) 空间。

要同时满足两条约束，需要更巧的技巧——**位运算**。

---

## 三、异或的两条神奇性质

`^` 是按位异或：

1. **`a ^ a = 0`**（同类相消）
2. **`a ^ 0 = a`**（和 0 没关系）

它还满足**交换律和结合律**：`a ^ b ^ c == c ^ a ^ b == ...`。顺序怎么换都行。

---

## 四、把所有数全异或起来

回到原问题。把数组里所有数异或在一起：

```
4 ^ 1 ^ 2 ^ 1 ^ 2
= 4 ^ (1 ^ 1) ^ (2 ^ 2)    （交换律重排）
= 4 ^ 0 ^ 0
= 4
```

成对的数互相抵消变成 0，最后剩下的就是那个"孤独"的数。

异或同时满足两条约束：

- **线性时间**：一趟扫描就够
- **常数空间**：只用一个累加器变量

---

## 五、写成代码

```python
from functools import reduce
from operator import xor

class Solution:
    def singleNumber(self, nums):
        return reduce(xor, nums)
```

`reduce(xor, nums)` 相当于 `nums[0] ^ nums[1] ^ ... ^ nums[-1]`。一行。

或者更直白的写法：

```python
ans = 0
for x in nums:
    ans ^= x
return ans
```

---

## 六、复杂度

- **时间** `O(n)`
- **空间** `O(1)`

---

## 七、容易踩的坑

1. **这套异或解法只适用于"其它数恰好出现 2 次"**。如果其它数出现 3 次（题目 137），就要换"按位计数 mod 3"的方法。
2. **异或是按位**的，所以数的正负、范围都不影响（包括负数也行，Python 的 `^` 对负数也是定义良好）。
3. **不要画蛇添足**：本题不需要哈希表，更不需要排序。

---

## 八、一句话记忆

> 全部异或：**同类相消变 0**，剩下的就是答案。
