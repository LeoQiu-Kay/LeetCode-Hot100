# 121. 买卖股票的最佳时机 · 阅读版

> 难度：简单 · [LeetCode 链接](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/)

---

## 一、题目讲了什么

数组 `prices[i]` 是股票第 i 天的价格。只能**买一次卖一次**（且必须先买后卖）。求最大利润。如果没法赚钱就返回 0。

例：

- `[7, 1, 5, 3, 6, 4]` → 第 2 天买（1），第 5 天卖（6），赚 5
- `[7, 6, 4, 3, 1]` → 一直跌，干脆不操作，赚 0

---

## 二、暴力是 O(n²)

枚举所有 `(buy_day, sell_day)` 对，时间 O(n²)，n = 10⁵ 时不够快。

---

## 三、换个视角：枚举"今天卖"

不去枚举所有买卖对，而是**遍历每一天，假设今天是卖出日**，问自己：

> "如果今天卖，最大利润是多少？" = 今天价格 − **过去最低买入价**

只要边走边维护"到目前为止见过的最低价 `lo`"，每天算一下 `prices[i] - lo`，全程取最大值。

这就是著名的 **Kadane 思路**：把"在所有区间里找最优"变成"枚举每个右端点 + 维护左端点的最优状态"，O(n²) → O(n)。

---

## 四、关键不变量

每一步循环结束时：

- `lo` 是 `prices[0..i]` 里的最小值（**今天为止见过的最低**）
- `ans` 是 `prices[0..i]` 里所有"以 ≤ i 的某天卖"的最大利润

注意顺序：**先更新 `lo`，再算今天的利润**，否则可能让"今天买今天卖"算出利润 0。其实即便用先算后更新的顺序，0 的方案也不会让答案变小（下界本来就是 0），但写成"先 `lo`、后利润"概念更清晰。

---

## 五、写成代码

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        # lo 维护"到目前为止见到的最低买入价"，初始设为正无穷
        lo = float("inf")
        # ans 是最大利润，下界 0（不操作）
        ans = 0
        # 一次遍历每天的价格
        for p in prices:
            # 先更新历史最低（保证 lo <= p，且 lo 出现在 p 之前或同位）
            lo = min(lo, p)
            # 再计算"今天卖"的利润，更新答案
            ans = max(ans, p - lo)
        return ans
```

---

## 六、复杂度

- **时间** `O(n)`：一趟扫描
- **空间** `O(1)`：两个变量

---

## 七、容易踩的坑

1. **答案下界是 0**，不是负数。一直跌的时候直接不操作即可。
2. **`lo` 初始用正无穷**（或 `prices[0]`），不能用 0。
3. **可以一笔，不能两笔**：这是 121 的关键约束；放开成可以多次交易是 122 题（贪心，把所有上涨段都吃掉）。

---

## 八、一句话记忆

> 一边走、一边记"历史最低买入价"，每天算"如果今天卖能赚多少"，全程取最大。
