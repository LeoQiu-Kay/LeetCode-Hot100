# 234. 回文链表 · 阅读版

> 难度：简单 · [LeetCode 链接](https://leetcode.cn/problems/palindrome-linked-list/)

---

## 一、题目讲了什么

判断单链表是否回文（正反读一样）。

例：

- `1 → 2 → 2 → 1` ✓
- `1 → 2` ✗

进阶：要求 **O(1) 额外空间**。

---

## 二、思路对比

| 方法 | 时间 | 空间 | 评价 |
|---|---|---|---|
| 把链表值塞到 list 再首尾对撞 | O(n) | O(n) | 简单暴力 |
| 用栈对比前半段 | O(n) | O(n) | 也是 O(n) 空间 |
| **快慢指针 + 反转后半段** | **O(n)** | **O(1)** | 满足进阶要求 |

讨论的是第 3 种。它把两个链表母题（141 快慢指针、206 反转链表）组合起来用。

---

## 三、三步走

**第一步：找中点**（141 的快慢指针）

```
slow 每次走 1，fast 每次走 2
fast 走到尽头时，slow 恰好在中央（偶数长度时落在前中或后中，具体看实现）
```

**第二步：反转后半段**（206 的三指针）

从 slow 开始把后半段链表就地反转。反转完后，后半段以一个新的"头"开始往后走，长度 = floor(n/2)。

**第三步：对比**

用原链表的 head 和反转后的"新头" prev 同时往后走，逐节点比对 val。如果直到 prev 走完都相等，就是回文。

---

## 四、为什么不用比完整长度

反转后半段后，新的"头" prev 只覆盖后半部分（长度 ≤ floor(n/2)）。让 prev 走完就停，即使原链表是奇数长度——中间那个节点不影响回文性，跳过没问题。

```
原链表 1 → 2 → 3 → 2 → 1
                ↑ slow 停在这（中间）
反转后半段：3 → 2 → 1   变成   1 → 2 → 3
现在比较：
  原 head: 1 → 2 → ...
  新 prev:  1 → 2 → 3
逐位比对 1==1, 2==2 后 prev 进入 3，再一步就是 None，停。
```

---

## 五、写成代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def isPalindrome(self, head: ListNode | None) -> bool:
        # 1. 用快慢指针找中点（fast 走到尽头时 slow 在中央/中右）
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
        # 2. 从 slow 开始，把后半段链表就地反转（用 206 的三指针法）
        prev = None
        while slow:
            # 这一行是 206 的三步合并：先存下一个、改指向、整体右移
            slow.next, prev, slow = prev, slow, slow.next
        # 3. 用反转后的后半段（prev）和原链表头同步比对
        while prev:
            if prev.val != head.val:
                return False
            prev = prev.next
            head = head.next
        # 后半段全部比完即回文（即使原链表长度奇数，中点不影响判定）
        return True
```

---

## 六、复杂度

- **时间** `O(n)`：三步都是 O(n)
- **空间** `O(1)`：只用指针

---

## 七、容易踩的坑

1. **比较循环用 prev 当终止条件**，不要用 head：head 这段可能比 prev 长 1（原链表奇数长度时），错用 head 会越界。
2. **三指针反转**那行 Python 元组赋值原子的特性救命：
   ```python
   slow.next, prev, slow = prev, slow, slow.next
   ```
   等价于 "存 nxt → 改 next → 移 prev → 移 slow"，但一行搞定。
3. **不破坏原链表**：题目通常不要求，但生产代码里有的话需要再反转回来恢复。

---

## 八、一句话记忆

> **三步走**：① 快慢找中点；② 反转后半段；③ 头和新头同步比对。
