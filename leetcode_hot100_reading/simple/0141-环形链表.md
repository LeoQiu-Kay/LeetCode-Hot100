# 141. 环形链表 · 阅读版

> 难度：简单 · [LeetCode 链接](https://leetcode.cn/problems/linked-list-cycle/)

---

## 一、题目讲了什么

判断链表里是否存在**环**——某个节点的 `next` 指向了链表里更前面的某个节点（包括自己）。

例（有环）：`3 → 2 → 0 → -4 → 2（回到第二个节点）`

要求：**O(1) 额外空间**——所以"用哈希表记录访问过的节点"虽然能解，但不算最优。

---

## 二、生活类比：跑道判圆

想象操场上两个人跑步：

- 慢的每秒走 **1 步**
- 快的每秒走 **2 步**

- **直线跑道**（无环）→ 快的先到终点（指针撞到 `None`）
- **圆形跑道**（有环）→ 快的进环后**绕一圈追上慢的**，两人会在某个节点重合

这就是著名的 **Floyd 龟兔赛跑**。

---

## 三、为什么有环时一定追得上

进入环之后，快慢指针都在环里转。每过一秒，快的相对慢的**多走 1 步**——等价于"快的以速度 1 在环里追慢的"。环长有限，最多绕一圈就追上。

为什么相对速度 1 而不是绝对 2？**两人都在动，差速才是关键。** 慢的每步前进 1，快的每步前进 2，差就是 1。

---

## 四、写成代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def hasCycle(self, head):
        slow = fast = head
        while fast and fast.next:    # fast 还能往前走 2 步
            slow = slow.next         # 慢走 1
            fast = fast.next.next    # 快走 2
            if slow is fast:
                return True
        return False    # fast 撞到 None，无环
```

---

## 五、几个细节

1. **循环条件 `fast and fast.next`**：保证 `fast.next.next` 不会越界。
2. **比较用 `is` 不用 `==`**：要的是"同一节点对象"，不是值相等。
3. **判定时机**：必须**走完一步后**判，而不是循环开头就判——否则起始 `slow == fast == head` 直接返回 True。

---

## 六、复杂度

- **时间** `O(n)`：无环时 fast 走 n 步到 None；有环时最多绕一圈
- **空间** `O(1)`：两个指针变量

---

## 七、容易踩的坑

1. **快指针每次走 2 步**，所以要双重检查 `fast and fast.next`。
2. **节点对象比较用 `is`**：`==` 在自定义类里若没重载就退化成 `is`，所以本题用 `==` 也行；但写 `is` 更准确。
3. **想"为什么不用步长 1 vs 3"**？理论上任何"差速 ≥ 1"都能追上，差速 1（即 1 vs 2）最简单。

---

## 八、一句话记忆

> **快慢指针绕跑道**：直线快的撞墙，圆形快的追上慢的。
