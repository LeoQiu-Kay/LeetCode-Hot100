# 118. 杨辉三角 · 阅读版

> 难度：简单 · [LeetCode 链接](https://leetcode.cn/problems/pascals-triangle/)

---

## 一、题目讲了什么

返回杨辉三角的前 `numRows` 行：

```
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
...
```

每行两端是 1，中间元素 = 上一行**左肩 + 右肩**。

---

## 二、规律就是答案

第 `i` 行（从 0 开始）的特性：

- 长度是 `i + 1`
- 两端 = 1
- 中间位置 `j`（1 ≤ j ≤ i-1）的值 = `prev[j-1] + prev[j]`

直接照着写就完了——**这题难度低就在于规律明显，直接逐行生成**。

---

## 三、画一遍 i = 4 的生成过程

上一行（i=3）：`[1, 3, 3, 1]`

新一行（i=4）长度 5，先全填 1：`[1, 1, 1, 1, 1]`

然后中间位置 j = 1, 2, 3 来自上一行的相邻和：

- `j=1`：`prev[0] + prev[1]` = 1 + 3 = 4
- `j=2`：`prev[1] + prev[2]` = 3 + 3 = 6
- `j=3`：`prev[2] + prev[3]` = 3 + 1 = 4

新一行：`[1, 4, 6, 4, 1]`。

---

## 四、写成代码

```python
class Solution:
    def generate(self, numRows: int) -> list[list[int]]:
        res: list[list[int]] = []   # 存放每一行
        # i 从 0 到 numRows-1，依次生成第 i 行
        for i in range(numRows):
            # 整行先全部填 1，长度为 i+1，两端的 1 就这样自然就位
            row = [1] * (i + 1)
            # 中间的位置（j = 1..i-1）由上一行相邻两个元素相加得到
            # 注意 i = 0、1 时这个循环 range(1, i) 为空，正好两端都是 1 即可
            for j in range(1, i):
                row[j] = res[i - 1][j - 1] + res[i - 1][j]
            res.append(row)
        return res
```

注意 `range(1, i)` 在 `i = 0, 1` 时为空，跳过中间逻辑——正好对应"前两行只有两端的 1"。

---

## 五、复杂度

- **时间** `O(numRows²)`：第 i 行做 O(i) 工作，求和 = numRows²
- **空间** `O(numRows²)`：输出本身

---

## 六、容易踩的坑

1. **`row = [1] * (i + 1)`**：长度 i+1，记 +1。
2. **内层循环只到 `i`，不到 `i+1`**：跳过两端的 1。
3. **不要用 `numRows-1` 当索引上限**——你要的是行号 `i`。

---

## 七、一句话记忆

> 杨辉三角 = **两端 1 + 中间是上一行左肩右肩之和**，逐行生成。
