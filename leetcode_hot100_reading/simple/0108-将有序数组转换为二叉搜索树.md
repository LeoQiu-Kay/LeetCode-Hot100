# 108. 将有序数组转换为二叉搜索树 · 阅读版

> 难度：简单 · [LeetCode 链接](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/)

---

## 一、题目讲了什么

一个**升序**数组，构造一棵**高度平衡**的二叉搜索树（BST）。

回顾两个性质：

- **BST**：每个节点 左子树所有值 < 根值 < 右子树所有值
- **高度平衡**：任一节点的左右子树高度差 ≤ 1

例：`[-10, -3, 0, 5, 9]` 可以建成：

```
       0
      / \
    -3   9
    /   /
  -10  5
```

也可以建成另一种合法形态，**答案不唯一**。

---

## 二、关键观察：BST 的中序遍历是升序

BST 的中序遍历必然是升序序列。**反过来**：拿到一个升序序列，把它**当作某棵 BST 的中序输出**反向构造一棵 BST，是合法的。

但题目要的不是任意 BST，是**平衡**的 BST。怎么保证平衡？

> **取中点作根，左半段建左子树，右半段建右子树**。

每次都从中间切，左右长度差最多 1，整棵树的高度就被严格控制在 `O(log n)` 范围内。

---

## 三、分治结构

写成递归非常对称：

```
build(left, right):                     # 用数组 nums[left..right]（闭区间）建一棵 BST
    if left > right: return None        # 空区间，对应空子树
    mid = (left + right) // 2           # 中点
    node = TreeNode(nums[mid])
    node.left  = build(left, mid - 1)   # 左半段递归
    node.right = build(mid + 1, right)  # 右半段递归
    return node
```

入口：`build(0, n - 1)`。

---

## 四、为什么这样建出来一定是 BST

- 每个 `node` 的左子树只用 `nums[left..mid-1]`（**都 < nums[mid]**），符合 "左 < 根"
- 右子树只用 `nums[mid+1..right]`（**都 > nums[mid]**），符合 "根 < 右"
- 递归下去，每层都满足，整棵树就是 BST

---

## 五、为什么这样建出来一定平衡

设区间长度 `len = right - left + 1`：

- 左半长度 `mid - left = (len - 1) // 2`
- 右半长度 `right - mid = len // 2`

两者差最多 1，所以左右子树**节点数**差最多 1 → 高度差也最多 1。

## 六、写成代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def sortedArrayToBST(self, nums: list[int]) -> TreeNode | None:
        # 子函数：用 nums[l..r] 这段（闭区间）构造一棵平衡 BST
        def build(l: int, r: int) -> TreeNode | None:
            # 区间无效，对应空子树
            if l > r:
                return None
            # 取中点作为当前子树的根
            m = (l + r) // 2
            # 左半段递归构造左子树，右半段递归构造右子树
            return TreeNode(nums[m], build(l, m - 1), build(m + 1, r))
        # 用整个数组的闭区间 [0, len-1] 启动
        return build(0, len(nums) - 1)
```

---

## 七、复杂度

- **时间** `O(n)`：每个数组元素被访问一次（建一个节点）
- **空间** `O(log n)`：递归栈深度等于树高，树平衡 → 高度 log n

---

## 八、容易踩的坑

1. **区间是闭还是开**：用闭区间 `[l, r]` 时，出口判 `l > r`。换成 `[l, r)` 半开区间也行，但循环条件、递归参数都要相应改。
2. **`(l + r) // 2` 与 `(l + r + 1) // 2`** 都行（偶数长度时取偏左 / 偏右），答案就不一样但都合法。
3. **题目说"高度平衡"不"完全平衡"**：差 1 也算平衡，所以中间随便取都 OK。

---

## 九、一句话记忆

> 升序数组 + 平衡 BST → **中点为根，左右递归**。
