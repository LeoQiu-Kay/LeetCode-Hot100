# 543. 二叉树的直径 · 阅读版

> 难度：简单 · [LeetCode 链接](https://leetcode.cn/problems/diameter-of-binary-tree/)

---

## 一、题目讲了什么

二叉树的"**直径**" = 任意两节点之间路径的**最长边数**（不一定经过根节点）。

例：

```
       1
      / \
     2   3
    / \
   4   5
```

最长路径：4 → 2 → 5（或 4 → 2 → 1 → 3），边数 3。

---

## 二、关键观察：最长路径在哪个节点"拐弯"

任何一条树上的路径必然在某个节点处**拐弯**（或者就是单边直线）。设拐点是节点 `X`：

> 经过 X 的最长路径长度 = **X 的左子树最深** + **X 的右子树最深**（单位是"边数"）

整棵树的直径 = 所有节点 X 中，上式的**最大值**。

所以这题是 104（最大深度）的"**升级**"：

- 104 只需要返回深度
- 543 在递归中**同时**：① 返回深度给父亲用；② 用左右深度更新全局答案

---

## 三、深度的单位：节点数 or 边数？

定义清楚：

- 用**边数**：空节点深度 0，单节点深度 0，深度 = max(左, 右) + 1（每加一层 +1）

  对应代码：`return 1 + max(l, r)`，l 和 r 是子树深度。

- 直径 = 拐点处左深 + 右深，**不用 +1**（因为左深是从 X 到左子树最深叶的边数，右深同理，加起来正好是穿过 X 的总边数）

很多人这里 +1 写错，结果差 1。

---

## 四、为什么必须用全局变量

递归函数只能**返回一个值**。这题需要：

1. 给父亲用：以当前节点为根的**单边最深**（父亲沿一条边继续往上延伸的最大长度）
2. 全局记录：**左深 + 右深**（穿过当前节点的最大路径，不能再延伸）

两个量结构不一样，所以——**返回 1，全局存 2**：

```
def depth(node):
    if not node: return 0
    l = depth(node.left)
    r = depth(node.right)
    self.ans = max(self.ans, l + r)    # 更新全局：穿过当前节点的路径
    return 1 + max(l, r)                # 返回单边深度给父亲
```

## 五、写成代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def diameterOfBinaryTree(self, root: TreeNode | None) -> int:
        # 用实例属性当"全局变量"，记录最长直径（边数）
        self.ans = 0
        def depth(node: TreeNode | None) -> int:
            # 空节点深度为 0（递归出口）
            if not node:
                return 0
            # 先递归算左右子树的深度
            l = depth(node.left)
            r = depth(node.right)
            # 经过当前节点的最长路径 = 左深 + 右深（单位是"边"，所以不 +1）
            # 用它更新全局答案；直径不一定经过整树根，所以必须用全局
            self.ans = max(self.ans, l + r)
            # 返回给父节点用的是"以当前节点为根、走一条边到底的最大深度"
            return 1 + max(l, r)
        depth(root)
        return self.ans
```

## 六、复杂度

- **时间** `O(n)`：每个节点访问一次
- **空间** `O(h)`：递归栈

---

## 七、容易踩的坑

1. **`l + r` 不要 +1**：边数已经包含了"经过当前节点"那部分。
2. **必须用全局答案变量**：直径不一定经过根，单靠返回值传不出来。
3. **空树直径是 0**，单节点也是 0（边数）。

---

## 八、一句话记忆

> **后序递归两件事**：返回"单边最深"给父亲；全局记"左深 + 右深"作答案。
