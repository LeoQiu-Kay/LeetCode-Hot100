# 21. 合并两个有序链表 · 阅读版

> 难度：简单 · [LeetCode 链接](https://leetcode.cn/problems/merge-two-sorted-lists/)

---

## 一、题目讲了什么

两条已排好序（升序）的链表，把它们合并成一条**新的升序链表**返回。

例：`1 → 2 → 4` 和 `1 → 3 → 4` → `1 → 1 → 2 → 3 → 4 → 4`

要求不开新节点的话直接复用原节点拼起来。

---

## 二、像归并排序的最后一步

如果你做过归并排序，会对这个动作很熟：两条有序数组合成一条有序数组——双指针，谁小先放谁。链表版本一样的思路：

```
A: 1 → 2 → 4
B: 1 → 3 → 4

指针 a = 1, b = 1
比较：1 ≤ 1，先放 A 的 1，a 前进

A: 2 → 4         结果: 1
B: 1 → 3 → 4

比较：2 > 1，先放 B 的 1，b 前进
...
```

直到某一条走完，把另一条剩余整段挂到结果末尾即可。

---

## 三、引入 dummy 头节点

链表合并时有个**讨厌的边界**：第一个节点到底是 A 的还是 B 的？要写成 `if/else` 决定 `result_head = ...` 然后再循环，代码就分叉。

**dummy（哑节点）技巧**：先造一个**假头节点**，循环里只往它后面挂；循环结束返回 `dummy.next`。这样**第一个节点的归属问题被消除了**——它和后面所有节点一样被同一段逻辑处理。

这是链表题最常用的小动作，记下来后面会反复用。

---

## 四、单步动作的画面

```
dummy → ?         a → 1 → 2 → 4
                   b → 1 → 3 → 4

  cur (指向 dummy)

第 1 步：a.val ≤ b.val，cur.next = a，然后 a 前进
dummy → 1 → ?    a → 2 → 4
                  b → 1 → 3 → 4
            ↑
           cur

第 2 步：cur 也前进到刚接上的节点，继续比较
...
```

记住两件事：

- `cur.next = 选中那个节点`
- **选中那条链的指针前进**；`cur` 也前进到新接上的节点

---

## 五、写成代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def mergeTwoLists(self, list1, list2):
        dummy = ListNode()    # 哑头
        cur = dummy           # 结果链表的"尾巴"

        while list1 and list2:
            if list1.val <= list2.val:
                cur.next = list1
                list1 = list1.next
            else:
                cur.next = list2
                list2 = list2.next
            cur = cur.next    # 尾巴往后挪

        # 一条走完了，把另一条的剩余整段挂上
        cur.next = list1 or list2
        return dummy.next
```

---

## 六、复杂度

- **时间** `O(m + n)`：每个节点最多访问一次
- **空间** `O(1)`：没造新节点，只挪指针

---

## 七、容易踩的坑

1. **dummy 必不可少**：手写 if 决定首节点会让代码变长且容易错。
2. **循环结束的"挂剩余"那行**：`cur.next = list1 or list2`——`a or b` 在 Python 里"a 真就用 a，否则用 b"，正好等价于"哪个还没走完就挂哪个"。
3. **如果允许 O(1) 但题目改成"不复用原节点"**：那就要在循环里 `cur.next = ListNode(...)` 拷贝节点，空间变 O(m+n)。本题没要求，所以复用。

---

## 八、一句话记忆

> **dummy 起头、双指针比较、谁小接谁、最后挂剩余**。
