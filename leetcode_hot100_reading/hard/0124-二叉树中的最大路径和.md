# 124. 二叉树中的最大路径和 · 阅读版

> 难度：困难 · [LeetCode 链接](https://leetcode.cn/problems/binary-tree-maximum-path-sum/)

---

## 一、题目讲了什么

二叉树里找一条**路径**（任意两节点间，可以不经过根，**至少一个节点**），使路径上**节点值之和最大**。

例：

```
   -10
   / \
  9  20
     / \
    15  7

最大路径：15 → 20 → 7，和 42
```

---

## 二、关键观察：543 的"权值版"

543 题（二叉树直径）求最长**边数**。这题求最长**权值和**。

同款思路：**最长路径在某节点 X 处"拐弯"**——

> 穿过 X 的最大路径和 = `X.val + 左单边最大贡献 + 右单边最大贡献`

其中"单边贡献"是从 X 向某一侧儿子延伸到底的最大值（路径只能选一边继续往上）。

---

## 三、负数怎么处理

权值可正可负。如果某条子树贡献是**负数**，**砍掉它**（取 0 代替）—— 不要这一段路径反而更大：

```
left_gain = max(0, gain(left))
right_gain = max(0, gain(right))
```

这样"负贡献"被截断为 0。

---

## 四、函数返回 vs 全局答案

每个节点要算两件事：

- **返回给父亲**：以当前节点为根、**单边**最大贡献。即 `val + max(left_gain, right_gain)`（父亲沿一条边继续往上拼）
- **全局答案**：穿过当前节点的**双侧**最大路径和。即 `val + left_gain + right_gain`（这条路径在当前节点拐弯，不能再向上延伸）

两个量不一样——所以**全局答案用变量**，返回值是单边贡献。

---

## 五、写成代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def maxPathSum(self, root):
        self.ans = float('-inf')
        def gain(node):
            if not node:
                return 0
            l = max(0, gain(node.left))
            r = max(0, gain(node.right))
            self.ans = max(self.ans, node.val + l + r)    # 拐点处的双侧
            return node.val + max(l, r)                    # 给父亲的单边
        gain(root)
        return self.ans
```

---

## 六、复杂度

- **时间** `O(n)`
- **空间** `O(h)`：递归栈

---

## 七、容易踩的坑

1. **答案初始用 `-inf`**：所有节点都是负数时答案可能是最大负数，不能是 0。
2. **返回给父亲的是单边**（max(l, r)），不是双侧（l + r）。
3. **负贡献砍 0**：`max(0, gain(child))`。

---

## 八、一句话记忆

> **后序递归 + 全局答案**：返回单边贡献，全局更新"拐点处双侧和"。负贡献砍 0。
