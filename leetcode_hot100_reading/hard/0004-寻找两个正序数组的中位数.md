# 4. 寻找两个正序数组的中位数 · 阅读版

> 难度：困难 · [LeetCode 链接](https://leetcode.cn/problems/median-of-two-sorted-arrays/)

---

## 一、题目讲了什么

两个**升序**数组 `nums1`, `nums2`。返回两者**合并后**的中位数。要求 **O(log(m + n))**。

例：

- `nums1 = [1, 3]`, `nums2 = [2]` → 2.0
- `nums1 = [1, 2]`, `nums2 = [3, 4]` → 2.5

---

## 二、为什么不能合并后取中位数

合并 O(m + n)，不满足 log 要求。需要更"提取重点"的做法。

---

## 三、转化：二分"切分位置"

想象在两个数组上**各切一刀**，把合并后的元素分成左右两半：

- 左半**总长** = `(m + n + 1) // 2`（+1 让奇数时左半多一个，中位数直接是左半 max）
- nums1 切在 i（左半含前 i 个）、nums2 切在 j = half - i

**"合法切分"的条件**：

```
A_left ≤ B_right  且  B_left ≤ A_right
```

（左半的所有数 ≤ 右半的所有数）

如果合法：

- 奇数总长 → 中位数 = `max(A_left, B_left)`
- 偶数总长 → 中位数 = `(max(A_left, B_left) + min(A_right, B_right)) / 2`

---

## 四、在较短数组上二分 i

二分 `i ∈ [0, m]`，对应 `j = half - i`。

- 如果 `A_left > B_right`：i 太大，缩小 → `hi = i - 1`
- 如果 `B_left > A_right`：i 太小，扩大 → `lo = i + 1`
- 否则合法，计算中位数

**保证 m ≤ n**（在较短数组上二分）确保 j 不越界。

---

## 五、边界用 ±∞ 哨兵

i = 0 时 `A_left` 不存在 → 视为 `-∞`。i = m 时 `A_right` 不存在 → 视为 `+∞`。同理 B。这样合法条件就不用一堆 if 判空。

---

## 六、写成代码

```python
class Solution:
    def findMedianSortedArrays(self, nums1: list[int], nums2: list[int]) -> float:
        # 保证 nums1 较短（在短的那个上二分，效率更高）
        if len(nums1) > len(nums2):
            nums1, nums2 = nums2, nums1
        m, n = len(nums1), len(nums2)
        # half 是"左半部分"应该包含的元素总数（奇数时左多一个）
        half = (m + n + 1) // 2
        lo, hi = 0, m
        while lo <= hi:
            # i 是 nums1 中"分到左半"的元素个数
            i = (lo + hi) // 2
            # j 是 nums2 中相应的元素个数（保证 i + j == half）
            j = half - i
            # 四个边界值；用 ±inf 处理 i / j 在两端的边界
            A_left = nums1[i - 1] if i > 0 else float("-inf")
            A_right = nums1[i] if i < m else float("inf")
            B_left = nums2[j - 1] if j > 0 else float("-inf")
            B_right = nums2[j] if j < n else float("inf")
            # 合法切分：A 左边 <= B 右边 且 B 左边 <= A 右边
            if A_left <= B_right and B_left <= A_right:
                if (m + n) % 2 == 1:
                    # 总长奇数：中位数 = 两个左边里更大的（左半比右半多 1）
                    return float(max(A_left, B_left))
                # 总长偶数：(左半 max + 右半 min) / 2
                return (max(A_left, B_left) + min(A_right, B_right)) / 2
            elif A_left > B_right:
                # A 左边太大 → i 太大，需要往左缩
                hi = i - 1
            else:
                # B 左边太大 → i 太小，需要往右增
                lo = i + 1
        return 0.0   # 理论上不会到这里
```

---

## 七、复杂度

- **时间** `O(log(min(m, n)))`
- **空间** `O(1)`

---

## 八、容易踩的坑

1. **必须在较短数组上二分**：保证 j 不越界 + 复杂度最优。
2. **`half = (m + n + 1) // 2`** 的 +1：让奇数时左半多 1 个，中位数直接是 `max(A_left, B_left)`。
3. **±∞ 哨兵**：边界时省一堆 if。
4. **整数除法 vs 浮点**：偶数情况要返回 float。

---

## 九、一句话记忆

> 在**较短数组**上二分**切分位置**，保证 `A_left ≤ B_right` 且 `B_left ≤ A_right`，奇数取 max(A_left, B_left)。
