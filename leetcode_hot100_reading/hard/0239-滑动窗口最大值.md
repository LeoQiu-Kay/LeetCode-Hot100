# 239. 滑动窗口最大值 · 阅读版

> 难度：困难 · [LeetCode 链接](https://leetcode.cn/problems/sliding-window-maximum/)

---

## 一、题目讲了什么

数组 `nums` 和窗口大小 `k`，返回每个窗口的**最大值**组成的数组。

例：`nums=[1,3,-1,-3,5,3,6,7], k=3` → `[3, 3, 5, 5, 6, 7]`

---

## 二、暴力 O(n × k) 不够

每个窗口扫一遍 O(k)，整体 O(n × k)。需要 **O(n)** —— 用**单调递减队列**。

---

## 三、单调递减双端队列

队列里存**下标**，对应值从队头到队尾**严格递减**。这样**队头永远是当前窗口的最大值**。

每步处理新元素 `nums[i]`：

1. **清队头**：如果队头下标已"过期"（`< i - k + 1`），出队
2. **清队尾**：当队尾对应值 `≤ nums[i]` 时，它们再也不可能成为最大值，出队
3. 把 i 入队
4. 当 i ≥ k - 1 时，**`nums[队头]` 是当前窗口最大**，记录到答案

---

## 四、为什么队尾清"≤ 自己"的

如果新元素 nums[i] ≥ 队尾值，那队尾的下标在 i 进入窗口期间不可能成为最大（它比 i 旧、还比 i 小）。**永远没机会**，直接弹掉。

清掉队尾保持单调性，且每个元素一进一出 → 总操作 O(n)。

---

## 五、走一遍 `[1, 3, -1, -3, 5, 3, 6, 7], k = 3`

| i | nums[i] | 清头? | 清尾 | 队列 (下标 → 值) | i ≥ k-1=2? | ans |
|---|---|---|---|---|---|---|
| 0 | 1 | - | - | [0(1)] | no | |
| 1 | 3 | - | 1 ≤ 3 弹 0 | [1(3)] | no | |
| 2 | -1 | - | 3 > -1 | [1(3), 2(-1)] | yes | 3 |
| 3 | -3 | dq[0]=1≥1? yes | -1 > -3 | [1(3), 2(-1), 3(-3)] | yes | 3 |
| 4 | 5 | dq[0]=1<2 弹 | -3,-1,3 ≤ 5 全弹 | [4(5)] | yes | 5 |
| 5 | 3 | - | 5 > 3 | [4(5), 5(3)] | yes | 5 |
| 6 | 6 | - | 3 ≤ 6 弹；5 ≤ 6 弹 | [6(6)] | yes | 6 |
| 7 | 7 | - | 6 ≤ 7 弹 | [7(7)] | yes | 7 |

答案 `[3, 3, 5, 5, 6, 7]`。

---

## 六、写成代码

```python
from collections import deque

class Solution:
    def maxSlidingWindow(self, nums: list[int], k: int) -> list[int]:
        # 双端队列存下标；对应的 nums 值从队头到队尾**严格递减**
        dq: deque[int] = deque()
        ans: list[int] = []
        for i, x in enumerate(nums):
            # 队头下标已滑出窗口左边界（最早只能是 i - k + 1），弹掉
            if dq and dq[0] < i - k + 1:
                dq.popleft()
            # 维护单调递减：从队尾弹出所有 <= x 的下标
            # 它们再也不可能是后续窗口最大值（被 x 替代了）
            while dq and nums[dq[-1]] <= x:
                dq.pop()
            dq.append(i)
            # 窗口装满（i >= k - 1）时记录当前窗口最大值
            if i >= k - 1:
                ans.append(nums[dq[0]])
        return ans
```

---

## 七、复杂度

- **时间** `O(n)`：每个下标最多入队、出队各一次
- **空间** `O(k)`：队列最多 k 个

---

## 八、容易踩的坑

1. **队列存下标，不是值**：要判过期需要下标。
2. **清队尾用 `<=`**：相等也弹，保留下标更靠右的（活得更久）。
3. **窗口起点公式**：`i - k + 1`，队头 < 它就过期。

---

## 九、一句话记忆

> **单调递减队列**存下标：清过期头、清 ≤ 当前的尾、入新；i ≥ k-1 时队头即窗口最大。
