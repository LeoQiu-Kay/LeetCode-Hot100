# 25. K 个一组翻转链表 · 阅读版

> 难度：困难 · [LeetCode 链接](https://leetcode.cn/problems/reverse-nodes-in-k-group/)

---

## 一、题目讲了什么

每 K 个节点为一组**翻转**链表。剩余不足 K 个节点**保持原样**。

例：`1 → 2 → 3 → 4 → 5`，k = 2 → `2 → 1 → 4 → 3 → 5`
k = 3 → `3 → 2 → 1 → 4 → 5`

---

## 二、关键：206 当子例程 + dummy 拼接

整个解法 = **反复调用 206**（反转一段链表）+ **dummy + 拼接**。

每轮做三件事：

1. **数 K 个节点**——不够 K 就剩余原样返回
2. **局部反转**这 K 个
3. **把反转后的小段重新接回**前面已处理部分 + 后面剩余部分

---

## 三、反转一段链表的技巧

把一段 [start, kth] 反转，关键是用 206 的三指针法，但**初始 `prev` 设为后续的下一组首节点 `next_group`**——这样反转完成后，原段尾 `start` 的 next 自动指向了下一组（省一行重接代码）。

```
prev = next_group     # 而不是 None
cur = start
while cur is not next_group:
    nxt = cur.next
    cur.next = prev
    prev = cur
    cur = nxt
# 此时 prev 指向反转后的新头（即原 kth），start 是新尾且 next 已指向下一组
```

---

## 四、循环框架

```
prev_group = dummy
while True:
    数 K 个节点：tail = prev_group，往后走 K 步，看够不够
    不够 → return dummy.next

    start = prev_group.next         # 本组的第一个（反转后的新尾）
    next_group = tail.next          # 下一组的第一个

    反转本组：
        prev = next_group
        cur = start
        while cur is not next_group:
            cur.next = prev
            prev = cur  # 等价上面三指针
            ...
        # 反转完：tail 是新头（指向 prev_group.next 接它）

    prev_group.next = tail          # 把已处理段接上新头
    prev_group = start              # start 变成下一组的前驱
```

## 五、写成代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def reverseKGroup(self, head, k):
        dummy = ListNode(0, head)
        prev_group = dummy

        while True:
            # 1. 数 K 个节点
            kth = prev_group
            for _ in range(k):
                kth = kth.next
                if not kth:
                    return dummy.next      # 不够 K，剩余保持

            # 2. 局部反转 [start, kth]
            start = prev_group.next
            next_group = kth.next
            prev = next_group
            cur = start
            while cur is not next_group:
                tmp = cur.next
                cur.next = prev
                prev = cur
                cur = tmp

            # 3. 把反转后的段接回
            prev_group.next = kth         # 新头是 kth
            prev_group = start             # start 是新尾，下一组前驱
```

---

## 六、复杂度

- **时间** `O(n)`：每个节点最多被访问 2 次（数 + 反转）
- **空间** `O(1)`

---

## 七、容易踩的坑

1. **数 K 个时 kth 走到 None 就 return**：不够 K 个保持原样。
2. **反转时 prev 初始 = next_group**（不是 None）：让 start 反转后 next 自动指向下一组。
3. **`prev_group = start`**：start 是反转后的"新尾"，下轮要从它后面继续。

---

## 八、一句话记忆

> **dummy 起头 + 数 K + 局部 206 反转**（prev 起始 = 下一组）+ **prev_group = start** 接下一组。
