# 84. 柱状图中最大的矩形 · 阅读版

> 难度：困难 · [LeetCode 链接](https://leetcode.cn/problems/largest-rectangle-in-histogram/)

---

## 一、题目讲了什么

一组柱子高度（宽度都是 1），求**能从这些柱子中切出的最大矩形面积**。矩形横跨连续若干根柱子。

例：`[2, 1, 5, 6, 2, 3]` → 10（5、6 两根，高 5 宽 2）。

---

## 二、思路：以"每根柱子的高度"做矩形高

每根柱子 i 都可以试当矩形高度，问题变成"**它向左向右最多能扩多远**"——也就是找两侧**第一个比它矮**的柱子。

```
矩形高度 = height[i]
矩形左边界 = i 左边第一个矮柱子的位置 + 1
矩形右边界 = i 右边第一个矮柱子的位置 - 1
宽 = 右边界 - 左边界 + 1 = (右矮位置 - 左矮位置 - 1)
```

"找两侧第一个矮的"是**单调栈**的经典题型。

---

## 三、单调递增栈

栈里存"还没结算的下标"，对应高度严格递增。

每个新柱子 t：

- 当栈非空 且 `height[栈顶] >= t` 时：**栈顶等到了右边比它矮的柱子**（就是 t）→ 弹出栈顶 j 并结算：
  - 宽 = `i - 栈顶（新栈顶弹完后的）- 1`
  - 高 = `height[j]`
- 然后 i 入栈

每个柱子最多入栈、出栈各一次 → O(n)。

---

## 四、两个哨兵简化边界

末尾加一个 **0 哨兵**：扫到末尾时仍能保证栈里所有柱子被弹出结算。

栈底放一个 -1 哨兵（或允许栈空但用 i 当宽）：弹完栈空时左边界是 -1，宽度 = `i - (-1) - 1 = i`，自然处理"这根柱子向左能扩到 0"。

---

## 五、走一遍 `[2, 1, 5, 6, 2, 3, 0]`（末尾加 0 哨兵）

栈底放 -1。

| i | t | 栈 (下标对应高度) | 动作 | ans |
|---|---|---|---|---|
| 0 | 2 | [-1] | 入 [−1, 0(2)] | 0 |
| 1 | 1 | [-1, 0(2)] | 2 ≥ 1 弹 0：宽=1-(-1)-1=1，面积=2×1=2，入 [−1, 1(1)] | 2 |
| 2 | 5 | [-1, 1(1)] | 入 [−1, 1, 2(5)] | 2 |
| 3 | 6 | [-1, 1, 2(5)] | 入 [−1, 1, 2, 3(6)] | 2 |
| 4 | 2 | [-1, 1, 2(5), 3(6)] | 6≥2 弹 3：宽=4-2-1=1，面积=6 | 6 |
| | | | 5≥2 弹 2：宽=4-1-1=2，面积=10 | **10** |
| | | | 1<2 不弹，入 [−1, 1, 4(2)] | |
| 5 | 3 | [-1, 1, 4(2)] | 入 [−1, 1, 4, 5(3)] | 10 |
| 6 | 0 | [...] | 弹所有非哨兵：3 宽 1 面积 3、2 宽 4 面积 8、1 宽 6 面积 6 | 10 |

答案 10。

## 六、写成代码

```python
class Solution:
    def largestRectangleArea(self, heights: list[int]) -> int:
        # 末尾加 0 哨兵：保证扫到最后时栈里所有柱子都能被弹出结算
        heights = heights + [0]
        # 栈底放 -1：当作"左边界前一位"的哨兵，结算时 width = i - (-1) - 1 = i
        stack: list[int] = [-1]
        ans = 0
        for i, h in enumerate(heights):
            # 新柱子 h 比栈顶柱子矮：栈顶柱子的"右边界第一个更矮的位置"就是 i
            # 弹出栈顶并结算它能扩展的最大矩形
            while stack[-1] != -1 and heights[stack[-1]] >= h:
                top = stack.pop()
                # 弹出后栈顶就是"左边界第一个更矮的位置"
                # 矩形宽 = 右边界(i) - 左边界(stack[-1]) - 1
                width = i - stack[-1] - 1
                ans = max(ans, heights[top] * width)
            # 当前柱子入栈，等待将来某个更矮的来结算
            stack.append(i)
        return ans
```

---

## 七、复杂度

- **时间** `O(n)`：每根柱子入栈出栈各一次
- **空间** `O(n)`：栈

---

## 八、容易踩的坑

1. **末尾加 0 哨兵**：否则栈里残留的柱子不被结算。
2. **栈底 -1 哨兵**：让左边界统一为"新栈顶"，宽度公式不分情况。
3. **`heights[stack[-1]] >= h` 用 ≥**：相等也弹，保证算到的是"右边界第一个严格更矮"。

---

## 九、一句话记忆

> **单调递增栈 + 双哨兵**：新柱子比栈顶矮就弹出栈顶结算，宽 = `i - 新栈顶 - 1`。
