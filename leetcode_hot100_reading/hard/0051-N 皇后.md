# 51. N 皇后 · 阅读版

> 难度：困难 · [LeetCode 链接](https://leetcode.cn/problems/n-queens/)

---

## 一、题目讲了什么

在 N × N 棋盘上放 N 个皇后，**两两不能互相攻击**（不能同行、同列、同对角线）。返回所有合法布局。

例：n = 4，答案 2 种。

---

## 二、回溯按行放

观察：N 个皇后 + N 行 → **每行恰好一个皇后**（否则同行冲突）。

按行 DFS：

```
dfs(row):
    if row == n: 收集结果
    for col in [0..n-1]:
        if (col, 主对角线, 副对角线) 都没被占:
            放下，记录冲突，递归 dfs(row+1)，撤回
```

按行处理就**避免了"同行"冲突**——只需要再排除列和对角线。

---

## 三、对角线的编号

主对角线（"\\"）：`row - col` 相同
副对角线（"/"）：`row + col` 相同

用三个 set：

- `cols`：被占的列
- `diag1`：被占的主对角线（`row - col`）
- `diag2`：被占的副对角线（`row + col`）

放皇后时加进三个 set，撤回时移除。

---

## 四、剪枝威力

朴素枚举所有放法 nⁿ。剪枝后剩下的合法布局少得多（N=8 时只有 92 个），效率提升巨大。

---

## 五、写成代码

```python
class Solution:
    def solveNQueens(self, n):
        ans = []
        cols = set()
        diag1 = set()        # row - col
        diag2 = set()        # row + col
        path = []            # path[i] = 第 i 行皇后的列号

        def dfs(row):
            if row == n:
                ans.append([
                    '.' * c + 'Q' + '.' * (n - c - 1)
                    for c in path
                ])
                return
            for col in range(n):
                if col in cols or (row - col) in diag1 or (row + col) in diag2:
                    continue
                cols.add(col)
                diag1.add(row - col)
                diag2.add(row + col)
                path.append(col)
                dfs(row + 1)
                cols.remove(col)
                diag1.remove(row - col)
                diag2.remove(row + col)
                path.pop()

        dfs(0)
        return ans
```

---

## 六、复杂度

- **时间** `O(n!)`（剪枝后，实际远低）
- **空间** `O(n)`：递归 + 三个 set

---

## 七、容易踩的坑

1. **主副对角线公式别记反**：主 `row - col`，副 `row + col`。
2. **撤回必须撤四件事**：cols、diag1、diag2、path。
3. **路径用 list 存"每行的列号"**：转字符串最后做。

---

## 八、一句话记忆

> 按行 DFS + **三个 set 剪枝**（列 / row-col / row+col）；撤回时四件套全还原。
