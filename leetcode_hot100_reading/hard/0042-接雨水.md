# 42. 接雨水 · 阅读版

> 难度：困难 · [LeetCode 链接](https://leetcode.cn/problems/trapping-rain-water/)

---

## 一、题目讲了什么

数组 `height` 表示一排垂直柱子的高度，下雨后求能接多少雨水。

例：`[0,1,0,2,1,0,1,3,2,1,2,1]` → 6

---

## 二、关键观察：单根柱子能接多少水

**一根柱子 i 能接的水** = `min(它左侧最高, 它右侧最高) - 它自身高度`。

如果这个差是负数，说明它自己就是高峰，接不到水。

直观：水位由"左右两侧最高的较矮一边"决定（水会从矮的那边溢出）。

---

## 三、思路 A：前后缀最大值数组

预处理 `lmax[i]` 和 `rmax[i]`，扫一遍累加：

```
ans += max(0, min(lmax[i], rmax[i]) - height[i])
```

时间 O(n)，空间 O(n)。

---

## 四、思路 B：相向双指针 O(1) 空间

把 lmax / rmax **边扫边维护**而不是预存。两指针从两端往中间走：

```
l, r = 0, n - 1
lmax = rmax = 0
while l < r:
    if height[l] < height[r]:
        # 左边较矮 → 左侧的"短板"就是 lmax（右侧一定有更高的柱子撑着）
        if height[l] >= lmax: lmax = height[l]
        else: ans += lmax - height[l]
        l += 1
    else:
        # 右边较矮（或相等） → 右侧短板是 rmax
        if height[r] >= rmax: rmax = height[r]
        else: ans += rmax - height[r]
        r -= 1
```

**关键不变量**：每一步移动较矮那侧时，**对侧一定有更高柱子**（因为对侧 ≥ 自己）—— 所以这一侧的"短板"就是 lmax 或 rmax，可以立刻结算。

---

## 五、思路 C：单调栈

栈里存"还没结算的下标"，对应高度递减。当新柱子比栈顶高时，弹出栈顶并算它能接的水：

```
弹出 top，宽 = 当前 i - 栈顶 - 1，高 = min(height[i], height[新栈顶]) - height[top]
```

每根柱子结算一次。这是 84 题"柱状图最大矩形"的同款思路。

代码稍长，但能解决"按行接水"的可视化直觉。

---

## 六、写成代码（双指针）

```python
class Solution:
    def trap(self, height: list[int]) -> int:
        l, r = 0, len(height) - 1
        lmax = rmax = 0   # 左侧已扫的最大、右侧已扫的最大
        ans = 0
        while l < r:
            if height[l] < height[r]:
                # 左边较矮 → 左边的短板是 lmax（因为右边一定有比 height[l] 高的柱子）
                if height[l] >= lmax:
                    lmax = height[l]   # 更新左侧最高（这一柱当不了水池底）
                else:
                    ans += lmax - height[l]   # 这一柱能接 lmax - height[l] 的水
                l += 1
            else:
                # 右边较矮（或相等） → 右边的短板是 rmax
                if height[r] >= rmax:
                    rmax = height[r]
                else:
                    ans += rmax - height[r]
                r -= 1
        return ans
```

---

## 七、复杂度

- **时间** `O(n)`
- **空间** `O(1)`（双指针）

---

## 八、容易踩的坑

1. **移动较矮的那侧**——和 11 题"盛水容器"一样的启发式。
2. **先比较再更新 lmax / rmax**：错了顺序会让"自己 ≥ max"时仍算到差。
3. **三种解法都对，选最熟的**：面试时双指针最常被夸"O(1) 空间"。

---

## 九、一句话记忆

> 单根柱子接水 = **min(左最高, 右最高) − 自己**。双指针"移矮的"边走边维护 lmax / rmax。
