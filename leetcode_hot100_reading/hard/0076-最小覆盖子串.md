# 76. 最小覆盖子串 · 阅读版

> 难度：困难 · [LeetCode 链接](https://leetcode.cn/problems/minimum-window-substring/)

---

## 一、题目讲了什么

字符串 s 和 t，返回 s 中**最短**的能覆盖 t 中**所有字符**（含重复次数）的子串。没有则返回 `""`。

例：`s="ADOBECODEBANC", t="ABC"` → `"BANC"`

"覆盖"指：每个字符在窗口里出现的次数 ≥ t 里的次数。

---

## 二、变长滑动窗口

母题。两指针 `l, r`：

- **右扩**：r 向右走，直到窗口"满足"（覆盖了 t）
- **左缩**：l 向右走，缩到"刚好不满足"为止
- 过程中记录最短窗口

---

## 三、用 `need` 巧妙判定"是否满足"

朴素做法：每次比较 26 长度的计数数组。代码长。

更巧的方法——只用一个**整数 `need`**：

- `need` 初始 = `len(t)`（**还需要补齐的字符次数总和**）
- 用 `cnt[c]` 表示"窗口外还差几个 c"：t 里 c 需要 k 个，初始 `cnt[c] = k`；窗口里出现 c 时 `cnt[c] -= 1`
- 当 `cnt[c]` 由正变 0 时，说明"一个原本缺的字符"被补上 → `need -= 1`
- 当 `cnt[c]` 由 0 变正（左端弹出）时 → `need += 1`

`need == 0` ⟺ 窗口覆盖 t。

---

## 四、写成代码

```python
from collections import Counter

class Solution:
    def minWindow(self, s, t):
        if not s or not t:
            return ""
        cnt = Counter(t)               # 还需要的字符次数（可负 = 窗口里多）
        need = len(t)
        l = 0
        best = (float('inf'), 0, 0)    # (长度, l, r+1)
        for r, c in enumerate(s):
            if cnt[c] > 0:              # 这个字符是 t 需要的，补一个
                need -= 1
            cnt[c] -= 1
            # 已覆盖，尝试左缩
            while need == 0:
                if r - l + 1 < best[0]:
                    best = (r - l + 1, l, r + 1)
                cnt[s[l]] += 1
                if cnt[s[l]] > 0:        # 弹出后变正：刚刚弹掉的字符是 t 需要的
                    need += 1
                l += 1
        return s[best[1]:best[2]] if best[0] != float('inf') else ""
```

---

## 五、复杂度

- **时间** `O(|s| + |t|)`：l 和 r 各走 |s|
- **空间** `O(|s| + |t|)`：Counter

---

## 六、关键细节：cnt 可以是负数

`cnt[c]` 可能变成负数（窗口里多于 t 需要的）。负数表示"多余"，不影响判定（只看是否还有"差"的字符）。

---

## 七、容易踩的坑

1. **`cnt[c] > 0` 才把 need 减 1**：超出 t 需要的不算。
2. **左缩时先 `cnt[s[l]] += 1`，再判 `> 0`**：弹出后变正才表示"破坏覆盖"。
3. **best 用 (长度, l, r+1) 元组**：方便最后切片输出。

---

## 八、一句话记忆

> 变长窗口右扩到 need==0，**左缩到刚好不满足**。`need` 是"还差的字符次数总和"。
