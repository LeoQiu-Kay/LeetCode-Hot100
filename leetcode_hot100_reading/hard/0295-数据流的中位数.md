# 295. 数据流的中位数 · 阅读版

> 难度：困难 · [LeetCode 链接](https://leetcode.cn/problems/find-median-from-data-stream/)

---

## 一、题目讲了什么

实现一个类支持两个操作：

- `addNum(num)`：加入一个数到数据流
- `findMedian()`：返回当前所有数的**中位数**

要求两个操作都尽量快。

---

## 二、为什么不能直接维护有序数组

`addNum` 用二分插入 O(log n)，但**移动元素 O(n)**，慢。

用堆：addNum O(log n)、findMedian O(1)。

---

## 三、双堆思路

把数据流分成**两半**：

- **小的那半**用**大顶堆 `lo`** 存（堆顶是这半边的**最大值**）
- **大的那半**用**小顶堆 `hi`** 存（堆顶是这半边的**最小值**）

**保持**：

- `lo` 的所有元素 ≤ `hi` 的所有元素
- 两堆大小相差 ≤ 1（让 lo 比 hi 多 0 或 1）

中位数：

- 总数为奇 → `lo` 多 1 个，中位数 = `lo` 顶
- 总数为偶 → 两堆相等，中位数 = `(lo.top + hi.top) / 2`

---

## 四、Python 怎么模拟大顶堆

heapq 只有小顶堆。**塞入负值**即可模拟：

```
push 大顶: heappush(lo, -x)
pop 大顶: -heappop(lo)
看顶: -lo[0]
```

---

## 五、addNum 的三步走

很多教程写一堆 if，我推荐**最稳的三步**：

1. **先 push 到 lo**（大顶堆）：`heappush(lo, -num)`
2. **lo 顶移到 hi**：`heappush(hi, -heappop(lo))`——做一次"过滤"
3. **平衡大小**：若 `len(hi) > len(lo)`，再从 hi pop 一个回 lo

这三步保证：

- 任何时候 `lo 的所有元素 ≤ hi 的所有元素`（因为步骤 2 把 lo 当前的最大值转交给了 hi）
- `len(lo) ≥ len(hi)`，差最多 1（奇数时 lo 多 1）

---

## 六、写成代码

```python
import heapq

class MedianFinder:
    def __init__(self):
        # lo 是大顶堆（存较小一半）；存入时取负，弹出时再取负还原
        self.lo: list[int] = []
        # hi 是小顶堆（存较大一半）
        self.hi: list[int] = []

    def addNum(self, num: int) -> None:
        # 策略：先把 num 放进 lo（大顶堆）
        # 然后从 lo 弹出最大值塞到 hi，相当于做一次"过滤"
        # 这样保证 lo 的所有元素都 <= hi 的所有元素
        heapq.heappush(self.lo, -num)
        heapq.heappush(self.hi, -heapq.heappop(self.lo))
        # 平衡两堆大小：让 lo 比 hi 多 1 个（奇数时）或相等（偶数时）
        if len(self.hi) > len(self.lo):
            heapq.heappush(self.lo, -heapq.heappop(self.hi))

    def findMedian(self) -> float:
        # 总数奇数：lo 多一个，中位数是 lo 顶（注意取负还原）
        if len(self.lo) > len(self.hi):
            return -self.lo[0]
        # 总数偶数：两堆顶平均
        return (-self.lo[0] + self.hi[0]) / 2
```

---

## 七、复杂度

- **addNum** `O(log n)`：每次最多 3 次堆操作
- **findMedian** `O(1)`：直接看堆顶
- **空间** `O(n)`：所有数

---

## 八、容易踩的坑

1. **大顶堆用负数模拟**：push 取负、pop 取负、看顶取负。
2. **三步法保证不变量**：先 push 到 lo、然后 lo 顶给 hi、最后平衡大小。
3. **奇偶判断**：lo 多 1 个时奇数，否则偶数。

---

## 九、一句话记忆

> **两堆**：大顶堆 lo（小一半）+ 小顶堆 hi（大一半），addNum 三步法保持有序 + 平衡。
