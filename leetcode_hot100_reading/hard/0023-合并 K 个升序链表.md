# 23. 合并 K 个升序链表 · 阅读版

> 难度：困难 · [LeetCode 链接](https://leetcode.cn/problems/merge-k-sorted-lists/)

---

## 一、题目讲了什么

`k` 条升序链表，合并成**一条升序链表**。21 题的"K 路版"。

例：`[[1,4,5], [1,3,4], [2,6]]` → `1 → 1 → 2 → 3 → 4 → 4 → 5 → 6`

---

## 二、思路对比

| 方法 | 时间 | 空间 | 评价 |
|---|---|---|---|
| **把所有值倒进小顶堆 + 逐个弹出建链** | **O(N log N)** | O(N) | **最直观，推荐先掌握** |
| 21 题逐对合并 K-1 次 | O(K × N) | O(1) | 较慢 |
| 分治两两合并 | O(N log K) | O(log K) | 优雅 |
| 小顶堆 K 路归并（只装 K 个头节点）| O(N log K) | O(K) | 最优，但代码绕一点 |

先讲**最直观的"全部倒进堆"**——它牺牲一点点空间，换来极清晰的代码。

---

## 三、把所有值倒进堆，再逐个弹出

完全不必纠结"K 条链表谁先谁后"。两步走：

1. **遍历每条链表，把所有节点的值逐个 push 进小顶堆**——堆会自动维护"当前最小值在堆顶"
2. **不断弹出堆顶（每次都是剩余最小值），依次接成新链表**

因为堆里存的是**整数值**（不是链表节点），所以根本不存在"节点无法比较"的麻烦——这是它比 K 路归并更易写的关键。

---

## 四、为什么存值就没有"比较的坑"

如果像 K 路归并那样把**节点**塞进堆，Python heapq 在值相等时会去比较 `ListNode` 对象，而 ListNode 没定义比较规则 → 报错，得额外塞一个序号占位。

而本解法堆里只装 `int`——整数天然可比较，干净利落。代价是堆要装下**全部 N 个值**（空间 O(N)），而不是只装 K 个头节点。

---

## 五、写成代码

```python
import heapq

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def mergeKLists(self, lists):
        # 小顶堆：存所有节点的"值"（int 天然可比较，没有节点比较的坑）
        min_heap = []
        # 第一步：遍历每条链表，把所有节点的值逐个 push 进堆
        for node in lists:
            while node:
                heapq.heappush(min_heap, node.val)
                node = node.next     # 沿这条链继续走
        # 第二步：逐个弹出最小值，串成新链表
        dummy = ListNode(0)          # 虚拟头节点，省去"第一个节点"的边界判断
        p = dummy                    # p 始终是新链表的"尾巴"
        while min_heap:
            # 弹出当前最小值，新建一个节点接到尾巴后面
            p.next = ListNode(heapq.heappop(min_heap))
            p = p.next               # 尾巴往后挪
        return dummy.next            # dummy.next 才是新链表真正的头
```

每个值进堆一次、出堆一次，各 O(log N)，共 N 个值 → O(N log N)。

---

## 六、复杂度

- **时间** `O(N log N)`：N 个值，每次进 / 出堆 O(log N)
- **空间** `O(N)`：堆要装下所有值（外加新建的 N 个节点）

> 进阶：若想把空间压到 O(K)、时间到 O(N log K)，可改成"堆里只装 K 个头节点、弹一个补一个"的 **K 路归并**（见第九节链接里 21 题的扩展）。代价是要给堆元素加唯一序号避免节点比较，代码更绕——先把本解法吃透再说。

---

## 七、容易踩的坑

1. **堆里存值（int）而不是节点**：这样天然可比较，免去序号占位的麻烦。
2. **弹出时要 `ListNode(...)` 新建节点**：堆里是裸值，不是现成节点。
3. **dummy 虚拟头**：和 21 题一样省去"第一个节点"的边界判断。

---

## 八、一句话记忆

> **所有值倒进小顶堆，再逐个弹最小串成链**——存值不存节点，最干净。
