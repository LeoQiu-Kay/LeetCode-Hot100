# 23. 合并 K 个升序链表 · 阅读版

> 难度：困难 · [LeetCode 链接](https://leetcode.cn/problems/merge-k-sorted-lists/)

---

## 一、题目讲了什么

`k` 条升序链表，合并成**一条升序链表**。21 题的"K 路版"。

例：`[[1,4,5], [1,3,4], [2,6]]` → `1 → 1 → 2 → 3 → 4 → 4 → 5 → 6`

---

## 二、思路对比

| 方法 | 时间 | 空间 | 评价 |
|---|---|---|---|
| 收集所有值 + 排序 + 建链 | O(N log N) | O(N) | 简单粗暴 |
| 21 题逐对合并 K-1 次 | O(K × N) | O(1) | 较慢 |
| **分治两两合并** | **O(N log K)** | O(log K) | 优雅 |
| **小顶堆 K 路归并** | **O(N log K)** | O(K) | 推荐 |

讲**小顶堆**——代码短、思路直观。

---

## 三、小顶堆 K 路归并

把每条链表的头节点（K 个）都放进小顶堆，每次：

1. **弹出堆顶**（当前 K 个候选里最小的那个）
2. 把它**接到结果链表的尾巴**
3. 它的 **next 也入堆**（如果存在）

直到堆空。

每次操作 O(log K)，总共 N 个节点 → O(N log K)。

---

## 四、堆比较时的"坑"

Python 的 heapq 用元组比较：`(val, ?, node)`。如果 val 相等，会比较元组的下一个元素——直接比 ListNode 对象**没有定义比较**会报错。

解决：**塞一个唯一序号 idx 占位**，元组变 `(val, idx, node)`。idx 自增，永远不重复。

---

## 五、写成代码

```python
import heapq

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def mergeKLists(self, lists):
        heap = []
        idx = 0
        for node in lists:
            if node:
                heapq.heappush(heap, (node.val, idx, node))
                idx += 1
        dummy = ListNode()
        cur = dummy
        while heap:
            _, _, node = heapq.heappop(heap)
            cur.next = node
            cur = cur.next
            if node.next:
                heapq.heappush(heap, (node.next.val, idx, node.next))
                idx += 1
        return dummy.next
```

---

## 六、复杂度

- **时间** `O(N log K)`：N 个节点，每次堆操作 O(log K)
- **空间** `O(K)`：堆里始终最多 K 个节点

---

## 七、容易踩的坑

1. **唯一序号 idx 必不可少**：避免 val 相等时去比 ListNode。
2. **初始入堆**要判 `if node`：空链表跳过。
3. **dummy 头**：和 21 题一样省边界。

---

## 八、一句话记忆

> **小顶堆 K 路归并**：每条链表的当前头入堆，弹最小、接上、它的 next 入堆。
