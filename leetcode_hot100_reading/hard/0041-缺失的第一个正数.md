# 41. 缺失的第一个正数 · 阅读版

> 难度：困难 · [LeetCode 链接](https://leetcode.cn/problems/first-missing-positive/)

---

## 一、题目讲了什么

未排序整数数组（可正可负可零），找出**没出现的最小正整数**。要求 **O(n) 时间、O(1) 额外空间**。

例：

- `[1, 2, 0]` → 3
- `[3, 4, -1, 1]` → 2
- `[7, 8, 9, 11, 12]` → 1

---

## 二、关键观察：答案的范围

设数组长 n。答案必然在 `[1, n + 1]` 范围内：

- 如果 1..n 都齐了 → 答案 n + 1
- 否则有缺失 → 答案是 1..n 中某个

值 ≤ 0、> n 的元素都不影响答案。

---

## 三、原地哈希

要 O(1) 空间 → 用**数组自身当哈希表**。把每个值 x ∈ [1, n] 放到下标 `x - 1` 的位置：

```
nums[x - 1] = x
```

如果能完美做到，最后扫一遍找第一个 `nums[i] != i + 1` 的位置 i，答案就是 `i + 1`。如果全部都对，答案是 n + 1。

---

## 四、怎么"原地放"

用 while 循环就地交换：

```
对每个 i：
    while nums[i] 在 [1, n] 内 且 nums[i] 没在正确位置上：
        把 nums[i] 换到它该去的位置 nums[nums[i] - 1]
```

为什么用 while 而不是 if：换过来的元素也得继续放，可能要连环交换。

---

## 五、防死循环的判定

**判定 `nums[x - 1] != x`**（而不是 `nums[i] != i + 1`）：当 x 该去的位置已经有 x 时（重复值），直接跳过——否则会无限交换两个相等元素。

---

## 六、走一遍 `[3, 4, -1, 1]`

| i | nums[i] | 动作 | nums |
|---|---|---|---|
| 0 | 3 | 该去 idx 2，那边是 -1（不等于 3），换 | [-1, 4, 3, 1] |
| 0 | -1 | 不在 [1, n]，i++ | |
| 1 | 4 | 该去 idx 3，那边是 1（不等于 4），换 | [-1, 1, 3, 4] |
| 1 | 1 | 该去 idx 0，那边是 -1（不等于 1），换 | [1, -1, 3, 4] |
| 1 | -1 | 不在 [1, n]，i++ | |
| 2 | 3 | 已在正确位置，i++ | |
| 3 | 4 | 已在正确位置，i++ | |

最终 nums = `[1, -1, 3, 4]`。扫一遍：`nums[1] = -1 ≠ 2`，答案 2。

---

## 七、写成代码

```python
class Solution:
    def firstMissingPositive(self, nums):
        n = len(nums)
        i = 0
        while i < n:
            x = nums[i]
            if 1 <= x <= n and nums[x - 1] != x:
                nums[i], nums[x - 1] = nums[x - 1], nums[i]
                # 换完不前进，继续检查换过来的新元素
            else:
                i += 1
        for i in range(n):
            if nums[i] != i + 1:
                return i + 1
        return n + 1
```

---

## 八、复杂度

- **时间** `O(n)`：每次交换至少把一个值放对，最多 n 次交换
- **空间** `O(1)`

---

## 九、容易踩的坑

1. **判 `nums[x - 1] != x`** 而不是 `nums[i] != i + 1`：防止重复值死循环。
2. **交换后 i 不前进**：换过来的元素继续 while 检查。
3. **答案范围 [1, n+1]**：全齐时返回 n + 1。

---

## 十、一句话记忆

> **原地哈希**：把每个 1..n 的值放到 `idx = val - 1`，最后扫第一个错位的就是答案。
