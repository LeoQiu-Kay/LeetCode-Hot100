# 32. 最长有效括号 · 阅读版

> 难度：困难 · [LeetCode 链接](https://leetcode.cn/problems/longest-valid-parentheses/)

---

## 一、题目讲了什么

字符串只含 `(` 和 `)`，求**最长有效括号子串**的长度。

例：

- `"(()"` → 2（"()"）
- `")()())"` → 4（"()()"）

---

## 二、思路对比

| 方法 | 时间 | 空间 |
|---|---|---|

| 两次扫描计数 | O(n) | **O(1)** |

讲**栈解法**——直观，和 20 题同源。

---

## 三、栈的精妙用法

不同于 20 题（栈里存字符），32 栈里存**下标**，且栈底始终维护**"上一个未匹配的 ')'"的位置**当作"基准"。

每次配对成功时，**当前有效串的长度 = `当前下标 - 栈顶（基准）`**。

具体规则：

- 初始 `stack = [-1]`（哨兵：表示"还没有任何未匹配 ')'"，基准在 -1）
- 遇到 `(` → push 下标
- 遇到 `)`：
  - **pop 一个**（不管是什么）
  - 如果栈空了 → 说明这个 ')' 没有 '(' 配，**它本身成为新基准**，push 它的下标
  - 否则配对成功 → 当前长度 = `i - stack[-1]`，更新答案

---

## 四、为什么栈顶始终是"上一个未匹配 ')'"的位置

每次：

- `(` push 下标 → 等待配对
- `)` pop：
  - 如果 pop 出 `(` 的下标（配对成功），栈顶又变回"上一个未匹配 ')'"
  - 如果 pop 出"上一个未匹配 ')'"（栈里没 ( 给它配），栈空 → 把当前 ')' 作为新基准 push

不变量：栈底永远是当前有效段的"前一个位置"。

---

## 五、举例 `")()())"`

stack 初始 `[-1]`，ans = 0。

| i | c | 动作 | stack | ans |
|---|---|---|---|---|
| 0 | ) | pop (-1)，栈空，push 0 | [0] | 0 |
| 1 | ( | push 1 | [0, 1] | 0 |
| 2 | ) | pop (1)，栈非空，ans = 2 - 0 = 2 | [0] | 2 |
| 3 | ( | push 3 | [0, 3] | 2 |
| 4 | ) | pop (3)，栈非空，ans = 4 - 0 = 4 | [0] | **4** |
| 5 | ) | pop (0)，栈空，push 5 | [5] | 4 |

答案 4。

---

## 六、写成代码

```python
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        # 栈底放 -1 作为"基准前位"：第一对配上时 i - (-1) 正好得到长度 2
        stack: list[int] = [-1]
        ans = 0
        for i, c in enumerate(s):
            if c == '(':
                # 左括号下标入栈，等右括号来配
                stack.append(i)
            else:
                # 右括号：先 pop 一个出来配对
                stack.pop()
                if not stack:
                    # 栈空说明没有左括号能配 → 当前 ')' 是新的"无效基准"
                    stack.append(i)
                else:
                    # 配对成功，当前有效串长度 = i - 栈顶（基准前位）
                    ans = max(ans, i - stack[-1])
        return ans
```

## 七、复杂度

- **时间** `O(n)`
- **空间** `O(n)`：栈

---

## 八、容易踩的坑

1. **哨兵 -1 必不可少**：否则空字符串 / 首字符就配对的长度算错。
2. **遇到 ')' 先 pop 后判**：pop 出的是上一个 ( 或是上一个未匹配 )，根据栈空与否区分两种情形。
3. **"基准前一位"的语义**：长度 = `i - 栈顶` 而不是 `i - 栈顶 + 1`，因为栈顶是基准本身的下标（基准不算在有效段里）。

---

## 九、一句话记忆

> 栈底放 -1 哨兵 → `(` 入栈、`)` 先 pop，**栈空就把 ')' 当新基准**，否则 `ans = i - 栈顶`。
