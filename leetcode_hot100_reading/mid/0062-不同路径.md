# 62. 不同路径 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/unique-paths/)

---

## 一、题目讲了什么

`m × n` 的方格，从左上角到右下角，**只能向下或向右**走。一共有多少种不同路径？

例：m=3, n=7 → 28 种。

---

## 二、状态定义

`dp[i][j]` = 从起点 (0, 0) 到 (i, j) 的不同路径数。

每个格子只能从**上方**或**左方**到达，所以：

```
dp[i][j] = dp[i-1][j] + dp[i][j-1]
```

**边界**：

- 第一行（i=0）：只能一路向右，`dp[0][j] = 1`
- 第一列（j=0）：只能一路向下，`dp[i][0] = 1`

这其实就是**杨辉三角**斜着写——你可能在 118 题见过同样的递推。

---

## 三、答案的组合数公式

数学上 `dp[m-1][n-1] = C(m+n-2, m-1)`——共需要走 m+n-2 步，其中 m-1 步是"下"，从中选位置。但 DP 写起来直观、不需要算组合数。

---

## 四、空间压成 O(n)

每个格子只依赖上方 + 左方，可以用**一维数组**滚动：

```
dp = [1] * n           # 第一行
for i in range(1, m):
    for j in range(1, n):
        dp[j] += dp[j - 1]    # 左边的 dp[j-1] 已是本行的新值，dp[j] 还是上一行
```

执行 `dp[j] += dp[j-1]` 时，`dp[j-1]` 已是本行（左方），`dp[j]` 还没更新所以是上一行（上方）——正好对应递推。

---

## 五、写成代码

```python
class Solution:
    def uniquePaths(self, m, n):
        dp = [1] * n
        for _ in range(1, m):
            for j in range(1, n):
                dp[j] += dp[j - 1]
        return dp[-1]
```

5 行。

---

## 六、复杂度

- **时间** `O(m × n)`
- **空间** `O(n)`（一维滚动）

---

## 七、容易踩的坑

1. **一维滚动时 j 必须从 1 开始**：`dp[0]` 永远是 1（第一列），不用动。
2. **理解"`dp[j]` 此刻是上一行的 dp[i-1][j]"**：在 += 之前还没被覆盖。
3. **递推方向**：`dp[i][j]` 由 `dp[i-1][j]` 和 `dp[i][j-1]` 决定，不要写反。

---

## 八、一句话记忆

> `dp[i][j] = dp[i-1][j] + dp[i][j-1]`，一维滚动 `dp[j] += dp[j-1]`。
