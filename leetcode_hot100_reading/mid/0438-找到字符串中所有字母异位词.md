# 438. 找到字符串中所有字母异位词 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/find-all-anagrams-in-a-string/)

---

## 一、题目讲了什么

字符串 s 和 p。返回 s 中所有 **p 的字母异位词** 的子串起始下标。

异位词 = 字母组成相同。

例：`s="cbaebabacd", p="abc"` → `[0, 6]`（"cba" 和 "bac"）

---

## 二、思路：定长滑动窗口

p 长度固定 = len(p)。"是否异位词"等价于"字母计数完全相同"。

→ **滑动窗口长度固定 = len(p)**，每次比较窗口内的字母计数和 p 的字母计数。

---

## 三、用 26 长度数组比较

把"字母计数"表示为长度 26 的数组（小写字母）：

```
cnt_p = [0] * 26
for c in p: cnt_p[ord(c) - ord('a')] += 1
```

窗口 `cnt_w` 同样维护。每滑一格：

- **右进**：`cnt_w[s[r]] += 1`
- **左出**（当窗口长 > len(p) 时）：`cnt_w[s[l]] -= 1`

每次窗口长 == len(p) 时检查 `cnt_w == cnt_p`。两个长度 26 数组比较是 O(26) = O(1)。

---

## 四、写成代码

```python
class Solution:
    def findAnagrams(self, s, p):
        ns, np = len(s), len(p)
        if ns < np: return []

        cnt_p = [0] * 26
        cnt_w = [0] * 26
        for c in p:
            cnt_p[ord(c) - ord('a')] += 1

        ans = []
        for i in range(ns):
            cnt_w[ord(s[i]) - ord('a')] += 1
            if i >= np:                              # 窗口超长，左端踢出
                cnt_w[ord(s[i - np]) - ord('a')] -= 1
            if i >= np - 1 and cnt_w == cnt_p:        # 窗口正好长 = np，比较
                ans.append(i - np + 1)
        return ans
```

---

## 五、复杂度

- **时间** `O(N × Σ)`：Σ = 26，常数。实际 O(N)
- **空间** `O(1)`：两个 26 长度数组

---

## 六、容易踩的坑

1. **窗口起点是 `i - np + 1`**：i 是右端下标。
2. **`i >= np` 时踢左端**、`i >= np - 1` 时比较：边界注意。
3. **特判 `ns < np`**：直接返回 `[]`，否则 `s[i - np]` 可能越界。

---

## 七、一句话记忆

> 定长窗口 + **26 长度计数数组**对比，长度相等时检查。
