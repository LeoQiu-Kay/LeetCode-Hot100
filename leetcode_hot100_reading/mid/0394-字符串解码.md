# 394. 字符串解码 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/decode-string/)

---

## 一、题目讲了什么

编码规则：`k[encoded_string]` 表示 encoded_string **重复 k 次**。可以**嵌套**。

例：

- `"3[a]2[bc]"` → `"aaabcbc"`
- `"3[a2[c]]"` → `"accaccacc"`（嵌套）
- `"2[abc]3[cd]ef"` → `"abcabccdcdcdef"`

---

## 二、嵌套结构 → 双栈

嵌套是经典栈题型。设两个栈：

- **数字栈** `num_stack`：每层的重复次数
- **字符串栈** `str_stack`：每层的"外层已积累的字符串"

扫描字符：

- **数字**：累积到 `num`（多位）
- **`[`**：进入新一层 — `num` 和 `cur` 入栈，重置
- **`]`**：结束本层 — 弹出外层 num 和 prev，新 `cur = prev + cur * num`
- **字母**：累积到 `cur`

---

## 三、画一遍 `"3[a2[c]]"`

| 字符 | num | cur | num_stack | str_stack | 备注 |
|---|---|---|---|---|---|
| 3 | 3 | "" | [] | [] | |
| [ | 0 | "" | [3] | [""] | 进新层 |
| a | 0 | "a" | [3] | [""] | |
| 2 | 2 | "a" | [3] | [""] | |
| [ | 0 | "" | [3, 2] | ["", "a"] | 进新层 |
| c | 0 | "c" | [3, 2] | ["", "a"] | |
| ] | 0 | "a" + "c"*2 = "acc" | [3] | [""] | 结束内层 |
| ] | 0 | "" + "acc"*3 = "accaccacc" | [] | [] | 结束外层 |

最终 cur = `"accaccacc"`。

---

## 四、写成代码

```python
class Solution:
    def decodeString(self, s: str) -> str:
        num_stack: list[int] = []   # 嵌套层的重复次数栈
        str_stack: list[str] = []   # 嵌套层的"外层已积累字符串"栈
        cur = ""    # 当前层正在累积的字符串
        num = 0     # 当前层正在累积的数字
        for c in s:
            if c.isdigit():
                # 数字可能多位，累加
                num = num * 10 + int(c)
            elif c == '[':
                # 进入新一层：把外层的数字和字符串压栈，当前层从头开始
                num_stack.append(num)
                str_stack.append(cur)
                num = 0
                cur = ""
            elif c == ']':
                # 结束当前层：弹出"外层字符串"和"重复次数"
                # 新 cur = 外层字符串 + 当前层字符串 * 次数
                k = num_stack.pop()
                prev = str_stack.pop()
                cur = prev + cur * k
            else:
                # 字母直接累积
                cur += c
        return cur
```

---

## 五、复杂度

- **时间** `O(N)`：N = 解码后总长度
- **空间** `O(d)`：嵌套深度

---

## 六、容易踩的坑

1. **数字可能多位**：`num = num * 10 + int(c)` 累加。
2. **`[` 时同时存 num 和 cur 入栈**，**两者都清零**：新一层从头算。
3. **`]` 时拼接顺序**：外层字符串在前、内层重复结果在后 → `prev + cur * k`。

---

## 七、一句话记忆

> **两个栈**：数字栈 + 字符串栈。`[` 入栈清零；`]` 弹栈拼接 `prev + cur * num`。
