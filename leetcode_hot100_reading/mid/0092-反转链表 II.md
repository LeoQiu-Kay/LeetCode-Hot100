# 92. 反转链表 II · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/reverse-linked-list-ii/)
> 📌 **不在 Hot 100 题单**，作为 206 反转链表的进阶补充。

---

## 一、题目讲了什么

给单链表，反转**第 `left` 到第 `right` 个节点**（位置从 1 数），其余不动。返回新链表。

例：`[1,2,3,4,5], left=2, right=4` → `[1,4,3,2,5]`（中间 `2,3,4` 反转成 `4,3,2`，两头的 1 和 5 不动）。

进阶要求：**一趟扫描**完成。

---

## 二、和 206（反转整条链表）的区别

206 是反转**整条**链表，92 是反转**中间一段**。难点多了两个：

1. **定位**：先找到第 left 个节点（和它的前驱）。
2. **缝合**：反转完那段后，要把它的两头正确接回前后两段——`前段尾 → 反转段 → 后段头` 不能断。

如果硬套 206 的"三指针反转一段 + 记住四个边界节点再缝回去"，能做但**容易把四个端点搞混**。这题有个更顺的写法：**头插法**。

---

## 三、头插法的画面

设 `prev` 停在反转段的**前一个**节点（left 的前驱）。反转段第一个节点叫 `cur`。

头插法的核心动作：**反复把 `cur` 后面的那个节点"摘下来"，插到 `prev` 的正后面**（即段首）。

```
初始（left=2, right=4，prev 指向节点 1，cur 指向节点 2）：
  1 → 2 → 3 → 4 → 5
  ↑   ↑
 prev cur

第 1 次：摘下 cur 后面的 3，插到 prev 后
  1 → 3 → 2 → 4 → 5
  ↑       ↑
 prev    cur（注意 cur 还是 2，但它后移了一格）

第 2 次：摘下 cur 后面的 4，插到 prev 后
  1 → 4 → 3 → 2 → 5
  ↑           ↑
 prev        cur

做 right - left = 2 次，结束。
```

**关键观察**：`cur` 始终是原来的那个节点（这里是 2），它在过程中**一路下沉到段尾**——所以代码里 cur 不需要更新，只要每次摘它后面的节点。

---

## 四、头插次数为什么是 `right - left`

反转段有 `right - left + 1` 个节点。头插法每做一次，就把一个节点提到段首——相当于"确定了一个节点的最终位置"。

但**段首第一个节点（cur）不需要被提**（它本来就在，最后沉到段尾）。所以只需要提**剩下的 `right - left` 个**。

例子里反转段 `2,3,4` 共 3 个，提 2 次（提 3、提 4），cur=2 自然沉底。

---

## 五、三行重连的顺序

每次头插的三行：

```python
nxt = cur.next          # ① 记住要摘的节点
cur.next = nxt.next     # ② cur 跳过 nxt（把 nxt 从链上摘下）
nxt.next = prev.next    # ③ nxt 指向当前段首
prev.next = nxt         # ④ prev 接上新段首 nxt
```

顺序不能乱：先 ① 存住 nxt，再 ② 让 cur 跳过它，最后 ③④ 把 nxt 接到段首。和所有指针题一样——**先备份要丢失的引用**。

---

## 六、dummy 头消边界

如果 `left == 1`，反转段从头节点开始，`prev` 就没有"前驱节点"可停。

加 **dummy 头**（指向 head），让 `prev` 从 dummy 出发，`left == 1` 时 prev 正好停在 dummy 上——统一处理，不用特判。最后返回 `dummy.next`。

---

## 七、写成代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def reverseBetween(self, head: ListNode | None, left: int, right: int) -> ListNode | None:
        dummy = ListNode(0, head)
        # 1. prev 走到第 left 个节点的前一个
        prev = dummy
        for _ in range(left - 1):
            prev = prev.next
        # 2. cur 是反转段第一个节点（会逐步沉到段尾，引用始终不变）
        cur = prev.next
        # 3. 头插法：把 cur 后面的节点一个个提到段首，共 right - left 次
        for _ in range(right - left):
            nxt = cur.next          # ① 要摘下来的节点
            cur.next = nxt.next     # ② cur 跳过 nxt
            nxt.next = prev.next    # ③ nxt 插到段首
            prev.next = nxt         # ④ prev 接上新段首
        return dummy.next
```

---

## 八、复杂度

- **时间** `O(n)`：prev 走 left-1 步，再头插 right-left 次，一趟
- **空间** `O(1)`：几个指针

---

## 九、容易踩的坑

1. **dummy 必备**：`left == 1` 时反转段含头节点，没 dummy 要单独特判。
2. **头插次数 `right - left`**（不是 +1）：cur 自己不用提。
3. **cur 不更新**：它始终是反转段原来的第一个节点，过程中沉到段尾。
4. **三行重连顺序**：先存 nxt，再让 cur 跳过，最后把 nxt 接到段首。
5. **prev 走 `left - 1` 步**：从 dummy 出发，停在 left 的前驱。

---

## 十、一句话记忆

> **dummy + 头插法**：prev 停在 left 前驱，把 cur 后面的节点逐个提到段首，提 `right - left` 次。cur 自动沉底。
