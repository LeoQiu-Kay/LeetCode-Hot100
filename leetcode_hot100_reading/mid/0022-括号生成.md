# 22. 括号生成 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/generate-parentheses/)

---

## 一、题目讲了什么

给一个数字 `n`，生成所有由 n 对括号组成的**合法**序列。

例：n = 3 →
```
((()))   (()())   (())()
()(())   ()()()
```

合法 = 每个 `(` 都能找到匹配的 `)`，且任何前缀里 `(` 的数量 ≥ `)` 的数量。

---

## 二、回溯 + 剪枝

类型上是"列出所有可能"——回溯。

每一步在 path 末尾追加一个字符：要么 `(` 要么 `)`。如果只是穷举所有 `2 × 2 × ... × 2 = 4ⁿ` 种字符串，再过滤合法的，太慢。

**剪枝**：能直接挡掉非法的就别走。两条规则：

1. **`(` 数量已用满 n 个** → 不能再加 `(`
2. **`)` 数量已 ≥ `(` 数量** → 不能再加 `)`（否则前缀非法）

记 `left` = 已用左括号数，`right` = 已用右括号数：

- 加 `(` 的条件：`left < n`
- 加 `)` 的条件：`right < left`

---

## 三、为什么这两条规则就够

任何**部分序列**只要满足"`right ≤ left ≤ n`"，就一定能扩展成合法的完整序列。所以这两条剪枝**既不漏**（每个合法序列都能被找到）**也不剩**（不会走到非法分支）。

最终生成的序列数 = 第 n 个 Catalan 数 `C(n)`，远小于 4ⁿ。

---

## 四、画一遍 n = 2 的递归树

```
              "" (0,0)
             /      \
        加(            ×（right<left=0 不满足）
        /
    "(" (1,0)
    /        \
  "((" (2,0)   "()" (1,1)
  /            /        \
"(()" (2,1)  "()(" (2,1)  ×（right<left=1，可以但 left=n=2 用满了，只能加 )）
  /            /
"(())" (2,2) "()()" (2,2)
```

得到 `(())` 和 `()()`，正确。

---

## 五、写成代码

```python
class Solution:
    def generateParenthesis(self, n: int) -> list[str]:
        ans: list[str] = []
        def dfs(left: int, right: int, path: str) -> None:
            # 用了 n 对括号，path 长度 == 2n，得到一种合法序列
            if len(path) == 2 * n:
                ans.append(path)
                return
            # 左括号还没用完，可以加
            if left < n:
                dfs(left + 1, right, path + '(')
            # 已用左括号比右括号多，才能加右括号
            # 否则会出现 ')' 在前面没有 '(' 配对的非法情形
            if right < left:
                dfs(left, right + 1, path + ')')
        dfs(0, 0, "")
        return ans
```

---

## 六、复杂度

- **时间** `O(C(n) × n)`：Catalan 数 × 每条路径的字符串拼接
- **空间** `O(n)`：递归栈

---

## 七、容易踩的坑

1. **剪枝条件第二条是 `right < left`**，不是 `right < n`。核心是"已用右不能超过已用左"。
2. **path 用字符串拼接**：每次新建一份，结果集就不需要 copy；要追求效率可以改 list + pop 回溯，但代码长一点。
3. **终止条件**：`len(path) == 2 * n` 而不是 `left == n`（虽然此时 left == right == n，等价）。

---

## 八、一句话记忆

> **回溯加两条剪枝**：`left < n` 才能加 `(`，`right < left` 才能加 `)`。
