# 560. 和为 K 的子数组 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/subarray-sum-equals-k/)

---

## 一、题目讲了什么

数组求**连续子数组**和等于 k 的**个数**（不是返回子数组本身）。数组**可能含负数**。

例：`nums=[1,1,1], k=2` → 2（前两 1 和后两 1）。

---

## 二、为什么不能用滑动窗口

数组含负数 → 增加元素和**不一定变大**。滑动窗口依赖单调性，本题失效。

---

## 三、前缀和 + 哈希

定义 `prefix[i]` = `nums[0..i-1]` 的累加和（前 i 个的和），`prefix[0] = 0`。

**子数组 `nums[i..j]` 的和** = `prefix[j+1] - prefix[i]`。

> "和为 k 的子数组数量" = 满足 `prefix[j+1] - prefix[i] == k` 的 (i, j) 对数

固定 j，问题变成 **"前面有多少个 prefix[i] 等于 prefix[j+1] - k"**。

→ 用哈希记 `count[前缀和] = 出现次数`。扫一遍数组时 ans 累加 `count[cur - k]`，再 `count[cur] += 1`。

**初始 `count[0] = 1`**：表示"空前缀的和是 0"——让"从下标 0 开始的子数组"能命中。

---

## 四、走一遍 `nums=[1,1,1], k=2`

| i | nums[i] | cur (前缀和) | count[cur - k] | ans | count |
|---|---|---|---|---|---|
| - | - | 0 | - | 0 | {0:1} |
| 0 | 1 | 1 | count[-1]=0 | 0 | {0:1, 1:1} |
| 1 | 1 | 2 | count[0]=1 | 1 | {0:1, 1:1, 2:1} |
| 2 | 1 | 3 | count[1]=1 | 2 | {0:1, 1:1, 2:1, 3:1} |

ans = 2。

---

## 五、写成代码

```python
from collections import defaultdict

class Solution:
    def subarraySum(self, nums: list[int], k: int) -> int:
        # 前缀和出现次数；count[0] = 1 表示"空前缀"的前缀和是 0，
        # 这样从下标 0 开始且和为 k 的子数组也能被正确计入
        count = defaultdict(int)
        count[0] = 1
        cur = 0      # 到当前位置的前缀和
        ans = 0
        for x in nums:
            cur += x
            # 之前有多少个前缀和等于 cur - k，就有多少条以当前位置结尾、和为 k 的子数组
            ans += count[cur - k]
            # 当前前缀和加入字典，供后面位置使用
            count[cur] += 1
        return ans
```

---

## 六、复杂度

- **时间** `O(n)`
- **空间** `O(n)`

---

## 七、为什么"先 ans += 再 count +="

如果先把当前前缀和加入 count，遇到 `k = 0` 的情况会把"自己"算成一个有效子数组（cur - cur = 0 命中自己）——这是 bug。

正确顺序：**先用 count 查、再把 cur 加入 count**。

---

## 八、容易踩的坑

1. **`count[0] = 1` 初始化**：处理"从下标 0 开始的子数组"。
2. **顺序**：先 ans 后 count。
3. **不能用滑动窗口**：有负数时窗口和不单调。

---

## 九、一句话记忆

> **前缀和 + 哈希**：`ans += count[cur - k]`，再 `count[cur] += 1`。
