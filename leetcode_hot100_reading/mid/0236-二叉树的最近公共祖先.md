# 236. 二叉树的最近公共祖先 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/)

---

## 一、题目讲了什么

二叉树里给两个节点 p、q，返回它们**最近的公共祖先**（LCA）——既是 p 的祖先、又是 q 的祖先，且**最深**的那个。一个节点也算自己的祖先。

例：

```
    3
   / \
  5   1
 / \  / \
6   2 0  8

LCA(5, 1) = 3
LCA(5, 4) = 5    （5 是 4 的祖先）
```

---

## 二、思路：后序递归 + "原样上传"

每个节点问左右子树："你们俩里有 p 或 q 吗？"

- **左右都返回非空** → 当前节点就是 LCA（p、q 分散在两侧，**只有这里能同时覆盖**）
- **只一边非空** → LCA 在那边或就是 p / q 本身 → **把那边的结果上传**
- **两边都空** → 返回 None

把 **p 或 q 本身**也视为"找到的祖先"——这样递归到 p 时直接返回 p，能优雅处理"一个是另一个的祖先"的情形。

---

## 三、为什么"一边非空就上传"是对的

当只有一边非空时：

- 那边的返回值是 LCA 或 p / q 本身（不知道具体是哪个，但都正确）
- 上传到上层后，要么上层另一侧把另一个目标也找到 → 上层成为新 LCA；要么一直上传直到根，最终的返回值就是 LCA

---

## 四、写成代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def lowestCommonAncestor(self, root, p, q):
        if not root or root is p or root is q:
            return root
        left = self.lowestCommonAncestor(root.left, p, q)
        right = self.lowestCommonAncestor(root.right, p, q)
        if left and right:
            return root          # 当前是 LCA
        return left or right     # 一侧非空 → 上传
```

---

## 五、复杂度

- **时间** `O(n)`
- **空间** `O(h)`：递归栈

---

## 六、容易踩的坑

1. **"遇到 p 或 q 就返回它"**：这一行让"p 是 q 祖先"的情况自动正确——不需要单独判。
2. **节点比较用 `is`**：判同一对象，不是 val 相等。
3. **两边都非空才是 LCA**：少了这条逻辑就找不到分叉点。

---

## 七、一句话记忆

> 后序递归："**遇到 p 或 q 返回它；两侧都非空当前是 LCA；一侧非空上传**"。
