# 208. 实现 Trie（前缀树） · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/implement-trie-prefix-tree/)

---

## 一、题目讲了什么

实现 **Trie**（也叫前缀树 / 字典树），支持三个操作：

- `insert(word)`：插入单词
- `search(word)`：是否**完整存在**这个单词
- `startsWith(prefix)`：是否有以 prefix 开头的单词

---

## 二、为什么不用普通哈希表

哈希表能做 search 但**做不了 startsWith**（除非把所有前缀都存进去，浪费空间）。

Trie 的核心是：

> **每个字符是树上的一条边**，从根开始沿着 word 各字符走，能走到底说明 word 存在。

前缀查询只是"能不能走到 prefix 末尾"，不要求标记结束。

---

## 三、节点结构

```
TrieNode:
    children: dict[char, TrieNode]   # 子节点（也可以用 26 长度数组）
    is_end:   bool                   # 这里是否有单词结束
```

根节点不存字符，只是入口。

---

## 四、三个操作的共同子例程

```
walk(s) → 节点 or None
    沿 s 的字符走，存在就返回末端节点，断链返回 None
```

- `insert(word)`：边走边创建缺失的孩子，最后标 `is_end = True`
- `search(word)`：walk(word)，返回的节点存在且 `is_end == True`
- `startsWith(prefix)`：walk(prefix)，返回的节点存在即可（不要求 is_end）

---

## 五、写成代码

```python
class TrieNode:
    def __init__(self):
        # 用 dict 比 26-数组更通用（支持任意字符），代码也更简洁
        self.children: dict[str, "TrieNode"] = {}
        # 是否有单词在当前节点结束
        self.is_end = False

class Trie:
    def __init__(self):
        # 根节点不存字符，只起"起点"作用
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        node = self.root
        for c in word:
            # 没有这条边就开一个新孩子
            if c not in node.children:
                node.children[c] = TrieNode()
            # 沿这条边走下去
            node = node.children[c]
        # 走到末尾打标记
        node.is_end = True

    def _walk(self, word: str) -> "TrieNode | None":
        # 沿 word 各字符走，返回最终落点节点；中途断链则返回 None
        node = self.root
        for c in word:
            if c not in node.children:
                return None
            node = node.children[c]
        return node

    def search(self, word: str) -> bool:
        # 必须走到底 且 该节点标记了 isEnd
        node = self._walk(word)
        return node is not None and node.is_end

    def startsWith(self, prefix: str) -> bool:
        # 只要能走到底就行，不要求 isEnd
        return self._walk(prefix) is not None
```

---

## 六、复杂度

- **时间**：每个操作 O(L)，L 是字符串长度
- **空间** `O(总字符数)`：所有插入字符串的总长

---

## 七、容易踩的坑

1. **search 必须看 `is_end`**，否则 prefix 误判为单词存在。
2. **startsWith 不看 is_end**，只要能走完 prefix 就行。
3. **`children` 用 dict 比 26 数组更通用**：支持任意字符；hot100 都是小写字母用数组也快。

---

## 八、一句话记忆

> Trie：**每字符一条边**，is_end 标记单词结束；insert 边走边建，search/startsWith 复用 walk。
