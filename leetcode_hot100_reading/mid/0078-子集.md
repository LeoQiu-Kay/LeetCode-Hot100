# 78. 子集 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/subsets/)

---

## 一、题目讲了什么

给一个**不含重复**元素的数组，返回它**所有子集**（包括空集和它自己）。

例：`[1, 2, 3]` → `[[], [1], [2], [3], [1,2], [1,3], [2,3], [1,2,3]]`

n 个元素共 `2ⁿ` 个子集。

---

## 二、两种主流思路

**思路 A：每个元素"选 / 不选"**

```
dfs(i):
    if i == n: 收集 path
    选 nums[i]：path.append; dfs(i+1); path.pop
    不选 nums[i]：dfs(i+1)
```

**思路 B：用 `start` 控制顺序（避免重复子集）**

```
dfs(start):
    每次进函数都收集 path（表示"当前已选的元素构成一个子集"）
    for i in [start..n-1]:
        path.append(nums[i])
        dfs(i + 1)
        path.pop()
```

两种都对、都常见。本文用 B（更自然地枚举每个子集，且和 39、46 题模板对齐）。

---

## 三、为什么思路 B 进入函数就收集

每进入 `dfs(start)` 一次，意味着 path 此刻就是一个有效子集（"当前已选的元素的组合"）。第一次进入时 path 是空 → 收集空集。

后面循环每选一个元素就递归继续，所以每个子集都对应**某次 dfs 入口的 path 快照**——所有子集都会被收集到。

---

## 四、画一遍 `[1, 2, 3]` 的递归

```
dfs(0) path=[]                          收集 []
├── 选 1 → dfs(1) path=[1]              收集 [1]
│   ├── 选 2 → dfs(2) path=[1,2]        收集 [1,2]
│   │   └── 选 3 → dfs(3) path=[1,2,3]  收集 [1,2,3]
│   └── 选 3 → dfs(3) path=[1,3]        收集 [1,3]
├── 选 2 → dfs(2) path=[2]              收集 [2]
│   └── 选 3 → dfs(3) path=[2,3]        收集 [2,3]
└── 选 3 → dfs(3) path=[3]              收集 [3]
```

正好 8 个子集。

---

## 五、写成代码

```python
class Solution:
    def subsets(self, nums: list[int]) -> list[list[int]]:
        ans: list[list[int]] = []
        path: list[int] = []
        def dfs(start: int) -> None:
            # 每个状态（无论 path 长度多少）都是一个子集
            ans.append(path.copy())
            # 从 start 开始往后挑（保证子集元素按原顺序，不重复）
            for i in range(start, len(nums)):
                path.append(nums[i])
                # 注意是 i+1 不是 start+1：下次从"刚选过这个之后"往后继续
                dfs(i + 1)
                path.pop()
        dfs(0)
        return ans
```

---

## 六、复杂度

- **时间** `O(n × 2ⁿ)`：2ⁿ 个子集，每个 path.copy() O(n)
- **空间** `O(n)`：递归栈 + path

---

## 七、容易踩的坑

1. **`dfs(i + 1)` 不是 `dfs(start + 1)`**：要从"刚选的位置之后"继续，否则跳过元素。
2. **每次进入函数都收集**（不是判终止条件再收集）：每个 dfs 入口的 path 就是一个有效子集。
3. **`path.copy()`** 必不可少：path 是会变的引用，不复制结果就全是同一个对象。

---

## 八、一句话记忆

> 进入 dfs 就**收集 path**；循环 i 从 start 到 n-1，选 → `dfs(i+1)` → 撤回。
