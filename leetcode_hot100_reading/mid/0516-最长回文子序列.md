# 516. 最长回文子序列 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/longest-palindromic-subsequence/)
> 📌 **不在 Hot 100 题单**，作为区间 DP 的经典母题补充进来（与 5 最长回文子串是姊妹题）。

---

## 一、题目讲了什么

给一个字符串 `s`，找出**最长回文子序列**的**长度**。

> **子序列**：不改变剩余字符的相对顺序，删除若干字符（可以一个不删）得到的序列。**不要求连续**。

例：

- `"bbbab"` → 4（取 `"bbbb"`，把中间的 `'a'` 删掉，剩下四个 `b` 是回文）
- `"cbbd"` → 2（取 `"bb"`）

---

## 二、和 5 题"最长回文**子串**"的区别

| 题 | 要求 | 例子 |
|---|---|---|
| **5** | 连续片段 | `"bbbab"` → 子串 `"bbb"`，长度 3 |
| **516** | 可跳过字符 | `"bbbab"` → 子序列 `"bbbb"`，长度 4 |

子序列可以跨字符挑选，所以答案 ≥ 5 题的答案。但**怎么挑**就成了关键。

中心扩展那套（5 题主解）在这里**不适用**——子序列允许跳字符，"扩展"没法连续走。这题就只能 DP。

---

## 三、状态定义

> `dp[i][j]` = 子串 `s[i..j]`（**闭区间**）的最长回文**子序列**长度

——和 5 题状态形式一样，但语义不同（5 题存的是"是否回文"，这里存的是"最长子序列长度"）。

---

## 四、递推关系：看两端字符

考察 `s[i..j]` 这段。**最长回文子序列的两端**有两种情形：

### 情形 A：`s[i] == s[j]`

两端字符相同——**它俩一定可以同时进入最长回文子序列**（不要白不要）。

```
dp[i][j] = dp[i+1][j-1] + 2
```

即"内部最长 + 两端各算一个"。

### 情形 B：`s[i] != s[j]`

两端不同——**至少一个不能同时出现在回文中**（否则两端不相等就不是回文了）。

要么放弃左端（看 `s[i+1..j]`），要么放弃右端（看 `s[i..j-1]`），取更长的：

```
dp[i][j] = max(dp[i+1][j], dp[i][j-1])
```

---

## 五、边界与填表顺序

**边界**：

- 长度 1：`dp[i][i] = 1`（单字符就是长度 1 的回文）
- 长度 2 时**不必单独写**：见下面"细节"

**填表顺序**：和 5 题一模一样的"i 必须反向遍历"问题。

`dp[i][j]` 依赖 `dp[i+1][j-1]`、`dp[i+1][j]`、`dp[i][j-1]`——前两个都涉及 `i+1`，所以 i 必须**从 n-1 反向到 0**，保证 `dp[i+1]` 那一行先算好。

---

## 六、长度 2 的细节

`j == i + 1` 时，递推用到 `dp[i+1][j-1] = dp[i+1][i]`，i+1 > i 是"非法区间"。**约定非法区间值为 0**（数组初始 0），那么：

- 两端相等：`dp[i][j] = 0 + 2 = 2` ✓（如 `"bb"` → 2）
- 两端不等：`dp[i][j] = max(dp[i+1][j], dp[i][j-1]) = max(1, 1) = 1` ✓（如 `"ab"` → 1）

都对，**所以不用为长度 2 单独写分支**。这是这题 DP 比 5 题更优雅的地方（5 题判"是否回文"时长度 2 必须单独写）。

---

## 七、走一遍 `"bbbab"`

n = 5，初始 `dp[i][i] = 1`：

```
   j= 0 1 2 3 4
i=0    1 . . . .
i=1      1 . . .
i=2        1 . .
i=3          1 .
i=4            1
```

外层 i 从 4 倒到 0；内层 j 从 i+1 到 n-1。

| i | j | s[i] | s[j] | 相等? | dp[i][j] 公式 | 值 |
|---|---|---|---|---|---|---|
| 3 | 4 | a | b | no | max(dp[4][4]=1, dp[3][3]=1) | 1 |
| 2 | 3 | b | a | no | max(dp[3][3]=1, dp[2][2]=1) | 1 |
| 2 | 4 | b | b | **yes** | dp[3][3] + 2 = 1 + 2 | **3** |
| 1 | 2 | b | b | **yes** | dp[2][1] + 2 = 0 + 2 | **2** |
| 1 | 3 | b | a | no | max(dp[2][3]=1, dp[1][2]=2) | 2 |
| 1 | 4 | b | b | **yes** | dp[2][3] + 2 = 1 + 2 | **3** |
| 0 | 1 | b | b | **yes** | dp[1][0] + 2 = 0 + 2 | **2** |
| 0 | 2 | b | b | **yes** | dp[1][1] + 2 = 1 + 2 | **3** |
| 0 | 3 | b | a | no | max(dp[1][3]=2, dp[0][2]=3) | 3 |
| 0 | 4 | b | b | **yes** | dp[1][3] + 2 = 2 + 2 | **4** |

`dp[0][4] = 4`，答案 4（对应 `"bbbb"`）。

---

## 八、写成代码

```python
class Solution:
    def longestPalindromeSubseq(self, s: str) -> int:
        n = len(s)
        # dp[i][j] = s[i..j] 的最长回文子序列长度
        dp = [[0] * n for _ in range(n)]

        # 单字符天然回文，长度 1
        for i in range(n):
            dp[i][i] = 1

        # 外层 i 反向遍历，保证 dp[i+1][...] 先算好
        for i in reversed(range(n)):
            # 内层 j 从 i+1 起，跳过单字符（已初始化）
            for j in range(i + 1, n):
                if s[i] == s[j]:
                    # 两端相等：内部 + 2
                    # j == i+1 时 dp[i+1][j-1] = dp[i+1][i] = 0（非法区间），+ 2 正好得 2
                    dp[i][j] = dp[i + 1][j - 1] + 2
                else:
                    # 两端不等：丢左端 或 丢右端
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])

        # 整个字符串的最长回文子序列长度
        return dp[0][n - 1]
```

---

## 九、复杂度

- **时间** `O(n²)`：双层填表
- **空间** `O(n²)`：dp 表。可压成 O(n) 滚动（因为只依赖 i+1 那一行）

---

## 十、容易踩的坑

1. **子序列 vs 子串**：5 题是子串（连续），516 是子序列（可跳）。状态语义不同，递推也不同。
2. **答案是 `dp[0][n-1]`**（整个字符串）——不是 `max(dp)`，也不是 dp 表对角线。
3. **填表顺序**：外层 i 反向遍历。正向会用到没算好的 `dp[i+1]`。
4. **长度 2 不用单独写**：约定非法区间为 0，递推公式自动算对。这是相对 5 题的简化。
5. **不要用中心扩展**：那套适合"连续子串"，子序列要跳字符没法连续扩。

---

## 十一、一句话记忆

> 区间 DP：**两端相等 → 内部 + 2；两端不等 → max(丢左, 丢右)**。i 反向、j 正向，答案在 `dp[0][n-1]`。
