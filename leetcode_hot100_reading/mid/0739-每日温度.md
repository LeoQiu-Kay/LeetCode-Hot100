# 739. 每日温度 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/daily-temperatures/)

---

## 一、题目讲了什么

数组 `temperatures`，对每个 i 找**下一个比 temperatures[i] 大的天**和 i 之间的天数差。没有更高的天就填 0。

例：`[73, 74, 75, 71, 69, 72, 76, 73]` → `[1, 1, 4, 2, 1, 1, 0, 0]`

---

## 二、暴力 O(n²)：每个 i 往后扫——太慢。

---

## 三、单调递减栈

"找下一个更大"的经典套路：**单调递减栈**。

栈里存"还没找到答案的下标"，对应温度从栈底到栈顶**严格递减**。

每个新元素 `t`：

- 当栈非空且 `temperatures[stack[-1]] < t` 时：弹出 j，**j 的答案 = i - j**
- 然后把 i 入栈

每个下标最多入栈、出栈各一次 → O(n)。

---

## 四、为什么是"递减"栈

栈里的下标对应的温度严格递减——意味着它们都还在等"未来某天更暖"。一旦来了个比栈顶大的，栈顶等到了；如果新来的还比第二个大，再弹；以此类推。

新元素入栈后，仍保持严格递减。

---

## 五、走一遍 `[73, 74, 75]`

| i | t | 栈 (下标对应温度) | 动作 | ans |
|---|---|---|---|---|
| 0 | 73 | [] | 入栈 [0] | [0,0,0] |
| 1 | 74 | [0] (73) | 73<74 弹出 0，ans[0]=1-0=1，入栈 [1] | [1,0,0] |
| 2 | 75 | [1] (74) | 74<75 弹出 1，ans[1]=2-1=1，入栈 [2] | [1,1,0] |

ans[2] 没人比它大，保持 0。

---

## 六、写成代码

```python
class Solution:
    def dailyTemperatures(self, temperatures):
        n = len(temperatures)
        ans = [0] * n
        stack = []                              # 单调递减栈，存下标
        for i, t in enumerate(temperatures):
            while stack and temperatures[stack[-1]] < t:
                j = stack.pop()
                ans[j] = i - j
            stack.append(i)
        return ans
```

---

## 七、复杂度

- **时间** `O(n)`：每个下标最多入栈出栈各一次
- **空间** `O(n)`：栈

---

## 八、容易踩的坑

1. **栈里存下标，不是温度**：要算距离需要下标。
2. **比较用 `<`（严格小于）**：题目要"更大"，相等不算。
3. **最后栈里剩下的下标 ans 保持 0**：初始化 [0] * n 自动处理。

---

## 九、一句话记忆

> **单调递减栈**：新元素来时把栈顶比它小的全弹出并结算 `ans[j] = i - j`。
