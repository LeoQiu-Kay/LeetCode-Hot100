# 763. 划分字母区间 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/partition-labels/)

---

## 一、题目讲了什么

字符串 `s`，把它**划分尽可能多的片段**，使得**每个字母至多出现在一段里**。返回每段的长度。

例：`s = "ababcbacadefegdehijhklij"` → `[9, 7, 8]`（"ababcbaca" / "defegde" / "hijhklij"）

---

## 二、思路：贪心 + "本段必须延伸到的右端"

每个字母**最后一次出现的位置**是一个硬约束——这个字母必须包含在它所在的段里。

策略：

1. **先扫一遍**记录每个字母**最后出现位置** `last[ch]`。
2. **再扫一遍**：维护当前段的"必须延伸到的右端 `end`"。每遇到一个字符 c，把 end 至少扩到 `last[c]`。当 `i == end` 时，本段结束，记录长度，开始下一段。

---

## 三、为什么这样切是"最多段"

每个段被切到的时机是"内部所有字母的 last 都 ≤ i"——意味着不能再往前切了（再切就会让某个字母出现在两段里）。换言之，**每个段的切点是必要的**——给定该约束下达到最早的切点。

由此，段数最多。

---

## 四、走一遍 `"ababcbaca"`（前 9 个字符）

预扫得 `last = {a:8, b:5, c:7}`。

| i | c | last[c] | end (新) | i == end? | 段长 |
|---|---|---|---|---|---|
| 0 | a | 8 | 8 | no | |
| 1 | b | 5 | 8 | no | |
| 2 | a | 8 | 8 | no | |
| 3 | b | 5 | 8 | no | |
| 4 | c | 7 | 8 | no | |
| 5 | b | 5 | 8 | no | |
| 6 | a | 8 | 8 | no | |
| 7 | c | 7 | 8 | no | |
| 8 | a | 8 | 8 | **yes** | 9 |

切一段长度 9。

---

## 五、写成代码

```python
class Solution:
    def partitionLabels(self, s):
        last = {c: i for i, c in enumerate(s)}
        ans = []
        start = 0
        end = 0
        for i, c in enumerate(s):
            end = max(end, last[c])
            if i == end:
                ans.append(i - start + 1)
                start = i + 1
        return ans
```

---

## 六、复杂度

- **时间** `O(n)`：两趟扫描
- **空间** `O(Σ)`：last 字典，最多 26 项

---

## 七、容易踩的坑

1. **必须先扫一遍记 last**：第二遍扫时才能即时查询。
2. **`end = max(end, last[c])`**：可能拉长本段。
3. **`i == end` 时立刻切**，且更新 `start = i + 1`。

---

## 八、一句话记忆

> 预扫记 last → 二扫维护 `end = max(end, last[c])`，**走到 end 就切段**。
