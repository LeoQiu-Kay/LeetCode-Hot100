# 105. 从前序与中序遍历序列构造二叉树 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/)

---

## 一、题目讲了什么

给一棵二叉树的**前序**和**中序**遍历结果（值不重复），重建原树。

例：preorder=`[3,9,20,15,7]`，inorder=`[9,3,15,20,7]` →

```
    3
   / \
  9  20
     / \
    15  7
```

---

## 二、关键观察

- **前序**：根 → 左子树 → 右子树。所以**前序首元素 = 当前子树的根**。
- **中序**：左子树 → 根 → 右子树。所以中序里**根的左边 = 左子树**、**根的右边 = 右子树**。

把两者结合：

1. 从前序拿出根（首位）
2. 在中序里**找到根的位置 mid**
3. 中序 `[0..mid-1]` 是左子树、`[mid+1..]` 是右子树
4. 前序里**根之后**对应的就是左子树（长度 = mid）和右子树
5. 递归构造左右

---

## 三、效率优化：哈希预存中序值的位置

每次"在中序里找根的位置"如果线性扫，整体 O(n²)。预先用哈希存 `值 → 中序下标`，单次查找 O(1)，整体 O(n)。

题目说"值不重复"——这才让哈希可行。

---

## 四、用全局指针消费前序

每次取"前序首元素"用全局/闭包指针 `pre_i` 表示"前序消费到哪了"。每次取一个就 +1。

**关键顺序**：

- 取根 → `pre_i++`
- **先递归左子树**：左子树的所有节点在前序里紧跟在根之后
- **再递归右子树**：右子树才轮到出现在前序里

如果反着先右后左，pre_i 就把右子树的节点取走了，左子树没节点可用。

---

## 五、写成代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def buildTree(self, preorder, inorder):
        idx_map = {v: i for i, v in enumerate(inorder)}
        pre_i = [0]
        def build(l, r):    # 当前子树对应中序的 [l, r] 闭区间
            if l > r:
                return None
            val = preorder[pre_i[0]]
            pre_i[0] += 1
            root = TreeNode(val)
            mid = idx_map[val]
            root.left = build(l, mid - 1)     # 先左
            root.right = build(mid + 1, r)    # 后右
            return root
        return build(0, len(inorder) - 1)
```

`pre_i` 用 list 是为了在闭包内可变；Python 3 可以用 `nonlocal` 配普通变量。

---

## 六、复杂度

- **时间** `O(n)`：每个节点构造一次
- **空间** `O(n)`：哈希表 + 递归栈

---

## 七、容易踩的坑

1. **必须先递归左子树**：前序消费顺序是"根、左、右"。
2. **中序值不重复**才能用哈希——题目保证。
3. **区间用闭 `[l, r]` 还是半开**：本文用闭区间，出口判 `l > r`。

---

## 八、一句话记忆

> 前序首位是根 → 中序里查根位置切分 → **先递归左子树再右**。
