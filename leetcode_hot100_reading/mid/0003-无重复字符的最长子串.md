# 3. 无重复字符的最长子串 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/longest-substring-without-repeating-characters/)

---

## 一、题目讲了什么

字符串 `s`，找出**不含重复字符**的**最长子串**的长度。

例：

- `"abcabcbb"` → `"abc"`，长度 3
- `"bbbbb"` → `"b"`，长度 1
- `"pwwkew"` → `"wke"`，长度 3

注意要的是**长度**不是子串本身；"子串"是**连续**的，不是"子序列"。

---

## 二、引出滑动窗口

朴素 O(n²)：枚举每个起点 i，往后扫直到遇到重复。

更优：用**滑动窗口** — 用两个指针 `l, r` 维护一个**没有重复字符**的窗口 `[l, r]`。`r` 不断右扩，遇到重复就把 `l` **跳到导致重复的那个字符上次位置 + 1**。每步更新最长长度。

为什么这样有效：当 r 把一个字符 `c` 加进窗口、发现 `c` 之前已经出现过时，新窗口的最大左边界就是"上次 c 出现位置 + 1"——再往左都会包含两个 c。

---

## 三、用哈希记"字符上次位置"

```
last = {}                 # 字符 → 上次出现的下标
l = 0                     # 窗口左端
ans = 0
for r, c in enumerate(s):
    if c in last and last[c] >= l:        # 上次 c 还在窗口里
        l = last[c] + 1                     # 跳到 c 上次位置 +1
    last[c] = r                              # 更新 c 的最新位置
    ans = max(ans, r - l + 1)
return ans
```

**关键判断 `last[c] >= l`**：c 可能很早出现过但已经被踢出窗口了，此时不需要再跳左端。

---

## 四、走一遍 `"abcabcbb"`

| r | c | last[c]? | 动作 | l | last | ans |
|---|---|---|---|---|---|---|
| 0 | a | - | 加入 | 0 | {a:0} | 1 |
| 1 | b | - | 加入 | 0 | {a:0, b:1} | 2 |
| 2 | c | - | 加入 | 0 | {a:0, b:1, c:2} | 3 |
| 3 | a | last[a]=0 ≥ l=0 | l = 1 | 1 | {a:3, b:1, c:2} | 3 |
| 4 | b | last[b]=1 ≥ l=1 | l = 2 | 2 | {a:3, b:4, c:2} | 3 |
| 5 | c | last[c]=2 ≥ l=2 | l = 3 | 3 | {a:3, b:4, c:5} | 3 |
| 6 | b | last[b]=4 ≥ l=3 | l = 5 | 5 | {a:3, b:6, c:5} | 3 |
| 7 | b | last[b]=6 ≥ l=5 | l = 7 | 7 | {a:3, b:7, c:5} | 3 |

答案 3。

---

## 五、写成代码

```python
class Solution:
    def lengthOfLongestSubstring(self, s):
        last = {}
        l = 0
        ans = 0
        for r, c in enumerate(s):
            if c in last and last[c] >= l:
                l = last[c] + 1
            last[c] = r
            ans = max(ans, r - l + 1)
        return ans
```

---

## 六、复杂度

- **时间** `O(n)`：每个字符最多被左端 / 右端各访问一次
- **空间** `O(|Σ|)`：哈希表大小 ≤ 字符集大小

---

## 七、容易踩的坑

1. **`last[c] >= l` 不能漏**：c 上次出现可能已被踢出窗口，此时不能拉回 l。
2. **`l = last[c] + 1` 不是 `l + 1`**：要直接跳，否则 O(n²)。
3. **窗口长度 `r - l + 1`**：闭区间 [l, r] 的长度。

---

## 八、一句话记忆

> 滑动窗口 + "字符→上次位置"哈希；遇到重复就把 **l 跳到上次位置 + 1**。
