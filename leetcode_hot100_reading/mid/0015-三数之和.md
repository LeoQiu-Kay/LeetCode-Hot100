# 15. 三数之和 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/3sum/)

---

## 一、题目讲了什么

数组找出**所有**和为 0 的**三元组** `[a, b, c]`，**不能重复**。

例：`[-1, 0, 1, 2, -1, -4]` → `[[-1, -1, 2], [-1, 0, 1]]`

注意"三元组不重复"指**值**不重复，不是下标。`[-1, 0, 1]` 有两个 -1 但只出现一次。

---

## 二、思路引导

题号 15 像是 1 题（两数之和）的扩展。但**关键差别**：

- 题 1：找任**一对**和等于 target，O(n) 哈希解法
- 题 15：找**所有**三元组，且要去重 — 哈希不好处理重复

**先排序**，让相同的元素挨在一起，**去重就变简单**：跳过相邻相同的位置即可。

排序后还得到一个红利：**两数之和能用相向双指针 O(n)**。

---

## 三、三层结构：固定 i + 双指针找 (l, r)

- 外层枚举 `i`，把 `nums[i]` 当作"第一个数"
- 在 `[i+1, n-1]` 范围内用**相向双指针** l 和 r 找两数之和等于 `-nums[i]`

时间从 O(n³) 暴力降到 O(n²)。

---

## 四、三层都要去重

**外层 i 去重**：

```
if i > 0 and nums[i] == nums[i-1]:
    continue
```

i 和前一个相同时直接跳——结果会和上一轮重复。

**内层去重**：找到一个三元组后，l 和 r **都要继续跳过相同值**：

```
l += 1
while l < r and nums[l] == nums[l-1]:
    l += 1
r -= 1
while l < r and nums[r] == nums[r+1]:
    r -= 1
```

否则像 `[-2, 0, 0, 2, 2]` 这种会产出多次 `[-2, 0, 2]`。

---

## 五、剪枝

排序后 `nums[i] > 0` 时，后面的数都 ≥ nums[i] > 0，三数和不可能为 0 — 直接 break。

---

## 六、写成代码

```python
class Solution:
    def threeSum(self, nums):
        nums.sort()
        n = len(nums)
        ans = []
        for i in range(n - 2):
            if nums[i] > 0:
                break                  # 剪枝
            if i > 0 and nums[i] == nums[i - 1]:
                continue                # 外层去重
            l, r = i + 1, n - 1
            target = -nums[i]
            while l < r:
                s = nums[l] + nums[r]
                if s == target:
                    ans.append([nums[i], nums[l], nums[r]])
                    l += 1
                    while l < r and nums[l] == nums[l - 1]:
                        l += 1
                    r -= 1
                    while l < r and nums[r] == nums[r + 1]:
                        r -= 1
                elif s < target:
                    l += 1
                else:
                    r -= 1
        return ans
```

---

## 七、复杂度

- **时间** `O(n²)`：排序 O(n log n) + 双层 O(n²)
- **空间** `O(1)`（不算输出和排序占用）

---

## 八、容易踩的坑

1. **三个地方都要去重**：i / l / r。漏一个就有重复三元组。
2. **必须先排序**才能用双指针 + 跳相邻去重。
3. **剪枝 `nums[i] > 0` break** 可省，但对最坏数据能省不少时间。
4. **i 上限是 `n - 2`**：要给 l 和 r 留位置。

---

## 九、一句话记忆

> **排序 + 固定一个 + 相向双指针**，三层（i, l, r）都要"跳过相邻相同值"。
