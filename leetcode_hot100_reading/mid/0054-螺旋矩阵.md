# 54. 螺旋矩阵 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/spiral-matrix/)

---

## 一、题目讲了什么

按**顺时针螺旋**顺序返回矩阵的所有元素。

例：

```
[1, 2, 3]              输出：[1, 2, 3, 6, 9, 8, 7, 4, 5]
[4, 5, 6]
[7, 8, 9]
```

走法：右、下、左、上、右……不断内缩。

---

## 二、维护四个边界

四个变量框出"未访问区域"：

```
top    = 0       # 上边界
bottom = m - 1   # 下边界
left   = 0       # 左边界
right  = n - 1   # 右边界
```

按 4 个方向一圈一圈走，**每走完一条边就把对应边界往内缩**：

1. **上边（左 → 右）**：扫完 `top++`
2. **右边（上 → 下）**：扫完 `right--`
3. **下边（右 → 左）**：扫完 `bottom--`
4. **左边（下 → 上）**：扫完 `left++`

直到 `top > bottom` 或 `left > right`。

---

## 三、单行 / 单列的退化

最后剩单行或单列时，**只走第 1 步（上边）**或**只走第 2 步（右边）**就完了——别再走第 3 / 4 步。

为防止重复扫，在第 3 / 4 步前判一下：

```
if top <= bottom:
    走下边
if left <= right:
    走左边
```

否则像 3×1 矩阵 [[1],[2],[3]] 在走完"右边"后会再扫"下边"和"左边"重复同一列。

---

## 四、写成代码

```python
class Solution:
    def spiralOrder(self, matrix: list[list[int]]) -> list[int]:
        if not matrix:
            return []
        m, n = len(matrix), len(matrix[0])
        top, bottom = 0, m - 1
        left, right = 0, n - 1
        ans: list[int] = []
        while top <= bottom and left <= right:
            # 1. 上边：从左到右
            for j in range(left, right + 1):
                ans.append(matrix[top][j])
            top += 1
            # 2. 右边：从上到下
            for i in range(top, bottom + 1):
                ans.append(matrix[i][right])
            right -= 1
            # 3. 下边：从右到左（要先确认还有行，避免单行被重复扫）
            if top <= bottom:
                for j in range(right, left - 1, -1):
                    ans.append(matrix[bottom][j])
                bottom -= 1
            # 4. 左边：从下到上（要先确认还有列，避免单列被重复扫）
            if left <= right:
                for i in range(bottom, top - 1, -1):
                    ans.append(matrix[i][left])
                left += 1
        return ans
```

---

## 五、复杂度

- **时间** `O(m × n)`：每个元素访问一次
- **空间** `O(1)`：不算输出

---

## 六、容易踩的坑

1. **第 3 / 4 步前判退化**：单行或单列时漏判会出重复数。
2. **方向区间**：从左到右 `range(left, right + 1)`、从右到左 `range(right, left - 1, -1)`。边界 +1 / -1 别错。
3. **边界更新时机**：每走完一条边**立刻**更新该边界，再走下一条。

---

## 七、一句话记忆

> **四边界 + 顺时针走 + 走完缩边**，下边 / 左边走前判防单行 / 单列重复。
