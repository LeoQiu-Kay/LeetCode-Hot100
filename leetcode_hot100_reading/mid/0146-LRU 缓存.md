# 146. LRU 缓存 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/lru-cache/)

---

## 一、题目讲了什么

实现一个 LRU（Least Recently Used）缓存，支持：

- `get(key)`：返回 key 的值，若不存在返回 -1
- `put(key, value)`：插入或更新；若插入后容量超出，淘汰**最久未使用**的键

要求 **get / put 均摊 O(1)**。

例：容量 2 → put(1,1)、put(2,2)、get(1)（命中 1）、put(3,3)（淘汰 2）、get(2)（已淘汰 → -1）……

---

## 二、单一数据结构做不到 O(1)

- 仅哈希表：查 O(1)，但找"最久未用"要扫一遍 O(n)
- 仅链表：插入头 O(1)，但查 key O(n)

**两者组合**：

- 哈希表 `key → 链表节点`，查 O(1)
- 双向链表维护"最近使用"顺序：表头是最新，表尾是最久未用

---

## 三、为什么必须双向链表

- 单向链表删除中间节点要先找前驱 O(n)
- 双向链表每个节点有 prev / next，**O(1) 删除任一节点**

LRU 操作里：

- `get`：找到节点 → 删除 → 移到头部 → 这里要"删任一节点"，必须 O(1)
- `put` 满了 → 删除尾部 → 也要 O(1)

---

## 四、dummy 头尾节点消除边界

链表两端各放一个**永远存在**的 dummy（哨兵）节点：

```
head ⇄ ... ⇄ tail
```

这样**任何节点都至少有前驱和后继**——`node.prev.next = node.next; node.next.prev = node.prev` 不会爆 None。新增 / 删除都用同一套代码。

---

## 五、写成代码

```python
class Node:
    def __init__(self, key=0, val=0):
        self.key = key
        self.val = val
        self.prev = None
        self.next = None

class LRUCache:
    def __init__(self, capacity):
        self.cap = capacity
        self.map = {}                 # key → Node
        # dummy 头尾
        self.head = Node()
        self.tail = Node()
        self.head.next = self.tail
        self.tail.prev = self.head

    def _remove(self, node):
        node.prev.next = node.next
        node.next.prev = node.prev

    def _add_to_head(self, node):
        node.prev = self.head
        node.next = self.head.next
        self.head.next.prev = node
        self.head.next = node

    def get(self, key):
        if key not in self.map:
            return -1
        node = self.map[key]
        self._remove(node)              # 命中后移到头部
        self._add_to_head(node)
        return node.val

    def put(self, key, value):
        if key in self.map:
            node = self.map[key]
            node.val = value
            self._remove(node)
            self._add_to_head(node)
        else:
            node = Node(key, value)
            self.map[key] = node
            self._add_to_head(node)
            if len(self.map) > self.cap:
                lru = self.tail.prev
                self._remove(lru)
                del self.map[lru.key]   # 同步删哈希表
```

---

## 六、复杂度

- **时间**：get / put 都是 O(1)
- **空间** `O(capacity)`

---

## 七、容易踩的坑

1. **Node 要存 key**，不只 val：淘汰时要从哈希表删，需要知道 key。
2. **删除时哈希表和链表都要删**：少一边就内存泄漏 / 逻辑错。
3. **dummy 头尾抹平边界**：插入头部、删除尾部都不用判 None。
4. **`_remove + _add_to_head` 写成两个函数**：`get` 和 `put` 都要用，封装一下避免重复代码。

---

## 八、一句话记忆

> **哈希表 + 双向链表 + 头尾 dummy**：哈希 O(1) 查、链表 O(1) 改顺序、dummy 抹边界。
