# 55. 跳跃游戏 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/jump-game/)

---

## 一、题目讲了什么

数组 `nums`，`nums[i]` 表示在位置 i 最多能跳几步。判断能否从起点跳到末尾。

例：

- `[2, 3, 1, 1, 4]` → 能（0→1→4）
- `[3, 2, 1, 0, 4]` → 不能（停在 3 处，0 跳不动，到不了 4）

---

## 二、贪心：维护"已知能到的最远位置"

不需要枚举具体跳法。一边遍历一边维护：

```
reach = 0    # 到目前为止，能跳到的最远下标
```

每到一个位置 `i`：

- 如果 `i > reach` → 卡死，返回 False（连 i 都到不了）
- 否则用 `i + nums[i]` 更新 reach：`reach = max(reach, i + nums[i])`

走完整个数组 / reach 已覆盖末尾 → 返回 True。

---

## 三、为什么贪心成立

如果"能到 i"，那从 i 一步能到的任何 `j ≤ i + nums[i]` 都"能到"。所以"目前能到的最远 reach"是一个**前缀连续的可达范围**——一旦 reach < i，i 永远到不了。

---

## 四、走一遍

例 1：`[2, 3, 1, 1, 4]`

| i | nums[i] | reach 前 | 检查 i > reach? | reach 后 |
|---|---|---|---|---|
| 0 | 2 | 0 | 0>0? no | max(0, 2)=2 |
| 1 | 3 | 2 | 1>2? no | max(2, 4)=4 |
| 2 | 1 | 4 | 2>4? no | max(4, 3)=4 |
| 3 | 1 | 4 | 3>4? no | max(4, 4)=4 |
| 4 | 4 | 4 | 4>4? no | max(4, 8)=8 |

reach=8 ≥ 4，True。

例 2：`[3, 2, 1, 0, 4]`

| i | nums[i] | reach 前 | 检查 | reach 后 |
|---|---|---|---|---|
| 0 | 3 | 0 | ok | 3 |
| 1 | 2 | 3 | ok | 3 |
| 2 | 1 | 3 | ok | 3 |
| 3 | 0 | 3 | ok | 3 |
| 4 | 4 | 3 | **4 > 3，卡死** | - |

返回 False。

---

## 五、写成代码

```python
class Solution:
    def canJump(self, nums: list[int]) -> bool:
        reach = 0   # 目前能到达的最远下标
        for i, x in enumerate(nums):
            # 当前位置 i 都到不了，卡死
            if i > reach:
                return False
            # 从 i 出发能到的最远位置是 i + x，更新 reach
            reach = max(reach, i + x)
            # 优化：已能到末尾，可以提前 return True
            if reach >= len(nums) - 1:
                return True
        return True
```

---

## 六、复杂度

- **时间** `O(n)`
- **空间** `O(1)`

---

## 七、容易踩的坑

1. **必须先判 `i > reach` 再更新 reach**：先更新会让"原本到不了 i"的情形过关。
2. **提前返回**：reach ≥ n-1 时可以提前结束省时间。
3. **不要写跳法 DP**：贪心 O(n) 已最优，DP 是大材小用。

---

## 八、一句话记忆

> 维护 `reach`：**先判 `i > reach`，再 `reach = max(reach, i + nums[i])`**。
