# 128. 最长连续序列 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/longest-consecutive-sequence/)

---

## 一、题目讲了什么

未排序数组里找**最长的连续整数序列**长度（连续指相邻整数，不要求在数组里位置相邻）。

要求 **O(n)**——所以不能排序。

例：`[100, 4, 200, 1, 3, 2]` → 序列 `[1, 2, 3, 4]`，长度 4。

---

## 二、暴力思路与瓶颈

最暴力：对每个数 x，往后数 x+1, x+2, ... 在不在数组里。`in` 是 O(n) 操作 → 整体 O(n³)。

第一步优化：用 **set** 把 `in` 降到 O(1) → O(n²)。

但若数组是 `[1, 2, 3, ..., n]`，对每个数都从中间往后数一遍，仍然 O(n²)。

---

## 三、关键剪枝：只从"起点"开始数

观察："一段连续序列"只有一个**起点**——比它小 1 的数**不在**数组里。

> 当 `x - 1 not in set` 时，x 是某段连续序列的起点，从它开始数才有意义。

如果 `x - 1 in set`，那么以 x 开头的段是被另一个更小的起点"包含"的，不需要重复数。

---

## 四、为什么加了剪枝就是 O(n)

- 外层 for 把每个 x 看一遍：O(n)
- 内层 while 从起点往后数：**每个数最多被内层 while 访问一次**（它属于唯一一段，只在那段的起点被数）
- 整体 O(n)

剪枝把"重复数中间"的浪费消除了。

---

## 五、走一遍 `[100, 4, 200, 1, 3, 2]`

`set = {100, 4, 200, 1, 3, 2}`

| x | x-1 in set? | 起点？ | 数到多长 |
|---|---|---|---|
| 100 | 99? no | ✓ | 1 |
| 4 | 3? yes | ✗ 跳过 |
| 200 | 199? no | ✓ | 1 |
| 1 | 0? no | ✓ | **4**（1→2→3→4）|
| 3 | 2? yes | ✗ 跳过 |
| 2 | 1? yes | ✗ 跳过 |

答案 4。

---

## 六、写成代码

```python
class Solution:
    def longestConsecutive(self, nums: list[int]) -> int:
        s = set(nums)
        ans = 0
        for x in s:
            # 关键剪枝：只从"序列的最左端点"开始数
            # x 是起点的条件：x - 1 不在集合里
            if x - 1 not in s:
                cur = x
                length = 1
                # 一路往后数，统计这段连续序列的长度
                while cur + 1 in s:
                    cur += 1
                    length += 1
                ans = max(ans, length)
        return ans
```

---

## 七、复杂度

- **时间** `O(n)`：set 构建 O(n) + 起点 + while 摊销 O(n)
- **空间** `O(n)`：set

---

## 八、容易踩的坑

1. **剪枝 `x - 1 not in s` 必不可少**：少了它复杂度 O(n²)。
2. **去重**：set 自动去重（题目可能有重复值）。
3. **不要排序**：题目要求 O(n)；排序 O(n log n) 算"次优"。

---

## 九、一句话记忆

> set 去重 + **只从起点（x-1 不在集合）开始数**，每段恰被数一次。
