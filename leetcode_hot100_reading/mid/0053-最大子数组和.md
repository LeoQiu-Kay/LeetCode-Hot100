# 53. 最大子数组和 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/maximum-subarray/)

---

## 一、题目讲了什么

数组里找一段**连续**的子数组，使它的和最大。返回最大和。

例：`[-2, 1, -3, 4, -1, 2, 1, -5, 4]` → `[4, -1, 2, 1]`，和 6。

---

## 二、Kadane 算法

经典 O(n) 解法。定义：

> **`cur` = 以 `nums[i]` 结尾的最大子数组和**

对每个 `nums[i]`，决策只有两个：

- **接到上一个子数组后面**：`cur_prev + nums[i]`
- **从 `nums[i]` 重新开始一个子数组**：`nums[i]` 本身

哪个大要哪个：

```
cur = max(nums[i], cur_prev + nums[i])
```

全局答案 = 所有 cur 的最大值。

---

## 三、为什么"自己重开"和"接着累加"二选一就够

**关键观察**：如果前面那段 `cur_prev` 是负数，把它加到 `nums[i]` 上只会**变小**。这时还不如丢掉它，从 `nums[i]` 重新算。

```
cur_prev + nums[i] vs nums[i]
                等价于
cur_prev > 0 时接着加；否则重开
```

`max` 自然处理这个选择。

---

## 四、走一遍 `[-2, 1, -3, 4, -1, 2, 1, -5, 4]`

| i | nums[i] | cur = max(自己, cur_prev + 自己) | ans |
|---|---|---|---|
| 0 | -2 | -2 | -2 |
| 1 | 1 | max(1, -2+1=-1) = 1 | 1 |
| 2 | -3 | max(-3, 1+-3=-2) = -2 | 1 |
| 3 | 4 | max(4, -2+4=2) = 4 | 4 |
| 4 | -1 | max(-1, 4+-1=3) = 3 | 4 |
| 5 | 2 | max(2, 3+2=5) = 5 | 5 |
| 6 | 1 | max(1, 5+1=6) = 6 | **6** |
| 7 | -5 | max(-5, 6+-5=1) = 1 | 6 |
| 8 | 4 | max(4, 1+4=5) = 5 | 6 |

答案 6。

---

## 五、写成代码

```python
class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        # cur 表示"以当前下标结尾的最大子数组和"
        # ans 是全局最大值，初始都是 nums[0]
        cur = ans = nums[0]
        for x in nums[1:]:
            # 关键决策：cur + x 还不如 x 大，说明前面那段是累赘，放弃，从 x 重新开始
            cur = max(x, cur + x)
            # 更新全局最大
            ans = max(ans, cur)
        return ans
```

---

## 六、复杂度

- **时间** `O(n)`
- **空间** `O(1)`

---

## 七、容易踩的坑

1. **初始 `cur = ans = nums[0]`** 不能用 0：全负数时答案是最大负数（最接近 0 的负数），用 0 会错。
2. **必须连续子数组**：题目里说"连续"，不能跳过元素。如果允许跳就是另一类 DP（300 LIS）。
3. **变量名记清**：`cur` 是"以当前结尾的最大"，不是"目前全局最大"。

---

## 八、一句话记忆

> Kadane：**`cur = max(自己, cur + 自己)`**——前面那段是负数就丢掉重开。
