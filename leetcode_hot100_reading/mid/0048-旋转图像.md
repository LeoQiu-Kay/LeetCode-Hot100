# 48. 旋转图像 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/rotate-image/)

---

## 一、题目讲了什么

一个 `n × n` 的方阵，**原地**顺时针旋转 90°。

例：

```
   原始              旋转后
[1, 2, 3]          [7, 4, 1]
[4, 5, 6]    →     [8, 5, 2]
[7, 8, 9]          [9, 6, 3]
```

**原地**：不允许另开 n × n 数组。

---

## 二、找规律：旋转的本质

第 i 行 → 旋转后变成**倒数第 i 列**。

```
原始 [i][j]  →  旋转后  [j][n-1-i]
```

这是单点变换公式。但要在**不打架**地完成全部交换不容易（A→B→C→D→A 是一个四元环）。

---

## 三、巧解：转置 + 行反转

**关键观察**：顺时针 90° = 转置 + **每行反转**。

```
   原始              转置                行反转后（= 顺时针 90°）
[1, 2, 3]         [1, 4, 7]          [7, 4, 1]
[4, 5, 6]    →    [2, 5, 8]    →     [8, 5, 2]
[7, 8, 9]         [3, 6, 9]          [9, 6, 3]
```

两步都是简单的 O(n²) 操作，原地容易实现。

---

## 四、为什么这个组合等于顺时针 90°

- **转置**：`(i, j) ↔ (j, i)`，等于沿主对角线翻折
- **每行反转**：`(i, j) ↔ (i, n-1-j)`

合起来：`(i, j) → (j, i) → (j, n-1-i)`，正好和"顺时针 90° 的公式 `[i][j] → [j][n-1-i]`"一致。

---

## 五、写成代码

```python
class Solution:
    def rotate(self, matrix: list[list[int]]) -> None:
        n = len(matrix)
        # 1. 沿主对角线翻转（转置）
        # 只交换 i < j 的部分，否则会自相消
        for i in range(n):
            for j in range(i + 1, n):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
        # 2. 每一行做左右翻转
        for row in matrix:
            row.reverse()
```

---

## 六、复杂度

- **时间** `O(n²)`：转置 + 反转都是
- **空间** `O(1)`：原地

---

## 七、容易踩的坑

1. **转置内层从 `i + 1` 开始**：从 0 开始的话每对元素会被交换两次（i,j 和 j,i），相互抵消等于没做。
2. **顺时针 vs 逆时针**：顺时针 = 转置 + 行反转；逆时针 = 转置 + 列反转（或先反转再转置）。
3. **想用"四元环交换"** 也行（每次同时交换 4 个位置），但代码更难写、易出 bug。

---

## 八、一句话记忆

> 顺时针 90° = **转置 + 行反转**。两步都是原地 O(1) 空间。
