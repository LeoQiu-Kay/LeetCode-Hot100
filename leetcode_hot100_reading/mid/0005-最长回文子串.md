# 5. 最长回文子串 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/longest-palindromic-substring/)

---

## 一、题目讲了什么

找出字符串里**最长的回文子串**。

例：`"babad"` → `"bab"` 或 `"aba"`（都长 3）；`"cbbd"` → `"bb"`。

回文 = 正反读一样；子串 = 连续片段。

---

## 二、思路对比

| 方法 | 时间 | 空间 | 评价 |
|---|---|---|---|
| 枚举所有 (i, j) 判回文 | O(n³) | O(1) | 太慢 |
| **中心扩展** | O(n²) | O(1) | 简单优雅，推荐主解 |
| **区间 DP**（`dp[i][j]` 是否回文）| O(n²) | O(n²) | 标准 DP 模板，思路清晰 |
| Manacher | O(n) | O(n) | 神算法，hot100 用不上 |

下面把**中心扩展**作为主解（更省空间），再给出**区间 DP** 作为对照——两者时间复杂度相同，思维角度不同。

---

## 三、中心扩展的关键观察

每个回文都有一个"**中心**"。回文长度有两类：

- **奇数长度**：中心是**一个字符**（如 `"aba"`，中心 'b'）
- **偶数长度**：中心是**两个字符之间**（如 `"abba"`，中心 'b' 和 'b' 之间）

总共有 `2n - 1` 个候选中心（n 个奇数中心 + n - 1 个偶数中心）。对每个中心向两边**扩展**，扩展到不能扩为止——记录到的最长回文就是答案。

---

## 四、扩展函数

```
expand(l, r):
    while l >= 0 and r < n and s[l] == s[r]:
        l -= 1
        r += 1
    # 退出 while 时 s[l] != s[r] 或越界，有效回文是 s[l+1 .. r-1]
    return l + 1, r       # 返回半开区间 [l+1, r)
```

调用方式：

- 以 i 为中心（奇数长）：`expand(i, i)`
- 以 (i, i+1) 为中心（偶数长）：`expand(i, i+1)`

两次扩展取较长的更新答案。

---

## 五、写成代码（中心扩展）

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        def expand(l: int, r: int) -> tuple[int, int]:
            # 从 (l, r) 向两侧扩展，返回最长回文的 (起点, 终点+1)
            while l >= 0 and r < len(s) and s[l] == s[r]:
                l -= 1
                r += 1
            # 退出时 s[l]、s[r] 不匹配或越界，有效范围是 [l+1, r-1]
            return l + 1, r
        best = (0, 1)   # (起点, 终点+1)
        for i in range(len(s)):
            # 奇数长度回文（以 i 为正中央）
            a, b = expand(i, i)
            if b - a > best[1] - best[0]:
                best = (a, b)
            # 偶数长度回文（以 i, i+1 为两中央）
            a, b = expand(i, i + 1)
            if b - a > best[1] - best[0]:
                best = (a, b)
        return s[best[0]:best[1]]
```

复杂度：

- **时间** `O(n²)`：n 个中心 × 每次 O(n) 扩展
- **空间** `O(1)`：只存最佳区间

## 六、区间 DP 的另一种视角

**状态定义**：

> `dp[i][j]` = 子串 `s[i..j]`（闭区间）是否是回文

**递推关系**：

- 子串长度 1：单字符天然回文 → `dp[i][i] = True`
- 子串长度 2：两字符相等才回文 → `dp[i][i+1] = (s[i] == s[i+1])`
- 子串长度 ≥ 3：**两端字符相等** 且 **去掉两端的内部子串也回文** → `dp[i][j] = (s[i] == s[j]) and dp[i+1][j-1]`

---

## 七、填表顺序——为什么要从右下角往上填

`dp[i][j]` 依赖 `dp[i+1][j-1]`——也就是 **i 更大、j 更小**的那个状态。如果按"i 从 0 到 n-1"的常规顺序填，会用到**还没算出来的** `dp[i+1][...]`，错。

解决：**外层 i 反向遍历**（从 n-1 到 0），保证算 `dp[i][j]` 时 `dp[i+1][...]` 已就绪。

或者按"子串长度"递增填：先填长度 1，再长度 2，再长度 3……这样依赖关系自然满足。两种顺序结果一样。

---

## 八、写成代码（区间 DP）

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        # dp[i][j] 表示子串 s[i..j]（闭区间）是否为回文
        n = len(s)
        if n == 0:
            return ""

        # 初始化全 False；下面把长度 1 的子串先标 True
        dp = [[False] * n for _ in range(n)]

        # 所有长度为 1 的子串都是回文（dp[i][i] = True）
        for i in range(n):
            dp[i][i] = True

        # 记录最长回文子串的起止位置（闭区间 [mi, mj]）
        mi, mj = 0, 0

        # 外层 i 反向遍历，保证算 dp[i][j] 时 dp[i+1][j-1] 已经算好
        for i in reversed(range(n)):
            # j 从 i+1 开始（dp[i][i] 已初始化，跳过）
            for j in range(i + 1, n):
                if j - i == 1:
                    # 长度 2：两字符相等才回文
                    dp[i][j] = (s[i] == s[j])
                else:
                    # 长度 ≥ 3：两端相等 + 内部回文
                    dp[i][j] = (s[i] == s[j]) and dp[i + 1][j - 1]

                # 一旦找到回文且更长，更新答案区间
                if dp[i][j] and (j - i) >= (mj - mi):
                    mi, mj = i, j

        # 切片是右开，最终返回 s[mi : mj + 1]
        return s[mi:mj + 1]
```

复杂度：

- **时间** `O(n²)`：双层循环填表
- **空间** `O(n²)`：dp 表

---

## 九、两种解法对比

| 视角 | 中心扩展 | 区间 DP |
|---|---|---|
| **思路** | 枚举每个回文的"中心" | 枚举所有 (i, j) 子串看是否回文 |
| **奇偶处理** | 必须分开（奇中心 / 偶中心两次扩展）| **统一**——dp[i][j] 自动覆盖所有长度 |
| **空间** | O(1) | O(n²) |
| **扩展性** | 单纯找回文很方便 | 需要"是否回文"的二维查询时直接用 dp 表 |
| **代码量** | 略少 | 略多 |

如果题目是"找最长回文子串"，中心扩展更省；如果题目要**多次**判"某区间是否回文"（比如 131 分割回文串），DP 表能直接复用。

---

## 十、容易踩的坑

1. **中心扩展必须两种中心都试**：少一种就会漏一类（少了偶数中心 → 找不到 "abba"）。
2. **DP 填表顺序**：必须保证 `dp[i+1][j-1]` 先算好——外层 i 反向遍历，或按子串长度递增。
3. **DP 长度 2 单独处理**：`dp[i+1][j-1]` 在长度 2 时是 `dp[i+1][i]`（i+1 > i），按约定"非法区间"应视为 True（空区间）。代码里单独 `j - i == 1` 分支处理更清晰。
4. **返回切片右开**：`s[mi:mj+1]` 别漏 +1。

---

## 十一、一句话记忆

> **中心扩展**：枚举每个中心（奇 / 偶），两侧扩展找最长。
> **区间 DP**：`dp[i][j] = (s[i]==s[j]) and dp[i+1][j-1]`，i 反向 / j 正向填表。
