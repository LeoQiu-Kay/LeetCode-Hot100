# 1143. 最长公共子序列 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/longest-common-subsequence/)

---

## 一、题目讲了什么

两个字符串 `text1`, `text2`。找它们**最长公共子序列**的长度。

子序列 = 保留相对顺序的若干字符（**不要求连续**）。公共 = 在两个串里都是子序列。

例：`"abcde"` 和 `"ace"` → `"ace"`，长度 3。

---

## 二、二维 DP 母题

定义 `dp[i][j]` = `text1[:i]` 和 `text2[:j]` 的 LCS 长度。

转移：分情况讨论两个串的**最后一个字符**：

- **相等**：把它们俩同时**纳入**LCS → `dp[i][j] = dp[i-1][j-1] + 1`
- **不等**：至少有一个不能纳入，**二选一丢掉**：
  - 丢 text1 末位 → `dp[i-1][j]`
  - 丢 text2 末位 → `dp[i][j-1]`
  - 取大的：`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`

边界：`dp[0][*] = dp[*][0] = 0`（任一串为空 → LCS 长 0）。

---

## 三、为什么两字符相等时直接 +1

`text1[i-1] == text2[j-1]` 时，**最优 LCS 必然包含这两字符**（不包含的情况不会更长）。所以问题缩成 `text1[:i-1]` 和 `text2[:j-1]`，+ 1。

不等时无法确定哪个字符在最终 LCS 里，只能两边都试。

---

## 四、走一遍 `"abc"` × `"ac"`

|   |  "" | a | c |
|---|---|---|---|
| "" | 0 | 0 | 0 |
| a | 0 | **1** | 1 |
| b | 0 | 1 | 1 |
| c | 0 | 1 | **2** |

`dp[3][2] = 2`，对应 LCS = "ac"。

---

## 五、写成代码

```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        m, n = len(text1), len(text2)
        # dp[i][j] 长度公共子序列；多开 1 行 1 列，dp[0][*] = dp[*][0] = 0（空串）
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                # 注意下标错位：dp[i][j] 对应 text1[i-1] 和 text2[j-1]
                if text1[i - 1] == text2[j - 1]:
                    # 末位相同，公共子序列长度 +1
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    # 末位不同，要么不要 text1 末位，要么不要 text2 末位
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
        return dp[m][n]
```

---

## 六、复杂度

- **时间** `O(m × n)`
- **空间** `O(m × n)`，可压成 O(min(m, n))

---

## 七、容易踩的坑

1. **下标错位**：`dp[i][j]` 对应 `text1[i-1]` 和 `text2[j-1]`，因为 dp 多开一行一列处理边界。
2. **子序列不是子串**：不要求连续。"子串"是题目 5、3 类，转移不同。
3. **只求长度，不求 LCS 本身**：要还原序列得回溯一遍 dp 表。

---

## 八、一句话记忆

> 二维 DP：相等取 **dp[i-1][j-1] + 1**，不等取 **max(dp[i-1][j], dp[i][j-1])**。
