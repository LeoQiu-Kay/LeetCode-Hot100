# 19. 删除链表的倒数第 N 个结点 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/)

---

## 一、题目讲了什么

删除链表里**倒数第 N 个**节点，返回新链表的头。

例：`1 → 2 → 3 → 4 → 5`，n = 2 → 删 4 → `1 → 2 → 3 → 5`

---

## 二、两趟扫法

最直接：

1. 先扫一遍统计长度 L
2. 倒数第 N 个 = 正数第 `L - N + 1` 个
3. 再扫一遍找到它的**前驱**，跳过它

可行但要两趟，能不能**一趟**搞定？——双指针。

---

## 三、双指针差 N 步

让一个**快指针**先走 N 步，然后**快慢同步**前进，直到快指针走到末尾。此时：

- 快指针在末尾，相当于走了"总长 L"步
- 慢指针走了 "L - N" 步，正好停在**倒数第 N 个之前**

更精确地：让快指针先走 `N + 1` 步，这样**慢指针停在被删节点的前一个**，直接 `slow.next = slow.next.next` 即可删除。

---

## 四、dummy 头消除边界

如果要删的是**第一个节点**呢？slow 没有"前一个"。

加 dummy 头：让 `slow = dummy` 开始，无论删哪个节点都能用 `slow.next = slow.next.next` 统一处理。

---

## 五、写成代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def removeNthFromEnd(self, head, n):
        dummy = ListNode(0, head)
        slow = fast = dummy

        # fast 先走 n + 1 步
        for _ in range(n + 1):
            fast = fast.next

        # 同步前进直到 fast 走到 None
        while fast:
            fast = fast.next
            slow = slow.next

        # slow 现在停在被删节点的前一个
        slow.next = slow.next.next
        return dummy.next
```

---

## 六、为什么 fast 是 `n + 1` 步而不是 `n` 步

设链表长 L（不含 dummy）。

- fast 先走 k 步后同步前进 → 同步走 `L + 1 - k` 步后 fast 到 None
- 慢指针此时走了 `L + 1 - k - 0` 步，落在**正数第 `L + 1 - k` 个位置（含 dummy 算第 0）**

我们要慢指针停在**被删节点的前一个**，也就是从尾巴数倒数第 `n + 1` 个 → 等价于"距离末尾还差 n 步"。

```
让 fast 走完后到 dummy.next 末尾的 None：
  fast 总共走 L + 1 步
  fast 已走 k 步（预热）→ 同步 L + 1 - k 步
  slow 同步走了 L + 1 - k 步
  slow 距离 None 的距离 = L + 1 - (L + 1 - k) = k 步
  要 slow 距离 None 是 n + 1 步（被删节点 + None） → k = n + 1
```

记不住推导也没关系，**记 `n + 1` 这个数字**就行。

---

## 七、复杂度

- **时间** `O(L)`：一趟
- **空间** `O(1)`：两个指针

---

## 八、容易踩的坑

1. **预走 `n + 1` 步而不是 `n` 步**：少 1 会停在被删节点本身，不是它的前驱。
2. **dummy 必不可少**：删第一个节点的边界用 dummy 抹平。
3. **返回 `dummy.next`** 而不是 `head`：head 可能已经被删。

---

## 九、一句话记忆

> **双指针差 N+1 步**：fast 先走 n+1，再同步直到 fast 到 None，slow 就停在被删节点前。
