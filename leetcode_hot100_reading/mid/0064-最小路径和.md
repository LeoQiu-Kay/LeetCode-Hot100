# 64. 最小路径和 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/minimum-path-sum/)

---

## 一、题目讲了什么

`m × n` 网格，每格有非负数。从左上到右下，只能向下或向右走。求所经路径上数字之**和最小**。

例：

```
[1, 3, 1]
[1, 5, 1]      最小路径：1 → 3 → 1 → 1 → 1，和 = 7
[4, 2, 1]
```

---

## 二、状态定义

类比 62 题（不同路径）的结构。这里 `dp[i][j]` = "从起点到 (i, j) 的最小路径和"。

每格从上 / 左来，取最小再加自己：

```
dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]
```

**边界**：

- 第一行：只能从左来 → `dp[0][j] = dp[0][j-1] + grid[0][j]`
- 第一列：只能从上来 → `dp[i][0] = dp[i-1][0] + grid[i][0]`

---

## 三、原地修改 grid 省空间

不必另开 dp 数组，**直接在 grid 上累计**：

```
grid[i][j] += min(grid[i-1][j], grid[i][j-1])
```

边界单独累加。最终答案就是 `grid[m-1][n-1]`。

---

## 四、写成代码

```python
class Solution:
    def minPathSum(self, grid):
        m, n = len(grid), len(grid[0])

        # 第一行：只能从左来
        for j in range(1, n):
            grid[0][j] += grid[0][j - 1]

        # 第一列：只能从上来
        for i in range(1, m):
            grid[i][0] += grid[i - 1][0]

        # 其它：min(上, 左) + 自己
        for i in range(1, m):
            for j in range(1, n):
                grid[i][j] += min(grid[i - 1][j], grid[i][j - 1])

        return grid[-1][-1]
```

---

## 五、复杂度

- **时间** `O(m × n)`
- **空间** `O(1)`（原地）

---

## 六、容易踩的坑

1. **必须先单独算第一行第一列**：它们只有一个来源。
2. **题目允许修改 grid 吗？** 一般没禁止；不能修改就开 dp 数组，思路一样。
3. **要数值非负的前提**：本题题目保证非负；若含负数，"只能向下或向右"仍能让贪心式 DP 成立（不会出现负数往回走的情况）。

---

## 七、一句话记忆

> `dp[i][j] = min(上来, 左来) + grid[i][j]`，原地累加省空间。
