# 138. 随机链表的复制 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/copy-list-with-random-pointer/)

---

## 一、题目讲了什么

链表每个节点除了 `next` 还有一个 `random` 指针——指向**链表中任意节点**（或 None）。复制（深拷贝）这条链表。

例：原链表 `[[7,null], [13,0], [11,4], [10,2], [1,0]]`（每对 `[val, random_idx]`）→ 返回一条全新的链表，结构完全相同但所有节点都是新对象。

---

## 二、难点在哪

普通链表只有 next，一趟扫描即可深拷贝。但 random 可能指向**链表中任意节点**——单趟扫描时，目标节点可能**还没创建**（如 random 指向 next.next，在没访问到它前就要赋值就出错）。

需要解决"**新旧节点的对应关系**"。

---

## 三、思路：哈希表两趟扫描

**第一趟**：扫一遍原链表，**只创建节点**（不接 next 和 random）。同时用 dict 存 `旧节点 → 新节点`。

**第二趟**：再扫一遍，根据映射设置每个新节点的 next 和 random：

```
new[old].next   = dict.get(old.next)     # 可能是 None
new[old].random = dict.get(old.random)   # 同上
```

`dict.get(None)` 返回 `None`，方便处理空指针。

---

## 四、为什么必须两趟

第一趟保证**所有节点都已经创建**好。第二趟设指针时无论 random 指向哪里，都能在 dict 里找到。

如果想一趟：每次创建节点时不能立即知道 random 目标的新节点对象——只能用"延迟绑定"或递归 + memo，本质上还是两阶段。

---

## 五、写成代码

```python
class Node:
    def __init__(self, x, next=None, random=None):
        self.val = x
        self.next = next
        self.random = random

class Solution:
    def copyRandomList(self, head):
        if not head: return None

        # 第一趟：创建节点 + 建立映射
        d = {}
        cur = head
        while cur:
            d[cur] = Node(cur.val)
            cur = cur.next

        # 第二趟：连指针
        cur = head
        while cur:
            d[cur].next   = d.get(cur.next)
            d[cur].random = d.get(cur.random)
            cur = cur.next

        return d[head]
```

---

## 六、复杂度

- **时间** `O(n)`：两趟
- **空间** `O(n)`：哈希表

---

## 七、进阶：O(1) 额外空间

经典技巧：

1. 把每个新节点**插在原节点后面**（A → A' → B → B' → ...）
2. 利用"A' 紧跟 A"的位置关系设 random：`A'.random = A.random.next`
3. 拆开两条链

代码长一点，但不用哈希表。Hot 100 范围里 O(n) 哈希解法够用。

---

## 八、容易踩的坑

1. **必须两趟**：第一趟只创建，第二趟只连指针。
2. **`dict.get(None)` 自然返回 None**：处理 next/random 为空的节点不需要特判。
3. **空链表返回 None**：开头特判。

---

## 九、一句话记忆

> **两趟扫描**：第一趟造节点 + 建 `旧 → 新` 映射；第二趟按映射连 next 和 random。
