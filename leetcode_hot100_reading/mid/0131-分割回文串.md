# 131. 分割回文串 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/palindrome-partitioning/)

---

## 一、题目讲了什么

字符串 `s`，把它**切分**成若干段，**每段都是回文**。返回所有可能的切分方案。

例：`s = "aab"` → `[["a","a","b"], ["aa","b"]]`

---

## 二、回溯 + 判回文

切分方案 = 在每个切点之间二选一切或不切。但有"每段必须回文"的硬约束。

回溯框架：

```
dfs(start):    "从 s[start..] 开始切"
    if start == n: 收集 path
    else:
        for i in [start..n-1]:
            if s[start..i] 是回文:
                path.append(s[start..i])
                dfs(i + 1)
                path.pop()
```

每层枚举本段的右端点 i，只在"是回文"时才递归继续。

---

## 三、判回文：双指针对撞

```
def is_pal(l, r):
    while l < r:
        if s[l] != s[r]: return False
        l += 1
        r -= 1
    return True
```

可以预处理一个二维 dp 表加速，但本题数据规模（s.length ≤ 16）直接 is_pal 也够快。

---

## 四、走一遍 `"aab"`

```
dfs(0)
├── i=0: "a" 回文 → path=["a"], dfs(1)
│       ├── i=1: "a" 回文 → path=["a","a"], dfs(2)
│       │       └── i=2: "b" 回文 → path=["a","a","b"], dfs(3) 收集
│       └── i=2: "ab" 不是回文，跳过
├── i=1: "aa" 回文 → path=["aa"], dfs(2)
│       └── i=2: "b" 回文 → path=["aa","b"], dfs(3) 收集
└── i=2: "aab" 不是回文，跳过
```

得到 `[["a","a","b"], ["aa","b"]]`。

---

## 五、写成代码

```python
class Solution:
    def partition(self, s: str) -> list[list[str]]:
        ans: list[list[str]] = []
        path: list[str] = []
        n = len(s)
        def is_pal(l: int, r: int) -> bool:
            # 判断 s[l..r] 是否回文（双指针对撞）
            while l < r:
                if s[l] != s[r]:
                    return False
                l += 1
                r -= 1
            return True
        def dfs(start: int) -> None:
            # 整个字符串切完，收集一种切法
            if start == n:
                ans.append(path.copy())
                return
            # 枚举本段的右端点 i（闭区间 [start, i]）
            for i in range(start, n):
                if is_pal(start, i):
                    # 本段是回文，加入路径继续切剩余部分
                    path.append(s[start:i + 1])
                    dfs(i + 1)
                    path.pop()
        dfs(0)
        return ans
```

---

## 六、复杂度

- **时间** `O(n × 2ⁿ)`：每个位置可切可不切（2ⁿ 切法），每段判回文 O(n)
- **空间** `O(n)`：递归栈 + path

---

## 七、容易踩的坑

1. **切片是 `s[start:i+1]`**（右开），不要漏 +1。
2. **判回文要传 `(start, i)` 闭区间**，不要传 `(start, i-1)`。
3. **回溯三件套缺一不可**：append → dfs → pop。
4. **可以预处理回文 DP 表**（题目 647 的子问题）加速，但题目数据规模不需要。

---

## 八、一句话记忆

> **枚举本段右端点 + 判回文 + 回溯继续**。
