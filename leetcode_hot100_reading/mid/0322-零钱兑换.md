# 322. 零钱兑换 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/coin-change/)

---

## 一、题目讲了什么

硬币面值 `coins`（无限供应），目标金额 `amount`。求**最少**用几枚硬币凑出 amount。凑不出返回 -1。

例：

- `coins=[1,2,5], amount=11` → 3（5+5+1）
- `coins=[2], amount=3` → -1

---

## 二、DP：`dp[i]` = 凑出 i 的最少枚数

```
dp[i] = min(dp[i - coin] + 1)   for coin in coins, coin ≤ i
边界 dp[0] = 0
```

枚举"最后一枚硬币是哪种"，等于 i - coin 的最优解 + 1。

---

## 三、初始值用什么

dp 初始要"足够大"——不可能比真实答案小。最大可能答案是 amount（全用面值 1，如果有 1 的话），用 `amount + 1` 当哨兵：

```
dp = [amount + 1] * (amount + 1)
dp[0] = 0
```

最后判 `dp[amount] != amount + 1`，否则返回 -1。

---

## 四、走一遍 `coins=[1,2,5], amount=11`

```
dp[0] = 0
dp[1] = dp[0]+1 = 1                              （用 1）
dp[2] = min(dp[1]+1, dp[0]+1) = 1                （用 2）
dp[3] = min(dp[2]+1, dp[1]+1) = 2                （2+1）
dp[4] = min(dp[3]+1, dp[2]+1) = 2                （2+2）
dp[5] = min(dp[4]+1, dp[3]+1, dp[0]+1) = 1       （用 5）
dp[6] = min(dp[5]+1, dp[4]+1, dp[1]+1) = 2
...
dp[11] = min(dp[10]+1, dp[9]+1, dp[6]+1) = 3
```

---

## 五、写成代码

```python
class Solution:
    def coinChange(self, coins, amount):
        INF = amount + 1
        dp = [INF] * (amount + 1)
        dp[0] = 0
        for i in range(1, amount + 1):
            for coin in coins:
                if i >= coin:
                    dp[i] = min(dp[i], dp[i - coin] + 1)
        return dp[amount] if dp[amount] != INF else -1
```

---

## 六、复杂度

- **时间** `O(amount × len(coins))`
- **空间** `O(amount)`

---

## 七、容易踩的坑

1. **初始 INF 用 `amount + 1`**（不能用 0）。最后判等就能识别"凑不出"。
2. **完全背包 vs 01 背包**：322 硬币无限用，对应**完全背包**，外层 i / 内层 coin 都正向遍历。如果硬币只能用一次（01 背包）就要逆序遍历容量。
3. **不要写贪心**：贪心（最大面值优先）会错——如 `[1,3,4], amount=6`，贪心给 4+1+1=3 枚，DP 给 3+3=2 枚。

---

## 八、一句话记忆

> 完全背包：**dp[i] = min(dp[i - coin]) + 1**。dp[0] = 0，其它初始 amount+1。
