# 152. 乘积最大子数组 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/maximum-product-subarray/)

---

## 一、题目讲了什么

找连续子数组使**乘积**最大，返回这个乘积。

例：`[2, 3, -2, 4]` → `[2, 3]`，乘积 6。
`[-2, 0, -1]` → 0（含 0 不如不算）。

---

## 二、和 53（最大子数组和）的差异

53 是求和，"前面是负数就丢掉重开"很自然。

152 是求积，**负数 × 负数 = 正数**——前面是负数不一定要丢，可能是个"巨大正数"等待下一个负数把它救回来：

```
[-2, 3, -4]
到 -2 时：当前 max = -2
到 3 时：当前 max = max(3, -2*3) = 3，但同时要记当前 min = -2 * 3 = -6
到 -4 时：当前 max = max(-4, 3*-4=-12, -6*-4=24) = 24  ← 用上"最小变最大"
```

所以同时维护**以 i 结尾的乘积最大 `cur_max` 和最小 `cur_min`**，遇到下一个数三选一（自己单独、prev_max × 自己、prev_min × 自己）。

---

## 三、递推

```
cur_max = max(x, prev_max * x, prev_min * x)
cur_min = min(x, prev_max * x, prev_min * x)
ans = max(ans, cur_max)
```

每步全局答案用 `cur_max` 更新。

---

## 四、关键：保存 prev 再更新

```
mx = cur_max
mn = cur_min
cur_max = max(x, mx * x, mn * x)
cur_min = min(x, mx * x, mn * x)
```

如果直接 `cur_max = ...` 然后再算 `cur_min`，第二步会用**新 cur_max** 算，错。

---

## 五、写成代码

```python
class Solution:
    def maxProduct(self, nums: list[int]) -> int:
        # 维护以 i 结尾的最大乘积和最小乘积
        cur_max = cur_min = ans = nums[0]
        for x in nums[1:]:
            # 三个候选：自己单独成段 / 之前的最大 × x / 之前的最小 × x
            # 必须用上一步的 cur_max 和 cur_min，所以先存起来
            mx, mn = cur_max, cur_min
            cur_max = max(x, mx * x, mn * x)
            cur_min = min(x, mx * x, mn * x)
            ans = max(ans, cur_max)
        return ans
```

---

## 六、复杂度

- **时间** `O(n)`
- **空间** `O(1)`

---

## 七、容易踩的坑

1. **必须同时维护 max 和 min**：负数会把"最小"翻成"最大"。
2. **先保存 prev 值再更新**：否则第二行用新值算就错。
3. **初始值用 `nums[0]`**，不能用 0 / 1（全负数 / 含 0 时会错）。

---

## 八、一句话记忆

> Kadane + **同时维护 max 和 min**——负数 × min 可能变 max。
