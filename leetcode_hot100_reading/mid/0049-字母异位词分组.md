# 49. 字母异位词分组 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/group-anagrams/)

---

## 一、题目讲了什么

字符串数组，把"字母异位词"分到同一组（**字母组成相同**就是异位词）。

例：`["eat", "tea", "tan", "ate", "nat", "bat"]` →
```
[["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]
```

返回顺序不限。

---

## 二、本质：分组 = 找"指纹"

要把异位词分到同组，需要一个"**指纹**"——对所有异位词都一样、对非异位词不一样。

最自然的指纹：**把单词的字母排序后拼成字符串**。

- "eat" → 排序 → "aet"
- "tea" → 排序 → "aet" ✓ 同组
- "tan" → 排序 → "ant"

哈希表 `指纹 → 单词列表`，扫一遍数组就能分好组。

---

## 三、写成代码

```python
from collections import defaultdict

class Solution:
    def groupAnagrams(self, strs):
        groups = defaultdict(list)
        for s in strs:
            key = ''.join(sorted(s))   # 指纹
            groups[key].append(s)
        return list(groups.values())
```

`defaultdict(list)` 让"键不存在时自动建一个空列表"，省去先 `if key not in` 的判断。

---

## 四、复杂度

- **时间** `O(N × K log K)`：N 个单词，每个长度 K，排序 K log K
- **空间** `O(N × K)`：哈希表存所有单词的指纹和分组

---

## 五、其它指纹选法

- **字母计数元组**：长度 26 的元组 `(c_a, c_b, ..., c_z)`。时间 O(K) 不需要排序，但代码稍长。
- **字符串排序**最简洁，本题 K ≤ 100 完全够快。

---

## 六、容易踩的坑

1. **`sorted(s)` 返回 list 不是 str**，要 `''.join(...)` 包成 str 才能当哈希 key。
2. **答案顺序无要求**：返回 `list(groups.values())` 即可。
3. **空数组要返回 `[]`**：上面的代码自然支持（defaultdict 为空，values 也空）。

---

## 七、一句话记忆

> **指纹 + 哈希表分组**：指纹用"排序后的字符串"或"字母计数元组"。
