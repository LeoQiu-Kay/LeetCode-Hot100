# 230. 二叉搜索树中第 K 小的元素 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/kth-smallest-element-in-a-bst/)

---

## 一、题目讲了什么

二叉搜索树（BST）里返回**第 k 小**的元素值。

例：

```
    3
   / \
  1   4         k=1 → 1
   \             k=2 → 2
    2            k=3 → 3
                 k=4 → 4
```

---

## 二、关键性质：BST 中序遍历就是升序

中序遍历到第 k 个节点 → 它就是答案。**提前 return**，不必跑完整棵树。

---

## 三、用 94 的迭代中序模板

```
stack = []
cur = root
while cur or stack:
    while cur:
        stack.append(cur)
        cur = cur.left
    cur = stack.pop()
    k -= 1
    if k == 0:
        return cur.val
    cur = cur.right
```

每次弹出栈顶就是中序的下一个；用 k 计数到 0 立刻返回。

---

## 四、写成代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def kthSmallest(self, root, k):
        stack = []
        cur = root
        while cur or stack:
            while cur:
                stack.append(cur)
                cur = cur.left
            cur = stack.pop()
            k -= 1
            if k == 0:
                return cur.val
            cur = cur.right
        return -1   # 不会到这里，题目保证 k 合法
```

---

## 五、复杂度

- **时间** `O(h + k)`：先沿左链下到底（h），再弹 k 次
- **空间** `O(h)`：栈

---

## 六、容易踩的坑

1. **必须用中序**：BST 的中序才是升序，前序 / 后序都不对。
2. **找到立即返回**：免得跑完整棵树。
3. **递归版本也行**：但栈深可能爆，迭代更稳。

---

## 七、一句话记忆

> BST 中序就是升序，**中序遍历到第 k 个就 return**。
