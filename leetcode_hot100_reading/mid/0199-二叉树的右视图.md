# 199. 二叉树的右视图 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/binary-tree-right-side-view/)

---

## 一、题目讲了什么

站在二叉树**右边**往左看，每一层能看到的**最右**节点。按从上到下的顺序返回。

例：

```
    1                          可见节点：1, 3, 4
   / \
  2   3
   \
    4
```

---

## 二、思路：层序遍历 + 每层取最右

直觉错法："只取右子树最右节点"——不对。如果右子树缺失，能看到的可能是左子树的某个节点（如题目例子中的 4 来自 2 的右子）。

正确：**BFS 层序遍历**（题 102），每层取最后一个出队的节点。

---

## 三、为什么"最后一个出队"就是最右

按"左→右"顺序入队，那么本层第一个出队的是最左、**最后一个是最右**。

---

## 四、写成代码

```python
from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def rightSideView(self, root):
        if not root:
            return []
        res = []
        q = deque([root])
        while q:
            size = len(q)
            for i in range(size):
                node = q.popleft()
                if i == size - 1:           # 本层最后一个 → 最右
                    res.append(node.val)
                if node.left:  q.append(node.left)
                if node.right: q.append(node.right)
        return res
```

---

## 五、复杂度

- **时间** `O(n)`
- **空间** `O(n)`：队列

---

## 六、容易踩的坑

1. **不能只取右子树最右**：右子树为空时，左子树的节点可能"露出来"。
2. **入队顺序左→右**，本层最后一个出队的就是最右。
3. **size 先记**：和 102 一样的层处理技巧。

---
