# 437. 路径总和 III · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/path-sum-iii/)

---

## 一、题目讲了什么

二叉树里求**和为 targetSum 的路径数**。路径要求：

- 从任意节点开始、在任意节点结束
- **方向必须向下**（不能往上走）
- 节点值可以是负数

例：节点值含负数 + targetSum，可能有 0 条或多条满足条件的路径。

---

## 二、暴力 O(n²)

对每个节点都跑一遍"以它为起点、和为 target 的路径数"。整体 O(n²)。

更优：**前缀和 + 哈希**，O(n)。

---

## 三、前缀和思路

定义"前缀和"：从根到当前节点路径上所有节点值的累加。

对当前节点的"前缀和 cur"，**任何祖先节点的前缀和等于 `cur - targetSum`** 时，那个祖先到当前节点的子路径**和就是 targetSum**。

```
祖先位置前缀和 = prefix_anc
当前位置前缀和 = cur
两者之间的路径和 = cur - prefix_anc

cur - prefix_anc == targetSum
⟺ prefix_anc == cur - targetSum
```

所以维护一个哈希 `count[前缀和] = 出现次数`，扫到每个节点 cur 时，**ans += count[cur - targetSum]**。

---

## 四、回溯：进入子节点前 +1，退出时 -1

哈希 count 必须对应**当前根→当前节点这条路径上的祖先**。所以：

```
DFS(node, cur):
    cur += node.val
    ans += count[cur - target]      # 找祖先里有多少匹配
    count[cur] += 1                  # 加入当前
    DFS(node.left, cur)
    DFS(node.right, cur)
    count[cur] -= 1                  # 回溯，撤回当前
```

不撤回会让兄弟子树的路径污染。

---

## 五、初始 `count[0] = 1`

这表示"从根开始的整条路径"也算——当 `cur == targetSum` 时，`count[cur - target] = count[0]` 命中 1，正确计数。

---

## 六、写成代码

```python
from collections import defaultdict

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def pathSum(self, root: TreeNode | None, targetSum: int) -> int:
        # count[s] = "从根到当前路径上"前缀和为 s 的节点数（路径上）
        count = defaultdict(int)
        # 初始放一个 {0: 1}，表示"从根开始的整条路径"也可以算（cur - 0 = cur 时直接命中）
        count[0] = 1
        self.ans = 0
        def dfs(node: TreeNode | None, cur: int) -> None:
            if not node:
                return
            cur += node.val
            # 找 (cur - targetSum) 这个前缀和在祖先链中出现的次数
            # 每一次匹配代表"那个祖先位置到当前节点"是一条和为 target 的路径
            self.ans += count[cur - targetSum]
            # 当前前缀和进入字典，供下层使用
            count[cur] += 1
            # 递归左右
            dfs(node.left, cur)
            dfs(node.right, cur)
            # 回溯：退出本节点时撤销其贡献，避免影响兄弟分支
            count[cur] -= 1
        dfs(root, 0)
        return self.ans
```

---

## 七、复杂度

- **时间** `O(n)`
- **空间** `O(n)`：哈希 + 递归栈

---

## 八、容易踩的坑

1. **回溯必须撤回 `count[cur] -= 1`**：不撤会让兄弟子树误用本子树的前缀和。
2. **`count[0] = 1` 初始化**：处理"从根开始的整条路径"。
3. **节点值可能是负数**：所以前缀和不单调，必须用哈希查找而不是双指针。

---

## 九、一句话记忆

> **前缀和 + 哈希 + 回溯**：`count[cur - target]` 累加；进入子树 `count[cur]++`，退出 `count[cur]--`。
