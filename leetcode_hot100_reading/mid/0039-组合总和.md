# 39. 组合总和 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/combination-sum/)

---

## 一、题目讲了什么

`candidates`（**无重复**正整数）和一个 `target`。返回所有组合，组合里的数加起来等于 target。**每个数字可以重复用任意次**。组合**不分顺序**（即 `[2, 2, 3]` 和 `[3, 2, 2]` 是同一个）。

例：`candidates = [2, 3, 6, 7], target = 7` → `[[2, 2, 3], [7]]`

---

## 二、回溯三件套 + 两个细节

回溯框架（**选 → 递归 → 撤回**）你在 17 题学过。本题的特别之处在于：

1. **可以重复选**：递归时**下次仍从 i 开始**（不是 i+1）。
2. **不出现重复组合**：用 `start` 控制只能往**后**挑——`[2, 3]` 永远是这个顺序，不会出现 `[3, 2]`。

---

## 三、DFS 函数定义

```
dfs(start, remain):
    "从 candidates[start..] 中挑数字，凑出 remain"
```

- `remain == 0`：凑齐了，收集 path
- `remain < 0`：超了，剪枝（也可以提前判 `remain < candidates[i]` 在循环里剪）
- 否则：对 `i` 从 start 到末尾，选 `candidates[i]`，递归 `dfs(i, remain - candidates[i])`（注意 i 不变）

---

## 四、为什么"下次从 i 开始"等于"允许重复"

回溯到 i 后的 `dfs(i, ...)` 意味着：下次仍然可以再选 candidates[i]。这样 `[2, 2, 3]` 这种"2 出现多次"的组合就能被生成。

而 `dfs(i + 1, ...)` 会强制 i 选完跳过，结果是"每个数最多用一次"（那是题 40）。

---

## 五、写成代码

```python
class Solution:
    def combinationSum(self, candidates, target):
        ans = []
        path = []
        def dfs(start, remain):
            if remain == 0:
                ans.append(path.copy())
                return
            if remain < 0:
                return
            for i in range(start, len(candidates)):
                path.append(candidates[i])
                dfs(i, remain - candidates[i])    # 下次仍从 i 开始
                path.pop()
        dfs(0, target)
        return ans
```

---

## 六、复杂度

很难给精确表达式，最坏与 target / min(candidates) 相关，本质是"列出所有可能"。

---

## 七、容易踩的坑

1. **下一次递归是 `dfs(i, ...)`，不是 `dfs(i + 1, ...)`**：差一字就变成 40 题。
2. **`path.copy()`** 收集结果：不复制就会被后续 pop 弄空。
3. **`start` 不能省**：少了它，`[2, 3]` 和 `[3, 2]` 都会被生成。

---

## 八、一句话记忆

> 回溯三件套 + `dfs(i, ...)`（允许重复） + `start` 控制单方向（避免重复组合）。
