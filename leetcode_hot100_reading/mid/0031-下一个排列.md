# 31. 下一个排列 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/next-permutation/)

---

## 一、题目讲了什么

给一个数字序列（数组），把它**原地**变成**字典序的下一个排列**。如果已经是最大排列（递减序），就重置为最小排列（递增序）。

例：

- `[1, 2, 3]` → `[1, 3, 2]`
- `[3, 2, 1]` → `[1, 2, 3]`（已最大，回到最小）
- `[1, 1, 5]` → `[1, 5, 1]`

---

## 二、找规律：从右往左看下降点

字典序"下一个"意思是：**在所有比当前序列大的排列里，找最小的那个**。

观察 `[1, 2, 7, 4, 3, 1]` 怎么变下一个：

```
[1, 2, 7, 4, 3, 1]
 ↑         ↑
 大段不动，从右往左找第一个"下降点"
```

从右往左找第一个 `nums[i] < nums[i+1]` 的位置 i —— i 之后是**递减段**（已经是局部"最大"）。

要让序列变大，必须改 i 这一位（或更左）。**只改 i 这一位**就能造出"下一个"，往左改会跳得更远。

---

## 三、三步走

1. **从右往左找下降点 i**：`nums[i] < nums[i+1]`。若没有（整个降序）→ 直接反转整个数组（最大→最小）。
2. **从右往左在 [i+1, n-1] 里找第一个 > nums[i] 的 j**，交换 `nums[i]` 和 `nums[j]`。

   为什么从右找？i 右边是降序段，"第一个比 nums[i] 大的"就是这段里**最小的更大值**，正好满足"变大但变得最小"。

3. **反转 i+1 之后的部分**：交换完后 i+1 之后仍是降序，把它反转成升序，就是 i 这位之后的"最小排列"。

---

## 四、走一遍 `[1, 2, 7, 4, 3, 1]`

第 1 步：从右往左找下降点。

- i=4: 3 vs 1 — 不是下降（递减）
- i=3: 4 vs 3 — 不是下降
- i=2: 7 vs 4 — 不是下降
- **i=1**: 2 vs 7 — **是！** 找到 i = 1

第 2 步：从右找第一个 > 2 的：

- j=5: 1 → no
- j=4: 3 → **yes**，交换 nums[1] 和 nums[4]

```
[1, 3, 7, 4, 2, 1]
```

第 3 步：反转 i+1 之后（[7, 4, 2, 1] → [1, 2, 4, 7]）：

```
[1, 3, 1, 2, 4, 7]
```

下一个排列。

---

## 五、写成代码

```python
class Solution:
    def nextPermutation(self, nums):
        n = len(nums)
        # 1. 找下降点
        i = n - 2
        while i >= 0 and nums[i] >= nums[i + 1]:
            i -= 1
        if i >= 0:
            # 2. 找右边第一个比 nums[i] 大的并交换
            j = n - 1
            while nums[j] <= nums[i]:
                j -= 1
            nums[i], nums[j] = nums[j], nums[i]
        # 3. 反转 i+1 之后（i = -1 时反转整个数组）
        l, r = i + 1, n - 1
        while l < r:
            nums[l], nums[r] = nums[r], nums[l]
            l += 1
            r -= 1
```

---

## 六、复杂度

- **时间** `O(n)`：每步都是线性
- **空间** `O(1)`：原地

---

## 七、容易踩的坑

1. **第 1 步 `nums[i] >= nums[i+1]`** 用 `>=`：相等也跳过，否则像 `[1, 1, 5]` 会找错下降点。
2. **第 2 步 `nums[j] <= nums[i]`** 用 `<=`：相等也跳过，找**严格大**的。
3. **找不到下降点（i = -1）时**，仍要执行第 3 步反转，把降序整体翻成升序（最大→最小）。

---

## 八、一句话记忆

> **从右找下降点 → 右边找比它大的最小值交换 → 反转下降段**。
