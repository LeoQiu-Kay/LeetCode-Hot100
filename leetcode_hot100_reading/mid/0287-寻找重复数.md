# 287. 寻找重复数 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/find-the-duplicate-number/)

---

## 一、题目讲了什么

数组长度 n+1，值在 `[1, n]` 范围内（**鸽巢原理保证至少一个重复**）。找出那个重复数。

约束：

- **不能修改数组**
- **O(1) 额外空间**
- **少于 O(n²) 时间**

这些约束基本排除了排序、哈希表、暴力等所有直观解法。

例：`[1, 3, 4, 2, 2]` → 2

---

## 二、神奇的转化：把数组当链表

把数组解读为一条链表：

> 节点 i 的下一个节点 = `nums[i]`

例 `[1, 3, 4, 2, 2]`：

```
0 → nums[0]=1 → nums[1]=3 → nums[3]=2 → nums[2]=4 → nums[4]=2 → nums[2]=4 → 2 → 4 → 2 → ...

走法：0 → 1 → 3 → 2 → 4 → 2（环开始）
```

**关键性质**：因为存在重复数，会有两个节点 `i ≠ j` 都满足 `nums[i] == nums[j]` —— 它们指向同一个目标——形成**环**。**环入口就是重复值**。

---

## 三、用 142 的 Floyd 龟兔找环入口

代码和 142 几乎一样，区别只在"走下一步"用 `nums[i]` 表示：

- `slow = nums[slow]`（走 1 步）
- `fast = nums[nums[fast]]`（走 2 步）

第一阶段相遇后，从 0 起点和相遇点同速齐进，再次相遇就是环入口 = 重复值。

---

## 四、为什么起点是 0

值域是 `[1, n]`，**0 不会出现在 nums 里**——所以 0 是"链表头"安全的起点，不会被环里其它指针冲撞。

---

## 五、写成代码

```python
class Solution:
    def findDuplicate(self, nums: list[int]) -> int:
        # 阶段 1：找相遇点（Floyd 判环）
        slow = fast = 0
        while True:
            slow = nums[slow]               # 走一步
            fast = nums[nums[fast]]         # 走两步
            if slow == fast:
                break
        # 阶段 2：从 0 和相遇点同速齐进，相遇即环入口（= 重复值）
        p = 0
        while p != slow:
            p = nums[p]
            slow = nums[slow]
        return p
```

---

## 六、复杂度

- **时间** `O(n)`
- **空间** `O(1)`

---

## 七、容易踩的坑

1. **不能修改数组、O(1) 空间** 是题目核心约束，否则可以用更简单的方法。
2. **起点 0** 不是 nums[0]——0 在值域外，是干净的起点。
3. **比较用 `==`**：操作的是整数 indices，不是节点对象。

---

## 八、一句话记忆

> 数组当链表 → **Floyd 龟兔找环入口 = 重复值**。
