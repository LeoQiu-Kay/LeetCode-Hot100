# 73. 矩阵置零 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/set-matrix-zeroes/)

---

## 一、题目讲了什么

`m × n` 矩阵，若某元素为 0，把它**所在的行和列全部置零**。**原地**操作。

例：

```
[1, 1, 1]              [1, 0, 1]
[1, 0, 1]      →       [0, 0, 0]
[1, 1, 1]              [1, 0, 1]
```

---

## 二、思路演进

- **O(mn) 空间**：复制一份原矩阵，根据原矩阵的 0 在副本上置零。简单但不优雅。
- **O(m + n) 空间**：用两个集合 / 数组记录"哪些行 / 列需要置零"。
- **O(1) 空间**：**用矩阵的第一行 / 第一列作为标记位**。

走 O(1) 空间。

---

## 三、用第一行第一列当"标记本"

策略：

1. **先记**：原始的第一行 / 第一列**本身**是否有 0（两个 bool 变量）
2. **第一遍扫**：对内部位置 (i, j)（i ≥ 1, j ≥ 1）若 `matrix[i][j] == 0`，把 `matrix[i][0]` 和 `matrix[0][j]` 都标 0
3. **第二遍扫**：根据第一行 / 第一列的标记，把内部位置置零
4. **最后处理第一行第一列本身**：根据步骤 1 记的 bool 决定要不要全置零

---

## 四、为什么要先记原始状态

第一行第一列要"既被读取又被写入"——它们同时是"数据"和"标记本"。如果不先记下它们原本是否有 0，第二步标记会**污染**它们原本的内容，最后无法判断要不要把它们全置零。

---

## 五、写成代码

```python
class Solution:
    def setZeroes(self, matrix: list[list[int]]) -> None:
        m, n = len(matrix), len(matrix[0])
        # 先记下首行首列原本是否有 0，因为后面要用它俩当"标记本"
        row0_zero = any(matrix[0][j] == 0 for j in range(n))
        col0_zero = any(matrix[i][0] == 0 for i in range(m))
        # 第一遍：扫除首行首列外的格子，发现 0 就把对应首行首列标 0
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][j] == 0:
                    matrix[i][0] = 0
                    matrix[0][j] = 0
        # 第二遍：根据首行首列的标记把内部置 0
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][0] == 0 or matrix[0][j] == 0:
                    matrix[i][j] = 0
        # 最后处理首行首列本身（用一开始记下的标志）
        if row0_zero:
            for j in range(n):
                matrix[0][j] = 0
        if col0_zero:
            for i in range(m):
                matrix[i][0] = 0
```

---

## 六、复杂度

- **时间** `O(m × n)`
- **空间** `O(1)`

---

## 七、容易踩的坑

1. **必须先记 row0_zero / col0_zero**：否则被标记动作污染后无法还原。
2. **第二遍扫只处理内部**（i ≥ 1, j ≥ 1）：第一行第一列最后单独处理。
3. **不要混淆"扫"的方向**：第一遍 i,j ≥ 1；第三遍处理第一行第一列要全长度。

---

## 八、一句话记忆

> 第一行第一列当**标记本**，先记本身是否有 0，扫内部时标记，第二遍按标记置零，最后再处理第一行第一列本身。
