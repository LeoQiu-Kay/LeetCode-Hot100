# 240. 搜索二维矩阵 II · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/search-a-2d-matrix-ii/)

---

## 一、题目讲了什么

矩阵满足：

- 每行**升序**
- 每列**升序**

注意**不**保证"上行末 < 下行首"——所以**不能像 74 那样当一维数组二分**。

判断 target 是否存在。

---

## 二、关键观察：从右上角开始走

选**右上角** `(0, n-1)` 为起点：

- 当前值 > target → **左移**（这一列都比 target 大，整列排除）
- 当前值 < target → **下移**（这一行都比 target 小，整行排除）
- 等于 → 找到

每步排除一整行 / 整列，时间 O(m + n)。

也可以从**左下角**开始，方向对称。但**不能从左上 / 右下开始**——那两个角的两个相邻方向都是"同向"（左上 → 右、下都增大），无法做出二选一的决策。

---

## 三、走一遍

```
[ 1,  4,  7, 11, 15]
[ 2,  5,  8, 12, 19]
[ 3,  6,  9, 16, 22]
[10, 13, 14, 17, 24]
[18, 21, 23, 26, 30]

target = 5，从 (0, 4) = 15 开始
15 > 5 → 左移 (0, 3) = 11
11 > 5 → 左移 (0, 2) = 7
7  > 5 → 左移 (0, 1) = 4
4  < 5 → 下移 (1, 1) = 5  ✓
```

---

## 四、写成代码

```python
class Solution:
    def searchMatrix(self, matrix, target):
        if not matrix:
            return False
        m, n = len(matrix), len(matrix[0])
        i, j = 0, n - 1                  # 右上角
        while i < m and j >= 0:
            v = matrix[i][j]
            if v == target:
                return True
            elif v > target:
                j -= 1                    # 左移
            else:
                i += 1                    # 下移
        return False
```

---

## 五、复杂度

- **时间** `O(m + n)`：每步排除一行或一列，总共最多 m + n 步
- **空间** `O(1)`

---

## 六、240 vs 74 区别

- **74**：每行升序 + **行首 > 上行末**（整体可当一维） → 一维二分 O(log mn)
- **240**：只保证行升 + 列升 → Z 字搜索 O(m + n)

题目性质不同，方法不同。别混。

---

## 七、容易踩的坑

1. **起点必须是右上或左下**：左上 / 右下两个方向都同向，无法决策。
2. **大于 → 左移、小于 → 下移**：方向别反。
3. **二分能解吗？** 也行——但要对每一行做二分 O(m log n)，比 Z 字慢一点。

---

## 八、一句话记忆

> 从**右上角**开始：**大于左移、小于下移**，O(m + n) 排除整行 / 列。
