# 416. 分割等和子集 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/partition-equal-subset-sum/)

---

## 一、题目讲了什么

数组判断能否分成**两个子集**使两者**和相等**。

例：`[1, 5, 11, 5]` → True（`[1,5,5]` 和 `[11]`，都是 11）；`[1, 2, 3, 5]` → False。

---

## 二、转化：能否凑出 sum/2

如果总和 `s` 是**奇数**，肯定分不平，返回 False。

否则只要从数组里挑出若干个数使其和等于 `target = s / 2`，剩下的自然也是 target，问题成立。

转化后是经典的 **01 背包"能否凑出目标"** 问题。

---

## 三、01 背包 DP

`dp[j]` = 能否从 nums 选出若干个数使其和恰好为 j。初始 `dp[0] = True`（不选任何数能凑出 0）。

对每个 x，更新：

```
dp[j] = dp[j] or dp[j - x]    （j 从 target 倒着到 x）
```

含义："不选 x"沿用 `dp[j]`；"选 x"看 `dp[j - x]` 是否为 True。

---

## 四、为什么必须**逆序**遍历容量

01 背包的核心。如果**正序**：

```
for j in range(x, target + 1):
    dp[j] |= dp[j - x]
```

dp[j - x] 在本轮可能已被更新过（即 x 已经"被选了"），再用它来更新 dp[j] 等于 x **被选第二次**——退化成完全背包（每个元素无限用）。

**逆序**保证 dp[j - x] 是**上一轮（没选 x 时）的值**——每个 x 只被用一次。

---

## 五、走一遍 `[1, 5, 11, 5]`

s = 22, target = 11。`dp = [T, F, F, F, F, F, F, F, F, F, F, F]`（长度 12）。

处理 x = 1：j 从 11 倒到 1
- `dp[1] |= dp[0]` → True
- 其它 dp[j] = dp[j] (False) or dp[j-1] (大多 False)
结果：`dp[0]=dp[1]=T`，其它 F

处理 x = 5：j 从 11 倒到 5
- `dp[5] |= dp[0]` → True
- `dp[6] |= dp[1]` → True
结果：`dp[0]=dp[1]=dp[5]=dp[6]=T`

处理 x = 11：j 从 11 倒到 11
- `dp[11] |= dp[0]` → True

`dp[11] = True`，返回 True。

---

## 六、写成代码

```python
class Solution:
    def canPartition(self, nums: list[int]) -> bool:
        s = sum(nums)
        # 总和奇数，不可能平分
        if s % 2 == 1:
            return False
        target = s // 2
        # dp[j] 表示能否从 nums 选出若干个数使其和等于 j
        dp = [False] * (target + 1)
        dp[0] = True   # 不选任何数能凑出 0
        for x in nums:
            # 必须**逆序**更新（01 背包标准技巧）
            # 否则 dp[j - x] 已被本轮更新过，相当于 x 被重复使用
            for j in range(target, x - 1, -1):
                # 选 x：dp[j] = dp[j - x]；不选 x：dp[j] 保持原值
                dp[j] = dp[j] or dp[j - x]
        return dp[target]
```

---

## 七、复杂度

- **时间** `O(n × target)`
- **空间** `O(target)`

---

## 八、容易踩的坑

1. **必须逆序遍历容量**：正序会让 x 被多次选，结果错。
2. **奇数和早返回**：False。
3. **范围 `range(target, x - 1, -1)`**：包含 x，到 x 为止。

---

## 九、一句话记忆

> 01 背包"能否凑 target"：dp[0]=True，**容量逆序** dp[j] |= dp[j-x]。
