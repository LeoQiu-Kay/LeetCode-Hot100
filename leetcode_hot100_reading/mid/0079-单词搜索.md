# 79. 单词搜索 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/word-search/)

---

## 一、题目讲了什么

字母网格 + 一个单词 `word`，判断网格中是否存在一条路径**按字母顺序拼出 word**。路径可上下左右移动，同一个格子**不能重复使用**。

例（word="ABCCED"）：

```
[A, B, C, E]              路径 A(0,0) → B(0,1) → C(0,2)
[S, F, C, S]                  → C(1,2) → E(2,2) → D(2,1)    ✓
[A, D, E, E]
```

---

## 二、回溯 + 网格 DFS

从每个格子尝试作为 word 的起点。每一步：

1. 检查当前格子是否匹配 word 的当前字符
2. 把当前格子**标记为已访问**
3. 向四方向递归找下一个字符
4. 任一方向成功 → 整体成功；都失败 → **回溯**：撤销访问标记，返回失败

---

## 三、用"原地修改"代替 visited 数组

为了 O(1) 空间标记访问，**临时把访问过的格子改成 `#`**（或其它不可能匹配的字符）。递归返回后**还原**。

```
board[i][j] = '#'   # 访问标记
... 递归 ...
board[i][j] = tmp   # 还原
```

---

## 四、写成代码

```python
class Solution:
    def exist(self, board, word):
        m, n = len(board), len(board[0])

        def dfs(i, j, k):
            # k 是 word 当前要匹配的字符位置
            if k == len(word):
                return True
            if not (0 <= i < m and 0 <= j < n) or board[i][j] != word[k]:
                return False
            tmp = board[i][j]
            board[i][j] = '#'                          # 标记
            found = (dfs(i + 1, j, k + 1)
                  or dfs(i - 1, j, k + 1)
                  or dfs(i, j + 1, k + 1)
                  or dfs(i, j - 1, k + 1))
            board[i][j] = tmp                          # 还原
            return found

        for i in range(m):
            for j in range(n):
                if dfs(i, j, 0):
                    return True
        return False
```

---

## 五、复杂度

- **时间** `O(m × n × 4ᴸ)`：L = word 长度。每个起点最坏走出 4ᴸ 条路径
- **空间** `O(L)`：递归栈

---

## 六、容易踩的坑

1. **回溯必须还原标记**：忘了 `board[i][j] = tmp`，一条失败路径会污染后续搜索。
2. **k 从 0 开始**，匹配 `word[0..L-1]`，到 k == L 就算成功。
3. **不要在四个方向之间漏判越界 / 字符不匹配**：函数开头一并检查最简洁。

---

## 七、一句话记忆

> 每个格子作起点，DFS 四方向 + **原地标记 `#` + 回溯还原**。
