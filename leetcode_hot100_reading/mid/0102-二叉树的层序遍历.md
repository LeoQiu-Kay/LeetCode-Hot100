# 102. 二叉树的层序遍历 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/binary-tree-level-order-traversal/)

---

## 一、题目讲了什么

按"每层一个数组"的形式返回二叉树的层序遍历结果。

例：

```
    3                 [[3],
   / \                 [9, 20],
  9  20                [15, 7]]
     / \
    15  7
```

---

## 二、BFS 自然契合

层序 = 广度优先搜索（BFS）。用一个**队列**，按顺序把节点出队、把孩子入队。

但 BFS 默认是"扁平"的，怎么区分"层"？—— **进入循环时记下当前队列长度 `size`**，正好就是这一层的节点数。

```
while queue 非空:
    size = len(queue)
    本层 = []
    重复 size 次:
        node = 出队
        本层.append(node.val)
        左孩子 / 右孩子 入队
    res.append(本层)
```

`size` 这一手把扁平 BFS 切成了"按层处理"。

---

## 三、为什么"先记 size 再循环"重要

如果用 `for _ in range(len(queue))`，python 会**在循环开始时一次性求值**，但有的语言或人会习惯性写成 `while len(queue) > 本层起始` 这种依赖动态长度的判断——后者要小心。

最稳的写法：进入 while 第一行 `size = len(queue)`，固定本层节点数。

---

## 四、写成代码

```python
from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def levelOrder(self, root: TreeNode | None) -> list[list[int]]:
        # 空树直接返回
        if not root:
            return []
        res: list[list[int]] = []
        # BFS 队列：deque 的 popleft 是 O(1)，比 list.pop(0) 的 O(n) 快
        q = deque([root])
        while q:
            # 进循环时 len(q) 正好是本层节点数（孩子还没入队）
            size = len(q)
            level: list[int] = []
            # 处理本层 size 个节点
            for _ in range(size):
                node = q.popleft()
                level.append(node.val)
                # 把左右孩子入队（构成下一层）
                if node.left:
                    q.append(node.left)
                if node.right:
                    q.append(node.right)
            # 一层处理完，加入结果
            res.append(level)
        return res
```

---

## 五、复杂度

- **时间** `O(n)`：每个节点入队、出队各一次
- **空间** `O(n)`：队列最大可能装一整层

---

## 六、容易踩的坑

1. **`size` 必须先记**，再开始内层 for 循环——不然会一直处理到下一层。
2. **`collections.deque`** 而不是 list 的 `pop(0)`：list 的 pop(0) 是 O(n)。
3. **空树要特判**：上面代码开头 `if not root: return []`。

---

## 七、一句话记忆

> BFS + **进循环先记 size**，循环 size 次处理本层。
