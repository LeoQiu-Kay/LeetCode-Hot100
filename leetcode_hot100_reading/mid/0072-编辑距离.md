# 72. 编辑距离 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/edit-distance/)

---

## 一、题目讲了什么

给你两个单词 `word1` 和 `word2`，每次可以做下面三种操作之一：

1. **插入**一个字符
2. **删除**一个字符
3. **替换**一个字符

问：把 `word1` 变成 `word2` **至少**要做多少次操作？

举个例子：`word1 = "horse"`、`word2 = "ros"`，答案是 3——

```
horse  → rorse  （把 'h' 替换成 'r'）
rorse  → rose   （删掉 'r'）
rose   → ros    （删掉 'e'）
```

直觉上你可能想"贪心地从前往后逐位对齐"，但很快会发现：到底是该改、该删、还是该插，常常需要看后面的字符才能决定。换句话说，**当前这一步的选择会影响后面**——这是动态规划的典型信号。

---

## 二、把问题"缩小"一格

DP 的核心思路是：**把一个大问题，拆成同种类型的更小问题**。

那么"把 `word1` 变成 `word2`"能怎么缩小？

把两个串都从**末尾**砍掉一点点试试。设：

- `word1` 的前 `i` 个字符是 `word1[:i]`
- `word2` 的前 `j` 个字符是 `word2[:j]`

定义：

> **`dp[i][j]` = 把 `word1[:i]` 变成 `word2[:j]` 至少需要几步**

我们的最终答案就是 `dp[m][n]`（`m`、`n` 是两个串的长度）。

---

## 三、找递推关系

现在站在 `dp[i][j]` 这个状态上，问自己：**最后一步**可能是什么？

### 情况 A：末位字符相同

如果 `word1[i-1] == word2[j-1]`（注意是下标 `i-1`，因为 `word1[:i]` 的最后一个字符在下标 `i-1`），那这两个末位天然就对上了，**不需要任何操作**。问题就退化成：

> 把 `word1[:i-1]` 变成 `word2[:j-1]`

也就是：

```
dp[i][j] = dp[i-1][j-1]
```

### 情况 B：末位字符不同

不一样就麻烦了——总得做点什么。仔细数一下，能让两个串变得"接近一点"的最后一步**只有三种**：

| 最后一步 | 操作后变成的子问题 | 操作数 |
|---|---|---|
| **删**掉 `word1` 的末位 | 把 `word1[:i-1]` 变成 `word2[:j]` | 1 + `dp[i-1][j]` |
| **插**入一个等于 `word2` 末位的字符（加到 `word1` 末尾） | 把 `word1[:i]` 变成 `word2[:j-1]` | 1 + `dp[i][j-1]` |
| **替换** `word1` 末位为 `word2` 末位 | 把 `word1[:i-1]` 变成 `word2[:j-1]` | 1 + `dp[i-1][j-1]` |

"插入"那一栏可能反直觉，多解释一句：往 `word1` 末尾插一个 `word2[j-1]` 之后，这个新末位就和 `word2[j-1]` 对齐"消掉了"，剩下的子问题是把**原来的** `word1[:i]` 变成 **去掉末位**的 `word2[:j-1]`。

三种里取最小，再 +1（这一步本身的代价）：

```
dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])
```

### 合在一起的转移方程

```
                  ┌─ dp[i-1][j-1]                          末位相同
dp[i][j] = │
                  └─ 1 + min(dp[i-1][j],
                              dp[i][j-1],
                              dp[i-1][j-1])                末位不同
```

---

## 四、边界条件（递推的"地基"）

光有递推还不行——递推要往回找更小的 `dp`，最终得停在某个已知答案上。最小的状态是：

- **`dp[i][0]`**：把 `word1[:i]` 变成**空串**，只能一个一个删，要 `i` 次 → `dp[i][0] = i`
- **`dp[0][j]`**：把**空串**变成 `word2[:j]`，只能一个一个插，要 `j` 次 → `dp[0][j] = j`

特殊地，`dp[0][0] = 0`（空串 → 空串，啥都不用做）。

## 五、画个表手算一遍：`"horse" → "ros"`

行是 `word1 = "horse"`（含空串），列是 `word2 = "ros"`（含空串）：

|        | ""(0) | r(1) | o(2) | s(3) |
|--------|------:|-----:|-----:|-----:|
| "" (0) | **0** |  1   |  2   |  3   |
| h (1)  |  1    |  1   |  2   |  3   |
| o (2)  |  2    |  2   |  1   |  2   |
| r (3)  |  3    |  2   |  2   |  2   |
| s (4)  |  4    |  3   |  3   |  2   |
| e (5)  |  5    |  4   |  4   |  **3** |

读法：右下角 `dp[5][3] = 3`，正好等于题目答案。手画一两行能很快验证转移方程是对的。

## 六、写成代码

```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m, n = len(word1), len(word2)
        # dp[i][j]：把 word1[:i] 变成 word2[:j] 的最少操作数
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        # 边界：把长度 i 的串变成空串要 i 次删除；空串变成长度 j 要 j 次插入
        for i in range(m + 1):
            dp[i][0] = i
        for j in range(n + 1):
            dp[0][j] = j
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if word1[i - 1] == word2[j - 1]:
                    # 末位相同：不需要操作，直接继承
                    dp[i][j] = dp[i - 1][j - 1]
                else:
                    # 末位不同：三种操作选最小再 +1
                    # 删（dp[i-1][j]）/ 插（dp[i][j-1]）/ 改（dp[i-1][j-1]）
                    dp[i][j] = 1 + min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1])
        return dp[m][n]
```

---

## 七、复杂度

- **时间** `O(m × n)`：填一张 `(m+1) × (n+1)` 的表
- **空间** `O(m × n)`：dp 表本身。可压到 `O(n)`——因为每个格子只依赖上一行 + 左边一格，滚动数组即可

---

## 八、容易踩的坑

1. **下标错位**：`dp[i][j]` 对应的是 `word1[i-1]` 和 `word2[j-1]`，写 `word1[i]` 是越界 bug。
2. **替换那一项别漏**：三种状态来源里，`dp[i-1][j-1] + 1`（替换）是最常被忘的，写成两项 `min` 就只对一半数据集。
3. **边界不能不初始化**：`dp[i][0]` 和 `dp[0][j]` 必须填好，否则递推从 0 开始算就错了。

---

## 九、一句话记忆

> **末位相同白送、不同三选一加一**：删（上来）、插（左来）、改（左上来），取最小再 +1。
