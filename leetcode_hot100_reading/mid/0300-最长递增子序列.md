# 300. 最长递增子序列 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/longest-increasing-subsequence/)

---

## 一、题目讲了什么

数组里找**最长严格递增子序列**的**长度**。子序列指**保持顺序、可跳过元素**。

例：`[10, 9, 2, 5, 3, 7, 101, 18]` → `[2, 3, 7, 18]` 或 `[2, 5, 7, 18]`，长度 4。

---

## 二、O(n²) DP

`dp[i]` = 以 `nums[i]` 结尾的 LIS 长度。

```
dp[i] = max(dp[j] + 1)  for j < i and nums[j] < nums[i]
        默认 dp[i] = 1  （单独一个就是长度 1）
答案 = max(dp)
```

O(n²) 能过本题数据。

---

## 三、O(n log n) 巧解

更优的"贪心 + 二分"：

维护一个数组 `tails`，`tails[k]` 表示**长度为 k+1 的递增子序列的最小末尾值**。

> 关键性质：tails 本身始终**严格递增**（"长 k 的最小末尾" < "长 k+1 的最小末尾"）。

遍历每个 `x`：

- 二分找 tails 中**第一个 ≥ x** 的位置 i
- **如果 i == len(tails)**：x 比所有末尾都大 → 扩展 tails（出现了新长度）
- **否则**：tails[i] = x（保留同长度但末尾更小的版本，给后续留更多空间）

最终 tails 的长度就是 LIS 长度。

注意：tails 本身**不是真正的 LIS**，只是一个辅助数组。

---

## 四、举例 `[10, 9, 2, 5, 3, 7, 101, 18]`

| x | tails 操作 | tails |
|---|---|---|
| 10 | 空，append | [10] |
| 9 | 找 ≥9 的位置 0，替换 | [9] |
| 2 | 找 ≥2 的位置 0，替换 | [2] |
| 5 | 找 ≥5 的位置 1（越界），append | [2, 5] |
| 3 | 找 ≥3 的位置 1，替换 | [2, 3] |
| 7 | 找 ≥7 的位置 2（越界），append | [2, 3, 7] |
| 101 | 找 ≥101 的位置 3（越界），append | [2, 3, 7, 101] |
| 18 | 找 ≥18 的位置 3，替换 | [2, 3, 7, 18] |

长度 4。

---

## 五、写成代码

```python
from bisect import bisect_left

class Solution:
    def lengthOfLIS(self, nums):
        tails = []
        for x in nums:
            i = bisect_left(tails, x)
            if i == len(tails):
                tails.append(x)
            else:
                tails[i] = x
        return len(tails)
```

---

## 六、复杂度

- **时间** `O(n log n)`：每个元素一次二分
- **空间** `O(n)`：tails

---

## 七、容易踩的坑

1. **tails 不是真正的 LIS**：它只是"每个长度的最小末尾"。
2. **严格递增 → `bisect_left`**；如果改"非严格递增"用 `bisect_right`。
3. **想还原序列**：得用 O(n²) DP + parent 数组。

---

## 八、一句话记忆

> 维护"长度 k+1 的最小末尾值"数组 `tails`，二分**位置替换**或**追加**。
