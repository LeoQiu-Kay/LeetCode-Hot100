# 300. 最长递增子序列 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/longest-increasing-subsequence/)

---

## 一、题目讲了什么

数组里找**最长严格递增子序列**的**长度**。子序列指**保持顺序、可跳过元素**。

例：`[10, 9, 2, 5, 3, 7, 101, 18]` → `[2, 3, 7, 18]` 或 `[2, 5, 7, 18]`，长度 4。

---

## 二、O(n²) DP（基础解法）

**状态定义**：

> `dp[i]` = **以 `nums[i]` 结尾**的最长递增子序列的长度

注意"以 nums[i] 结尾"这个限定——它强迫 nums[i] 必须被选中作为子序列的末位，这样状态之间才有清晰的递推关系。

**递推关系**：以 nums[i] 结尾的 LIS，前一位必然是某个 `nums[j]`，要满足：

- `j < i`（在 i 前面）
- `nums[j] < nums[i]`（严格递增）

那么把 nums[i] 接到"以 nums[j] 结尾的 LIS"后面就行：

```
dp[i] = max(dp[j] + 1)   对所有满足 j < i 且 nums[j] < nums[i] 的 j
默认 dp[i] = 1           没有任何合法的 j 时，nums[i] 单独成 LIS
```

**答案**：因为 LIS 可以以**任何位置**结尾，所以最终答案是 `max(dp)`，不是 `dp[n-1]`。

---

## 三、走一遍 `[10, 9, 2, 5, 3, 7, 101, 18]`

| i | nums[i] | 前面所有满足 nums[j] < nums[i] 的 j | dp[i] = max(dp[j]+1, 1) |
|---|---|---|---|
| 0 | 10 | 无 | 1 |
| 1 | 9 | 无 | 1 |
| 2 | 2 | 无 | 1 |
| 3 | 5 | j=2 (dp=1) | 2 |
| 4 | 3 | j=2 (dp=1) | 2 |
| 5 | 7 | j=2,3,4 (dp=1,2,2) | 3 |
| 6 | 101 | j=0,1,2,3,4,5 (max dp=3) | 4 |
| 7 | 18 | j=2,3,4,5 (max dp=3) | 4 |

`dp = [1, 1, 1, 2, 2, 3, 4, 4]`，`max(dp) = 4`。

---

## 四、写成代码（DP 版）

```python
class Solution:
    def lengthOfLIS(self, nums: list[int]) -> int:
        # dp[i] = 以 nums[i] 结尾的最长递增子序列的长度
        n = len(nums)
        # 多开一格只是为了让 max(dp) 在 nums 为空时不报错；nums 非空时不影响结果
        # 全 1 表示"每个元素自己单独成一段长度 1 的 LIS"
        dp = [1] * (n + 1)
        # 正向更新：扫到 i 时，往后找所有可以"接在 nums[i] 之后"的 j
        for i in range(n):
            for j in range(i + 1, n):
                # 若 nums[j] 严格大于 nums[i]，nums[j] 可以接在 nums[i] 后面延长一段
                if nums[j] > nums[i]:
                    # 用 "以 nums[i] 结尾的 LIS + nums[j]" 这个候选去更新 dp[j]
                    dp[j] = max(dp[j], dp[i] + 1)
        # LIS 可以以任意位置结尾，所以答案是整个 dp 的最大值
        return max(dp)
```

> **正向 vs 反向**：上面是"扫 i，更新所有更远的 j"——每个 i 是"贡献者"。
> 也可以反过来写："扫 i，回看所有 j < i"——每个 i 是"接收者"，`dp[i] = max(dp[j] + 1)`。
> 两种循环方向语义等价、结果完全相同，写起来挑一种顺手的就行。

复杂度：

- **时间** `O(n²)`：双层循环
- **空间** `O(n)`：dp 数组

n ≤ 2500 时这个解法绰绰有余。如果 n 更大（比如 10⁵），就要换下面的 O(n log n) 解法。

## 五、O(n log n) 巧解（进阶）

更优的"贪心 + 二分"：

维护一个数组 `tails`，`tails[k]` 表示**长度为 k+1 的递增子序列的最小末尾值**。

> 关键性质：tails 本身始终**严格递增**（"长 k 的最小末尾" < "长 k+1 的最小末尾"）。

遍历每个 `x`：

- 二分找 tails 中**第一个 ≥ x** 的位置 i
- **如果 i == len(tails)**：x 比所有末尾都大 → 扩展 tails（出现了新长度）
- **否则**：tails[i] = x（保留同长度但末尾更小的版本，给后续留更多空间）

最终 tails 的长度就是 LIS 长度。

注意：tails 本身**不是真正的 LIS**，只是一个辅助数组。

---

## 六、举例 `[10, 9, 2, 5, 3, 7, 101, 18]`

| x | tails 操作 | tails |
|---|---|---|
| 10 | 空，append | [10] |
| 9 | 找 ≥9 的位置 0，替换 | [9] |
| 2 | 找 ≥2 的位置 0，替换 | [2] |
| 5 | 找 ≥5 的位置 1（越界），append | [2, 5] |
| 3 | 找 ≥3 的位置 1，替换 | [2, 3] |
| 7 | 找 ≥7 的位置 2（越界），append | [2, 3, 7] |
| 101 | 找 ≥101 的位置 3（越界），append | [2, 3, 7, 101] |
| 18 | 找 ≥18 的位置 3，替换 | [2, 3, 7, 18] |

长度 4。

---

## 七、写成代码（贪心 + 二分版）

```python
from bisect import bisect_left

class Solution:
    def lengthOfLIS(self, nums: list[int]) -> int:
        # tails[k] = "长度为 k+1 的递增子序列的最小末尾值"
        # tails 本身始终保持递增
        tails: list[int] = []
        for x in nums:
            # 找第一个 >= x 的位置
            i = bisect_left(tails, x)
            if i == len(tails):
                # x 比所有已知末尾都大，扩展 tails（LIS 长度 +1）
                tails.append(x)
            else:
                # 替换：让长度为 i+1 的子序列末尾变得更小，给后续留更多空间
                tails[i] = x
        return len(tails)
```

## 八、复杂度对比

| 解法 | 时间 | 空间 | 适用 |
|---|---|---|---|
| O(n²) DP | O(n²) | O(n) | 通用，能还原序列（用 parent 数组） |
| 贪心 + 二分 | O(n log n) | O(n) | 数据规模大；只要长度 |

---

## 九、容易踩的坑

1. **DP 状态是"以 nums[i] 结尾"**，不是"前 i 个里的 LIS"——后者递推关系不清晰。
2. **答案是 `max(dp)`**，不是 `dp[n-1]`：LIS 可以在任何位置结尾。
3. **tails 不是真正的 LIS**：贪心解法里它只是"每个长度的最小末尾"。
4. **严格递增 → `bisect_left`**；如果改"非严格递增"用 `bisect_right`。
5. **想还原序列**：得用 O(n²) DP + parent 数组记录每步从哪个 j 转移来。

---

## 十、一句话记忆

> **DP**：以 nums[i] 结尾的 LIS，看 i 前面所有比它小的 dp[j]，取 max + 1。
> **贪心**：维护"长度 k+1 的最小末尾值"数组 tails，二分**位置替换**或**追加**。
