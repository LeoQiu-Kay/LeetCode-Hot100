# 139. 单词拆分 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/word-break/)

---

## 一、题目讲了什么

字符串 `s` 和字典 `wordDict`（单词列表）。判断 s 能不能被切分成**一个或多个字典里单词**的连接。同一个单词可以重复用。

例：

- `s = "leetcode", wordDict = ["leet", "code"]` → True（"leet" + "code"）
- `s = "applepenapple", ["apple", "pen"]` → True
- `s = "catsandog", ["cats", "dog", "sand", "and", "cat"]` → False

---

## 二、回溯能解但慢

枚举所有切法用回溯 O(2ⁿ)。会超时。

---

## 三、DP：`dp[i]` 表示 `s[:i]` 能否拆

定义：

> **`dp[i]` = `s[:i]`（前 i 个字符）能否切分**

转移：枚举本段的起点 j（即上一段的终点）：

```
dp[i] 为 True ⟺ 存在 j 使 dp[j] 为 True 且 s[j..i-1] 在字典里
```

也就是说"前 j 个能拆 + 剩下的 s[j..i-1] 是字典里的单词" → 前 i 个能拆。

**边界**：`dp[0] = True`（空串视为能拆）。

---

## 四、把字典转成 set 加速 in 查询

`s[j:i] in wordDict` 如果 wordDict 是 list 就是 O(L)（L 是字典大小）。改成 set 后是 O(K)（K 是单词长度，哈希）。

---

## 五、走一遍 `s = "leetcode", wordDict = ["leet", "code"]`

dp 数组 8+1=9 个，初始 `dp[0] = True`。

| i | 找 j 使 dp[j] = True 且 s[j..i-1] ∈ dict | dp[i] |
|---|---|---|
| 1..3 | s[0..0]="l", s[0..1]="le", s[0..2]="lee" 都不在 dict | F, F, F |
| 4 | j=0: dp[0]=T，s[0..3]="leet" ∈ dict → True | **T** |
| 5..7 | j=0: s[0..4]="leetc" ∉；j=4: dp[4]=T，s[4..4]="c" ∉。同理 6, 7 都 F | F, F, F |
| 8 | j=4: dp[4]=T，s[4..7]="code" ∈ dict → True | **T** |

`dp[8] = True`。

---

## 六、写成代码

```python
class Solution:
    def wordBreak(self, s, wordDict):
        words = set(wordDict)
        n = len(s)
        dp = [False] * (n + 1)
        dp[0] = True
        for i in range(1, n + 1):
            for j in range(i):
                if dp[j] and s[j:i] in words:
                    dp[i] = True
                    break
        return dp[n]
```

---

## 七、复杂度

- **时间** `O(n² × L)`：双层 O(n²) + 切片 / set 查询 O(L)（L 是平均单词长）
- **空间** `O(n + 字典)`

---

## 八、容易踩的坑

1. **`dp[0] = True`** 必不可少：表示空串"可拆"。
2. **找到一个 j 就 break**：再继续没意义，剪枝。
3. **`s[j:i]`**：Python 切片右开，对应字符串 `s[j..i-1]`。

---

## 九、一句话记忆

> `dp[i]` 看是否存在 j 让 `dp[j] = True` 且 `s[j..i]` 是字典词。
