# 45. 跳跃游戏 II · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/jump-game-ii/)

---

## 一、题目讲了什么

数组 `nums`，`nums[i]` 表示**在位置 i 最多能向前跳几步**。题目保证你**一定能到末尾**。求到达末尾的**最少跳跃次数**。

例：`[2, 3, 1, 1, 4]` → 2（位置 0 跳到位置 1，再跳到末尾）。

---

## 二、思路：BFS 视角

把"位置"看作图的节点，从 i 能到 j（`j ≤ i + nums[i]`）就有一条边。求最少跳跃就是**从 0 到 n-1 的最短路**。BFS！

但 BFS 显式建图会很慢。可以**模拟 BFS 的层次结构**：

- **第 0 层**：起点 `0`
- **第 1 层**：从第 0 层一步能到的所有位置
- **第 2 层**：从第 1 层一步能到的位置（且不在前面层）
- ……

回答"到 n-1 在第几层"。

---

## 三、贪心模拟分层

不需要真的存所有节点，只需要维护**当前层的"右边界"**和**下一层能到的"最远位置"**：

```
jumps   = 0     # 已跳次数
end     = 0     # 本次跳能到的最远（当前层右边界）
farthest = 0    # 下一次跳能到的最远

遍历 i 从 0 到 n-2：
    farthest = max(farthest, i + nums[i])
    if i == end:        # 走到当前层的边界
        jumps += 1       # 必须发起下一跳
        end = farthest    # 推到下一层的右边界
```

为什么遍历到 `n-2` 而不是 `n-1`？走到 n-1 就到终点了，不需要再触发新跳。

---

## 四、走一遍 `[2, 3, 1, 1, 4]`

n = 5，遍历 i = 0..3：

| i | nums[i] | farthest = max(prev, i+nums[i]) | i == end? | jumps | end |
|---|---|---|---|---|---|
| 0 | 2 | 0+2 = 2 | 0 == 0 ✓ | 1 | 2 |
| 1 | 3 | max(2, 1+3)=4 | 1 == 2 ✗ | 1 | 2 |
| 2 | 1 | max(4, 2+1)=4 | 2 == 2 ✓ | 2 | 4 |
| 3 | 1 | max(4, 3+1)=4 | 3 == 4 ✗ | 2 | 4 |

答案 2。

---

## 五、写成代码

```python
class Solution:
    def jump(self, nums):
        jumps = 0
        end = 0
        farthest = 0
        for i in range(len(nums) - 1):
            farthest = max(farthest, i + nums[i])
            if i == end:
                jumps += 1
                end = farthest
        return jumps
```

---

## 六、复杂度

- **时间** `O(n)`：单趟扫描
- **空间** `O(1)`

---

## 七、容易踩的坑

1. **遍历范围 `range(n - 1)`**：到 n-1 就不需要再跳。漏掉 -1 会多跳一次。
2. **`farthest` 在外面累计 max**，不是每轮重置。
3. **题目保证能到达**，所以不用判"卡死"（题目 55 才需要）。

---

## 八、一句话记忆

> **BFS 分层 + 贪心**：维护"当前层右边界 end"和"下一层最远 farthest"，走到 end 就触发新一跳。
