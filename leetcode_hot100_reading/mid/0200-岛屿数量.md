# 200. 岛屿数量 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/number-of-islands/)

---

## 一、题目讲了什么

`m × n` 网格，`'1'` 表示陆地、`'0'` 表示水。**相邻**陆地（上下左右）连通为同一座岛。求岛屿数。

例：

```
['1', '1', '0', '0']         有 2 座岛：
['1', '1', '0', '0']         左上 4 个 1 一块，右下两个 1 一块
['0', '0', '1', '0']
['0', '0', '1', '1']
```

---

## 二、思路：DFS 淹没

扫描网格。遇到 `'1'`：

1. **岛数 +1**
2. **DFS 把整块岛"淹没"成 '0'**（标记已访问）

继续扫描时不会再遇到这块岛的 1，下一次遇到 1 就是新岛了。

把"淹没"作为 visited 标记，省一个 O(mn) 的额外数组。

---

## 三、DFS 四方向递归

```
def dfs(i, j):
    越界或不是 '1'：return
    grid[i][j] = '0'      # 标记已访问 / 淹没
    dfs(i+1, j); dfs(i-1, j); dfs(i, j+1); dfs(i, j-1)
```

---

## 四、写成代码

```python
class Solution:
    def numIslands(self, grid: list[list[str]]) -> int:
        if not grid:
            return 0
        m, n = len(grid), len(grid[0])
        def dfs(i: int, j: int) -> None:
            # 越界或当前不是陆地：停止
            if not (0 <= i < m and 0 <= j < n) or grid[i][j] != '1':
                return
            # 把陆地"淹没"为 0，同时也起到 visited 标记作用
            grid[i][j] = '0'
            # 向四个方向递归
            dfs(i + 1, j)
            dfs(i - 1, j)
            dfs(i, j + 1)
            dfs(i, j - 1)
        count = 0
        for i in range(m):
            for j in range(n):
                # 遇到一块未访问的陆地，岛数 +1 并把整块岛淹没
                if grid[i][j] == '1':
                    count += 1
                    dfs(i, j)
        return count
```

---

## 五、复杂度

- **时间** `O(m × n)`：每格最多被访问一次
- **空间** `O(m × n)`：最坏整网格是岛，DFS 栈深 mn

## 六、字符 vs 整数

题目给的是**字符** `'1'` 和 `'0'`（不是整数 1/0），比较和赋值时记得带引号。这是经典坑。

---

## 七、容易踩的坑

1. **比较用 `'1'`**：注意引号。
2. **修改原 grid 作 visited**：题目允许 / 简洁；不允许就开 visited 数组。
3. **BFS 同理也可**：用队列，思路一样。

---

## 八、一句话记忆

> 遇 '1' **岛数 +1** 并 DFS **把整块岛淹成 '0'**。
