# 215. 数组中的第 K 个最大元素 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/kth-largest-element-in-an-array/)

---

## 一、题目讲了什么

数组里返回**第 k 大**的元素。注意"第 k 大"指排序后的第 k 个（包含重复值），不是"第 k 个不同的值"。

例：`[3, 2, 1, 5, 6, 4], k=2` → 5

---

## 二、思路对比

| 方法 | 时间 | 空间 | 评价 |
|---|---|---|---|
| 排序后取 `nums[-k]` | O(n log n) | O(1) | 可过但不够"题面" |
| **小顶堆维护 k 个最大** | **O(n log k)** | O(k) | 推荐，最易实现 |
| 快速选择 | **平均 O(n)** | O(1) | 最优，但代码长 |

讲**堆解法**——好写、不易错。

---

## 三、小顶堆维护 "k 个最大"

直觉：题目要的是"前 k 大里最小的那个"——刚好是大小为 k 的**小顶堆**的顶。

边遍历边维护：

```
heap = []
for x in nums:
    heappush(heap, x)
    if len(heap) > k:
        heappop(heap)   # 弹出 k 个里最小的（保留 k 个最大）
return heap[0]
```

最终堆里就是数组里最大的 k 个，堆顶就是答案。

---

## 四、为什么不直接堆排序整个数组

整个数组堆排序是 O(n log n)。本题 k 通常 << n，**大小为 k 的堆**操作只 O(log k)，整体 O(n log k) 更优。

---

## 五、写成代码

```python
import heapq

class Solution:
    def findKthLargest(self, nums, k):
        heap = []
        for x in nums:
            heapq.heappush(heap, x)
            if len(heap) > k:
                heapq.heappop(heap)
        return heap[0]
```

---

## 六、复杂度

- **时间** `O(n log k)`
- **空间** `O(k)`

---

## 七、容易踩的坑

1. **Python 的 heapq 默认小顶堆**：维护"k 个最大"用小顶堆（堆顶就是这 k 个里最小的）。维护"k 个最小"则用大顶堆，要把 push 的值取负。
2. **要"第 k 大"不是"第 k 小"**：写错就反了。
3. **可以用 `heapq.nlargest(k, nums)[-1]`**：一行调用，背后是同样思路。

---

## 八、一句话记忆

> **小顶堆维护 k 个最大**，堆顶即答案。
