# 75. 颜色分类 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/sort-colors/)

---

## 一、题目讲了什么

数组只含 0、1、2 三种值。**原地**把它们排序，让结果为 `[0...0, 1...1, 2...2]`。要求 **一趟扫描、O(1) 空间**。

例：`[2, 0, 2, 1, 1, 0]` → `[0, 0, 1, 1, 2, 2]`

---

## 二、为什么经典排序不够"题面"

`sort()` 是 O(n log n)，能过但题目暗示有更优。计数排序两趟扫（先统计 + 后填充）也能 O(n)，但要两遍。

要求**一趟原地**——经典名字叫 **荷兰国旗算法**（Dijkstra 提出）。

---

## 三、三指针荷兰国旗

设三个指针：

- `lo`：**0 区右边界**——`[0, lo)` 都是 0
- `hi`：**2 区左边界**——`(hi, n-1]` 都是 2
- `mid`：扫描指针，`[lo, mid)` 都是 1，`[mid, hi]` 是未处理

不断扫 `mid`：

- `nums[mid] == 0`：和 `nums[lo]` 交换，`lo++`、`mid++`
- `nums[mid] == 2`：和 `nums[hi]` 交换，`hi--`；**mid 不动**（换过来的还得检查）
- `nums[mid] == 1`：`mid++`（1 已经在 1 区，跳过）

终止：`mid > hi`。

---

## 四、为什么遇到 2 时 `mid` 不动

遇到 0 时和 `lo` 交换，换过来的元素来自 `[lo, mid)`——保证是 1（因为这区间都是 1）—— 可以直接 mid++。

遇到 2 时和 `hi` 交换，换过来的元素来自 `(hi 之前的未处理区)`——**不知道**是什么。所以 mid 不能 ++，下一轮重新看。

---

## 五、走一遍 `[2, 0, 2, 1, 1, 0]`

| 步 | lo | mid | hi | nums | 动作 |
|---|---|---|---|---|---|
| 初 | 0 | 0 | 5 | [2,0,2,1,1,0] | nums[mid]=2，换 mid↔hi，hi-- |
| 1 | 0 | 0 | 4 | [0,0,2,1,1,2] | nums[mid]=0，换 mid↔lo，两都++ |
| 2 | 1 | 1 | 4 | [0,0,2,1,1,2] | nums[mid]=0，换 mid↔lo（同位），都++ |
| 3 | 2 | 2 | 4 | [0,0,2,1,1,2] | nums[mid]=2，换 mid↔hi，hi-- |
| 4 | 2 | 2 | 3 | [0,0,1,1,2,2] | nums[mid]=1，mid++ |
| 5 | 2 | 3 | 3 | [0,0,1,1,2,2] | nums[mid]=1，mid++ |
| 6 | 2 | 4 | 3 | - | mid > hi，停 |

结果 `[0,0,1,1,2,2]`。

---

## 六、写成代码

```python
class Solution:
    def sortColors(self, nums: list[int]) -> None:
        # 三个指针：
        # [0, lo) 是已确认的 0 区
        # [lo, mid) 是已确认的 1 区
        # [mid, hi] 是未处理区
        # (hi, n) 是已确认的 2 区
        lo, mid, hi = 0, 0, len(nums) - 1
        while mid <= hi:
            if nums[mid] == 0:
                # 当前是 0：换到 0 区末尾，lo 和 mid 都前进
                nums[lo], nums[mid] = nums[mid], nums[lo]
                lo += 1
                mid += 1
            elif nums[mid] == 2:
                # 当前是 2：换到 2 区开头，hi 左移
                # 注意 mid 不动：从 hi 换过来的元素还没处理过，下一轮重新看
                nums[mid], nums[hi] = nums[hi], nums[mid]
                hi -= 1
            else:
                # 当前是 1：1 直接进 1 区
                mid += 1
```

---

## 七、复杂度

- **时间** `O(n)`：一趟
- **空间** `O(1)`

---

## 八、容易踩的坑

1. **遇到 2 时 mid 不动**：换过来的是未处理元素。
2. **遇到 0 时 mid 必须 ++**：换过来的是 1 区元素，跳过即可。
3. **循环条件 `mid <= hi`**：等于时也得处理一下（hi 那一格还没确认）。

---

## 九、一句话记忆

> 三指针：`lo` 圈 0 区、`hi` 圈 2 区，`mid` 扫——0 换前+1，1 跳过，2 换后但 mid 不动。
