# 347. 前 K 个高频元素 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/top-k-frequent-elements/)

---

## 一、题目讲了什么

数组里返回**出现频次最高的 k 个元素**。顺序不限。

例：`[1,1,1,2,2,3], k=2` → `[1, 2]`

要求**优于 O(n log n)**——所以排序 + 取前 k 不够。

---

## 二、两步走

**第一步：统计频次**——`collections.Counter(nums)`，得到 `{val: freq}`。

**第二步：从 (val, freq) 对里挑出 freq 最大的 k 个**——这就是"前 K 大"问题。可以：

- **小顶堆**（按 freq）大小为 k → O(N log k)
- **桶排序** → O(N)

讲堆解法（最常见），桶排序作为优化拓展。

---

## 三、小顶堆维护前 k 高频

和 215 同款思路：

- 堆按 freq 比较（freq 小的在堆顶）
- 边遍历 (val, freq) 对：push 进堆 → size > k 弹堆顶
- 最后堆里就是前 k 高频

---

## 四、写成代码

```python
from collections import Counter
import heapq

class Solution:
    def topKFrequent(self, nums: list[int], k: int) -> list[int]:
        # 统计每个数字的出现次数
        cnt = Counter(nums)
        # 小顶堆，元素是 (频次, 数字)；按频次比较，频次小的在堆顶
        heap: list[tuple[int, int]] = []
        for v, f in cnt.items():
            heapq.heappush(heap, (f, v))
            # 堆大小超过 k：弹掉频次最小的
            if len(heap) > k:
                heapq.heappop(heap)
        # 堆里剩下的 k 个就是前 k 高频的数字
        return [v for _, v in heap]
```

或者一行：

```python
return [v for v, _ in cnt.most_common(k)]
```

`Counter.most_common(k)` 内部就是 heap-select 的优化版。

---

## 五、复杂度

- **时间** `O(N log k)`：N 个不同元素，每次堆操作 log k
- **空间** `O(N)`：Counter

---

## 六、桶排序 O(N) 拓展

频次最大不超过 N。可以开 `N+1` 个桶，每个桶装"频次相等的元素列表"：

```
buckets[freq] = [val1, val2, ...]
```

从高频桶往低频桶倒着收集，凑齐 k 个就停。

代码稍长但严格 O(N)。

---

## 七、容易踩的坑

1. **堆元素的第一项是 freq**：按它比较。`(freq, val)` 是 tuple 字典序，freq 相等会比 val——不影响正确性，但 val 不可比较时会报错（hot100 都是 int 不用担心）。
2. **小顶堆维护前 k 大**：堆顶是这 k 个里最小的。
3. **不要直接 sort**：题目要求**优于 O(n log n)**，O(N log k) 才合规。

---

## 八、一句话记忆

> **Counter 统计 + 小顶堆维护前 k**（或 most_common）。
