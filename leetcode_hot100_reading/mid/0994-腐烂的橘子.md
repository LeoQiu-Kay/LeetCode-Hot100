# 994. 腐烂的橘子 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/rotting-oranges/)

---

## 一、题目讲了什么

网格：`0` 空、`1` 新鲜橘子、`2` 腐烂橘子。**每分钟**腐烂橘子让**四个相邻**新鲜橘子腐烂。求所有新鲜橘子都腐烂需要多少分钟；不可能就返回 -1。

例：

```
[2, 1, 1]
[1, 1, 0]      → 4 分钟
[0, 1, 1]
```

---

## 二、多源 BFS

注意"**所有腐烂橘子同时扩散**"——不是从一个开始。这是典型的**多源 BFS**。

把所有初始腐烂橘子一起入队作为"第 0 层"，按层 BFS。每一层就是一分钟。最后若还有新鲜橘子（被隔绝），返回 -1。

---

## 三、为什么不能"单源跑多次"

如果从某个腐烂点开始 BFS，要算"它能在第几分钟腐烂某个新鲜橘子"。多个起点彼此干扰，复杂度爆炸。

**多源 BFS** 的关键：**起点齐发**，按"哪个先到"自然取最小。所有起点同时进队即可。

---

## 四、按层 BFS

```
q = deque(所有初始腐烂位置)
fresh = 统计新鲜橘子数
minutes = 0

while q 且 fresh > 0:
    for _ in range(len(q)):       # 处理本层
        i, j = q.popleft()
        for 四方向 ni, nj:
            if 新鲜：
                grid[ni][nj] = 2
                fresh -= 1
                q.append((ni, nj))
    minutes += 1

if fresh > 0: return -1
return minutes
```

`size = len(q)` 切层的技巧和题 102 一样。

---

## 五、写成代码

```python
from collections import deque

class Solution:
    def orangesRotting(self, grid: list[list[int]]) -> int:
        m, n = len(grid), len(grid[0])
        q = deque()
        fresh = 0
        # 初始扫描：所有腐烂的入队、统计新鲜
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 2:
                    q.append((i, j))
                elif grid[i][j] == 1:
                    fresh += 1
        # 没有新鲜橘子，0 分钟就完成
        if fresh == 0:
            return 0
        minutes = 0
        dirs = [(1, 0), (-1, 0), (0, 1), (0, -1)]
        # 标准"按层 BFS"：每轮处理当前队列里所有节点，再 +1 分钟
        while q and fresh > 0:
            for _ in range(len(q)):
                i, j = q.popleft()
                for di, dj in dirs:
                    ni, nj = i + di, j + dj
                    # 邻居是新鲜橘子 → 腐烂、入队、计数 -1
                    if 0 <= ni < m and 0 <= nj < n and grid[ni][nj] == 1:
                        grid[ni][nj] = 2
                        fresh -= 1
                        q.append((ni, nj))
            minutes += 1
        # 还有新鲜橘子没被腐烂 → 不可能全部腐烂
        return minutes if fresh == 0 else -1
```

---

## 六、复杂度

- **时间** `O(m × n)`
- **空间** `O(m × n)`：队列

---

## 七、容易踩的坑

1. **多源 BFS**：起点是**所有**腐烂橘子，一次性入队。
2. **fresh 计数**：开头记，过程中减，结尾判 -1。
3. **fresh == 0 时直接返回 0**：没有新鲜橘子就不用扩散。
4. **`while q and fresh > 0`**：fresh 提前归零时退出，避免多算分钟。

---

## 八、一句话记忆

> **多源 BFS**：所有腐烂橘子一起入队，按层扩散，每层 +1 分钟。
