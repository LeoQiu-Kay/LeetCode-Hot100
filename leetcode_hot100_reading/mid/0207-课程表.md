# 207. 课程表 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/course-schedule/)

---

## 一、题目讲了什么

`numCourses` 门课，`prerequisites[i] = [b, a]` 表示**修 b 之前必须先修 a**。判断能不能修完所有课。

例：

- `numCourses=2, prerequisites=[[1,0]]` → True（先修 0 再修 1）
- `numCourses=2, prerequisites=[[1,0], [0,1]]` → False（循环依赖）

---

## 二、抽象为图论

把课程看作有向图节点，"a 是 b 的先修课"对应有向边 `a → b`（a 必须排在 b 前）。

"能修完所有课" ⟺ **图中无环**（有环就互相等待，谁都修不了）。

也等价于**能做出一个拓扑排序**。

---

## 三、Kahn 拓扑排序（BFS）

经典做法：

1. 算每个节点的**入度**（多少个先修课没修）
2. 把所有"入度为 0"的节点入队（没有先修课，可以直接修）
3. BFS：出队一个 → 删它出发的边（即它的所有"后继课"入度 -1）→ 新增的入度 0 节点入队
4. 出队的节点总数 = numCourses → 无环 → 能修完；否则有环

---

## 四、注意先修关系的方向

题目格式 `[b, a]` 表示 "b 的先修课是 a"——对应边 `a → b`，**不是 b → a**。常被画反。

```
建图时：g[a].append(b)，indeg[b] += 1
```

---

## 五、写成代码

```python
from collections import deque

class Solution:
    def canFinish(self, numCourses: int, prerequisites: list[list[int]]) -> bool:
        # 邻接表：g[a] 列出所有"以 a 为先修课"的下游课程
        # 入度数组：indeg[b] 是课程 b 还有几个未完成的先修课
        g: list[list[int]] = [[] for _ in range(numCourses)]
        indeg = [0] * numCourses
        for b, a in prerequisites:
            # 题目格式 [b, a] 表示要修 b 必须先修 a，即 a → b
            g[a].append(b)
            indeg[b] += 1
        # 所有入度为 0 的课（无先修课）先入队
        q = deque(i for i in range(numCourses) if indeg[i] == 0)
        done = 0   # 已完成的课程数
        while q:
            x = q.popleft()
            done += 1
            # 把 x 的所有后继课程的入度减 1
            for y in g[x]:
                indeg[y] -= 1
                # 入度归零意味着所有先修课已修完，可以学了
                if indeg[y] == 0:
                    q.append(y)
        # 全部完成 ⟺ 无环
        return done == numCourses
```

## 六、复杂度

- **时间** `O(V + E)`：节点 + 边
- **空间** `O(V + E)`：图和队列

---

## 七、容易踩的坑

1. **图方向**：题目 `[b, a]` 是 `a → b`，画反就 wrong answer。
2. **入度为 0 才入队**：少了这条就无法启动。
3. **判定**：出队总数 = numCourses ⟺ 无环。

---

## 八、一句话记忆

> Kahn 拓扑：**入度 0 入队 → 出队减后继入度 → 出队数 = 节点总数**。
