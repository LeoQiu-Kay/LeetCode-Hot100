# 279. 完全平方数 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/perfect-squares/)

---

## 一、题目讲了什么

给一个正整数 n，求**和为 n 的完全平方数（1, 4, 9, 16, ...）的最少个数**。

例：

- n = 12 → 12 = 4 + 4 + 4，最少 3 个
- n = 13 → 13 = 9 + 4，最少 2 个

---

## 二、像 322 零钱兑换的特例

把"完全平方数 1, 4, 9, 16, ..."当成**面值无限的硬币**，凑出 n 的最少枚数。

`dp[i]` = 凑成 i 的最少完全平方数个数。转移：

```
dp[i] = min(dp[i - j*j] + 1)  for j*j ≤ i
```

边界 `dp[0] = 0`（凑 0 用 0 个）。

---

## 三、走一遍 n = 12

```
dp[0] = 0
dp[1] = dp[0] + 1 = 1
dp[2] = dp[1] + 1 = 2
dp[3] = dp[2] + 1 = 3
dp[4] = min(dp[3]+1, dp[0]+1) = min(4, 1) = 1
dp[5] = min(dp[4]+1, dp[1]+1) = min(2, 2) = 2
...
dp[12] = min(dp[11]+1, dp[8]+1, dp[3]+1) = min(?, 3, 4) = 3
```

`dp[12] = 3`。

---

## 四、写成代码

```python
class Solution:
    def numSquares(self, n):
        dp = [0] + [n] * n         # dp[0]=0；其它初始化为 n（保证可达上界）
        for i in range(1, n + 1):
            j = 1
            while j * j <= i:
                dp[i] = min(dp[i], dp[i - j * j] + 1)
                j += 1
        return dp[n]
```

---

## 五、复杂度

- **时间** `O(n × √n)`：i 从 1 到 n，每个 i 枚举 j 到 √i
- **空间** `O(n)`

---

## 六、为什么 dp 初始用 n

n 本身就是"用 n 个 1 凑出 n"的上界，任何 dp[i] ≤ i ≤ n，初始 n 不会比真实答案小。

---

## 七、数学定理（拓展）

**拉格朗日四平方和定理**：任何正整数最多 4 个完全平方数就能表示。LeetCode 不要求用，但是面试时能讲出来加分。

---

## 八、容易踩的坑

1. **`dp[0] = 0`** 是基本情况：凑 0 用 0 个。
2. **`j * j <= i`**：j 的范围。
3. **dp 初始值 n** 而不是 `inf`：方便，避免溢出。

---

## 九、一句话记忆

> 完全背包：**dp[i] = min(dp[i - j²]) + 1**，j² ≤ i。
