# 155. 最小栈 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/min-stack/)

---

## 一、题目讲了什么

设计一个支持下面操作的栈，**所有操作 O(1)**：

- `push(val)`
- `pop()`
- `top()` 返回栈顶
- `getMin()` 返回当前栈中的**最小值**

例：push(-2), push(0), push(-3), getMin() → -3, pop(), top() → 0, getMin() → -2

---

## 二、难点在 getMin

普通栈所有操作 O(1) 没问题，但**当前最小值**用普通栈算是 O(n)。每次 pop 后最小可能变，没法只存一个全局变量。

---

## 三、辅助栈同步存最小值

**关键观察**：栈的"当前最小值"和"当前栈内元素"是一一对应的——push 后最小值可能改，pop 后会回到 push 之前的状态。

所以维护一个**辅助栈** `min_stack`，长度与主栈同步：

- `push(x)`：主栈 push x；辅助栈 push `min(min_stack[-1], x)`
- `pop()`：主栈和辅助栈同时 pop
- `getMin()`：返回 `min_stack[-1]`

辅助栈的每个位置存"**到这个位置为止主栈所有元素的最小值**"。

---

## 四、举个例子

主栈   `[-2, 0, -3]`
辅助栈 `[-2, -2, -3]`  → 栈顶 -3 就是当前最小

pop 后主栈   `[-2, 0]`
辅助栈 `[-2, -2]`  → 栈顶 -2 是当前最小

---

## 五、写成代码

```python
class MinStack:
    def __init__(self):
        # 主栈：实际存所有元素
        self.stack: list[int] = []
        # 辅助栈：每个位置对应主栈到该位置为止的最小值
        # 两个栈长度永远相同，pop/push 同步进行
        self.min_stack: list[int] = []

    def push(self, val: int) -> None:
        self.stack.append(val)
        # 辅助栈 push 的是"当前 val"与"之前最小"的较小值
        # 这样不论主栈如何 push，min_stack[-1] 永远是当前主栈的最小
        if self.min_stack:
            self.min_stack.append(min(self.min_stack[-1], val))
        else:
            self.min_stack.append(val)

    def pop(self) -> None:
        # 两个栈一起 pop，保持同步
        self.stack.pop()
        self.min_stack.pop()

    def top(self) -> int:
        return self.stack[-1]

    def getMin(self) -> int:
        return self.min_stack[-1]
```

---

## 六、复杂度

- **时间**：所有操作 O(1)
- **空间** `O(n)`：辅助栈

---

## 七、容易踩的坑

1. **辅助栈和主栈必须同步 push / pop**：长度永远相等。
2. **push 时辅助栈存的是 `min(栈顶, val)`**——不是单纯的 val。
3. **首次 push** 辅助栈为空，要单独处理（或者初始化时放一个哨兵）。

---

## 八、一句话记忆

> **辅助栈同步存最小值**：push 存 `min(栈顶, val)`，pop 同步弹，getMin 返回栈顶。
