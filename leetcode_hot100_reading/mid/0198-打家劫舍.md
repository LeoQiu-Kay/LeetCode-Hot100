# 198. 打家劫舍 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/house-robber/)

---

## 一、题目讲了什么

一排房子里有钱，**不能偷相邻**两间。求能偷的最大金额。

例：

- `[1, 2, 3, 1]` → 偷 [0, 2] 得 1+3=4
- `[2, 7, 9, 3, 1]` → 偷 [0, 2, 4] 得 2+9+1=12

---

## 二、思路：每间房子"偷或不偷"

DP 入门题。定义：

> `dp[i]` = 偷到第 i 间房（含）能拿到的最大金额

每间有两种决策：

- **偷**：那 i-1 不能偷 → `dp[i-2] + nums[i]`
- **不偷**：金额沿用 → `dp[i-1]`

```
dp[i] = max(dp[i-1], dp[i-2] + nums[i])
```

**边界**：

- `dp[0] = nums[0]`
- `dp[1] = max(nums[0], nums[1])`

---

## 三、空间压到 O(1)：滚动变量

`dp[i]` 只依赖 `dp[i-1]` 和 `dp[i-2]` —— 两个变量就够：

```
prev2 = 0       # 相当于 dp[-2]，假想"再前一个"
prev1 = 0       # 相当于 dp[-1]
for x in nums:
    cur = max(prev1, prev2 + x)
    prev2, prev1 = prev1, cur
return prev1
```

初始 `prev1 = prev2 = 0`：表示"还没开始偷"的状态，转移公式自然处理 nums[0]。

---

## 四、走一遍 `[2, 7, 9, 3, 1]`

| x | prev1 (旧) | prev2 (旧) | cur = max(prev1, prev2+x) | prev1 (新) | prev2 (新) |
|---|---|---|---|---|---|
| 2 | 0 | 0 | max(0, 0+2)=2 | 2 | 0 |
| 7 | 2 | 0 | max(2, 0+7)=7 | 7 | 2 |
| 9 | 7 | 2 | max(7, 2+9)=11 | 11 | 7 |
| 3 | 11 | 7 | max(11, 7+3)=11 | 11 | 11 |
| 1 | 11 | 11 | max(11, 11+1)=12 | **12** | 11 |

答案 12。

---

## 五、写成代码

```python
class Solution:
    def rob(self, nums: list[int]) -> int:
        # prev2 表示"不包括当前位置往前推 2 间"的最大值（dp[i-2]）
        # prev1 表示"到上一间为止"的最大值（dp[i-1]）
        prev2 = prev1 = 0
        for x in nums:
            # cur = max(不偷当前=prev1, 偷当前=prev2+x)
            cur = max(prev1, prev2 + x)
            # 滚动：旧的 prev1 变成新的 prev2
            prev2, prev1 = prev1, cur
        # 循环结束 prev1 就是答案
        return prev1
```

## 六、复杂度

- **时间** `O(n)`
- **空间** `O(1)`

---

## 七、容易踩的坑

1. **转移公式两选一**：偷 = prev2 + x（**不是 prev1 + x**）；不偷 = prev1（沿用）。
2. **prev2 / prev1 初始 0**：自然处理"空数组前缀"的边界。
3. **滚动顺序**：`prev2, prev1 = prev1, cur` 元组赋值原子，先算右边再绑左边。

---

## 八、一句话记忆

> 每间二选一：**偷 (prev2 + x) vs 不偷 (prev1)**，滚动两个变量。
