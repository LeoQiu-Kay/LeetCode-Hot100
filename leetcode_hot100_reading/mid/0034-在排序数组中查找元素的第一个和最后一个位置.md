# 34. 在排序数组中查找元素的第一个和最后一个位置 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/)

---

## 一、题目讲了什么

升序数组 + 一个 target，返回 target 第一次和最后一次出现的下标 `[first, last]`。不存在返回 `[-1, -1]`。

要求 **O(log n)**——明示二分。

例：`[5, 7, 7, 8, 8, 10], target = 8` → `[3, 4]`。

---

## 二、把"首末位置"变成两个独立的"下界"问题

复用 35 题学到的 **lower_bound** 模板（找第一个 ≥ t 的位置）：

- **first** = `lower_bound(target)`：第一个 ≥ target 的位置
- **last** = `lower_bound(target + 1) - 1`：第一个 > target 的位置 减 1，即最后一个 ≤ target 的位置

把"找区间端点"拆成两次"找下界"，每次都用同一个模板。

---

## 三、为什么这样找最后位置

要找 target 最后一次出现的位置 → 等价于"找第一个 > target 的位置 j，那么 last = j - 1"。

而"第一个 > target"等价于"第一个 ≥ target + 1"。lower_bound 模板再用一次。

---

## 四、找不到 target 时的判断

`first = lower_bound(target)` 不一定真的指向 target，它只表示"第一个 ≥ target 的位置"。

判断不存在：

- `first == len(nums)`：越界（所有数都 < target）
- 或 `nums[first] != target`

满足任一条件 → 返回 `[-1, -1]`。

---

## 五、写成代码

```python
class Solution:
    def searchRange(self, nums: list[int], target: int) -> list[int]:
        def lower_bound(t: int) -> int:
            # 找第一个 >= t 的位置（半开区间二分）
            lo, hi = 0, len(nums)
            while lo < hi:
                mid = (lo + hi) // 2
                if nums[mid] < t:
                    lo = mid + 1
                else:
                    hi = mid
            return lo
        left = lower_bound(target)
        # target 不存在的两种情况：左边界越界 或 对应位置不是 target
        if left == len(nums) or nums[left] != target:
            return [-1, -1]
        # 找第一个 > target 的位置（即 lower_bound(target + 1)），再减 1 就是最后位置
        right = lower_bound(target + 1) - 1
        return [left, right]
```

---

## 六、复杂度

- **时间** `O(log n)`：两次二分
- **空间** `O(1)`

---

## 七、容易踩的坑

1. **必须先判 `first == len(nums)` 再访问 `nums[first]`**：否则越界。
2. **`lower_bound(target + 1) - 1`** 这种"上界 = 下下界 - 1"的技巧记牢，比写两套二分模板省事。
3. **`hi = len(nums)`**（不是 n - 1）：lower_bound 半开区间标配。

---

## 八、一句话记忆

> 两次 lower_bound：**`lb(t)` 是首；`lb(t+1) - 1` 是末**。先判越界 / 不等 → 返回 `[-1, -1]`。
