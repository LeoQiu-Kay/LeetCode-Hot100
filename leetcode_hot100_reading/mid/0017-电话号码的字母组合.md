# 17. 电话号码的字母组合 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/)

---

## 一、题目讲了什么

老式按键手机上，一个数字键对应几个字母（一格键盘里塞了几个）：

```
2 → abc      3 → def      4 → ghi
5 → jkl      6 → mno      7 → pqrs
8 → tuv      9 → wxyz
```

给你一个数字串（只含 `2–9`），列出**它能拼出的所有字母组合**。

例如 `digits = "23"`：

- `2` 能挑出 a / b / c 三个字母之一
- `3` 能挑出 d / e / f 三个字母之一
- 把两位的选择两两组合，一共 `3 × 3 = 9` 种：

```
ad  ae  af
bd  be  bf
cd  ce  cf
```

题目要求**全部**列出来，顺序不限。

---

## 二、先识题型：这是"列出所有可能"的题

DP 是"算出最优"，这道题是"**列出所有**结果"——本质不一样。**列举类问题没有捷径，必须一个一个枚举**。

数学上，这就是个**笛卡尔积**：

> "23" 的所有组合 = `{a, b, c} × {d, e, f}` = 9 个串

> "234" 的所有组合 = `{a,b,c} × {d,e,f} × {g,h,i}` = 27 个串

笛卡尔积怎么用代码"算"出来？**嵌套循环**：

```python
for c1 in 'abc':
    for c2 in 'def':
        ans.append(c1 + c2)
```

两位数字写两层 for 当然行，但题目说 `digits.length` 最大 4，最少 1——**位数不固定**。总不能写四套代码分别对应 1、2、3、4 层 for 循环。

需要一种**循环层数可变**的写法。这就是**递归**最自然的用武之地。

---

## 三、把"嵌套循环"变成"递归"

写法的关键转换：

```
两层 for：
    for c1 in 'abc':          ←  第 0 位选一个字母
        for c2 in 'def':      ←  第 1 位选一个字母
            收集 c1 + c2

递归：
    dfs(i):                   ←  当前要选第 i 位
        for ch in 第 i 位能选的字母:
            把 ch 加进 path
            dfs(i + 1)        ←  让下一位接着选
            把 ch 撤下来
        如果 i 已经超过末位:
            把整条 path 收集起来
```

把"层数"变成函数参数 `i`，每一层"一层 for"就分散到一次递归调用里。位数不固定的问题就消失了——递归到 `i == len(digits)` 自动停。

---

## 四、画一下递归树（以 `"23"` 为例）

```
                          dfs(0)  path = ""
                              │
              ┌───────────────┼───────────────┐
              选 a             选 b            选 c
              │                │                │
          dfs(1) "a"        dfs(1) "b"       dfs(1) "c"
              │                │                │
          ┌─┼─┐            ┌─┼─┐            ┌─┼─┐
         d  e  f           d  e  f           d  e  f
         │  │  │           │  │  │           │  │  │
       dfs(2) 都是"叶子"，触发"收集 path"
        ad ae af          bd be bf          cd ce cf
```

- 树的**深度** = `digits` 长度
- 每一**层**展开的分支数 = 当前数字对应的字母数（3 或 4）
- 触底（i == len(digits)）就是**叶子**，叶子上的 path 就是一个答案
- 整棵树的叶子数 = 答案总数 = 笛卡尔积大小

理解了这棵树，代码就只是"忠实地把树走一遍"。

---

## 五、关键细节：path 要"回溯"

递归到一个叶子后，我们要往**回退**去探索别的分支。例如走完左边那条 `a → d → ad`，要回去试 `a → e → ae`。回退的时候，`path` 里**不能**还留着上一次的字母——必须把它撤下来：

```python
path.append(ch)     # ① 选
dfs(i + 1)          # ② 往下走
path.pop()          # ③ 撤回（这就是"回溯"二字的含义）
```

这是回溯模板的精髓："**选 → 递归 → 撤回**" 三件套。少了第三步，path 就会越积越长、结果全错。

> **类比**：你在迷宫里探路，每往前一步就在地图上画个箭头。一条路走死了回头时，要把刚才画的最后一个箭头**擦掉**，不然别的路径会污染。

---

## 六、写成代码

```python
class Solution:
    def letterCombinations(self, digits: str) -> list[str]:
        # 边界：空串单独处理，否则会进入 dfs 然后在 i == 0 == len("") 时
        # 直接收集一个空 path，得到 [""]，但题目期望是 []
        if not digits:
            return []

        # 数字 → 字母的映射表
        m = {
            '2': 'abc', '3': 'def', '4': 'ghi', '5': 'jkl',
            '6': 'mno', '7': 'pqrs', '8': 'tuv', '9': 'wxyz',
        }

        ans: list[str] = []
        path: list[str] = []   # 用 list 而不是 str，append/pop 都是 O(1)

        def dfs(i: int) -> None:
            # i 走到末尾 → path 是一个完整组合
            if i == len(digits):
                ans.append(''.join(path))   # 把字符列表拼成字符串
                return
            # 遍历当前数字能选的所有字母
            for ch in m[digits[i]]:
                path.append(ch)   # ① 选
                dfs(i + 1)        # ② 递归处理下一位
                path.pop()        # ③ 撤回（回溯）

        dfs(0)
        return ans
```

---

## 七、复杂度

- **时间** `O(4ⁿ · n)`：叶子数最多 `4ⁿ`（每位最多 4 个字母，n = digits 长度），每条叶子还要 `''.join` 一次（O(n)）
- **空间** `O(n)`：递归栈深度 = n；`path` 列表也是 O(n)。**结果集不算**

实际题目 `n ≤ 4`，所以最多 `4⁴ = 256` 个答案，绝对不会超时。

---

## 八、容易踩的坑

1. **空输入返回 `[]` 而不是 `[""]`**：题目要的是空数组。不特判会得到一个含空串的列表。
2. **path 用 list 比 str 高效**：每次 `path + ch` 都新建字符串（不可变），改用 `list.append` + `''.join` 摊销下来快很多。
3. **不要在 dfs 外用 `path = []` 然后传参**：那样每次递归调用都把 path 整体复制一份，复杂度爆炸。让 path 是**闭包共享**的一个 list，靠 `append/pop` 维护状态。
4. **回溯三件套缺一不可**：`append → dfs → pop`，少了 `pop` 结果就乱。

---

## 九、一句话记忆

> **数字键盘 = 笛卡尔积 = 多层 for 循环 = 递归 dfs**。每层选一个字母、递归到底收集、回头时把字母撤掉。

---

## 十、回溯框架在哪里出现

回溯几乎是所有"枚举所有可能"问题的统一解法。本题学到的"选 → 递归 → 撤回"在下面这些题里**结构一模一样**，只是"每层在选什么"不同：

| 题号 | 名字 | 每层在选什么 |
|---|---|---|
| **46** | 全排列 | 选一个**还没用过**的数字（需要 visited 数组） |
| **78** | 子集 | 每个元素**选 / 不选**（也可以"枚举从 i 开始的下一个"） |
| **39** | 组合总和 | 从 candidates 里挑一个，**允许重复选自己** |
| **22** | 括号生成 | 每层选 `(` 或 `)`，加剪枝（左括号已用满 / 右括号比左多） |
| **79** | 单词搜索 | 在网格上从四个方向选一个走 |
| **131** | 分割回文串 | 选一个切分位置 |
| **51** | N 皇后 | 每行选一列，加列/对角线冲突剪枝 |

掌握了 17 的"选 / 递归 / 撤回"三件套，上面这些题的骨架你已经会了，剩下只是改"每层选什么"和"什么时候剪枝"。
