# 33. 搜索旋转排序数组 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/search-in-rotated-sorted-array/)

---

## 一、题目讲了什么

升序数组在某个位置**被旋转**了：

```
原始：    [0, 1, 2, 4, 5, 6, 7]
旋转后：  [4, 5, 6, 7, 0, 1, 2]      （从下标 3 处旋转）
```

数组**不重复**。在这种"半有序"数组里找 target，返回下标；找不到返回 -1。要求 **O(log n)**。

---

## 二、为什么还能二分

虽然整体不再有序，但**任取一个 mid**，把数组切成 `[lo, mid]` 和 `[mid, hi]` 两段——**至少有一段是完全升序的**：

```
[4, 5, 6, 7, 0, 1, 2]    mid 在 7：[4,5,6,7] 升序、[7,0,1,2] 不升
                          mid 在 1：[4,5,6,7,0,1] 不升、[1,2] 升序
```

判断哪段升序后，**看 target 是否在升序那段的范围内**：

- 在 → 在升序段里二分
- 不在 → 一定在另一段，继续二分

每步把搜索范围缩半，所以仍是 O(log n)。

---

## 三、怎么判"哪段升序"

很简单：**比较 `nums[lo]` 和 `nums[mid]`**。

- `nums[lo] <= nums[mid]`：**左段** `[lo, mid]` 升序（注意等号——mid == lo 时单点视为升序）
- 否则：**右段** `[mid, hi]` 升序

---

## 四、target 是否在升序段内

例如左段升序：

```
if nums[lo] <= target < nums[mid]:    # target 在左段范围内
    hi = mid - 1                       # 缩到左段继续
else:
    lo = mid + 1                       # 缩到右段
```

**等号位置很关键**：左端用 `<=`（含 lo），右端用 `<`（不含 mid，因为 mid 已检查过）。右段升序时镜像写。

---

## 五、写成代码

```python
class Solution:
    def search(self, nums: list[int], target: int) -> int:
        lo, hi = 0, len(nums) - 1
        while lo <= hi:
            mid = (lo + hi) // 2
            if nums[mid] == target:
                return mid
            # 关键判断：左半段 [lo..mid] 是否有序
            if nums[lo] <= nums[mid]:
                # 左半有序：看 target 是否落在 [nums[lo], nums[mid]) 这个有序范围
                if nums[lo] <= target < nums[mid]:
                    hi = mid - 1
                else:
                    lo = mid + 1
            else:
                # 左半无序 → 右半 [mid..hi] 一定有序
                # 看 target 是否落在 (nums[mid], nums[hi]] 这个范围
                if nums[mid] < target <= nums[hi]:
                    lo = mid + 1
                else:
                    hi = mid - 1
        return -1
```

---

## 六、复杂度

- **时间** `O(log n)`
- **空间** `O(1)`

---

## 七、容易踩的坑

1. **`nums[lo] <= nums[mid]` 用 `<=`**：mid == lo 时也算左段升序，否则会进错分支。
2. **target 边界等号位置**：左段 `[lo] <= target < [mid]`，右段 `(mid] < target <= [hi]`，写反就死循环或漏答案。
3. **如果有重复元素**（题目 81）就要先跳重复，本题保证不重复，可以放心比较。

---

## 八、一句话记忆

> **mid 把数组切两段，至少一段升序**；判 target 在不在升序段，缩到对应那段继续二分。
