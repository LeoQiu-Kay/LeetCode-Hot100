# 56. 合并区间 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/merge-intervals/)

---

## 一、题目讲了什么

区间数组，把重叠的区间合并成一个。

例：`[[1,3], [2,6], [8,10], [15,18]]` → `[[1,6], [8,10], [15,18]]`

`[1,3]` 和 `[2,6]` 重叠合成 `[1,6]`。

---

## 二、核心观察：按起点排序后，只需邻接判断

如果区间无序，要判**任意两个**是否重叠是 O(n²)。

**排序按起点**后：任何能合并的区间必然**相邻**（因为更晚出现的区间起点 ≥ 当前区间起点，只可能和当前的合，不可能和更早的不相邻的合）。

→ 排完序后，一遍扫描：若当前区间和**最后合并段**重叠 → 扩展；否则 → 开新段。

---

## 三、重叠判定

`[a, b]` 和 `[c, d]`（a ≤ c）重叠 ⟺ `c ≤ b`（即新起点 ≤ 旧终点）。

合并后：`[a, max(b, d)]`（终点取较大）。

注意端点**相等也算重叠**（`[1, 3]` 和 `[3, 5]` 合成 `[1, 5]`）——题目通常这样定义。

---

## 四、写成代码

```python
class Solution:
    def merge(self, intervals):
        intervals.sort(key=lambda x: x[0])
        res = []
        for s, e in intervals:
            if res and res[-1][1] >= s:    # 与最后一段重叠
                res[-1][1] = max(res[-1][1], e)
            else:
                res.append([s, e])
        return res
```

8 行解决。

---

## 五、复杂度

- **时间** `O(n log n)`：排序主导
- **空间** `O(n)`（输出）/ `O(log n)`（排序栈）

---

## 六、容易踩的坑

1. **必须排序**：否则邻接判断不成立。
2. **`res[-1][1] >= s` 用 `>=`**：端点相等算重叠（按题意）。
3. **合并后终点取 `max`**：不要只用新来那个的终点，可能比旧的还小。
4. **题目不要求"包含"判定**：完全包含的小区间（如 `[2, 4]` 在 `[1, 6]` 内）也按这套合并逻辑处理，自然包含进去。

---

## 七、一句话记忆

> **按起点排序后一趟扫**：重叠就扩展终点 max，不重叠就开新段。
