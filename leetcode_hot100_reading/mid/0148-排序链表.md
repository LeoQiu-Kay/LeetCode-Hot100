# 148. 排序链表 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/sort-list/)

---

## 一、题目讲了什么

把链表升序排序。要求 **O(n log n) 时间**，最好 **O(1) 额外空间**。

例：`4 → 2 → 1 → 3` → `1 → 2 → 3 → 4`

---

## 二、为什么不用 sort

把所有值塞 list、sort、再写回——O(n log n) 时间 + O(n) 空间。能过但不够"链表题"。

链表上排序的经典是**归并排序**：

- 链表归并不像数组那样需要临时缓冲（合并两条有序链表 = 题 21，O(1) 空间）
- 找中点 + 拆分用快慢指针 O(n)

整体 O(n log n) 时间 + 递归栈 O(log n)。

---

## 三、三步走：分 + 治 + 合

```
sortList(head):
    出口：空 / 单节点直接返回
    1. 找中点：快慢指针
    2. 切断：mid.next 之前断开
    3. 递归排好左右两半
    4. 合并：用题 21 的合并模板
```

---

## 四、找中点的细节

快慢指针找中点时，要让 slow 停在**前半段的末尾**（而不是后半段的开头），方便接下来切断 `slow.next = None`。

让 fast 从 `head.next` 开始（不是 head）：

```
slow, fast = head, head.next
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
# 退出时：slow 是前半段的末尾
mid = slow.next
slow.next = None     # 切断！
```

如果 fast 从 head 开始，偶数长度时 slow 会停在后中，切断会让左段比右段多 1，仍正确但稍微不平衡。

---

## 五、写成代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def sortList(self, head: ListNode | None) -> ListNode | None:
        # 出口：空或单节点，直接返回（已有序）
        if not head or not head.next:
            return head
        # 1. 快慢指针找中点 + 切断前半段
        # 这里 fast 从 head.next 开始，保证偶数长度时切在前中（slow 落在前半段末）
        slow, fast = head, head.next
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
        mid = slow.next     # 后半段起点
        slow.next = None    # 切断！否则前半段会一直串到尾
        # 2. 递归排好左右两半
        left = self.sortList(head)
        right = self.sortList(mid)
        # 3. 用 21 题合并模板把两条有序链表合起来
        return self._merge(left, right)

    def _merge(self, a: ListNode | None, b: ListNode | None) -> ListNode | None:
        dummy = ListNode()
        cur = dummy
        while a and b:
            if a.val <= b.val:
                cur.next, a = a, a.next
            else:
                cur.next, b = b, b.next
            cur = cur.next
        cur.next = a or b
        return dummy.next
```

---

## 六、复杂度

- **时间** `O(n log n)`：归并排序
- **空间** `O(log n)`：递归栈

想要严格 O(1) 空间用**自底向上**迭代归并（先 1 个一对合并、再 2 个一对、4、8 ……），代码更长，比赛常用。

---

## 七、容易踩的坑

1. **`slow.next = None` 必不可少**：不切断递归会死循环（左段一直串到尾）。
2. **fast 起点是 `head.next`**：让 slow 停在前半段末，方便切断。
3. **合并复用题 21 模板**：dummy + 双指针。

---

## 八、一句话记忆

> 链表归并：**快慢找中点 → 切断 → 递归排 → 合并（题 21）**。
