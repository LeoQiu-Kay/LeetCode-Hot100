# 189. 轮转数组 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/rotate-array/)

---

## 一、题目讲了什么

数组**原地**向右轮转 `k` 个位置。

例：`[1, 2, 3, 4, 5, 6, 7], k = 3` → `[5, 6, 7, 1, 2, 3, 4]`

后面 3 个移到前面，前面 4 个移到后面。

---

## 二、几种思路对比

| 方法 | 时间 | 空间 | 备注 |
|---|---|---|---|
| 用临时数组重排 | O(n) | O(n) | 简单但不"原地" |
| 每次右移 1 位，重复 k 次 | O(n × k) | O(1) | 慢 |
| **三次反转法** | O(n) | O(1) | 推荐 |

讲**三次反转法**——优雅又快。

---

## 三、三次反转法

观察："右移 k 位"的结果是 `[后 k 个] + [前 n-k 个]`。这正好可以用**三次反转**得到：

```
原始：       [1, 2, 3, 4, 5, 6, 7]
1. 全反：    [7, 6, 5, 4, 3, 2, 1]
2. 反前 k：   [5, 6, 7, 4, 3, 2, 1]
3. 反后 n-k：[5, 6, 7, 1, 2, 3, 4]    ← 答案
```

数学上：把原数组按"前 n-k | 后 k"分成两段 A | B。右移 k 位结果是 B | A。

反转整个数组得到 reverse(B) | reverse(A)。再分别反转两段得到 B | A，正是答案。

---

## 四、注意 k 可能 > n

`k %= n`。比如 n=7, k=10，等价于 k=3。不取模会让"反转前 k 个"区间错乱。

---

## 五、写成代码

```python
class Solution:
    def rotate(self, nums: list[int], k: int) -> None:
        n = len(nums)
        k %= n   # k > n 时取模（轮转 n 次回到原状）
        def reverse(l: int, r: int) -> None:
            # 反转 nums[l..r]（闭区间）
            while l < r:
                nums[l], nums[r] = nums[r], nums[l]
                l += 1
                r -= 1
        # 1. 全反
        reverse(0, n - 1)
        # 2. 反转前 k 个
        reverse(0, k - 1)
        # 3. 反转后 n-k 个
        reverse(k, n - 1)
```

---

## 六、复杂度

- **时间** `O(n)`：三次反转都是 O(n)
- **空间** `O(1)`

---

## 七、容易踩的坑

1. **必须 `k %= n`**：k > n 时不取模会让区间错乱。
2. **反转区间用闭区间 `[l, r]`**：`reverse(0, k-1)` 而不是 `reverse(0, k)`。
3. **三次反转的顺序**：全反 → 反前 k → 反后 n-k。换顺序会错。

---

## 八、一句话记忆

> **三次反转**：全反 → 反前 k → 反后 n-k。别忘 `k %= n`。
