# 24. 两两交换链表中的节点 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/swap-nodes-in-pairs/)

---

## 一、题目讲了什么

把链表里**每两个相邻节点**交换位置。**不允许只交换节点值**——必须真的改指针。

例：`1 → 2 → 3 → 4` → `2 → 1 → 4 → 3`

---

## 二、画指针重连

每一对 `a → b → 后续` 要变成 `b → a → 后续`。

需要哪些"手"？

- **prev**：这对的前驱（要它的 next 指向新头 b）
- **a**：原第一个
- **b**：原第二个

三条边重连（顺序很重要）：

```
prev.next = b      ← 让前驱指向 b（新对头）
a.next    = b.next ← a 接到"对外"的下个节点
b.next    = a      ← b 指向 a（完成对内交换）
```

做完，新的"对的尾巴"是 a。下次循环 `prev = a`。

---

## 三、dummy 头消边界

第一对没有自然的前驱节点 — 用 dummy 头。

```
dummy → 1 → 2 → 3 → 4
   ↑
  prev
```

循环条件：`prev.next` 和 `prev.next.next` 都存在（至少有 2 个节点能交换）。

---

## 四、走一遍 `1 → 2 → 3 → 4`

| 轮次 | prev | a | b | 操作后 |
|---|---|---|---|---|
| 1 | dummy | 1 | 2 | `dummy → 2 → 1 → 3 → 4` |
| 2 | 1（新尾） | 3 | 4 | `dummy → 2 → 1 → 4 → 3` |
| 3 | 3（新尾） | None | - | 退出 |

返回 `dummy.next`。

---

## 五、写成代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def swapPairs(self, head: ListNode | None) -> ListNode | None:
        # dummy 头，便于统一处理"第一对"
        dummy = ListNode(0, head)
        prev = dummy   # prev 始终是"将要交换的一对"的前一个节点
        # 至少要有两个节点才能交换
        while prev.next and prev.next.next:
            a = prev.next        # 这一对的第一个
            b = a.next           # 这一对的第二个
            # 三条边重连，画图最清楚：
            #   prev → b → a → (b 原本的下一个)
            a.next = b.next      # a 指向"对子的下下一个"
            b.next = a           # b 指向 a，完成内部交换
            prev.next = b        # 前驱接 b，让 b 成为这一对的新头
            # prev 跳到 a（也就是新一对的前驱），准备下一轮
            prev = a
        return dummy.next
```

---

## 六、复杂度

- **时间** `O(n)`：每个节点处理一次
- **空间** `O(1)`：几个指针

---

## 七、容易踩的坑

1. **三条边的赋值顺序**：先 `a.next = b.next`（救出"对外"的下个节点引用），再改 `b.next = a` 和 `prev.next = b`。顺序乱了会丢链。
2. **prev 移动到 a 而不是 b**：交换后 a 在后，下对前驱应该是 a。
3. **dummy 必不可少**：第一对的前驱用 dummy 抹平。

---

## 八、一句话记忆

> **dummy 起头、prev/a/b 三指针、三边重连、prev 跳到 a**。
