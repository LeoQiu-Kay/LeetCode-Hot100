# 74. 搜索二维矩阵 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/search-a-2d-matrix/)

---

## 一、题目讲了什么

`m × n` 矩阵满足两条性质：

1. 每行**升序**
2. 每行的第一个元素**大于上一行的最后一个元素**

判断 `target` 是否在矩阵里。

例（target=3）：

```
[1,  3,  5,  7]
[10, 11, 16, 20]      → True
[23, 30, 34, 60]
```

---

## 二、关键观察：本质是一维升序数组

把矩阵按行**首尾相连**展开：

```
[1, 3, 5, 7, 10, 11, 16, 20, 23, 30, 34, 60]
```

完全升序。所以这题可以**当一维数组做二分**。

下标映射：一维下标 `k` ↔ 二维位置 `(k // n, k % n)`。

---

## 三、二分模板（闭区间）

```
lo, hi = 0, m * n - 1
while lo <= hi:
    mid = (lo + hi) // 2
    val = matrix[mid // n][mid % n]
    if val == target:
        return True
    elif val < target:
        lo = mid + 1
    else:
        hi = mid - 1
return False
```

---

## 四、写成代码

```python
class Solution:
    def searchMatrix(self, matrix: list[list[int]], target: int) -> bool:
        # 空矩阵特判
        if not matrix or not matrix[0]:
            return False
        m, n = len(matrix), len(matrix[0])
        # 把矩阵当作长度 m*n 的一维升序数组，做闭区间二分
        lo, hi = 0, m * n - 1
        while lo <= hi:
            mid = (lo + hi) // 2
            # 把一维下标 mid 映射回二维坐标 (mid // n, mid % n)
            x = matrix[mid // n][mid % n]
            if x == target:
                return True
            elif x < target:
                # mid 太小，答案在右半段
                lo = mid + 1
            else:
                # mid 太大，答案在左半段
                hi = mid - 1
        return False
```

---

## 五、复杂度

- **时间** `O(log(m × n))`
- **空间** `O(1)`

---

## 六、74 vs 240 的区别

题目 240 看似类似，**性质不同**：

- 74：**每行首 > 上行末**（整体可看作一维升序）→ 用一维二分
- 240：每行升序、每列升序，但**不保证整体升序** → 从右上角 Z 字搜索（O(m+n)）

别把两题混了。

---

## 七、容易踩的坑

1. **二维下标转换**：行 = `mid // n`，列 = `mid % n`，**`n` 是列数**。
2. **空矩阵特判**：开头若 matrix 为空或 matrix[0] 为空，直接返回 False。
3. **闭区间二分模板**用 `<=`、`hi = mid - 1`；半开区间也行，但要一致。

---

## 八、一句话记忆

> 矩阵满足"行首递增、行内递增" → **当一维升序数组**做二分，下标映射 `(mid // n, mid % n)`。
