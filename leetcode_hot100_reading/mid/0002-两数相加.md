# 2. 两数相加 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/add-two-numbers/)

---

## 一、题目讲了什么

两条非空链表，每个节点存一个**数字（0–9）**，代表一个**反向存储**的非负整数：

```
342 → 链表 2 → 4 → 3   （个位在前）
465 → 链表 5 → 6 → 4
```

把它们相加，结果也用反向链表表示：`342 + 465 = 807` → `7 → 0 → 8`。

---

## 二、为什么"反序存储"反而方便

正常加法是**从低位到高位**做的（个位相加，进位往十位）。题目给的链表恰好是**个位在头**——刚好顺着指针往后走就是从低位到高位。

如果反过来（个位在尾），我们就得**先反转两条链表**才能加，多一步。

---

## 三、像竖式加法那样模拟

```
  3 4 2          2 → 4 → 3      l1 从头到尾
+ 4 6 5          5 → 6 → 4      l2
-------          ---------
  8 0 7          7 → 0 → 8      结果

按位相加：
  2 + 5 = 7，没进位，结果第 1 位 7
  4 + 6 = 10，进位 1，结果第 2 位 0
  3 + 4 + 1(进位) = 8，结果第 3 位 8
```

变量：

- 两个指针 `l1, l2` 同步往后走
- `carry` 记进位（初始 0）
- 新链表 dummy 头

每一步：

```
sum = (l1.val if l1 else 0) + (l2.val if l2 else 0) + carry
new_node.val = sum % 10
carry        = sum // 10
```

---

## 四、循环终止条件不是"两条都走完"

容易写错的地方：什么时候停？

❌ `while l1 and l2`：l1 走完时不停了，但 l2 可能还有；甚至最后一步还有 carry。

✓ `while l1 or l2 or carry`：只要**还有数位要加** 或 **还有进位要消化**，就继续。

例：`[9,9,9] + [1] = [0,0,0,1]`，最后那位 1 完全是 carry，不能漏。

---

## 五、写成代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def addTwoNumbers(self, l1: ListNode | None, l2: ListNode | None) -> ListNode | None:
        # dummy 哑节点，最后返回 dummy.next 即结果首节点
        dummy = ListNode()
        cur = dummy          # cur 是新链表的"尾巴"
        carry = 0            # 进位
        # 只要还有数位要处理、或还有进位没消化，就继续
        while l1 or l2 or carry:
            # 取当前位的值；走到 None 就当作 0（短链表补 0）
            a = l1.val if l1 else 0
            b = l2.val if l2 else 0
            # 当前位求和：两个数位 + 上一位进上来的进位
            s = a + b + carry
            # 新节点存个位（s 模 10）
            cur.next = ListNode(s % 10)
            cur = cur.next
            # 把整十位提取出来，作为下一位的进位（0 或 1）
            carry = s // 10
            # 两条链表各自前进一步（前提是还没到 None）
            if l1: l1 = l1.next
            if l2: l2 = l2.next
        return dummy.next
```

---

## 六、复杂度

- **时间** `O(max(m, n))`：最长链表长度决定循环次数
- **空间** `O(max(m, n))`：新建链表

---

## 七、容易踩的坑

1. **循环条件含 `carry`**：漏了就算不到最高位的进位。
2. **短链表用 0 补齐**：`l1.val if l1 else 0`。
3. **数字反序存储**：不用反转链表，顺着加就好。

---

## 八、一句话记忆

> **从头到尾按位加 + carry**，循环条件三个 or：`l1 or l2 or carry`。
