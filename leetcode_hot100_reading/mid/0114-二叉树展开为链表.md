# 114. 二叉树展开为链表 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/flatten-binary-tree-to-linked-list/)

---

## 一、题目讲了什么

把二叉树**就地**展开成一个**单链表**：

- 链表用 `right` 指针连接，`left` 都设为 `None`
- 链表顺序 = **前序遍历**顺序

例：

```
     1                  1
    / \                  \
   2   5         →        2
  / \   \                  \
 3   4   6                  3
                             \
                              4
                               \
                                5
                                 \
                                  6
```

---

## 二、几种思路

| 方法 | 思路 | 评价 |
|---|---|---|
| 前序遍历存数组再重建 | 简单但额外 O(n) 空间 | 不够"漂亮" |
| 递归右→左→根，维护 prev | O(h) 空间，原地 | 推荐 |
| 迭代版（找前驱节点） | O(1) 额外空间 | 最优雅 |

讲**第二种**：思路清晰。

---

## 三、逆向后序遍历 + prev 指针

把"前序"是 `根 → 左 → 右`。把整棵树展平后，链表是 `根 → 左子树 → 右子树`。

考虑递归方向：**反过来走**（**右 → 左 → 根**），维护一个全局变量 `prev`（已展平的链表头）。

- 递归到一个节点 node 时：右子树已展平、左子树已展平、prev 是它们俩合并后的头
- node 把自己放到链表头：`node.right = prev`, `node.left = None`
- 更新 `prev = node`

---

## 四、为什么右→左→根

我们希望节点处理时，**它的右子树和左子树都已经在 prev 链里展平了**——这样把 node 接到 prev 前面即可。后序的顺序"右、左、根"刚好满足这个先决条件。

---

## 五、写成代码

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def flatten(self, root: TreeNode | None) -> None:
        # prev 是"已处理段链表的头"，处理新节点时它的 right 直接指到 prev
        self.prev: TreeNode | None = None
        def dfs(node: TreeNode | None) -> None:
            if not node:
                return
            # 先递归处理右子树（逆向后序：右 → 左 → 根）
            dfs(node.right)
            # 再处理左子树
            dfs(node.left)
            # 现在处理当前节点：把它接到已展开链表的最前面
            node.right = self.prev
            node.left = None
            # 把当前节点设为新的链表头
            self.prev = node
        dfs(root)
```

---

## 六、复杂度

- **时间** `O(n)`：每个节点访问一次
- **空间** `O(h)`：递归栈

---

## 七、容易踩的坑

1. **递归顺序是右→左→根**：常见错写法是普通后序（左→右→根），结果完全不对。
2. **node.left 必须置 None**：题目要求展平后没有 left 指针。
3. **prev 是全局/闭包变量**：每次更新会影响后续递归。

---

## 八、一句话记忆

> **逆向后序（右→左→根）+ prev 累计**：每个节点接到已展平链表的前面。
