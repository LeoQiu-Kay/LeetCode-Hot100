# 98. 验证二叉搜索树 · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/validate-binary-search-tree/)

---

## 一、题目讲了什么

判断一棵二叉树是否是合法的**二叉搜索树**（BST）。

BST 定义：每个节点满足

> **左子树的所有值** < 节点值 < **右子树的所有值**

注意是"**所有**"，不是"直接子节点"。

---

## 二、最容易踩的坑：只比直接子节点不够

错误想法："只要每个节点比它的左孩子大、比右孩子小就行"。

反例：

```
        5
       / \
      4   6
         / \
        3   7
```

每个节点都比直接孩子合法（5>4、5<6、6>3、6<7），但**整棵树不是 BST**——3 在 5 的右子树里，却比 5 小，违反"右子树**所有值** > 5"。

---

## 三、思路 A：上下界递归

每个节点要满足"**所有祖先**的约束"——不只是父亲。

定义：

```
check(node, lo, hi):    # node 的值必须在开区间 (lo, hi) 内
    if node 为空: True
    if not (lo < node.val < hi): False
    return check(left, lo, node.val) ∧ check(right, node.val, hi)
```

递归到左子树时**上界收紧为 node.val**；右子树时**下界收紧为 node.val**。这样**祖先链上的所有约束**都传下来了。

入口 `(lo, hi) = (-∞, +∞)`。

---

## 四、思路 B：中序遍历必须严格递增

BST 的中序遍历是有序的。所以只要中序遍历过程中**前一个值 < 当前值**就行。

```
prev = -∞
中序遍历每个节点 v:
    if v <= prev: 不是 BST
    prev = v
```

代码也短。两种思路任选。

---

## 五、写成代码（上下界递归）

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def isValidBST(self, root: TreeNode | None) -> bool:
        # 子函数：验证以 node 为根的子树是否合法
        # lo / hi 是"允许的开区间"，初始是 (-inf, +inf)
        def check(node: TreeNode | None, lo: float, hi: float) -> bool:
            if not node:
                return True
            # 当前节点必须严格落在开区间内
            if not (lo < node.val < hi):
                return False
            # 递归左子树：上界收紧为 node.val（左子树所有值都要 < node.val）
            # 递归右子树：下界收紧为 node.val
            return check(node.left, lo, node.val) and check(node.right, node.val, hi)
        return check(root, float("-inf"), float("inf"))
```

---

## 六、复杂度

- **时间** `O(n)`：每个节点访问一次
- **空间** `O(h)`：递归栈

---

## 七、容易踩的坑

1. **必须用严格不等号 `<`**：BST 默认严格——相等也算违反。
2. **上下界要随递归传**：只比父亲漏祖先约束。
3. **`float('-inf')` / `float('inf')`** 初始上下界，比写 `None` 然后判空简洁。

---

## 八、一句话记忆

> 递归时带**祖先收紧的开区间** `(lo, hi)`；或者**中序遍历严格递增**。
