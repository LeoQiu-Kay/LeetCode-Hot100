# 142. 环形链表 II · 阅读版

> 难度：中等 · [LeetCode 链接](https://leetcode.cn/problems/linked-list-cycle-ii/)

---

## 一、题目讲了什么

链表里如果有环，**返回环的入口节点**；没环返回 None。要求 O(1) 空间。

例：

```
3 → 2 → 0 → -4
        ↑    │
        └────┘   入口是 2
```

---

## 二、141 + 数学结论

第一步还是 141 的快慢指针判环。重点是**判完环后，怎么找入口**？

数学结论：**相遇点和 head 同时各放一个慢指针，同速前进，再次相遇就是环入口**。

---

## 三、为什么这个结论成立（推导）

设：

- a：head 到环入口的距离
- b：环入口到相遇点的距离（顺着方向）
- c：相遇点到环入口的距离（继续顺着方向走完一圈）
- 环长 L = b + c

第一阶段相遇时：

- 慢指针走了 a + b
- 快指针走了 a + b + k × L（在环里多绕了 k 圈，k ≥ 1）
- 快是慢的两倍：`2(a + b) = a + b + k × L` → `a + b = k × L` → `a = k × L - b = (k-1) × L + c`

意思是：**从 head 走 a 步到入口** = **从相遇点走 c 步（再多绕几圈）到入口**。所以两个慢指针同速并行，恰好在入口相遇。

不会推导也没关系，**记住"head 出发 + 相遇点出发，同速齐进，相遇点 = 入口"** 就能写代码。

---

## 四、写成代码

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def detectCycle(self, head: ListNode | None) -> ListNode | None:
        # 第一阶段：标准 Floyd 龟兔判环
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow is fast:
                # 第二阶段：相遇后，新慢从 head 出发
                p = head
                # p 和 slow 同速前进，在环入口相遇（数学性质决定）
                while p is not slow:
                    p = p.next
                    slow = slow.next
                return p
        # fast 走到链尾说明无环
        return None
```

---

## 五、复杂度

- **时间** `O(n)`：第一阶段 + 第二阶段都是 O(n)
- **空间** `O(1)`

---

## 六、容易踩的坑

1. **第二阶段两个指针都走 1 步**——不是 1 步 vs 2 步。
2. **从 head 出发那个指针** 用 `is`（同对象）比较，不要用 `==`。
3. **没环时 fast 走到 None**：循环正常退出返回 None。

---

## 七、一句话记忆

> 判环用快慢；找入口用 **head 和相遇点同速齐进**，再次相遇即入口。
